# ข้อผิดพลาด Python ที่พบบ่อย

ข้อความ error เป็นเบาะแสที่ช่วยชี้จุดผิด ไม่ใช่คำตัดสิน อ่านบรรทัดท้ายของ traceback ก่อน แล้วเปิดไฟล์และบรรทัดที่แจ้ง

| ข้อความ | ความหมาย | วิธีตรวจและแก้ |
|---|---|---|
| `python is not recognized` | Windows หาโปรแกรม Python จาก PATH ไม่พบ | ลอง `py -3.12 --version`; ถ้าใช้ได้ให้เรียก `py -3.12 practice.py start` หรือเลือก Python interpreter ใน VS Code หากไม่มีทั้งคู่ให้ติดตั้ง Python จากแหล่งที่เชื่อถือได้ แล้วเปิด terminal ใหม่ |
| `can't open file ... practice.py` | terminal อยู่ผิดโฟลเดอร์ หรือชื่อไฟล์/พาธไม่ตรง | ใช้ `Get-Location`, `Get-ChildItem`, และ `Set-Location -LiteralPath "F:\python for poohx\python-quant-lab"` |
| `ModuleNotFoundError` | โมดูลที่ import หาไม่พบ หรือเลือก interpreter คนละตัว | ตรวจชื่อแพ็กเกจและ interpreter ก่อน ไลบรารีภายนอกต้องติดตั้งใน virtual environment ของโครงการ ไม่ใช่ Python ส่วนกลาง |
| `SyntaxError` | โครงสร้างคำสั่งไม่ถูกต้อง เช่น วงเล็บหรือเครื่องหมายคำพูดไม่ครบ | ดูตำแหน่ง `^` ที่ Python ชี้ ตรวจบรรทัดนั้นและบรรทัดก่อนหน้า |
| `IndentationError` | ระยะเยื้องไม่สม่ำเสมอ หรือบล็อกหลัง `if`, `for`, `def` ว่าง | ใช้การเยื้อง 4 ช่องให้สม่ำเสมอ ห้ามผสม tab กับ spaces และต้องมีคำสั่งอยู่ในบล็อก |
| `NameError` | ใช้ชื่อตัวแปรหรือฟังก์ชันที่ยังไม่ได้กำหนด หรือสะกดต่างกัน | เทียบตัวพิมพ์ใหญ่เล็กกับชื่อที่ประกาศ เช่น `price` กับ `Price` เป็นคนละชื่อ |
| `TypeError` | ใช้ชนิดข้อมูลไม่เข้ากับการดำเนินการ เช่น บวก `str` กับ `int` | ตรวจ `type(value)` และแปลงข้อมูลจาก `input()` ด้วย `int()` หรือ `float()` เมื่อเหมาะสม |
| `ValueError` | ชนิดข้อมูลพอใช้ได้ แต่ค่าข้างในแปลงไม่ได้ เช่น `int("abc")` | ตรวจรูปแบบก่อนแปลง หรือจับ exception ตามขอบเขตที่โจทย์กำหนด |
| `ZeroDivisionError` | ตัวหารมีค่าเป็นศูนย์ | นิยามกรณีนี้ก่อนคำนวณ เช่น คืน `None` หรือแจ้ง error ตามสัญญาของฟังก์ชัน |
| `AssertionError` หรือ grader แสดง `FAIL` | ค่าที่ได้ไม่ตรงกับผลตามข้อกำหนด หรือเงื่อนไขใน test ยังไม่ครอบคลุม | อ่าน input และ expected ของ test คิดผลด้วยมือ แล้วเทียบชนิดข้อมูลและขอบเขต อย่าปรับ expected เพื่อให้คำตอบผ่าน |
| ผลลัพธ์ไม่ตรงทั้งที่คำนวณถูก | ช่องว่าง บรรทัดใหม่ ลำดับรายการ หรือรูปแบบตัวเลขต่างกัน | เปรียบเทียบ output ตัวอักษรต่ออักษร ตรวจ `\n`, การปัดเศษ และว่าโจทย์ต้องคืนค่าหรือ `print()` |
| ภาษาไทยแสดงเป็นอักขระผิด | ไฟล์ไม่ได้อ่าน/เขียนเป็น UTF-8 หรือ terminal ใช้ encoding ต่างกัน | บันทึกไฟล์เป็น UTF-8; ใช้ `encoding="utf-8"` กับไฟล์; ใน PowerShell/VS Code ใช้ terminal รุ่นใหม่และตรวจว่าเปิดไฟล์ด้วย UTF-8 |

## เมื่อติดปัญหา dependency

ระดับ 1–10 รุ่นนี้ใช้ Python standard library และไม่ต้องติดตั้งแพ็กเกจเพื่อเริ่มเรียน หาก `import pandas` หรือไลบรารีเสริมไม่พบ ให้ตรวจว่าบทเรียนนั้นระบุ optional dependency หรือไม่ และเลือก interpreter ของ `.venv` ก่อน อย่าติดตั้งแพ็กเกจลง Python ส่วนกลางโดยไม่ตั้งใจ

## วิธีเขียนรายงานปัญหาที่แก้ได้เร็ว

ระบุคำสั่งที่รัน โฟลเดอร์ปัจจุบัน ข้อความ error เต็ม และ input ที่ทำให้เกิดปัญหา ลบข้อมูลส่วนตัวออกก่อนส่งตัวอย่าง หลีกเลี่ยงการส่งภาพเฉพาะส่วนที่ตัดบรรทัดสำคัญทิ้ง
