# แผนที่การเรียน Python Quant Lab

หลักสูตรมี 10 ระดับ ระดับละ 15 แบบฝึกหัด รหัส E015 เป็นการประเมินท้ายระดับ ใช้ความรู้จากข้อก่อนหน้า ผู้เรียนควรอ่านบทเรียนและลองเขียนด้วยตนเองก่อนเปิดเฉลย

| ระดับ | เรียนอะไรและทำไม | ตัวอย่างงานจริง | ต้องรู้อะไรก่อน | เมื่อจบแล้วทำอะไรได้ |
|---|---|---|---|---|
| 1. พื้นฐาน Python | คำสั่ง ตัวแปร ตัวเลข ข้อความ การรับ input และคำนวณ เพื่อสร้างโปรแกรมสั้นที่อ่านข้อมูลแล้วแสดงผล | ยอดซื้อ ส่วนลด ค่าเดินทาง และกำไรจำลอง | ไม่ต้องมีพื้นฐาน Python | เขียนสูตรง่าย ๆ รับข้อมูลและจัดรูปแบบผลลัพธ์ได้ |
| 2. เงื่อนไขและลูป | เปรียบเทียบค่า เลือกทางทำงาน และทำซ้ำ เพื่อเขียนกฎที่ใช้กับหลายกรณี | ตรวจสิทธิ์ส่งฟรี แจ้งเตือนงบ และนับรายการที่ผ่านเกณฑ์ | ระดับ 1 | แยกกรณีปกติ ขอบเขต และกรณีที่ต้องหยุดได้ |
| 3. โครงสร้างข้อมูล | เก็บหลายค่าใน list, tuple, set และ dict เพื่อแทนรายการและข้อมูลที่สัมพันธ์กัน | ตะกร้าสินค้า สต็อก สถิตินักเรียน และบันทึกรายการ | ระดับ 2 | เลือกชนิดข้อมูล ค้นหา วนอ่าน และสรุปข้อมูลพื้นฐานได้ |
| 4. ฟังก์ชันและโมดูล | แบ่งโปรแกรมเป็นส่วนที่เรียกใช้ซ้ำได้ แยก input, การคำนวณ และ output | คำนวณภาษี ค่าจัดส่ง เงินเดือน และค่าธรรมเนียม | ระดับ 3 | เขียนฟังก์ชันที่มีหน้าที่ชัด รับค่าและคืนผล พร้อมแยกไฟล์ได้ |
| 5. Python สำหรับงานจริง | อ่านและตรวจข้อมูลไฟล์ จัดการข้อผิดพลาด และทดสอบพฤติกรรม | นำเข้ารายการขาย ตรวจ CSV และสรุปรายจ่าย | ระดับ 4 | อ่าน CSV/JSON ตรวจข้อมูลเสีย เขียนรายงาน และใช้ unittest เบื้องต้นได้ |
| 6. วิเคราะห์ข้อมูล | ทำความสะอาด คัดกรอง และสรุปข้อมูลตามเวลา | รายงานยอดขาย ค่าใช้จ่าย และข้อมูล OHLCV สังเคราะห์ | ระดับ 5 | อธิบายขั้นตอนวิเคราะห์และสร้างตารางหรือกราฟได้ เมื่อเลือกติดตั้งไลบรารีเสริม |
| 7. คณิตศาสตร์และสถิติ | ทำความเข้าใจค่าเฉลี่ย การกระจาย ความน่าจะเป็น และความไม่แน่นอน | วิเคราะห์ผลทดลอง ยอดขาย และการกระจายผลตอบแทน | ระดับ 6 และเลขคณิตพื้นฐาน | คำนวณและอธิบายค่าเฉลี่ย ความแปรปรวน สหสัมพันธ์ และข้อจำกัดของตัวอย่างได้ |
| 8. การเงินและความเสี่ยง | คิดผลตอบแทนสุทธิหลังต้นทุน ประเมินขนาดสถานะและการขาดทุน | ตรวจค่า fee, slippage, drawdown และความเสี่ยงพอร์ตจำลอง | ระดับ 7 | คำนวณกำไรขาดทุนสุทธิ ความเสี่ยงต่อรายการ และตัวชี้วัดพอร์ตแบบจำลองได้ |
| 9. วิจัยเชิงปริมาณ | เปลี่ยนแนวคิดเป็นสมมติฐาน ตรวจข้อมูล และทดสอบนอกตัวอย่าง | เปรียบเทียบกลยุทธ์กับ benchmark และตรวจ look-ahead bias | ระดับ 8 | สร้างการทดลองที่ทำซ้ำได้ แยกข้อมูล train/test และรายงานข้อจำกัดได้ |
| 10. วิศวกรรมบอท paper | ประกอบข้อมูล สัญญาณ การจำลองคำสั่ง บัญชีความเสี่ยง และการบันทึก | replay ข้อมูลออฟไลน์และจำลองพอร์ตโดยไม่ส่งคำสั่งจริง | ระดับ 9 และความเข้าใจ CSV/ฟังก์ชัน | สร้างระบบ paper trading ออฟไลน์ที่ทำซ้ำได้ ตรวจสอบได้ และหยุดเมื่อข้อมูลหรือความเสี่ยงผิดปกติ |

## วิธีผ่านระดับ

ทำแบบฝึกหัดตามลำดับแล้วทำ E015 โดยไม่เปิด hint หรือ solution ของ assessment variant ที่กำลังทำ ระบบจะเก็บผลตรวจแยกจากประวัติการเปิดคำใบ้และเฉลย การผ่าน assessment เป็นหลักฐานว่าคำตอบตรงกับกรณีทดสอบที่กำหนด ไม่ใช่ใบรับรองว่าจำเนื้อหาได้ทั้งหมด ผู้เรียนควรอธิบายวิธีคิดและลองปรับ input เพิ่มเองด้วย

ทุกระดับมีบทเรียนพิมพ์ตามและแบบประเมิน A/B ใน E015 แล้ว Levels 2–10 มีงานห้ารูปแบบใน E001–E005 และโจทย์ E006–E014 ที่ระบุ input/output, กรณีขอบ, คำใบ้ และคำอธิบายเฉพาะข้อ ชุดทดสอบของข้อเหล่านี้แยกจากตัวอย่างใน curriculum และตรวจด้วย reference solution; การผ่านชุดทดสอบบอกความถูกต้องเฉพาะกรณีที่กำหนด ไม่รับรองความเข้าใจหรือผลตอบแทนจากกลยุทธ์
