# L09-E009 — ตรวจการรั่วไหลของข้อมูล

**บริบทวิจัย:** ผู้ตรวจ backtest flag feature timestamp ที่ไม่มาก่อนเวลาใช้ตัดสินใจ

**สัญญา:** คืน True หาก feature_time >= decision_time อย่างน้อยหนึ่งคู่

**ขั้นตอน:** ตรวจทุกคู่เวลา; feature ต้องมาก่อน decision อย่างเคร่งครัด

**กรณีขอบ:** ความเท่ากันถูก flag; รายการว่างหรือ feature เก่าทั้งหมดคืน False

backtest ไม่ยืนยันว่ามี edge จริง
