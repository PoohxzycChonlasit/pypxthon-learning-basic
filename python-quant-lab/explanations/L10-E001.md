# L10-E001 — ตรวจคำสั่ง paper

**บริบท:** ระบบ paper bot รับคำสั่ง buy/sell ที่ราคาและจำนวนถูกต้องและผ่านวงเงินเงินสด

**สัญญา:** True เมื่อ event เป็น dict, side ถูกต้อง, quantity/price finite และบวก, cash finite ไม่ติดลบ; buy ต้องไม่เกิน cash

**ขั้นตอน:** ตรวจชนิด event; ตรวจ side; ตรวจตัวเลขและ isfinite; เช็ก notional เทียบ cash เฉพาะ buy

**กรณีขอบ:** ขายไม่ลด cash ล่วงหน้า; bool ไม่ถือเป็นจำนวนเงิน; ไม่มีการส่ง order จริง

โครงการนี้จำลอง offline paper เท่านั้น ไม่มี live order
