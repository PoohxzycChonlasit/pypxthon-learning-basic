# L07-E003 — ส่วนเบี่ยงเบนมาตรฐานประชากร

ฟังก์ชัน `population_standard_deviation` รับ `values` แล้วคืนค่าตามกติกาในโจทย์

อัลกอริทึม: `import math; return math.sqrt(sum((x-sum(values)/len(values))**2 for x in values)/len(values)) if values else 0`

Python จะคำนวณ expression ทางขวาของ `return` แล้วส่งค่านั้นกลับไปยังผู้เรียก การใช้ `return` ทำให้ตรวจค่าได้โดยไม่ต้องอ่าน stdout

ข้อผิดพลาดที่พบบ่อย: ลืมกรณีข้อมูลว่างหรือหารด้วยศูนย์; สับสนระหว่างการคืนค่ากับการแสดงผล

ตัวอย่างผลลัพธ์: `1.118033988749895`
