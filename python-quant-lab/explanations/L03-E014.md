# L03-E014 — คลี่รายการซ้อน

**ผู้ใช้และปัญหา:** ระบบนำเข้ารายงานคลี่แถวข้อมูลย่อยเป็นลำดับเดียวก่อนประมวลผล

**สัญญา:** ต่อสมาชิกในแต่ละ row ตามลำดับ; คลี่เพียงหนึ่งชั้น

**แนวทาง:** วน row ด้านนอกและ value ด้านใน; เพิ่ม value ทีละตัว

**กรณีขอบ:** แถวว่างไม่มีผล; input ว่างคืน []; ไม่ทำ recursive flatten

**ตรวจด้วยตัวอย่าง:** flatten_nested_rows([1, 2], [3], []) ให้ผล [1, 2, 3]
