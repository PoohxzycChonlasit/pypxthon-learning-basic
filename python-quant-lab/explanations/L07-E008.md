# L07-E008 — ความกว้างของพิสัย

**ผู้ใช้และปัญหา:** เจ้าหน้าที่ตรวจช่วงห่างระหว่างค่าต่ำสุดกับค่าสูงสุดของผลวัด

**สัญญา input/output:** คืน max(values)-min(values)

**คิดทีละขั้น:** หา max และ min แล้วลบค่าต่ำสุดออกจากค่าสูงสุด

**กรณีขอบ:** list ว่างคืน 0; ค่าซ้ำทั้งหมดให้ช่วง 0

**ตัวอย่าง:** range_width([2, 10, 5],) ให้ผล 8

ข้อควรระวัง: list ว่างคืน 0; ค่าซ้ำทั้งหมดให้ช่วง 0
