# L02-E012 — นับช่วงที่เพิ่มขึ้น

**ผู้ใช้และปัญหา:** ทีมรายงานนับกี่ครั้งที่ยอดวันนี้สูงกว่ายอดวันก่อน

**สัญญา:** นับคู่ติดกันที่ current > previous; นับจำนวนช่วงเพิ่ม ไม่ใช่ความยาวของช่วง

**แนวทาง:** สร้างคู่ติดกัน; เพิ่มตัวนับเฉพาะเมื่อค่าที่สองมากกว่าค่าแรก

**กรณีขอบ:** ค่าซ้ำไม่นับ; มีน้อยกว่าสองค่าคืน 0

**ตรวจด้วยตัวอย่าง:** count_consecutive_rises([1, 2, 2, 4],) ให้ผล 2
