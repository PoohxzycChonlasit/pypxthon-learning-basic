# L08-E012 — สัดส่วนเงินที่เปิดรับความเสี่ยง

**ผู้ใช้:** นักวิเคราะห์วัด notional exposure เทียบกับ equity ปัจจุบัน

**สัญญา:** fraction = price*quantity/equity; คืน None เมื่อ equity เป็น 0

**แนวทาง:** คูณ price กับ quantity; ตรวจ equity; หารด้วย equity

**กรณีขอบ:** fraction เกิน 1 หมายถึง exposure มากกว่า equity; ไม่จำกัดอัตโนมัติ
