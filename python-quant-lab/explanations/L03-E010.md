# L03-E010 — ลบค่าซ้ำโดยคงลำดับ

**ผู้ใช้และปัญหา:** เจ้าหน้าที่ทำความสะอาดรายชื่อลูกค้าตัดชื่อซ้ำโดยเก็บครั้งแรก

**สัญญา:** คืน list ที่มี occurrence แรกของแต่ละค่าเรียงตาม input

**แนวทาง:** เก็บค่าที่เคยเห็นและเพิ่มเข้าผลลัพธ์เฉพาะครั้งแรก

**กรณีขอบ:** list ว่างคืน []; สมาชิกต้อง hashable

**ตรวจด้วยตัวอย่าง:** remove_duplicate_preserving_order(['A', 'B', 'A', 'C', 'B'],) ให้ผล ['A', 'B', 'C']
