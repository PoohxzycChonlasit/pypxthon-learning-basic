# L05-E007 — จัดรูปแบบบรรทัดบันทึก

**ผู้ใช้และปัญหา:** โปรแกรมนำเข้าบันทึกงานทำความสะอาดช่องว่างรอบแต่ละคอลัมน์ก่อนเขียนไฟล์รายงาน

**สัญญา input/output:** แยกด้วย comma; strip แต่ละ field; ต่อกลับด้วย comma โดยคงคอลัมน์ว่าง

**คิดทีละขั้น:** วนทุก field ที่ split; strip; join ด้วย comma

**กรณีขอบ:** ไม่ลบ field ว่างและไม่แยก comma ที่อยู่ใน quoted field; รูปแบบนี้ไม่รองรับ quoted CSV

**ตัวอย่าง:** format_log_row(' A, B ,C ',) ให้ผล 'A,B,C'

ข้อควรระวัง: ไม่ลบ field ว่างและไม่แยก comma ที่อยู่ใน quoted field; รูปแบบนี้ไม่รองรับ quoted CSV
