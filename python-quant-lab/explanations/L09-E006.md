# L09-E006 — แบ่งข้อมูลตามเวลา

**บริบทวิจัย:** นักวิจัยแบ่งข้อมูลเรียงตามเวลาเป็น train ช่วงแรก 2/3 และ test ที่เหลือ

**สัญญา:** จุดตัด floor(2*n/3); คืน tuple (train,test) โดยไม่ shuffle

**ขั้นตอน:** ใช้ len(values)*2//3 เป็น split index แล้ว slice สองช่วง

**กรณีขอบ:** รักษาลำดับ; test อาจว่างในชุดเล็ก

backtest ไม่ยืนยันว่ามี edge จริง
