# L03-E008 — แบ่งค่าบวกและค่าที่เหลือ

**ผู้ใช้และปัญหา:** ผู้ดูแลแบบสำรวจแยกคะแนนบวกจากศูนย์และค่าติดลบ

**สัญญา:** คืน tuple (positives, rest); ค่า > 0 อยู่กลุ่มแรก; ค่า <= 0 อยู่กลุ่มสอง

**แนวทาง:** คัดสมาชิกด้วยเงื่อนไข > 0 และ <= 0 แยกกัน

**กรณีขอบ:** ศูนย์อยู่ rest; ค่าซ้ำและลำดับต้องคงเดิม

**ตรวจด้วยตัวอย่าง:** split_into_positives_and_rest([2, 0, -1, 2],) ให้ผล ([2, 2], [0, -1])

ข้อควรระวัง: ศูนย์อยู่ rest; ค่าซ้ำและลำดับต้องคงเดิม
