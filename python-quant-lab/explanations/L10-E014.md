# L10-E014 — บันทึกเหตุการณ์แบบมีโครงสร้าง

**บริบท:** ระบบ log เก็บข้อมูลสำคัญของ event พร้อมป้าย paper_only

**สัญญา:** คืน dict event=id, side=side, paper_only=True

**ขั้นตอน:** คัด id และ side; เพิ่ม paper_only=True เสมอ

**กรณีขอบ:** field ที่หายคืน None; paper_only ต้อง boolean True

โครงการนี้จำลอง offline paper เท่านั้น ไม่มี live order
