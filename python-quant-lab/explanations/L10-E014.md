# L10-E014 — บันทึกเหตุการณ์แบบมีโครงสร้าง

ฟังก์ชัน `structured_event_log` รับ `event` แล้วคืนค่าตามกติกาในโจทย์

อัลกอริทึม: `return {'event':event.get('id'),'side':event.get('side'),'paper_only':True}`

Python จะคำนวณ expression ทางขวาของ `return` แล้วส่งค่านั้นกลับไปยังผู้เรียก การใช้ `return` ทำให้ตรวจค่าได้โดยไม่ต้องอ่าน stdout

ข้อผิดพลาดที่พบบ่อย: ลืมกรณีข้อมูลว่างหรือหารด้วยศูนย์; สับสนระหว่างการคืนค่ากับการแสดงผล

ตัวอย่างผลลัพธ์: `{'event': 'a', 'side': 'buy', 'paper_only': True}`
