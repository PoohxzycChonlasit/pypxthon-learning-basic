# L01-E009 — เปอร์เซ็นต์การเปลี่ยนแปลง

ฟังก์ชัน `percentage_change` รับ `a, b` แล้วคืนค่าตามกติกาในโจทย์

อัลกอริทึม: `return (b-a)/a*100 if a else None`

Python จะคำนวณ expression ทางขวาของ `return` แล้วส่งค่านั้นกลับไปยังผู้เรียก การใช้ `return` ทำให้ตรวจค่าได้โดยไม่ต้องอ่าน stdout

ข้อผิดพลาดที่พบบ่อย: ลืมกรณีข้อมูลว่างหรือหารด้วยศูนย์; สับสนระหว่างการคืนค่ากับการแสดงผล

ตัวอย่างผลลัพธ์: `-80.0`
