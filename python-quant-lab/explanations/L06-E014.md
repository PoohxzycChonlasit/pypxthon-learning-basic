# L06-E014 — จับคู่ลำดับกับค่า

**ผู้ใช้และปัญหา:** นักวิเคราะห์เก็บหมายเลขแถวคู่กับค่าที่โหลดจากไฟล์

**สัญญา input/output:** คืน list ของ (index,value) โดยเริ่ม index ที่ 0 และเก็บ None ตามจริง

**คิดทีละขั้น:** ใช้ enumerate เพื่อสร้างคู่ index/value

**กรณีขอบ:** ข้อมูลว่างคืน []; ไม่กรอง missing

**ตัวอย่าง:** pair_indexes_and_values([10, 20],) ให้ผล [(0, 10), (1, 20)]

ข้อควรระวัง: ข้อมูลว่างคืน []; ไม่กรอง missing
