# L07-E006 — อัตราค่าบวก

**ผู้ใช้และปัญหา:** นักวิเคราะห์คำนวณสัดส่วนผลทดลองที่เป็นบวก

**สัญญา input/output:** คืนจำนวนค่าบวกหารด้วยจำนวนการทดลองทั้งหมด; zero และค่าลบยังอยู่ในตัวหาร

**คิดทีละขั้น:** นับ x>0; หารด้วย len(values)

**กรณีขอบ:** ข้อมูลว่างคืน None; ผลลัพธ์อยู่ระหว่าง 0 ถึง 1

**ตัวอย่าง:** positive_rate([1, -1, 2, 0],) ให้ผล 0.5

ข้อควรระวัง: ข้อมูลว่างคืน None; ผลลัพธ์อยู่ระหว่าง 0 ถึง 1
