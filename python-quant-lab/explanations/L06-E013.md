# L06-E013 — ค่าสูงสุดเคลื่อนที่

**ผู้ใช้และปัญหา:** ทีมสังเกตการณ์คำนวณค่าสูงสุดในหน้าต่างสองแถวที่เลื่อนไปทีละแถว

**สัญญา input/output:** คืน max ของทุกคู่ติดกันที่ทั้งสองค่าไม่ใช่ None; ข้ามคู่ที่มี missing

**คิดทีละขั้น:** จับคู่ adjacent values; กรองคู่ที่มี None; เพิ่ม max ของคู่ที่เหลือ

**กรณีขอบ:** ใช้หน้าต่างกว้าง 2; ข้อมูลน้อยกว่าสองค่าคืน []

**ตัวอย่าง:** rolling_maximum([1, 4, 2, 5],) ให้ผล [4, 4, 5]

ข้อควรระวัง: ใช้หน้าต่างกว้าง 2; ข้อมูลน้อยกว่าสองค่าคืน []
