# L05-E009 — แยกคู่กุญแจและค่า

ฟังก์ชัน `parse_key_value` รับ `text` แล้วคืนค่าตามกติกาในโจทย์

อัลกอริทึม: `return dict(part.split('=',1) for part in text.split(';') if '=' in part)`

Python จะคำนวณ expression ทางขวาของ `return` แล้วส่งค่านั้นกลับไปยังผู้เรียก การใช้ `return` ทำให้ตรวจค่าได้โดยไม่ต้องอ่าน stdout
