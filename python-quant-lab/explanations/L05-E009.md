# L05-E009 — แยกคู่กุญแจและค่า

**ผู้ใช้และปัญหา:** สคริปต์นำเข้าอ่านการตั้งค่ารูปแบบ key=value คั่นด้วย semicolon

**สัญญา input/output:** แปลงคู่ key=value เป็น dict; strip key/value; ถ้าซ้ำให้คู่หลังสุดชนะ; ข้ามส่วนที่ไม่มี =

**คิดทีละขั้น:** วนส่วนที่แบ่งด้วย semicolon; แบ่งแต่ละส่วนด้วย = หนึ่งครั้ง; strip และกำหนดค่าใน dict

**กรณีขอบ:** value อาจมีเครื่องหมาย = ภายใน; split ที่เครื่องหมายแรกเท่านั้น

**ตัวอย่าง:** parse_key_value(' mode = paper ; fee=0.1=extra;invalid;mode=offline ',) ให้ผล {'mode': 'offline', 'fee': '0.1=extra'}

ข้อควรระวัง: value อาจมีเครื่องหมาย = ภายใน; split ที่เครื่องหมายแรกเท่านั้น
