# L02-E015 — ประเมินเงื่อนไขและลูป

ฟังก์ชัน `final_loop_assessment` รับ `values` แล้วคืนค่าตามกติกาในโจทย์

อัลกอริทึม: `return {'count':len(values),'positive':sum(x>0 for x in values),'net':sum(values)}`

Python จะคำนวณ expression ทางขวาของ `return` แล้วส่งค่านั้นกลับไปยังผู้เรียก การใช้ `return` ทำให้ตรวจค่าได้โดยไม่ต้องอ่าน stdout

ข้อผิดพลาดที่พบบ่อย: ลืมกรณีข้อมูลว่างหรือหารด้วยศูนย์; สับสนระหว่างการคืนค่ากับการแสดงผล

ตัวอย่างผลลัพธ์: `{'count': 4, 'positive': 2, 'net': 2}`
