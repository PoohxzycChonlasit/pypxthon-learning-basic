# L03-E011 — ค่าเฉลี่ยเคลื่อนที่สองจุด

**ผู้ใช้และปัญหา:** นักวิเคราะห์ทำค่าเฉลี่ยของแต่ละคู่วันติดกันเพื่อ smoothing

**สัญญา:** คืนค่า (a+b)/2 ของทุกคู่ติดกัน; หน้าต่างเลื่อนทีละหนึ่ง

**แนวทาง:** จับคู่ list กับ list ที่เริ่ม index 1; บวกแล้วหารสอง

**กรณีขอบ:** น้อยกว่าสองค่าให้คืน []; ผลลัพธ์ยอมเป็น float

**ตรวจด้วยตัวอย่าง:** two_item_moving_averages([2, 4, 8],) ให้ผล [3.0, 6.0]
