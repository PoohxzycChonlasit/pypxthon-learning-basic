# L08-E014 — จำนวนหน่วยตามระยะขาดทุน

**ผู้ใช้:** นักวิจัยกำหนดจำนวนหน่วยจาก risk budget และระยะขาดทุนต่อหน่วย

**สัญญา:** quantity = risk_budget/abs(entry-stop); ถ้าระยะเป็น 0 คืน 0

**แนวทาง:** ใช้ระยะสัมบูรณ์; ตรวจศูนย์; หาร budget ด้วยระยะ

**กรณีขอบ:** risk budget ไม่ติดลบ; quantity ที่คืนไม่ติดลบ
