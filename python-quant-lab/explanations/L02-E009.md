# L02-E009 — สร้างผลรวมสะสม

**ผู้ใช้และปัญหา:** เจ้าหน้าที่บัญชีสร้างยอดสะสมหลังอ่านรายการค่าใช้จ่ายแต่ละบรรทัด

**สัญญา:** คืน list ซึ่งค่าตำแหน่ง i คือผลรวมตั้งแต่รายการแรกถึง i

**แนวทาง:** เริ่มยอดสะสมที่ 0; บวกจำนวนเงินแต่ละบรรทัด; บันทึกยอดหลังบวก

**กรณีขอบ:** list ว่างคืน []; รวมค่าลบตามจริง

**ตรวจด้วยตัวอย่าง:** build_running_totals([3, 4, -2],) ให้ผล [3, 7, 5]
