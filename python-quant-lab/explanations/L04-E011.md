# L04-E011 — ประกอบการคูณและบวก

**ผู้ใช้และปัญหา:** ทีมบัญชีปรับยอดด้วยการคูณสองก่อนบวกค่าชดเชย

**สัญญา:** คืน value*2 + offset; ทำการคูณก่อนการบวก

**แนวทาง:** คูณพารามิเตอร์แรกด้วย 2 แล้วบวกพารามิเตอร์ที่สอง

**กรณีขอบ:** offset ติดลบใช้ลดผลลัพธ์ได้

**ตรวจด้วยตัวอย่าง:** compose_scale_and_offset(3, 4) ให้ผล 10

ข้อควรระวัง: offset ติดลบใช้ลดผลลัพธ์ได้
