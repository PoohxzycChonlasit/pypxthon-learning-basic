# L09-E015 — ตัดสินใจจากงานวิจัย

ฟังก์ชัน `final_research_decision` รับ `values` แล้วคืนค่าตามกติกาในโจทย์

อัลกอริทึม: `return {'observations':len(values),'mean':sum(values)/len(values) if values else None,'decision':'evaluate out of sample' if len(values)>=3 else 'insufficient data'}`

Python จะคำนวณ expression ทางขวาของ `return` แล้วส่งค่านั้นกลับไปยังผู้เรียก การใช้ `return` ทำให้ตรวจค่าได้โดยไม่ต้องอ่าน stdout

ข้อผิดพลาดที่พบบ่อย: ลืมกรณีข้อมูลว่างหรือหารด้วยศูนย์; สับสนระหว่างการคืนค่ากับการแสดงผล

ตัวอย่างผลลัพธ์: `{'observations': 5, 'mean': 105.2, 'decision': 'evaluate out of sample'}`
