# L05-E006 — แปลงจำนวนอย่างปลอดภัย

**ผู้ใช้และปัญหา:** เจ้าหน้าที่บัญชีอ่านบรรทัด CSV รูปแบบ invoice_id,amount เพื่อดึงยอดเงิน

**สัญญา input/output:** คืน float ของ field ที่สองเมื่อมีสอง field และแปลงได้; มิฉะนั้นคืน None

**คิดทีละขั้น:** แยก comma; ตรวจจำนวน field; แปลง field ที่สองใน try/except ValueError

**กรณีขอบ:** ตัดช่องว่างรอบยอดก่อนแปลง; input เสียต้องไม่ทำให้โปรแกรมล้ม

**ตัวอย่าง:** safe_parse_amount('INV-1,12.50',) ให้ผล 12.5
