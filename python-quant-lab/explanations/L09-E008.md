# L09-E008 — หักต้นทุนไปกลับ

**บริบทวิจัย:** นักวิจัยหัก round-trip cost อัตราเดียวกันออกจาก gross return ทุกช่วง

**สัญญา:** รับ gross_returns และ round_trip_cost; คืน r-cost ต่อสมาชิก

**ขั้นตอน:** ลบต้นทุนเดียวกันออกจากทุก return

**กรณีขอบ:** cost เป็นสัดส่วนไม่ใช่เงินสด; cost=0 ใช้ได้

backtest ไม่ยืนยันว่ามี edge จริง
