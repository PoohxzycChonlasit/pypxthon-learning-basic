# L08-E001 — กำไรขั้นต้นสถานะซื้อ

**ผู้ใช้:** ผู้ดูแล paper portfolio สรุปกำไรขั้นต้นของสถานะซื้อก่อนหักค่าธรรมเนียม

**สัญญา:** gross profit = (exit-entry)*quantity; quantity ไม่ติดลบ

**แนวทาง:** คำนวณการเปลี่ยนแปลงต่อหน่วยแล้วคูณจำนวนหน่วย

**กรณีขอบ:** ราคาออกเท่าราคาเข้าให้กำไร 0

ทำงานใน paper mode เท่านั้น
