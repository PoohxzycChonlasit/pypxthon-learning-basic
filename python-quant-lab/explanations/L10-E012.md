# L10-E012 — หยุดเมื่อขาดทุนรายวันถึงขีดจำกัด

**บริบท:** risk gate หยุดจำลองเมื่อ day PnL ขาดทุนถึง loss limit

**สัญญา:** คืน True เมื่อ day_pnl <= -abs(loss_limit)

**ขั้นตอน:** แปลง limit เป็นขนาดบวก; เทียบ PnL กับค่าลบของ limit

**กรณีขอบ:** ขาดทุนเท่าขีดจำกัดต้องหยุด; day_pnl=0 และ limit=0 ก็หยุด
