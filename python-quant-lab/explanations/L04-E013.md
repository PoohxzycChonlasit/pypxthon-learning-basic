# L04-E013 — จำกัดผลตอบแทนติดลบ

**ผู้ใช้และปัญหา:** ผู้ดูแลความเสี่ยงจำกัด return ไว้ระหว่าง -100% กับเพดานที่กำหนด

**สัญญา:** รับ candidate x และ upper cap y; คืนค่าที่ clamp อยู่ในช่วง [-1,y]

**แนวทาง:** ใช้ min กันค่าเกินเพดาน แล้วใช้ max กันค่าต่ำกว่า -1

**กรณีขอบ:** สมมติ y >= -1; ค่าภายในช่วงไม่เปลี่ยน

**ตรวจด้วยตัวอย่าง:** clamp_signed_return(0.5, 0.2) ให้ผล 0.2

ข้อควรระวัง: สมมติ y >= -1; ค่าภายในช่วงไม่เปลี่ยน
