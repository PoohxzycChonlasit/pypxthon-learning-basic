# L06-E006 — นับค่าที่หายไป

**ผู้ใช้และปัญหา:** นักวิเคราะห์คุณภาพข้อมูลนับช่องที่ไม่มีค่าจากการนำเข้า CSV

**สัญญา input/output:** คืนจำนวนสมาชิกที่เป็น None โดยไม่ถือ 0 หรือ chuỗi ว่างเป็น missing

**คิดทีละขั้น:** วนค่าและนับเฉพาะค่า is None

**กรณีขอบ:** list ว่างคืน 0; zero เป็นข้อมูลจริง

**ตัวอย่าง:** count_missing_values([1, None, 0, None],) ให้ผล 2

ข้อควรระวัง: list ว่างคืน 0; zero เป็นข้อมูลจริง
