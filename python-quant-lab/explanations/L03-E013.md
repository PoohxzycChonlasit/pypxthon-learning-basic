# L03-E013 — เพิ่มผลรวมท้ายรายการ

**ผู้ใช้และปัญหา:** ร้านค้าต่อผลรวมท้ายรายการราคาเพื่อสร้างสรุปใบเสร็จ

**สัญญา:** คืน list ใหม่ที่คงสมาชิกเดิมและเพิ่ม sum(items) เป็นสมาชิกสุดท้าย

**แนวทาง:** คำนวณ sum แล้วต่อเป็น list หนึ่งสมาชิก

**กรณีขอบ:** list ว่างคืน [0]; ต้องไม่แก้ list ต้นฉบับ

**ตรวจด้วยตัวอย่าง:** append_collection_total([3, 4, 5],) ให้ผล [3, 4, 5, 12]
