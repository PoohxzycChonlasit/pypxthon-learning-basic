# L06-E010 — คำนวณพิสัย

ฟังก์ชัน `compute_range` รับ `values` แล้วคืนค่าตามกติกาในโจทย์

อัลกอริทึม: `return max(v for v in values if v is not None)-min(v for v in values if v is not None) if any(v is not None for v in values) else None`

Python จะคำนวณ expression ทางขวาของ `return` แล้วส่งค่านั้นกลับไปยังผู้เรียก การใช้ `return` ทำให้ตรวจค่าได้โดยไม่ต้องอ่าน stdout

ข้อผิดพลาดที่พบบ่อย: ลืมกรณีข้อมูลว่างหรือหารด้วยศูนย์; สับสนระหว่างการคืนค่ากับการแสดงผล

ตัวอย่างผลลัพธ์: `20`
