# L06-E010 — คำนวณพิสัย

**ผู้ใช้และปัญหา:** นักวิเคราะห์สรุปช่วงการแกว่งของคอลัมน์ยอดขายที่มี missing values

**สัญญา input/output:** คืน max(valid)-min(valid) โดยละเว้น None; ถ้าไม่มีค่าคืน None

**คิดทีละขั้น:** สร้างชุดค่าที่ไม่ใช่ None; ถ้ามีให้ลบ min ออกจาก max

**กรณีขอบ:** ค่าเดียวมี range 0; zero เป็นข้อมูลจริง

**ตัวอย่าง:** compute_range([3, None, 10, -2],) ให้ผล 12

ข้อควรระวัง: ค่าเดียวมี range 0; zero เป็นข้อมูลจริง
