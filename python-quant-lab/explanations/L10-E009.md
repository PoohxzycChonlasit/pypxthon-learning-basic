# L10-E009 — ใช้ค่าธรรมเนียมเริ่มต้น

**บริบท:** paper bot ใช้ fee 0 เมื่อ event ไม่มี fee หรือระบุค่าไม่สมเหตุผล

**สัญญา:** คืน fee หากเป็น finite number >=0 และไม่ใช่ bool; มิฉะนั้น 0.0

**ขั้นตอน:** ตรวจชนิด; ตรวจ finite; ยอมรับเฉพาะค่าที่ไม่ติดลบ

**กรณีขอบ:** ปฏิเสธ string, bool, NaN, infinity และค่าติดลบ

โครงการนี้จำลอง offline paper เท่านั้น ไม่มี live order
