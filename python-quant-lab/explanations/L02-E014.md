# L02-E014 — แยกกำไรกับขาดทุน

**ผู้ใช้และปัญหา:** นักวิเคราะห์แยกวันที่กำไรกับวันที่ขาดทุนเป็นสองคอลัมน์

**สัญญา:** คืน tuple (gains, losses); กำไร > 0; ขาดทุน < 0; คงลำดับและค่าซ้ำ

**แนวทาง:** กรองรายการเดียวกันด้วยสองเงื่อนไข strict เพื่อสร้างสองกลุ่ม

**กรณีขอบ:** ศูนย์ถูกละเว้น; กลุ่มที่ไม่พบเป็น []

**ตรวจด้วยตัวอย่าง:** separate_gains_and_losses([3, -2, 0, 3],) ให้ผล ([3, 3], [-2])

ข้อควรระวัง: ศูนย์ถูกละเว้น; กลุ่มที่ไม่พบเป็น []
