# L02-E011 — หยุดก่อนขาดทุนแรก

**ผู้ใช้และปัญหา:** ระบบนำเข้าใบแจ้งหนี้หยุดอ่านเมื่อพบรายการขาดทุนตัวแรก

**สัญญา:** คืนทุกค่าก่อนสมาชิกติดลบตัวแรก; ไม่รวมค่านั้น; หากไม่มีคืนทั้งหมด

**แนวทาง:** ไล่จากซ้ายไปขวา; หยุดเมื่อพบค่าต่ำกว่า 0; คืนส่วนก่อนจุดหยุด

**กรณีขอบ:** ศูนย์ไม่ใช่ขาดทุน; ถ้าค่าแรกติดลบคืน []

**ตรวจด้วยตัวอย่าง:** stop_at_first_loss([2, 0, -1, 5],) ให้ผล [2, 0]
