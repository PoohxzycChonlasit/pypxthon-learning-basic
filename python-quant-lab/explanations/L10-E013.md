# L10-E013 — กู้คืนยอดเงินสด

**บริบท:** บอทกู้คืนเงินสดจาก state ที่บันทึกไว้และใช้ bankroll 100 เมื่อข้อมูลเสีย

**สัญญา:** คืน cash ถ้าเป็น finite number >=0 มิฉะนั้นคืน 100.0

**ขั้นตอน:** ตรวจชนิดและ isfinite; รับค่าที่ไม่ติดลบ; fallback เป็น 100.0 เมื่อผิดเงื่อนไข

**กรณีขอบ:** cash=0 เป็นค่าถูกต้อง; ปฏิเสธ bool, string, NaN, infinity และค่าลบ
