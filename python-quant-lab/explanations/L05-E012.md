# L05-E012 — แยกบรรทัดข้อมูล

**ผู้ใช้และปัญหา:** ผู้ดูแลระบบแยกข้อความหลายบรรทัดเป็น record โดยไม่เก็บบรรทัดว่างรอบนอก

**สัญญา input/output:** ตัด whitespace รอบนอกแล้วใช้ splitlines; เก็บบรรทัดภายในตามลำดับ

**คิดทีละขั้น:** ตรวจข้อความว่างก่อน; strip รอบนอก; splitlines

**กรณีขอบ:** ข้อความว่างคืน []; blank line ที่อยู่กลางข้อมูลยังคงอยู่

**ตัวอย่าง:** encode_record_lines('a\\nb\\n',) ให้ผล ['a', 'b']

ข้อควรระวัง: ข้อความว่างคืน []; blank line ที่อยู่กลางข้อมูลยังคงอยู่
