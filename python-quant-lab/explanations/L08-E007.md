# L08-E007 — กำไรขั้นต้นสถานะขายชอร์ต

**ผู้ใช้:** ผู้วิเคราะห์ประเมินกำไรขั้นต้นของสถานะ short ที่ซื้อคืนภายหลัง

**สัญญา:** gross profit = (entry-exit)*quantity

**แนวทาง:** ลบ exit ออกจาก entry แล้วคูณจำนวนหน่วย

**กรณีขอบ:** ราคาซื้อต่ำกว่าราคาขายทำให้กำไรบวก; ยังไม่รวม fee

ทำงานใน paper mode เท่านั้น
