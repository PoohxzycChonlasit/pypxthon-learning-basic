# L07-E001 — ค่าเฉลี่ยเลขคณิต

**ผู้ใช้และปัญหา:** ทีมสำรวจสรุปค่าเฉลี่ยเลขคณิตของผลการวัด

**สัญญา input/output:** คืน sum(values)/len(values); คืน None เมื่อไม่มีค่าที่วัดได้

**คิดทีละขั้น:** หาผลรวม; หารด้วยจำนวนสมาชิก; แยกกรณีว่างก่อนหาร

**กรณีขอบ:** list ว่างคืน None; แต่ละค่ามีน้ำหนักเท่ากัน

**ตัวอย่าง:** arithmetic_mean([2, 4, 6],) ให้ผล 4.0

ข้อควรระวัง: list ว่างคืน None; แต่ละค่ามีน้ำหนักเท่ากัน
