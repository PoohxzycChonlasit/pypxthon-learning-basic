# L08-E013 — สัดส่วนการลดลง

**ผู้ใช้:** ทีมความเสี่ยงคำนวณ drawdown จาก peak equity ถึง current equity

**สัญญา:** คืน max(0,(peak-current)/peak); หาก peak ไม่บวกคืน 0

**แนวทาง:** คำนวณสัดส่วนที่ลดจาก peak; clamp ค่าลบเป็น 0

**กรณีขอบ:** equity เหนือ peak ไม่ใช่ drawdown; คืน 0

ทำงานใน paper mode เท่านั้น
