# L10-E006 — หยุดเมื่อเงินถึงขีดจำกัด

**บริบท:** risk gate หยุดการจำลองเมื่อ paper cash ลดถึง floor ที่กำหนด

**สัญญา:** คืน True เมื่อ cash <= risk_floor; ถ้าไม่มี floor ให้ใช้ 0

**ขั้นตอน:** อ่าน cash และ risk_floor; เปรียบเทียบด้วย <=

**กรณีขอบ:** ค่าเท่ากับ floor ต้องหยุด; cash สูงกว่า floor ยังทำต่อ

โครงการนี้จำลอง offline paper เท่านั้น ไม่มี live order
