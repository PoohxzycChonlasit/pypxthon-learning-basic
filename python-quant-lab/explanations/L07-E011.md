# L07-E011 — ผลตอบแทนทบต้น

**ผู้ใช้และปัญหา:** นักวิจัยรวมผลตอบแทนหลายช่วงแบบทบต้น

**สัญญา input/output:** คืน product(1+r) - 1

**คิดทีละขั้น:** คูณ growth factor ของแต่ละช่วง; ลบ 1 เมื่อได้ factor สุดท้าย

**กรณีขอบ:** list ว่างคืน 0; ถ้า return เป็น -1 เงินลงทุนหมดและผลรวมจะเป็น -1

**ตัวอย่าง:** positive_compounding([0.1, -0.1],) ให้ผล -0.01

ข้อควรระวัง: list ว่างคืน 0; ถ้า return เป็น -1 เงินลงทุนหมดและผลรวมจะเป็น -1
