# L06-E015 — ประเมินและทำความสะอาดข้อมูล

ฟังก์ชัน `final_data_cleaning_assessment` รับ `values` แล้วคืนค่าตามกติกาในโจทย์

อัลกอริทึม: `return {'clean': [x for x in values if x is not None], 'missing':sum(x is None for x in values)}`

Python จะคำนวณ expression ทางขวาของ `return` แล้วส่งค่านั้นกลับไปยังผู้เรียก การใช้ `return` ทำให้ตรวจค่าได้โดยไม่ต้องอ่าน stdout

ข้อผิดพลาดที่พบบ่อย: ลืมกรณีข้อมูลว่างหรือหารด้วยศูนย์; สับสนระหว่างการคืนค่ากับการแสดงผล

ตัวอย่างผลลัพธ์: `{'clean': [100, 105, 110, 90], 'missing': 1}`
