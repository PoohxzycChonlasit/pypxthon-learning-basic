# L08-E006 — กำไรสุทธิหลังค่าธรรมเนียม

**ผู้ใช้:** นักวิจัยคำนวณกำไรสถานะซื้อหลังเสีย fee 0.1% ของ notional ทั้งขาเข้าและขาออก

**สัญญา:** net = (exit-entry)*quantity - (entry+exit)*quantity*0.001

**แนวทาง:** คำนวณ gross ก่อน; หัก fee ของ notional ทั้งสองขา

**กรณีขอบ:** ราคาไม่เปลี่ยนยังขาดทุนค่าธรรมเนียม; quantity 0 ให้ผล 0

ทำงานใน paper mode เท่านั้น
