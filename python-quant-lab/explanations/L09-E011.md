# L09-E011 — สร้างสัญญาณตามเกณฑ์

**บริบทวิจัย:** นักวิจัยสร้าง long signal เมื่อ simple return ระหว่างราคาติดกันเกิน threshold

**สัญญา:** คืน 1 เมื่อ current/previous-1 > minimum_return มิฉะนั้น 0

**ขั้นตอน:** คำนวณ simple return แต่ละคู่; เปรียบเทียบแบบ strict greater-than

**กรณีขอบ:** เท่ากับ threshold ไม่ผ่าน; output ยาว n-1; previous<=0 ให้ 0

backtest ไม่ยืนยันว่ามี edge จริง
