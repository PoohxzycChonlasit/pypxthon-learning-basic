# L08-E015 — ประเมินความเสี่ยง paper

ฟังก์ชัน `final_paper_risk_assessment` รับ `entry, exit, quantity` แล้วคืนค่าตามกติกาในโจทย์

อัลกอริทึม: `return {'gross':(exit-entry)*quantity,'fee':(entry+exit)*quantity*.001,'net':(exit-entry)*quantity-(entry+exit)*quantity*.001,'live_trading':False}`

Python จะคำนวณ expression ทางขวาของ `return` แล้วส่งค่านั้นกลับไปยังผู้เรียก การใช้ `return` ทำให้ตรวจค่าได้โดยไม่ต้องอ่าน stdout

ข้อผิดพลาดที่พบบ่อย: ลืมกรณีข้อมูลว่างหรือหารด้วยศูนย์; สับสนระหว่างการคืนค่ากับการแสดงผล

ตัวอย่างผลลัพธ์: `{'gross': 5.0, 'fee': 0.105, 'net': 4.895, 'live_trading': False}`
