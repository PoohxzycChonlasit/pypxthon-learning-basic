# L04-E006 — ระยะความเสี่ยงสัมบูรณ์

**ผู้ใช้และปัญหา:** ผู้จัดการความเสี่ยงวัดระยะระหว่างราคาเข้ากับ stop

**สัญญา:** คืน abs(entry-stop) ในหน่วยราคา

**แนวทาง:** ลบราคาสองค่าและใช้ abs กับผลต่าง

**กรณีขอบ:** ระยะไม่ขึ้นกับทิศทาง; ราคาเท่ากันคืน 0

**ตรวจด้วยตัวอย่าง:** absolute_risk_distance(10, 2) ให้ผล 8

ข้อควรระวัง: ระยะไม่ขึ้นกับทิศทาง; ราคาเท่ากันคืน 0
