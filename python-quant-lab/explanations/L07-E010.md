# L07-E010 — ผลตอบแทนลอการิทึม

**ผู้ใช้และปัญหา:** นักวิเคราะห์คำนวณ log return ระหว่างราคาปิดที่เรียงตามเวลา

**สัญญา input/output:** สำหรับราคาติดกันที่เป็นบวก คืน ln(current/previous)

**คิดทีละขั้น:** ตรวจราคาทั้งสองเป็นบวก; ใช้ natural log ของอัตราส่วน

**กรณีขอบ:** ข้ามคู่ที่ราคาใดไม่มากกว่า 0; ค่าผลลัพธ์เป็น log return ไม่ใช่เปอร์เซ็นต์อย่างง่าย

**ตัวอย่าง:** log_returns([100, 110, 99],) ให้ผล [0.09531017980432493, -0.10536051565782628]
