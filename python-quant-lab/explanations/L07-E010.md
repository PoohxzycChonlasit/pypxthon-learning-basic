# L07-E010 — ผลตอบแทนลอการิทึม

ฟังก์ชัน `log_returns` รับ `values` แล้วคืนค่าตามกติกาในโจทย์

อัลกอริทึม: `import math; return [math.log(b/a) for a,b in zip(values,values[1:]) if a>0 and b>0]`

Python จะคำนวณ expression ทางขวาของ `return` แล้วส่งค่านั้นกลับไปยังผู้เรียก การใช้ `return` ทำให้ตรวจค่าได้โดยไม่ต้องอ่าน stdout

ข้อผิดพลาดที่พบบ่อย: ลืมกรณีข้อมูลว่างหรือหารด้วยศูนย์; สับสนระหว่างการคืนค่ากับการแสดงผล

ตัวอย่างผลลัพธ์: `[0.6931471805599453, 0.4054651081081644, 0.28768207245178085]`
