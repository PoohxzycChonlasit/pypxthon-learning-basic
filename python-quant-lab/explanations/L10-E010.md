# L10-E010 — บันทึกผลคำสั่ง

**บริบท:** ระบบ audit บันทึกผลคำสั่งเป็น event ที่ยืนยันว่าเป็น paper

**สัญญา:** คืน dict ที่มี id จาก event, status="paper", live=False

**ขั้นตอน:** คัด id; เพิ่ม status คงที่; กำหนด live เป็น False

**กรณีขอบ:** id หายคืน None; live เป็น boolean False เสมอ

โครงการนี้จำลอง offline paper เท่านั้น ไม่มี live order
