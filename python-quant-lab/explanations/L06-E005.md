# L06-E005 — ปรับสเกลค่าต่ำสุดและสูงสุด

ฟังก์ชัน `min_max_normalization` รับ `values` แล้วคืนค่าตามกติกาในโจทย์

อัลกอริทึม: `return [(x-min(values))/(max(values)-min(values)) for x in values] if values and max(values)!=min(values) else ([0.0]*len(values))`

Python จะคำนวณ expression ทางขวาของ `return` แล้วส่งค่านั้นกลับไปยังผู้เรียก การใช้ `return` ทำให้ตรวจค่าได้โดยไม่ต้องอ่าน stdout

ข้อผิดพลาดที่พบบ่อย: ลืมกรณีข้อมูลว่างหรือหารด้วยศูนย์; สับสนระหว่างการคืนค่ากับการแสดงผล
