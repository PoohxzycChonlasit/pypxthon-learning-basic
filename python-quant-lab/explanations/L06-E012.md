# L06-E012 — นับค่าบวก

**ผู้ใช้และปัญหา:** นักวิเคราะห์นับผลตอบแทนบวก โดยเว้นช่อง None และไม่นับศูนย์

**สัญญา input/output:** นับค่าที่มากกว่า 0 และไม่ใช่ None

**คิดทีละขั้น:** ตรวจแต่ละค่าด้วยเงื่อนไข not None และ > 0

**กรณีขอบ:** None และ 0 ไม่นับ; list ว่างคืน 0

**ตัวอย่าง:** positive_observation_count([1, None, -1, 0, 2],) ให้ผล 2

ข้อควรระวัง: None และ 0 ไม่นับ; list ว่างคืน 0
