# L06-E007 — เลือกค่าที่สูงกว่าค่าเฉลี่ย

ฟังก์ชัน `select_above_average` รับ `values` แล้วคืนค่าตามกติกาในโจทย์

อัลกอริทึม: `return [x for x in values if x is not None and x>sum(v for v in values if v is not None)/len([v for v in values if v is not None])] if any(v is not None for v in values) else []`

Python จะคำนวณ expression ทางขวาของ `return` แล้วส่งค่านั้นกลับไปยังผู้เรียก การใช้ `return` ทำให้ตรวจค่าได้โดยไม่ต้องอ่าน stdout

ข้อผิดพลาดที่พบบ่อย: ลืมกรณีข้อมูลว่างหรือหารด้วยศูนย์; สับสนระหว่างการคืนค่ากับการแสดงผล

ตัวอย่างผลลัพธ์: `[105, 110]`
