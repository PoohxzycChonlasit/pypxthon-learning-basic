# L05-E013 — ตรวจจำนวนฟิลด์

**ผู้ใช้และปัญหา:** ทีมตรวจข้อมูลก่อน import ต้องยืนยันว่า record มีสาม field คั่นด้วย comma

**สัญญา input/output:** คืน True เมื่อจำนวน comma-separated field เท่ากับ 3 มิฉะนั้น False

**คิดทีละขั้น:** นับจำนวนส่วนที่ได้จาก split comma และเทียบกับ 3

**กรณีขอบ:** รองรับ field ว่างได้หากยังมีสามช่อง; ไม่รองรับ comma ที่ quote ครอบ

**ตัวอย่าง:** validate_three_fields('A,10,B',) ให้ผล True
