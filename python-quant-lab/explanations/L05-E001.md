# L05-E001 — ตัดช่องว่าง

**ผู้ใช้และปัญหา:** ผู้ดูแลไฟล์รายชื่อลูกค้าลบช่องว่างหัวและท้ายที่เกิดจากการคัดลอก

**สัญญา input/output:** คืนข้อความหลัง strip ช่องว่างรอบนอก; ไม่เปลี่ยนช่องว่างภายใน

**คิดทีละขั้น:** ใช้ strip เพื่อสร้างข้อความใหม่โดยไม่แก้ข้อความเดิม

**กรณีขอบ:** ข้อความว่างหรือมีแต่ช่องว่างคืน ""

**ตัวอย่าง:** normalize_whitespace('  Mali  ',) ให้ผล 'Mali'

ข้อควรระวัง: ข้อความว่างหรือมีแต่ช่องว่างคืน ""
