# L08-E010 — อัตราผลตอบแทนต่อความเสี่ยง

**ผู้ใช้:** นักวิจัยเปรียบเทียบระยะเป้ากำไรกับระยะ stop เพื่อคำนวณ reward-to-risk

**สัญญา:** ratio = abs(target-entry)/abs(entry-stop); ถ้า stop distance เป็น 0 คืน None

**แนวทาง:** คำนวณ reward และ risk distance แยกกัน; ตรวจตัวหารก่อนหาร

**กรณีขอบ:** ทิศทาง long/short ไม่เปลี่ยนระยะ; ห้ามหารด้วยศูนย์
