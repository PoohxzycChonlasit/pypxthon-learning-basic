# L04-E015 — ประเมินฟังก์ชัน

**สิ่งที่วัด:** คืนส่วนต่าง actual-target และ ratio actual/target

**แนวทางแก้:** คำนวณ difference; ตรวจ target=0 ก่อนหาร; เก็บสองผลใน dict

**กรณีขอบ:** ทดสอบ actual มากกว่า/น้อยกว่า target และ target เป็นศูนย์

variant A และ B เปลี่ยนบริบทเพื่อทดสอบการประยุกต์ ผลที่ผ่านยืนยันเฉพาะกรณีทดสอบ ไม่ใช่หลักฐานว่าเข้าใจทุกกรณีหรือว่ากลยุทธ์ทำกำไร
