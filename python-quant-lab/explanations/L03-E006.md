# L03-E006 — ตารางความถี่

**ผู้ใช้และปัญหา:** ร้านค้าออนไลน์สรุปจำนวนครั้งที่แต่ละ SKU ปรากฏในคำสั่งซื้อ

**สัญญา:** คืน dict ที่ key เป็นสมาชิกและ value เป็นจำนวนครั้งที่พบ

**แนวทาง:** เริ่ม dict ว่าง; ใช้ get(key,0) แล้วเพิ่มตัวนับหนึ่งเมื่อพบสมาชิก

**กรณีขอบ:** list ว่างคืน {}; key ที่พบหนึ่งครั้งมีค่า 1

**ตรวจด้วยตัวอย่าง:** frequency_table(['tea', 'rice', 'tea'],) ให้ผล {'tea': 2, 'rice': 1}

ข้อควรระวัง: list ว่างคืน {}; key ที่พบหนึ่งครั้งมีค่า 1
