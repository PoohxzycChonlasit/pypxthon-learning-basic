# L09-E012 — ปฏิเสธผลทดสอบติดลบ

**บริบทวิจัย:** ทีมวิจัยดำเนินการต่อเมื่อค่าเฉลี่ย return ในช่วงทดสอบเป็นบวก

**สัญญา:** คืน continue เมื่อ list ไม่ว่างและ mean > 0; มิฉะนั้น reject

**ขั้นตอน:** หาค่าเฉลี่ยเมื่อมีข้อมูล; เลือก continue เฉพาะกรณีบวก

**กรณีขอบ:** ค่าเฉลี่ยศูนย์และข้อมูลว่างให้ reject

backtest ไม่ยืนยันว่ามี edge จริง
