# L10-E015 — ประเมินบอทออฟไลน์

ฟังก์ชัน `final_offline_bot_assessment` รับ `event` แล้วคืนค่าตามกติกาในโจทย์

อัลกอริทึม: `return {'orders':1 if event.get('quantity',0)>0 else 0,'cash_after':event.get('cash',0)-event.get('quantity',0)*event.get('price',0) if event.get('side')=='buy' else event.get('cash',0),'live_trading':False}`

Python จะคำนวณ expression ทางขวาของ `return` แล้วส่งค่านั้นกลับไปยังผู้เรียก การใช้ `return` ทำให้ตรวจค่าได้โดยไม่ต้องอ่าน stdout

ข้อผิดพลาดที่พบบ่อย: ลืมกรณีข้อมูลว่างหรือหารด้วยศูนย์; สับสนระหว่างการคืนค่ากับการแสดงผล

ตัวอย่างผลลัพธ์: `{'orders': 1, 'cash_after': 90, 'live_trading': False}`
