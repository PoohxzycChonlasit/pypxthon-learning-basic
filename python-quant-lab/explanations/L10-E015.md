# L10-E015 — Assessment transfer

**สิ่งที่วัด:** อ่านข้อกำหนดของ variant ที่แสดง แล้วเลือกใช้แนวคิดที่เรียนมาให้ตรงกับ input และ output ของข้อนั้น

**แนวทาง:** ระบุ output ทุกช่องก่อนเขียนโค้ด; แยกขั้นคำนวณ; ตรวจกรณีขอบที่ prompt ระบุ

**กรณีขอบ:** ใช้ตัวอย่างและขอบเขตของ variant ปัจจุบัน อย่านำคำตอบของอีก variant มาใช้แทน

สำหรับ variant B เมื่อ event ถูกปฏิเสธและ cash กับ position ใช้งานได้ ให้คงยอดทั้งสองไว้ แม้ quantity หรือ price จะแปลงเป็นตัวเลขไม่ได้. Input ที่ไม่ใช่ dict คืนยอด 0 ตาม prompt.

ขอบเขตที่ยังไม่กำหนด: prompt ไม่ระบุว่าจะคืนค่าอย่างไรเมื่อ cash หรือ position เดิมแปลงเป็นตัวเลขไม่ได้ หรือเป็นค่าไม่ finite. อย่าตีความ fallback ของ reference solution ว่าเป็นกติกาบัญชีสำหรับกรณีเหล่านี้.
