# L07-E009 — คะแนนมาตรฐานค่าล่าสุด

ฟังก์ชัน `standard_score_last_value` รับ `values` แล้วคืนค่าตามกติกาในโจทย์

อัลกอริทึม: `import math; m=sum(values)/len(values); s=math.sqrt(sum((x-m)**2 for x in values)/len(values)); return (values[-1]-m)/s if values and s else None`

Python จะคำนวณ expression ทางขวาของ `return` แล้วส่งค่านั้นกลับไปยังผู้เรียก การใช้ `return` ทำให้ตรวจค่าได้โดยไม่ต้องอ่าน stdout

ข้อผิดพลาดที่พบบ่อย: ลืมกรณีข้อมูลว่างหรือหารด้วยศูนย์; สับสนระหว่างการคืนค่ากับการแสดงผล
