# L07-E009 — คะแนนมาตรฐานค่าล่าสุด

**ผู้ใช้และปัญหา:** นักวิเคราะห์เปรียบเทียบค่าล่าสุดกับค่าเฉลี่ยด้วย population z-score

**สัญญา input/output:** คำนวณ (last-mean)/population_std; คืน None ถ้าว่างหรือส่วนเบี่ยงเบนมาตรฐานเป็น 0

**คิดทีละขั้น:** คำนวณ mean; หารผลรวมกำลังสองด้วย n แล้ว sqrt; เทียบค่าสุดท้าย

**กรณีขอบ:** ทุกค่าคงที่ให้ None เพราะหารด้วยศูนย์; ใช้ population variance หารด้วย n

**ตัวอย่าง:** standard_score_last_value([0, 2, 4],) ให้ผล 1.224744871391589

ข้อควรระวัง: ทุกค่าคงที่ให้ None เพราะหารด้วยศูนย์; ใช้ population variance หารด้วย n
