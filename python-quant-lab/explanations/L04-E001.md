# L04-E001 — ผลตอบแทนอย่างง่าย

**ผู้ใช้และปัญหา:** นักวิเคราะห์เปรียบเทียบราคาเริ่มกับราคาสิ้นสุดเพื่อคำนวณ return

**สัญญา:** คืน (end-start)/start; ถ้า start เป็นศูนย์คืน None

**แนวทาง:** หาผลต่าง; หารด้วย start; แยก start==0 ก่อนหาร

**กรณีขอบ:** ราคาเท่ากันคืน 0; ศูนย์ห้ามเป็นตัวหาร

**ตรวจด้วยตัวอย่าง:** simple_return(100, 110) ให้ผล 0.1

ข้อควรระวัง: ราคาเท่ากันคืน 0; ศูนย์ห้ามเป็นตัวหาร
