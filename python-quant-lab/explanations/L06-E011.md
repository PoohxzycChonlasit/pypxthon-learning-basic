# L06-E011 — ปรับข้อมูลให้อยู่รอบค่าเฉลี่ย

**ผู้ใช้และปัญหา:** นักวิเคราะห์ปรับข้อมูลรอบศูนย์ด้วยการลบค่าเฉลี่ยของชุดข้อมูล

**สัญญา input/output:** คืน list ที่แต่ละค่าเป็น value - population mean

**คิดทีละขั้น:** หาค่าเฉลี่ยของทุกค่า; ลบ mean ออกจากแต่ละสมาชิก

**กรณีขอบ:** list ว่างคืน []; ค่าผลรวมหลัง demean ควรใกล้ศูนย์เมื่อคำนวณด้วย float

**ตัวอย่าง:** demean_series([1, 2, 3],) ให้ผล [-1.0, 0.0, 1.0]

ข้อควรระวัง: list ว่างคืน []; ค่าผลรวมหลัง demean ควรใกล้ศูนย์เมื่อคำนวณด้วย float
