# L06-E001 — คำนวณผลตอบแทนรายวัน

**ผู้ใช้และปัญหา:** นักวิเคราะห์ทำ return ต่อวันจากราคาปิดที่เรียงตามเวลา

**สัญญา input/output:** สำหรับคู่ติดกันที่ค่าทั้งสองมีข้อมูลและราคาก่อนหน้าไม่เป็นศูนย์ คืน current/previous - 1

**คิดทีละขั้น:** จับคู่ราคาติดกัน; ตรวจ missing และตัวหาร; คำนวณ return แบบสัดส่วน

**กรณีขอบ:** ข้ามคู่ที่มี None หรือ previous=0; current=0 ให้ผล -1

**ตัวอย่าง:** daily_returns([100, 110, 99],) ให้ผล [0.1, -0.1]

ข้อควรระวัง: ข้ามคู่ที่มี None หรือ previous=0; current=0 ให้ผล -1
