# L06-E001 — คำนวณผลตอบแทนรายวัน

ฟังก์ชัน `daily_returns` รับ `values` แล้วคืนค่าตามกติกาในโจทย์

อัลกอริทึม: `return [b/a-1 for a,b in zip(values,values[1:]) if a and b is not None]`

Python จะคำนวณ expression ทางขวาของ `return` แล้วส่งค่านั้นกลับไปยังผู้เรียก การใช้ `return` ทำให้ตรวจค่าได้โดยไม่ต้องอ่าน stdout

ข้อผิดพลาดที่พบบ่อย: ลืมกรณีข้อมูลว่างหรือหารด้วยศูนย์; สับสนระหว่างการคืนค่ากับการแสดงผล

ตัวอย่างผลลัพธ์: `[0.050000000000000044, -0.18181818181818177]`
