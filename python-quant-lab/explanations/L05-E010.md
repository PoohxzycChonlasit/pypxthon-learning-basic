# L05-E010 — ตรวจแถวหัวตาราง

**ผู้ใช้และปัญหา:** ระบบรายงานตรวจว่าบรรทัดแรกของไฟล์เป็น header ที่เริ่มด้วยคอลัมน์ date

**สัญญา input/output:** คืน True เมื่อหลังตัดช่องว่างนำหน้าแล้วบรรทัดขึ้นต้นด้วย date, โดยไม่สนตัวพิมพ์เล็กใหญ่

**คิดทีละขั้น:** strip แล้วแปลงเป็นตัวพิมพ์เล็ก; ตรวจ prefix date,

**กรณีขอบ:** date ต้องตามด้วย comma; บรรทัดข้อมูลที่เริ่มด้วยวันที่จริงไม่ถือเป็น header

**ตัวอย่าง:** detect_header_row('Date,Revenue,Region',) ให้ผล True

ข้อควรระวัง: date ต้องตามด้วย comma; บรรทัดข้อมูลที่เริ่มด้วยวันที่จริงไม่ถือเป็น header
