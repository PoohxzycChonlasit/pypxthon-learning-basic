# L02-E008 — วัดการลดลงระหว่างจุด

**ผู้ใช้และปัญหา:** ผู้ดูแลบัญชี paper วัดการเปลี่ยนแปลงร้อยละระหว่างยอดที่อยู่ติดกัน

**สัญญา:** คำนวณ b/a - 1 ของคู่ติดกันที่ a ไม่เป็นศูนย์; คืนค่าต่ำสุดที่พบ หรือ 0 หากไม่มีการลดลง

**แนวทาง:** จับคู่ยอดแต่ละวันกับวันถัดไป; ข้ามตัวหารศูนย์; เลือกสัดส่วนการเปลี่ยนแปลงที่ต่ำสุด

**กรณีขอบ:** รายการสั้นกว่าสองค่าและกรณีไม่มีค่าลดลงคืน 0

**ตรวจด้วยตัวอย่าง:** maximum_drawdown_step([100, 90, 95],) ให้ผล -0.1

ข้อควรระวัง: รายการสั้นกว่าสองค่าและกรณีไม่มีค่าลดลงคืน 0
