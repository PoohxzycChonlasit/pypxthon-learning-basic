# L05-E008 — ลบช่องว่างจากฟิลด์

**ผู้ใช้และปัญหา:** ทีมจัดซื้อแปลงช่องรายการที่ไม่ว่างจากบรรทัดคำสั่งซื้อให้เป็น list

**สัญญา input/output:** แยกด้วย comma; strip ค่า; ทิ้ง field ที่ว่างหลัง strip

**คิดทีละขั้น:** กรอง field หลัง strip แล้วสร้าง list

**กรณีขอบ:** input ว่างคืน []; คงลำดับและค่าซ้ำ

**ตัวอย่าง:** remove_blank_fields(' tea, ,rice, tea ',) ให้ผล ['tea', 'rice', 'tea']
