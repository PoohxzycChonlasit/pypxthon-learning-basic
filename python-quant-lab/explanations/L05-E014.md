# L05-E014 — นับสัญลักษณ์ซ้ำ

**ผู้ใช้และปัญหา:** ทีมสนับสนุนสรุปจำนวน ticker ในข้อความ comma-separated โดยไม่สนตัวพิมพ์และช่องว่าง

**สัญญา input/output:** ตัดช่องว่างและแปลงแต่ละ token เป็นตัวพิมพ์ใหญ่; คืน dict นับจำนวน; ข้าม token ว่าง

**คิดทีละขั้น:** normalize แต่ละ token ก่อนนับและเพิ่มค่าความถี่ใน dict

**กรณีขอบ:** ticker ที่ต่างกันแค่ตัวพิมพ์นับรวม; ไม่แสดง key ว่าง

**ตัวอย่าง:** count_repeated_symbols('btc, ETH,btc, ,eth ',) ให้ผล {'BTC': 2, 'ETH': 2}

ข้อควรระวัง: ticker ที่ต่างกันแค่ตัวพิมพ์นับรวม; ไม่แสดง key ว่าง
