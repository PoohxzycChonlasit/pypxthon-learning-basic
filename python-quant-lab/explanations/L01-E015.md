# L01-E015 — ภารกิจสรุป paper trade

โปรแกรมรับข้อมูล 4 ค่าและแปลงเป็น float จากนั้นคำนวณผลต่างราคาคูณจำนวนเหรียญ ค่าธรรมเนียมคิดจากมูลค่าซื้อและขายรวม แล้วหักจาก gross ฟอร์แมต `:.2f` ทำให้แต่ละบรรทัดมีทศนิยมสองหลัก Test ของ variant แต่ละชุดใช้ตัวเลขที่ต่างกัน เพื่อยืนยันว่าโปรแกรมคำนวณจาก input จริง ไม่ใช่ค่าตัวอย่าง
