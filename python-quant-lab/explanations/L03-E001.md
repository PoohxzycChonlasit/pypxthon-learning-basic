# L03-E001 — ค่าล่าสุด

**ผู้ใช้และปัญหา:** ผู้ดูแลคลังอ่านจำนวนคงเหลือล่าสุดจากบันทึกเรียงตามเวลา

**สัญญา:** คืนสมาชิกท้ายสุดของ list; ถ้าว่างคืน None

**แนวทาง:** ตรวจว่ามีข้อมูล; ใช้ items[-1] เมื่อมี และคืน None เมื่อไม่มี

**กรณีขอบ:** ต้องตรวจ list ว่างก่อน index -1

**ตรวจด้วยตัวอย่าง:** latest_observation([4, 7, 2],) ให้ผล 2

ข้อควรระวัง: ต้องตรวจ list ว่างก่อน index -1
