# L06-E008 — ผลรวมสะสม

**ผู้ใช้และปัญหา:** นักวิเคราะห์สร้างยอดสะสมของปริมาณขายตามลำดับเวลา

**สัญญา input/output:** คืน list ยอดสะสมตั้งแต่แถวแรกถึงแถวปัจจุบัน

**คิดทีละขั้น:** เริ่ม total ที่ 0; เพิ่มแต่ละค่าแล้วบันทึก total

**กรณีขอบ:** list ว่างคืน []; รองรับค่าติดลบตามข้อมูลปรับปรุงยอด

**ตัวอย่าง:** cumulative_sum([3, 4, -2],) ให้ผล [3, 7, 5]

ข้อควรระวัง: list ว่างคืน []; รองรับค่าติดลบตามข้อมูลปรับปรุงยอด
