# L02-E006 — กรองค่าศูนย์

**ผู้ใช้และปัญหา:** เจ้าหน้าที่เซนเซอร์ลบค่า 0 ที่หมายถึงไม่มีการอ่าน แต่เก็บค่าติดลบไว้

**สัญญา:** คืน list ใหม่ที่ตัดเฉพาะสมาชิกเท่ากับ 0; รักษาลำดับและค่าที่เหลือ

**แนวทาง:** เริ่ม list ผลลัพธ์; อ่านค่าทีละตัว; เพิ่มเมื่อค่าไม่เท่ากับศูนย์

**กรณีขอบ:** list ว่างคืน []

**ตรวจด้วยตัวอย่าง:** keep_nonzero_readings([0, 3, 0, -2, 5],) ให้ผล [3, -2, 5]

ข้อควรระวัง: list ว่างคืน []
