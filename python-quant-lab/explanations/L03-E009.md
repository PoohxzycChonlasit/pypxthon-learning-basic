# L03-E009 — เพิ่มหมายเลขลำดับ

**ผู้ใช้และปัญหา:** ทีมคลังติดหมายเลขตำแหน่งให้แถวข้อมูลที่อ่านจากไฟล์

**สัญญา:** คืน list ของคู่ (index,value) โดย index เริ่มจาก 0

**แนวทาง:** ใช้ enumerate แล้วแปลงผลให้เป็น list

**กรณีขอบ:** list ว่างคืน []; ค่าซ้ำยังคงมี index แยกกัน

**ตรวจด้วยตัวอย่าง:** indexed_observations(['A', 'B', 'C'],) ให้ผล [(0, 'A'), (1, 'B'), (2, 'C')]

ข้อควรระวัง: list ว่างคืน []; ค่าซ้ำยังคงมี index แยกกัน
