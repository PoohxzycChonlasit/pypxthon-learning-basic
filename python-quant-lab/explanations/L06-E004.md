# L06-E004 — ค่าเฉลี่ยเคลื่อนที่สองจุด

ฟังก์ชัน `rolling_two_point_mean` รับ `values` แล้วคืนค่าตามกติกาในโจทย์

อัลกอริทึม: `return [(a+b)/2 for a,b in zip(values,values[1:]) if a is not None and b is not None]`

Python จะคำนวณ expression ทางขวาของ `return` แล้วส่งค่านั้นกลับไปยังผู้เรียก การใช้ `return` ทำให้ตรวจค่าได้โดยไม่ต้องอ่าน stdout

ข้อผิดพลาดที่พบบ่อย: ลืมกรณีข้อมูลว่างหรือหารด้วยศูนย์; สับสนระหว่างการคืนค่ากับการแสดงผล

ตัวอย่างผลลัพธ์: `[102.5, 100.0]`
