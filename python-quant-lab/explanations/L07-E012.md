# L07-E012 — นับค่าที่สูงกว่ามัธยฐาน

**ผู้ใช้และปัญหา:** นักวิเคราะห์นับค่าที่สูงกว่ามัธยฐานทางสถิติของชุดข้อมูล

**สัญญา input/output:** คำนวณ median แบบมาตรฐาน; เมื่อ n เป็นเลขคู่ใช้ค่าเฉลี่ยของสองค่ากลาง; นับสมาชิกที่ > median

**คิดทีละขั้น:** เรียงข้อมูลเพื่อหา median; นับสมาชิกเดิมที่มากกว่า median

**กรณีขอบ:** ข้อมูลว่างคืน 0; ค่าที่เท่ามัธยฐานไม่นับ

**ตัวอย่าง:** count_above_median([1, 2, 3, 4],) ให้ผล 2

ข้อควรระวัง: ข้อมูลว่างคืน 0; ค่าที่เท่ามัธยฐานไม่นับ
