# L07-E007 — ผลคาดหมายต่อรายการ

**ผู้ใช้และปัญหา:** นักวิจัยประเมิน expected value ต่อ trade จากโอกาสชนะและค่าเฉลี่ยของผลชนะ/แพ้

**สัญญา input/output:** รับ win_probability, average_win, average_loss; คำนวณ p*win + (1-p)*loss; loss เป็นค่าลบ

**คิดทีละขั้น:** คำนวณโอกาสแพ้ 1-p; คูณผลลัพธ์แต่ละกรณีด้วยโอกาส; รวมสองส่วน

**กรณีขอบ:** p อยู่ระหว่าง 0 ถึง 1; p=0 คืน average_loss; p=1 คืน average_win

**ตัวอย่าง:** expected_trade_result(0.6, 10, -5) ให้ผล 4.0

ข้อควรระวัง: p อยู่ระหว่าง 0 ถึง 1; p=0 คืน average_loss; p=1 คืน average_win
