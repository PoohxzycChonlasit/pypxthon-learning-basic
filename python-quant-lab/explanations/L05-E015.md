# L05-E015 — ประเมินการแยกข้อมูล

**สิ่งที่วัด:** normalize comma-separated text และคืนจำนวน field

**แนวทางแก้:** strip, split, strip สมาชิก, uppercase แล้ว join กลับ

**กรณีขอบ:** ตรวจช่องว่างรอบนอกและหลาย field; อย่าแปลงเป็นตัวเลข

variant A และ B เปลี่ยนบริบทเพื่อทดสอบการประยุกต์ ผลที่ผ่านยืนยันเฉพาะกรณีทดสอบ ไม่ใช่หลักฐานว่าเข้าใจทุกกรณีหรือว่ากลยุทธ์ทำกำไร
