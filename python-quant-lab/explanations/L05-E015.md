# L05-E015 — Assessment transfer

**สิ่งที่วัด:** อ่านข้อกำหนดของ variant ที่แสดง แล้วเลือกใช้แนวคิดที่เรียนมาให้ตรงกับ input และ output ของข้อนั้น

**แนวทาง:** ระบุ output ทุกช่องก่อนเขียนโค้ด; แยกขั้นคำนวณ; ตรวจกรณีขอบที่ prompt ระบุ

**กรณีขอบ:** ใช้ตัวอย่างและขอบเขตของ variant ปัจจุบัน อย่านำคำตอบของอีก variant มาใช้แทน
