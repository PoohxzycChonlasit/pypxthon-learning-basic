# L02-E010 — เพิ่มเฉพาะค่าบวกเป็นสองเท่า

**ผู้ใช้และปัญหา:** ร้านค้าเพิ่มแต้มสะสมสองเท่าเฉพาะค่าบวก และเก็บรายการอื่นไว้

**สัญญา:** คืน list ความยาวเดิม; ค่ามากกว่า 0 คูณ 2; ค่า 0 หรือติดลบคงเดิม

**แนวทาง:** เลือกผลลัพธ์ด้วย if/else สำหรับแต่ละค่า; ไม่กรองสมาชิกออก

**กรณีขอบ:** รักษาลำดับและสมาชิกทุกตำแหน่ง

**ตรวจด้วยตัวอย่าง:** double_only_winners([3, -2, 0, 4],) ให้ผล [6, -2, 0, 8]
