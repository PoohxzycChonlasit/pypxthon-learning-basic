# L03-E015 — ประเมินโครงสร้างข้อมูล

**สิ่งที่วัด:** คืน length, first และจำนวนค่าไม่ซ้ำจากรายการ

**แนวทางแก้:** ตรวจ list ว่างก่อนอ่านตัวแรก; นับ unique โดยไม่เปลี่ยนลำดับ input

**กรณีขอบ:** เทียบกรณีมีค่าซ้ำกับกรณีว่าง; อย่าใช้ unique แทน length
