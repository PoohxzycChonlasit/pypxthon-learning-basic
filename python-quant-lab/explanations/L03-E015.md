# L03-E015 — ประเมินโครงสร้างข้อมูล

ฟังก์ชัน `final_structure_assessment` รับ `items` แล้วคืนค่าตามกติกาในโจทย์

อัลกอริทึม: `return {'length':len(items),'first':items[0] if items else None,'unique':len(set(items))}`

Python จะคำนวณ expression ทางขวาของ `return` แล้วส่งค่านั้นกลับไปยังผู้เรียก การใช้ `return` ทำให้ตรวจค่าได้โดยไม่ต้องอ่าน stdout

ข้อผิดพลาดที่พบบ่อย: ลืมกรณีข้อมูลว่างหรือหารด้วยศูนย์; สับสนระหว่างการคืนค่ากับการแสดงผล

ตัวอย่างผลลัพธ์: `{'length': 4, 'first': 3, 'unique': 3}`
