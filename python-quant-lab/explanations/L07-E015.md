# L07-E015 — ประเมินสถิติ

ฟังก์ชัน `final_statistics_assessment` รับ `values` แล้วคืนค่าตามกติกาในโจทย์

อัลกอริทึม: `return {'mean':sum(values)/len(values) if values else None,'n':len(values),'min':min(values) if values else None,'max':max(values) if values else None}`

Python จะคำนวณ expression ทางขวาของ `return` แล้วส่งค่านั้นกลับไปยังผู้เรียก การใช้ `return` ทำให้ตรวจค่าได้โดยไม่ต้องอ่าน stdout

ข้อผิดพลาดที่พบบ่อย: ลืมกรณีข้อมูลว่างหรือหารด้วยศูนย์; สับสนระหว่างการคืนค่ากับการแสดงผล

ตัวอย่างผลลัพธ์: `{'mean': 2.5, 'n': 4, 'min': 1, 'max': 4}`
