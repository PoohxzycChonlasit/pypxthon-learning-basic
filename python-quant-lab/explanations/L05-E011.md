# L05-E011 — จัดการข้อความว่าง

**ผู้ใช้และปัญหา:** ระบบรับข้อความบันทึกเหตุการณ์และแทน input ว่างด้วย None เพื่อสื่อว่าไม่มีข้อมูล

**สัญญา input/output:** คืนข้อความเดิมถ้ามีอักขระที่ไม่ใช่ช่องว่าง; ถ้าว่างหลัง strip ให้คืน None

**คิดทีละขั้น:** ตรวจ text.strip(); เลือกคืน None หรือข้อความ input เดิม

**กรณีขอบ:** เมื่อข้อความไม่ว่างต้องคืนข้อความเดิมรวมช่องว่างเดิม

**ตัวอย่าง:** redact_empty_input('  alert  ',) ให้ผล '  alert  '

ข้อควรระวัง: เมื่อข้อความไม่ว่างต้องคืนข้อความเดิมรวมช่องว่างเดิม
