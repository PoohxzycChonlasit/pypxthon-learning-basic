# L04-E014 — เลือกค่าระมัดระวัง

**ผู้ใช้และปัญหา:** ผู้วางแผนใช้งบเลือกค่าประมาณที่ต่ำกว่าเพื่อกันความเสี่ยงจากการประเมินสูงเกินจริง

**สัญญา:** คืนค่าต่ำสุดระหว่าง estimate_a และ estimate_b

**แนวทาง:** เปรียบเทียบสองประมาณการแล้วคืนตัวที่น้อยกว่า

**กรณีขอบ:** ค่าที่เท่ากันคืนค่านั้น; รองรับจำนวนลบ

**ตรวจด้วยตัวอย่าง:** choose_conservative_estimate(10, 8) ให้ผล 8
