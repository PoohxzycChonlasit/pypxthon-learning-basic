# L04-E010 — จัดรูปแบบเปอร์เซ็นต์

**ผู้ใช้และปัญหา:** เจ้าหน้าที่รายงานแสดงสัดส่วนเป็นเปอร์เซ็นต์ตามจำนวนทศนิยมที่เลือก

**สัญญา:** รับ fraction และ digits; คืนข้อความเปอร์เซ็นต์โดย digits อยู่ระหว่าง 0 ถึง 4

**แนวทาง:** ใช้ precision แบบ dynamic ใน f-string; format % คูณค่า 100 ให้เอง

**กรณีขอบ:** 0.125 กับ 1 หลักต้องได้ 12.5%; digits เป็นจำนวนเต็ม

**ตรวจด้วยตัวอย่าง:** format_percent(0.125, 1) ให้ผล '12.5%'

ข้อควรระวัง: 0.125 กับ 1 หลักต้องได้ 12.5%; digits เป็นจำนวนเต็ม
