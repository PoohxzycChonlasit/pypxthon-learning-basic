# L04-E008 — มูลค่าสถานะ

**ผู้ใช้และปัญหา:** ผู้จัดการสต็อกประเมินมูลค่าสินค้าจากราคาต่อหน่วยและจำนวนหน่วย

**สัญญา:** คืน price * quantity; ไม่ปัดเศษ

**แนวทาง:** คูณราคาต่อหน่วยด้วยจำนวนหน่วย

**กรณีขอบ:** จำนวนหน่วยศูนย์ให้มูลค่า 0; รองรับเศษส่วน

**ตรวจด้วยตัวอย่าง:** position_notional(10, 2) ให้ผล 20

ข้อควรระวัง: จำนวนหน่วยศูนย์ให้มูลค่า 0; รองรับเศษส่วน
