# L09-E007 — ผลตอบแทนตามสัญญาณขั้นต้น

ฟังก์ชัน `gross_signal_returns` รับ `values` แล้วคืนค่าตามกติกาในโจทย์

อัลกอริทึม: `return [signal*(b/a-1) for a,b,signal in zip(values,values[1:], [1]*(len(values)-1)) if a]`

Python จะคำนวณ expression ทางขวาของ `return` แล้วส่งค่านั้นกลับไปยังผู้เรียก การใช้ `return` ทำให้ตรวจค่าได้โดยไม่ต้องอ่าน stdout

ข้อผิดพลาดที่พบบ่อย: ลืมกรณีข้อมูลว่างหรือหารด้วยศูนย์; สับสนระหว่างการคืนค่ากับการแสดงผล

ตัวอย่างผลลัพธ์: `[0.050000000000000044, -0.01904761904761909, 0.06796116504854366, -0.018181818181818188]`
