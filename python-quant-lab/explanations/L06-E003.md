# L06-E003 — เติมค่าจากข้อมูลก่อนหน้า

ฟังก์ชัน `fill_missing_from_previous` รับ `values` แล้วคืนค่าตามกติกาในโจทย์

อัลกอริทึม: `return [next((values[j] for j in range(i,-1,-1) if values[j] is not None),None) for i in range(len(values))]`

Python จะคำนวณ expression ทางขวาของ `return` แล้วส่งค่านั้นกลับไปยังผู้เรียก การใช้ `return` ทำให้ตรวจค่าได้โดยไม่ต้องอ่าน stdout

ข้อผิดพลาดที่พบบ่อย: ลืมกรณีข้อมูลว่างหรือหารด้วยศูนย์; สับสนระหว่างการคืนค่ากับการแสดงผล

ตัวอย่างผลลัพธ์: `[100, 105, 105, 110, 90]`
