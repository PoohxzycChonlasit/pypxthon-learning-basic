# L10-E007 — มูลค่าสถานะ paper

**บริบท:** ผู้ดูแลพอร์ตสรุป notional exposure ของคำสั่ง paper

**สัญญา:** คืน quantity*price โดย field ที่หายใช้ 0

**ขั้นตอน:** อ่าน quantity/price ด้วย default 0; คูณกัน

**กรณีขอบ:** quantity หรือ price ศูนย์ให้ exposure 0

โครงการนี้จำลอง offline paper เท่านั้น ไม่มี live order
