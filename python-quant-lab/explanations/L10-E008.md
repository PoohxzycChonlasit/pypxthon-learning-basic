# L10-E008 — ปรับรูปแบบสัญลักษณ์ตลาด

ฟังก์ชัน `market_event_symbol` รับ `event` แล้วคืนค่าตามกติกาในโจทย์

อัลกอริทึม: `return str(event.get('symbol','')).upper()`

Python จะคำนวณ expression ทางขวาของ `return` แล้วส่งค่านั้นกลับไปยังผู้เรียก การใช้ `return` ทำให้ตรวจค่าได้โดยไม่ต้องอ่าน stdout
