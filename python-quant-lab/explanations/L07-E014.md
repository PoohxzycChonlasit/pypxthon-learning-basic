# L07-E014 — ค่าเฉลี่ยเคลื่อนที่สามจุด

**ผู้ใช้และปัญหา:** นักวิเคราะห์ smooth series ด้วยค่าเฉลี่ยของหน้าต่างสามข้อมูลติดกัน

**สัญญา input/output:** คืนค่าเฉลี่ยสามจุดสำหรับทุกหน้าต่างเต็ม โดยเลื่อนไปครั้งละหนึ่ง

**คิดทีละขั้น:** เลือกสามค่าที่ index i-1,i,i+1; รวมแล้วหาร 3

**กรณีขอบ:** น้อยกว่าสามค่าให้คืน []; ผลลัพธ์ยาว n-2

**ตัวอย่าง:** rolling_mean([1, 2, 3, 4],) ให้ผล [2.0, 3.0]

ข้อควรระวัง: น้อยกว่าสามค่าให้คืน []; ผลลัพธ์ยาว n-2
