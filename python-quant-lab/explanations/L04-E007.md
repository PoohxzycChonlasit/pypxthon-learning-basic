# L04-E007 — ผลตอบแทนทบต้นรายปี

**ผู้ใช้และปัญหา:** นักวิเคราะห์แปลงผลตอบแทนต่อช่วงเป็นผลตอบแทนทบต้นหลายช่วง

**สัญญา:** รับ return ต่อช่วง r และจำนวนช่วง n; คืน (1+r)**n - 1

**แนวทาง:** สร้าง growth factor 1+r; ยกกำลัง n; ลบ 1

**กรณีขอบ:** สมมติ r > -1 และ n เป็นจำนวนเต็มไม่ติดลบ

**ตรวจด้วยตัวอย่าง:** annualized_simple_return(0.01, 12) ให้ผล 0.12682503013196977

ข้อควรระวัง: สมมติ r > -1 และ n เป็นจำนวนเต็มไม่ติดลบ
