# L07-E013 — ค่าเบี่ยงเบนสัมบูรณ์เฉลี่ย

ฟังก์ชัน `mean_absolute_deviation` รับ `values` แล้วคืนค่าตามกติกาในโจทย์

อัลกอริทึม: `return sum(abs(x-sum(values)/len(values)) for x in values)/len(values) if values else 0`

Python จะคำนวณ expression ทางขวาของ `return` แล้วส่งค่านั้นกลับไปยังผู้เรียก การใช้ `return` ทำให้ตรวจค่าได้โดยไม่ต้องอ่าน stdout

ข้อผิดพลาดที่พบบ่อย: ลืมกรณีข้อมูลว่างหรือหารด้วยศูนย์; สับสนระหว่างการคืนค่ากับการแสดงผล

ตัวอย่างผลลัพธ์: `1.0`
