# L07-E003 — เติมสูตร population variance

**ระดับ:** Level 7 — คณิตศาสตร์และสถิติ<br>
**ความยาก:** Tier 3 — ปานกลาง — หลายขั้นตอน<br>
**ชนิดคำตอบ:** โปรแกรม Python แสดงผล (stdout)

## 1. เรียนรู้อะไร

คำนวณค่าเฉลี่ยระยะห่างกำลังสองจาก mean

## 2. ก่อนเริ่ม

ทบทวน: [L07-E002](L07-E002.md). หากคำศัพท์ในโจทย์ยังไม่คุ้น ให้เริ่มจากคำอธิบายแนวคิดในหน้านี้ก่อน

**แนวคิดสำคัญ:** variance มีหน่วยเป็นกำลังสองของข้อมูลและวัดการกระจายรอบค่าเฉลี่ย

## 3. ตัวอย่างสั้น

ตัวอย่างนี้ฝึกแนวคิดที่เกี่ยวข้อง แต่ใช้ค่าและสถานการณ์แยกจากโจทย์ที่ต้องส่ง

~~~python
import csv
import io
rows = list(csv.DictReader(io.StringIO("sku,qty\nA1,2\n")))
print(rows[0]["sku"], int(rows[0]["qty"]))
~~~

ในตัวอย่างนี้ ให้ดูว่าคำสั่ง print ส่งค่าใดไปยังหน้าจอ; ข้อความหลังเครื่องหมาย # เป็นคำอธิบาย output ของตัวอย่าง

## 4. งานของคุณ

เติม population_variance(values) ตามนิยามประชากร: หาค่าเฉลี่ยก่อน จากนั้นเฉลี่ยค่า (x - mean) ** 2; คืน None เมื่อ list ว่าง รับตัวเลขคั่นด้วย comma
