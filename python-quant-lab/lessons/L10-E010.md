# L10-E010 — บันทึกผลคำสั่ง

**ระดับ:** Level 10 — วิศวกรรม paper bot ออฟไลน์<br>
**ความยาก:** Tier 2 — ง่าย — รวมแนวคิดคุ้นเคย<br>
**ชนิดคำตอบ:** เขียนฟังก์ชันและคืนค่าด้วย return

## 1. เรียนรู้อะไร

คืน dict ที่มี id จาก event, status="paper", live=False

## 2. ก่อนเริ่ม

ทบทวน: [L10-E009](L10-E009.md). หากคำศัพท์ในโจทย์ยังไม่คุ้น ให้เริ่มจากคำอธิบายแนวคิดในหน้านี้ก่อน

**แนวคิดสำคัญ:** แนวคิด: คืน dict ที่มี id จาก event, status="paper", live=False

ขั้นตอน: คัด id; เพิ่ม status คงที่; กำหนด live เป็น False

## 3. ตัวอย่างสั้น

ตัวอย่างนี้ฝึกแนวคิดที่เกี่ยวข้อง แต่ใช้ค่าและสถานการณ์แยกจากโจทย์ที่ต้องส่ง

~~~python
point = (3, 4)
x, y = point
print(x + y)
~~~

อ่าน arguments ที่ส่งให้ฟังก์ชันแล้วตามค่าที่ return; ถ้าไม่มี print การคืนค่าไม่ได้แสดงใน Terminal

## 4. งานของคุณ

สถานการณ์: ระบบ audit บันทึกผลคำสั่งเป็น event ที่ยืนยันว่าเป็น paper

เขียน record_order_result(event) ตามสัญญา: คืน dict ที่มี id จาก event, status="paper", live=False.

กรณีขอบ: id หายคืน None; live เป็น boolean False เสมอ.
ใช้ข้อมูลจำลองออฟไลน์เท่านั้นและคืนค่าตามโจทย์

## 5. เขียนคำตอบที่ไหน

ไฟล์ส่งคำตอบ: [exercises/level_10/L10-E010.py](../exercises/level_10/L10-E010.py)

แก้ฟังก์ชัน record_order_result(event) ในไฟล์นี้. คงชื่อและ signature ไว้ และคืนผลด้วย return

## 6. ลำดับทำงาน

1. อ่าน signature record_order_result(event) และดูว่า parameter แต่ละตัวรับข้อมูลอะไร
2. แก้เฉพาะ body ที่โจทย์กำหนด และส่งผลด้วย return
3. ตรวจกรณีขอบที่ระบุ โดยคงชื่อฟังก์ชันและ signature
4. ใช้ run ดูค่าคืนจากกรณีแรก แล้วใช้ check ตรวจ test ทั้งหมด

## 7. ข้อมูลเข้าและผลลัพธ์

- **ข้อมูลเข้า:** grader เรียก record_order_result ด้วย parameters ตาม signature ที่ให้.
- **ผลลัพธ์:** ฟังก์ชันต้องคืนค่า (dict มี key: id, status, live); return ส่งค่ากลับ ส่วน print แสดงข้อความ.
- **ชุดตรวจ:** มี 2 กรณี รวมขอบเขตตามโจทย์

ข้อจำกัดที่ต้องรักษา: Python 3.12; id หายคืน None; live เป็น boolean False เสมอ; ไม่มีการเชื่อมต่อ exchange หรือ wallet

## 8. Run และ Check

รันจากโฟลเดอร์โครงการที่มี practice.py:

~~~powershell
py -3.12 -B practice.py run L10-E010
py -3.12 -B practice.py check L10-E010
~~~

บน macOS Terminal ใช้ python3.12 แทน py -3.12:

~~~sh
python3.12 -B practice.py run L10-E010

~~~

การกด Run บนฟังก์ชันที่มีแต่ def อาจไม่แสดงอะไร เพราะยังไม่มีใครเรียกฟังก์ชัน; practice.py run เรียก test แรกให้ ส่วน check เรียกทุกกรณี

Run ทดลองกรณีตัวอย่างแรก; Check เปรียบเทียบกับทุกกรณีและบันทึกสถานะการเรียน

## 9. ถ้าไม่ผ่าน

สิ่งที่พลาดง่าย: id หายคืน None; live เป็น boolean False เสมอ ห้ามแปลงงานจำลองเป็นคำสั่งเงินจริง. ตรวจค่าที่คืนและชนิดของมันก่อนตรวจการแสดงผล

หากต้องการความช่วยเหลือหลังลองเอง ให้ใช้ py -3.12 -B practice.py hint L10-E010 1. คำใบ้และการเปิดเฉลยจะถูกบันทึกใน progress
