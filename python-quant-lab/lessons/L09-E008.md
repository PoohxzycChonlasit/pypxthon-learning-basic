# L09-E008 — หักต้นทุนไปกลับ

**ระดับ:** Level 9 — วิจัย Quant และ backtest<br>
**ความยาก:** Tier 3 — ปานกลาง — หลายขั้นตอน<br>
**ชนิดคำตอบ:** เขียนฟังก์ชันและคืนค่าด้วย return

## 1. เรียนรู้อะไร

รับ gross_returns และ round_trip_cost; คืน r-cost ต่อสมาชิก

## 2. ก่อนเริ่ม

ทบทวน: [L09-E007](L09-E007.md). หากคำศัพท์ในโจทย์ยังไม่คุ้น ให้เริ่มจากคำอธิบายแนวคิดในหน้านี้ก่อน

**แนวคิดสำคัญ:** แนวคิด: รับ gross_returns และ round_trip_cost; คืน r-cost ต่อสมาชิก

ขั้นตอน: ลบต้นทุนเดียวกันออกจากทุก return

## 3. ตัวอย่างสั้น

ตัวอย่างนี้ฝึกแนวคิดที่เกี่ยวข้อง แต่ใช้ค่าและสถานการณ์แยกจากโจทย์ที่ต้องส่ง

~~~python
from math import sqrt
print(sqrt(81))
~~~

อ่าน arguments ที่ส่งให้ฟังก์ชันแล้วตามค่าที่ return; ถ้าไม่มี print การคืนค่าไม่ได้แสดงใน Terminal

## 4. งานของคุณ

สถานการณ์: นักวิจัยหัก round-trip cost อัตราเดียวกันออกจาก gross return ทุกช่วง

เขียน subtract_round_trip_cost(gross_returns, round_trip_cost) ตามสัญญา: รับ gross_returns และ round_trip_cost; คืน r-cost ต่อสมาชิก.

กรณีขอบ: cost เป็นสัดส่วนไม่ใช่เงินสด; cost=0 ใช้ได้.
คืนค่าตามลำดับเวลาและอย่า shuffle time series

## 6. ลำดับทำงาน

1. อ่าน signature subtract_round_trip_cost(gross_returns, round_trip_cost) และดูว่า parameter แต่ละตัวรับข้อมูลอะไร
2. แก้เฉพาะ body ที่โจทย์กำหนด และส่งผลด้วย return
3. ตรวจกรณีขอบที่ระบุ โดยคงชื่อฟังก์ชันและ signature
4. ใช้ run ดูค่าคืนจากกรณีแรก แล้วใช้ check ตรวจ test ทั้งหมด

## 7. ข้อมูลเข้าและผลลัพธ์

- **ข้อมูลเข้า:** grader เรียก subtract_round_trip_cost ด้วย parameters ตาม signature ที่ให้.
- **ผลลัพธ์:** ฟังก์ชันต้องคืนค่า (list); return ส่งค่ากลับ ส่วน print แสดงข้อความ.
- **ชุดตรวจ:** มี 2 กรณี รวมขอบเขตตามโจทย์

ข้อจำกัดที่ต้องรักษา: Python 3.12; cost เป็นสัดส่วนไม่ใช่เงินสด; cost=0 ใช้ได้; time series เรียงตามเวลา; ห้ามใช้ข้อมูลอนาคตสร้างผลในอดีต
