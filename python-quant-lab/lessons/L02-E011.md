# L02-E011 — หยุดก่อนขาดทุนแรก

**ระดับ:** Level 2 — เงื่อนไขและลูป<br>
**ความยาก:** Tier 4 — ท้าทาย — เงื่อนไขและกรณีขอบ<br>
**ชนิดคำตอบ:** เขียนฟังก์ชันและคืนค่าด้วย return

## 1. เรียนรู้อะไร

คืนทุกค่าก่อนสมาชิกติดลบตัวแรก; ไม่รวมค่านั้น; หากไม่มีคืนทั้งหมด

## 2. ก่อนเริ่ม

ทบทวน: [L02-E010](L02-E010.md). หากคำศัพท์ในโจทย์ยังไม่คุ้น ให้เริ่มจากคำอธิบายแนวคิดในหน้านี้ก่อน

**แนวคิดสำคัญ:** แนวคิด: คืนทุกค่าก่อนสมาชิกติดลบตัวแรก; ไม่รวมค่านั้น; หากไม่มีคืนทั้งหมด

คิดทีละขั้น: ไล่จากซ้ายไปขวา; หยุดเมื่อพบค่าต่ำกว่า 0; คืนส่วนก่อนจุดหยุด

## 3. ตัวอย่างสั้น

ตัวอย่างนี้ฝึกแนวคิดที่เกี่ยวข้อง แต่ใช้ค่าและสถานการณ์แยกจากโจทย์ที่ต้องส่ง

~~~python
grades = [72, 88, 91]
print(sorted(grades))
~~~

อ่าน arguments ที่ส่งให้ฟังก์ชันแล้วตามค่าที่ return; ถ้าไม่มี print การคืนค่าไม่ได้แสดงใน Terminal

## 4. งานของคุณ

สถานการณ์: ระบบนำเข้าใบแจ้งหนี้หยุดอ่านเมื่อพบรายการขาดทุนตัวแรก

เขียน stop_at_first_loss(values) ให้ทำตามสัญญา: คืนทุกค่าก่อนสมาชิกติดลบตัวแรก; ไม่รวมค่านั้น; หากไม่มีคืนทั้งหมด.

กรณีขอบ: ศูนย์ไม่ใช่ขาดทุน; ถ้าค่าแรกติดลบคืน [].
ส่งค่ากลับด้วย return และรักษาชนิดผลลัพธ์ตามตัวอย่าง

## 5. เขียนคำตอบที่ไหน

ไฟล์ส่งคำตอบ: [exercises/level_02/L02-E011.py](../exercises/level_02/L02-E011.py)

แก้ฟังก์ชัน stop_at_first_loss(values) ในไฟล์นี้. คงชื่อและ signature ไว้ และคืนผลด้วย return

## 6. ลำดับทำงาน

1. อ่าน signature stop_at_first_loss(values) และดูว่า parameter แต่ละตัวรับข้อมูลอะไร
2. แก้เฉพาะ body ที่โจทย์กำหนด และส่งผลด้วย return
3. ตรวจกรณีขอบที่ระบุ โดยคงชื่อฟังก์ชันและ signature
4. ใช้ run ดูค่าคืนจากกรณีแรก แล้วใช้ check ตรวจ test ทั้งหมด

## 7. ข้อมูลเข้าและผลลัพธ์

- **ข้อมูลเข้า:** grader เรียก stop_at_first_loss ด้วย parameters ตาม signature ที่ให้.
- **ผลลัพธ์:** ฟังก์ชันต้องคืนค่า (list); return ส่งค่ากลับ ส่วน print แสดงข้อความ.
- **ชุดตรวจ:** มี 2 กรณี รวมขอบเขตตามโจทย์

ข้อจำกัดที่ต้องรักษา: Python 3.12; ศูนย์ไม่ใช่ขาดทุน; ถ้าค่าแรกติดลบคืน []; ใช้เฉพาะข้อมูลตามสัญญาโจทย์; ห้ามแก้ grader หรือเฉลย

## 8. Run และ Check

รันจากโฟลเดอร์โครงการที่มี practice.py:

~~~powershell
py -3.12 -B practice.py run L02-E011
py -3.12 -B practice.py check L02-E011
~~~

บน macOS Terminal ใช้ python3.12 แทน py -3.12:

~~~sh
python3.12 -B practice.py run L02-E011
python3.12 -B practice.py check L02-E011
~~~

การกด Run บนฟังก์ชันที่มีแต่ def อาจไม่แสดงอะไร เพราะยังไม่มีใครเรียกฟังก์ชัน; practice.py run เรียก test แรกให้ ส่วน check เรียกทุกกรณี

Run ทดลองกรณีตัวอย่างแรก; Check เปรียบเทียบกับทุกกรณีและบันทึกสถานะการเรียน

## 9. ถ้าไม่ผ่าน

สิ่งที่พลาดง่าย: ศูนย์ไม่ใช่ขาดทุน; ถ้าค่าแรกติดลบคืน [] ตรวจชนิดและลำดับของผลลัพธ์ก่อนคืนค่า. ตรวจค่าที่คืนและชนิดของมันก่อนตรวจการแสดงผล

หากต้องการความช่วยเหลือหลังลองเอง ให้ใช้ py -3.12 -B practice.py hint L02-E011 1. คำใบ้และการเปิดเฉลยจะถูกบันทึกใน progress
