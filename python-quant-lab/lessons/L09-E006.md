# L09-E006 — แบ่งข้อมูลตามเวลา

**ระดับ:** Level 9 — วิจัย Quant และ backtest<br>
**ความยาก:** Tier 2 — ง่าย — รวมแนวคิดคุ้นเคย<br>
**ชนิดคำตอบ:** เขียนฟังก์ชันและคืนค่าด้วย return

## 1. เรียนรู้อะไร

จุดตัด floor(2*n/3); คืน tuple (train,test) โดยไม่ shuffle

## 2. ก่อนเริ่ม

ทบทวน: [L09-E005](L09-E005.md). หากคำศัพท์ในโจทย์ยังไม่คุ้น ให้เริ่มจากคำอธิบายแนวคิดในหน้านี้ก่อน

**แนวคิดสำคัญ:** แนวคิด: จุดตัด floor(2*n/3); คืน tuple (train,test) โดยไม่ shuffle

ขั้นตอน: ใช้ len(values)*2//3 เป็น split index แล้ว slice สองช่วง

## 3. ตัวอย่างสั้น

ตัวอย่างนี้ฝึกแนวคิดที่เกี่ยวข้อง แต่ใช้ค่าและสถานการณ์แยกจากโจทย์ที่ต้องส่ง

~~~python
numbers = [7, 2, 7, 4]
unique = list(dict.fromkeys(numbers))
print(unique)
~~~

อ่าน arguments ที่ส่งให้ฟังก์ชันแล้วตามค่าที่ return; ถ้าไม่มี print การคืนค่าไม่ได้แสดงใน Terminal

## 4. งานของคุณ

สถานการณ์: นักวิจัยแบ่งข้อมูลเรียงตามเวลาเป็น train ช่วงแรก 2/3 และ test ที่เหลือ

เขียน split_chronological_data(values) ตามสัญญา: จุดตัด floor(2*n/3); คืน tuple (train,test) โดยไม่ shuffle.

กรณีขอบ: รักษาลำดับ; test อาจว่างในชุดเล็ก.
คืนค่าตามลำดับเวลาและอย่า shuffle time series

## 6. ลำดับทำงาน

1. อ่าน signature split_chronological_data(values) และดูว่า parameter แต่ละตัวรับข้อมูลอะไร

4. ใช้ run ดูค่าคืนจากกรณีแรก แล้วใช้ check ตรวจ test ทั้งหมด

## 7. ข้อมูลเข้าและผลลัพธ์

- **ข้อมูลเข้า:** grader เรียก split_chronological_data ด้วย parameters ตาม signature ที่ให้.
- **ผลลัพธ์:** ฟังก์ชันต้องคืนค่า (list); return ส่งค่ากลับ ส่วน print แสดงข้อความ.
- **ชุดตรวจ:** มี 2 กรณี รวมขอบเขตตามโจทย์
