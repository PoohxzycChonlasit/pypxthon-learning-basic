# L01-E006 — สร้างป้ายราคาด้วย f-string

## เป้าหมาย

แทรกค่าตัวแปรลงในข้อความ

## แนวคิด

f-string เริ่มด้วย `f` ก่อนเครื่องหมายคำพูด ค่าตัวแปรภายใน `{}` จะถูกแทนด้วยค่าจริง

## ตัวอย่าง

```python
asset = "BTC"
print(f"Asset: {asset}")
```

## โจทย์

สร้างตัวแปร asset เป็น `BTC` และ price เป็น 10 จากนั้นแสดง `BTC price: 10` ด้วย f-string

## รูปแบบ input/output

asset=BTC, price=10

ผลที่ต้องการ: BTC price: 10

ข้อควรระวัง: ลืม f หน้า string หรือใช้วงเล็บผิด
