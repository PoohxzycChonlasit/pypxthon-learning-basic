# L05-E012 — แยกบรรทัดข้อมูล

**ระดับ:** Level 5 — Python สำหรับงานจริง<br>
**ความยาก:** Tier 3 — ปานกลาง — หลายขั้นตอน<br>
**ชนิดคำตอบ:** เขียนฟังก์ชันและคืนค่าด้วย return

## 1. เรียนรู้อะไร

ตัด whitespace รอบนอกแล้วใช้ splitlines; เก็บบรรทัดภายในตามลำดับ

## 2. ก่อนเริ่ม

ทบทวน: [L05-E011](L05-E011.md). หากคำศัพท์ในโจทย์ยังไม่คุ้น ให้เริ่มจากคำอธิบายแนวคิดในหน้านี้ก่อน

**แนวคิดสำคัญ:** แนวคิด: ตัด whitespace รอบนอกแล้วใช้ splitlines; เก็บบรรทัดภายในตามลำดับ

ลำดับคิด: ตรวจข้อความว่างก่อน; strip รอบนอก; splitlines

## 3. ตัวอย่างสั้น

ตัวอย่างนี้ฝึกแนวคิดที่เกี่ยวข้อง แต่ใช้ค่าและสถานการณ์แยกจากโจทย์ที่ต้องส่ง

~~~python
person = {"name": "Mali", "active": True}
print(person.get("active", False))
~~~

อ่าน arguments ที่ส่งให้ฟังก์ชันแล้วตามค่าที่ return; ถ้าไม่มี print การคืนค่าไม่ได้แสดงใน Terminal

## 4. งานของคุณ

สถานการณ์: ผู้ดูแลระบบแยกข้อความหลายบรรทัดเป็น record โดยไม่เก็บบรรทัดว่างรอบนอก

เขียน encode_record_lines(text) ตามกติกา: ตัด whitespace รอบนอกแล้วใช้ splitlines; เก็บบรรทัดภายในตามลำดับ.

กรณีขอบ: ข้อความว่างคืน []; blank line ที่อยู่กลางข้อมูลยังคงอยู่.
ส่งค่ากลับด้วย return และอย่าแก้ input ต้นฉบับ

## 5. เขียนคำตอบที่ไหน

ไฟล์ส่งคำตอบ: [exercises/level_05/L05-E012.py](../exercises/level_05/L05-E012.py)

แก้ฟังก์ชัน encode_record_lines(text) ในไฟล์นี้. คงชื่อและ signature ไว้ และคืนผลด้วย return

## 6. ลำดับทำงาน

1. อ่าน signature encode_record_lines(text) และดูว่า parameter แต่ละตัวรับข้อมูลอะไร
2. แก้เฉพาะ body ที่โจทย์กำหนด และส่งผลด้วย return
3. ตรวจกรณีขอบที่ระบุ โดยคงชื่อฟังก์ชันและ signature
4. ใช้ run ดูค่าคืนจากกรณีแรก แล้วใช้ check ตรวจ test ทั้งหมด

## 7. ข้อมูลเข้าและผลลัพธ์

- **ข้อมูลเข้า:** grader เรียก encode_record_lines ด้วย parameters ตาม signature ที่ให้.
- **ผลลัพธ์:** ฟังก์ชันต้องคืนค่า (list); return ส่งค่ากลับ ส่วน print แสดงข้อความ.
- **ชุดตรวจ:** มี 2 กรณี รวมขอบเขตตามโจทย์

ข้อจำกัดที่ต้องรักษา: Python 3.12; ข้อความว่างคืน []; blank line ที่อยู่กลางข้อมูลยังคงอยู่; ใช้ข้อมูลตามรูปแบบที่ระบุในโจทย์; output ต้องตรงทั้งชนิดและลำดับ
