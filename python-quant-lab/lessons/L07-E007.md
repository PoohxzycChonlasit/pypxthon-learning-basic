# L07-E007 — ผลคาดหมายต่อรายการ

**ระดับ:** Level 7 — คณิตศาสตร์และสถิติ<br>
**ความยาก:** Tier 3 — ปานกลาง — หลายขั้นตอน<br>
**ชนิดคำตอบ:** เขียนฟังก์ชันและคืนค่าด้วย return

## 1. เรียนรู้อะไร

รับ win_probability, average_win, average_loss; คำนวณ p*win + (1-p)*loss; loss เป็นค่าลบ

## 2. ก่อนเริ่ม

ทบทวน: [L07-E006](L07-E006.md). หากคำศัพท์ในโจทย์ยังไม่คุ้น ให้เริ่มจากคำอธิบายแนวคิดในหน้านี้ก่อน

**แนวคิดสำคัญ:** แนวคิด: รับ win_probability, average_win, average_loss; คำนวณ p*win + (1-p)*loss; loss เป็นค่าลบ

ลำดับคิด: คำนวณโอกาสแพ้ 1-p; คูณผลลัพธ์แต่ละกรณีด้วยโอกาส; รวมสองส่วน

## 3. ตัวอย่างสั้น

ตัวอย่างนี้ฝึกแนวคิดที่เกี่ยวข้อง แต่ใช้ค่าและสถานการณ์แยกจากโจทย์ที่ต้องส่ง

~~~python
from math import sqrt
print(sqrt(81))
~~~

อ่าน arguments ที่ส่งให้ฟังก์ชันแล้วตามค่าที่ return; ถ้าไม่มี print การคืนค่าไม่ได้แสดงใน Terminal

## 4. งานของคุณ

สถานการณ์: นักวิจัยคำนวณผลคาดหมายต่อรายการจากโอกาสชนะและผลเฉลี่ย. เขียน expected_trade_result(win_probability, average_win, average_loss) ให้ใช้ input ทั้งสามค่าและคืน expected value

## 5. เขียนคำตอบที่ไหน

ไฟล์ส่งคำตอบ: [exercises/level_07/L07-E007.py](../exercises/level_07/L07-E007.py)

แก้ฟังก์ชัน expected_trade_result(win_probability, average_win, average_loss) ในไฟล์นี้. คงชื่อและ signature ไว้ และคืนผลด้วย return

## 6. ลำดับทำงาน

1. อ่าน signature expected_trade_result(win_probability, average_win, average_loss) และดูว่า parameter แต่ละตัวรับข้อมูลอะไร
2. แก้เฉพาะ body ที่โจทย์กำหนด และส่งผลด้วย return
3. ตรวจกรณีขอบที่ระบุ โดยคงชื่อฟังก์ชันและ signature
4. ใช้ run ดูค่าคืนจากกรณีแรก แล้วใช้ check ตรวจ test ทั้งหมด

## 7. ข้อมูลเข้าและผลลัพธ์

- **ข้อมูลเข้า:** grader เรียก expected_trade_result ด้วย parameters ตาม signature ที่ให้.
- **ผลลัพธ์:** ฟังก์ชันต้องคืนค่า (float); return ส่งค่ากลับ ส่วน print แสดงข้อความ.
- **ชุดตรวจ:** มี 2 กรณี รวมขอบเขตตามโจทย์

ข้อจำกัดที่ต้องรักษา: Python 3.12; p อยู่ระหว่าง 0 ถึง 1; p=0 คืน average_loss; p=1 คืน average_win; ใช้ข้อมูลตามรูปแบบที่ระบุในโจทย์; output ต้องตรงทั้งชนิดและลำดับ
