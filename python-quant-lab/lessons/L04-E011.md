# L04-E011 — ประกอบการคูณและบวก

**ระดับ:** Level 4 — ฟังก์ชันและโมดูล<br>
**ความยาก:** Tier 2 — ง่าย — รวมแนวคิดคุ้นเคย<br>
**ชนิดคำตอบ:** เขียนฟังก์ชันและคืนค่าด้วย return

## 1. เรียนรู้อะไร

คืน value*2 + offset; ทำการคูณก่อนการบวก

## 2. ก่อนเริ่ม

ทบทวน: [L04-E010](L04-E010.md). หากคำศัพท์ในโจทย์ยังไม่คุ้น ให้เริ่มจากคำอธิบายแนวคิดในหน้านี้ก่อน

**แนวคิดสำคัญ:** แนวคิด: คืน value*2 + offset; ทำการคูณก่อนการบวก

คิดทีละขั้น: คูณพารามิเตอร์แรกด้วย 2 แล้วบวกพารามิเตอร์ที่สอง

## 3. ตัวอย่างสั้น

ตัวอย่างนี้ฝึกแนวคิดที่เกี่ยวข้อง แต่ใช้ค่าและสถานการณ์แยกจากโจทย์ที่ต้องส่ง

~~~python
numbers = [7, 2, 7, 4]
unique = list(dict.fromkeys(numbers))
print(unique)
~~~

อ่าน arguments ที่ส่งให้ฟังก์ชันแล้วตามค่าที่ return; ถ้าไม่มี print การคืนค่าไม่ได้แสดงใน Terminal

## 4. งานของคุณ

สถานการณ์: ทีมบัญชีปรับยอดด้วยการคูณสองก่อนบวกค่าชดเชย

เขียน compose_scale_and_offset(x, y) ให้ทำตามสัญญา: คืน value*2 + offset; ทำการคูณก่อนการบวก.

กรณีขอบ: offset ติดลบใช้ลดผลลัพธ์ได้.
ส่งค่ากลับด้วย return และรักษาชนิดผลลัพธ์ตามตัวอย่าง

## 5. เขียนคำตอบที่ไหน

ไฟล์ส่งคำตอบ: [exercises/level_04/L04-E011.py](../exercises/level_04/L04-E011.py)

แก้ฟังก์ชัน compose_scale_and_offset(x, y) ในไฟล์นี้. คงชื่อและ signature ไว้ และคืนผลด้วย return

## 6. ลำดับทำงาน

1. อ่าน signature compose_scale_and_offset(x, y) และดูว่า parameter แต่ละตัวรับข้อมูลอะไร
2. แก้เฉพาะ body ที่โจทย์กำหนด และส่งผลด้วย return
3. ตรวจกรณีขอบที่ระบุ โดยคงชื่อฟังก์ชันและ signature
4. ใช้ run ดูค่าคืนจากกรณีแรก แล้วใช้ check ตรวจ test ทั้งหมด

## 7. ข้อมูลเข้าและผลลัพธ์

- **ข้อมูลเข้า:** grader เรียก compose_scale_and_offset ด้วย parameters ตาม signature ที่ให้.
- **ผลลัพธ์:** ฟังก์ชันต้องคืนค่า (int); return ส่งค่ากลับ ส่วน print แสดงข้อความ.
- **ชุดตรวจ:** มี 2 กรณี รวมขอบเขตตามโจทย์

ข้อจำกัดที่ต้องรักษา: Python 3.12; offset ติดลบใช้ลดผลลัพธ์ได้; ใช้เฉพาะข้อมูลตามสัญญาโจทย์; ห้ามแก้ grader หรือเฉลย

## 9. ถ้าไม่ผ่าน

สิ่งที่พลาดง่าย: offset ติดลบใช้ลดผลลัพธ์ได้ ตรวจชนิดและลำดับของผลลัพธ์ก่อนคืนค่า. ตรวจค่าที่คืนและชนิดของมันก่อนตรวจการแสดงผล
