# L07-E012 — นับค่าที่สูงกว่ามัธยฐาน

**ระดับ:** Level 7 — คณิตศาสตร์และสถิติ<br>
**ความยาก:** Tier 4 — ท้าทาย — เงื่อนไขและกรณีขอบ<br>
**ชนิดคำตอบ:** เขียนฟังก์ชันและคืนค่าด้วย return

## 1. เรียนรู้อะไร

คำนวณ median แบบมาตรฐาน; เมื่อ n เป็นเลขคู่ใช้ค่าเฉลี่ยของสองค่ากลาง; นับสมาชิกที่ > median

## 2. ก่อนเริ่ม

ทบทวน: [L07-E011](L07-E011.md). หากคำศัพท์ในโจทย์ยังไม่คุ้น ให้เริ่มจากคำอธิบายแนวคิดในหน้านี้ก่อน

**แนวคิดสำคัญ:** แนวคิด: คำนวณ median แบบมาตรฐาน; เมื่อ n เป็นเลขคู่ใช้ค่าเฉลี่ยของสองค่ากลาง; นับสมาชิกที่ > median

ลำดับคิด: เรียงข้อมูลเพื่อหา median; นับสมาชิกเดิมที่มากกว่า median

## 3. ตัวอย่างสั้น

ตัวอย่างนี้ฝึกแนวคิดที่เกี่ยวข้อง แต่ใช้ค่าและสถานการณ์แยกจากโจทย์ที่ต้องส่ง

~~~python
for step in range(3):
    print("step", step + 1)
~~~

อ่าน arguments ที่ส่งให้ฟังก์ชันแล้วตามค่าที่ return; ถ้าไม่มี print การคืนค่าไม่ได้แสดงใน Terminal

## 4. งานของคุณ

สถานการณ์: นักวิเคราะห์นับค่าที่สูงกว่ามัธยฐานทางสถิติของชุดข้อมูล

เขียน count_above_median(values) ตามกติกา: คำนวณ median แบบมาตรฐาน; เมื่อ n เป็นเลขคู่ใช้ค่าเฉลี่ยของสองค่ากลาง; นับสมาชิกที่ > median.

กรณีขอบ: ข้อมูลว่างคืน 0; ค่าที่เท่ามัธยฐานไม่นับ.
ส่งค่ากลับด้วย return และอย่าแก้ input ต้นฉบับ

## 7. ข้อมูลเข้าและผลลัพธ์

- **ข้อมูลเข้า:** grader เรียก count_above_median ด้วย parameters ตาม signature ที่ให้.
