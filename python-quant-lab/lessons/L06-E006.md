# L06-E006 — นับค่าที่หายไป

**ระดับ:** Level 6 — วิเคราะห์ข้อมูล<br>
**ความยาก:** Tier 2 — ง่าย — รวมแนวคิดคุ้นเคย<br>
**ชนิดคำตอบ:** เขียนฟังก์ชันและคืนค่าด้วย return

## 1. เรียนรู้อะไร

คืนจำนวนสมาชิกที่เป็น None โดยไม่ถือ 0 หรือ chuỗi ว่างเป็น missing

## 2. ก่อนเริ่ม

ทบทวน: [L06-E005](L06-E005.md). หากคำศัพท์ในโจทย์ยังไม่คุ้น ให้เริ่มจากคำอธิบายแนวคิดในหน้านี้ก่อน

**แนวคิดสำคัญ:** แนวคิด: คืนจำนวนสมาชิกที่เป็น None โดยไม่ถือ 0 หรือ chuỗi ว่างเป็น missing

ลำดับคิด: วนค่าและนับเฉพาะค่า is None

## 3. ตัวอย่างสั้น

ตัวอย่างนี้ฝึกแนวคิดที่เกี่ยวข้อง แต่ใช้ค่าและสถานการณ์แยกจากโจทย์ที่ต้องส่ง

~~~python
def add_tip(total, rate=0.05):
    return total + total * rate
print(add_tip(80))
~~~

อ่าน arguments ที่ส่งให้ฟังก์ชันแล้วตามค่าที่ return; ถ้าไม่มี print การคืนค่าไม่ได้แสดงใน Terminal

## 4. งานของคุณ

สถานการณ์: นักวิเคราะห์คุณภาพข้อมูลนับช่องที่ไม่มีค่าจากการนำเข้า CSV

เขียน count_missing_values(values) ตามกติกา: คืนจำนวนสมาชิกที่เป็น None โดยไม่ถือ 0 หรือ chuỗi ว่างเป็น missing.

กรณีขอบ: list ว่างคืน 0; zero เป็นข้อมูลจริง.
ส่งค่ากลับด้วย return และอย่าแก้ input ต้นฉบับ

3. ตรวจกรณีขอบที่ระบุ โดยคงชื่อฟังก์ชันและ signature
4. ใช้ run ดูค่าคืนจากกรณีแรก แล้วใช้ check ตรวจ test ทั้งหมด

## 7. ข้อมูลเข้าและผลลัพธ์

- **ข้อมูลเข้า:** grader เรียก count_missing_values ด้วย parameters ตาม signature ที่ให้.
- **ผลลัพธ์:** ฟังก์ชันต้องคืนค่า (int); return ส่งค่ากลับ ส่วน print แสดงข้อความ.
