# L06-E013 — ค่าสูงสุดเคลื่อนที่

**ระดับ:** Level 6 — วิเคราะห์ข้อมูล<br>
**ความยาก:** Tier 3 — ปานกลาง — หลายขั้นตอน<br>
**ชนิดคำตอบ:** เขียนฟังก์ชันและคืนค่าด้วย return

## 1. เรียนรู้อะไร

คืน max ของทุกคู่ติดกันที่ทั้งสองค่าไม่ใช่ None; ข้ามคู่ที่มี missing

## 2. ก่อนเริ่ม

ทบทวน: [L06-E012](L06-E012.md). หากคำศัพท์ในโจทย์ยังไม่คุ้น ให้เริ่มจากคำอธิบายแนวคิดในหน้านี้ก่อน

**แนวคิดสำคัญ:** แนวคิด: คืน max ของทุกคู่ติดกันที่ทั้งสองค่าไม่ใช่ None; ข้ามคู่ที่มี missing

ลำดับคิด: จับคู่ adjacent values; กรองคู่ที่มี None; เพิ่ม max ของคู่ที่เหลือ

## 3. ตัวอย่างสั้น

ตัวอย่างนี้ฝึกแนวคิดที่เกี่ยวข้อง แต่ใช้ค่าและสถานการณ์แยกจากโจทย์ที่ต้องส่ง

~~~python
grades = [72, 88, 91]
print(sorted(grades))
~~~

อ่าน arguments ที่ส่งให้ฟังก์ชันแล้วตามค่าที่ return; ถ้าไม่มี print การคืนค่าไม่ได้แสดงใน Terminal

## 4. งานของคุณ

สถานการณ์: ทีมสังเกตการณ์คำนวณค่าสูงสุดในหน้าต่างสองแถวที่เลื่อนไปทีละแถว

เขียน rolling_maximum(values) ตามกติกา: คืน max ของทุกคู่ติดกันที่ทั้งสองค่าไม่ใช่ None; ข้ามคู่ที่มี missing.

กรณีขอบ: ใช้หน้าต่างกว้าง 2; ข้อมูลน้อยกว่าสองค่าคืน [].
ส่งค่ากลับด้วย return และอย่าแก้ input ต้นฉบับ

## 5. เขียนคำตอบที่ไหน

ไฟล์ส่งคำตอบ: [exercises/level_06/L06-E013.py](../exercises/level_06/L06-E013.py)

แก้ฟังก์ชัน rolling_maximum(values) ในไฟล์นี้. คงชื่อและ signature ไว้ และคืนผลด้วย return

## 6. ลำดับทำงาน

1. อ่าน signature rolling_maximum(values) และดูว่า parameter แต่ละตัวรับข้อมูลอะไร
2. แก้เฉพาะ body ที่โจทย์กำหนด และส่งผลด้วย return
3. ตรวจกรณีขอบที่ระบุ โดยคงชื่อฟังก์ชันและ signature
4. ใช้ run ดูค่าคืนจากกรณีแรก แล้วใช้ check ตรวจ test ทั้งหมด

## 7. ข้อมูลเข้าและผลลัพธ์

- **ข้อมูลเข้า:** grader เรียก rolling_maximum ด้วย parameters ตาม signature ที่ให้.
- **ผลลัพธ์:** ฟังก์ชันต้องคืนค่า (list); return ส่งค่ากลับ ส่วน print แสดงข้อความ.
- **ชุดตรวจ:** มี 2 กรณี รวมขอบเขตตามโจทย์

ข้อจำกัดที่ต้องรักษา: Python 3.12; ใช้หน้าต่างกว้าง 2; ข้อมูลน้อยกว่าสองค่าคืน []; ใช้ข้อมูลตามรูปแบบที่ระบุในโจทย์; output ต้องตรงทั้งชนิดและลำดับ
