# L03-E006 — ตารางความถี่

**ระดับ:** Level 3 — โครงสร้างข้อมูล<br>
**ความยาก:** Tier 2 — ง่าย — รวมแนวคิดคุ้นเคย<br>
**ชนิดคำตอบ:** เขียนฟังก์ชันและคืนค่าด้วย return

## 1. เรียนรู้อะไร

คืน dict ที่ key เป็นสมาชิกและ value เป็นจำนวนครั้งที่พบ

## 2. ก่อนเริ่ม

ทบทวน: [L03-E005](L03-E005.md). หากคำศัพท์ในโจทย์ยังไม่คุ้น ให้เริ่มจากคำอธิบายแนวคิดในหน้านี้ก่อน

**แนวคิดสำคัญ:** แนวคิด: คืน dict ที่ key เป็นสมาชิกและ value เป็นจำนวนครั้งที่พบ

คิดทีละขั้น: เริ่ม dict ว่าง; ใช้ get(key,0) แล้วเพิ่มตัวนับหนึ่งเมื่อพบสมาชิก

## 3. ตัวอย่างสั้น

ตัวอย่างนี้ฝึกแนวคิดที่เกี่ยวข้อง แต่ใช้ค่าและสถานการณ์แยกจากโจทย์ที่ต้องส่ง

~~~python
text = "  offline paper  "
print(text.strip().upper())
~~~

อ่าน arguments ที่ส่งให้ฟังก์ชันแล้วตามค่าที่ return; ถ้าไม่มี print การคืนค่าไม่ได้แสดงใน Terminal

## 4. งานของคุณ

สถานการณ์: ร้านค้าออนไลน์สรุปจำนวนครั้งที่แต่ละ SKU ปรากฏในคำสั่งซื้อ

เขียน frequency_table(items) ให้ทำตามสัญญา: คืน dict ที่ key เป็นสมาชิกและ value เป็นจำนวนครั้งที่พบ.

กรณีขอบ: list ว่างคืน {}; key ที่พบหนึ่งครั้งมีค่า 1.
ส่งค่ากลับด้วย return และรักษาชนิดผลลัพธ์ตามตัวอย่าง

## 5. เขียนคำตอบที่ไหน

ไฟล์ส่งคำตอบ: [exercises/level_03/L03-E006.py](../exercises/level_03/L03-E006.py)

แก้ฟังก์ชัน frequency_table(items) ในไฟล์นี้. คงชื่อและ signature ไว้ และคืนผลด้วย return

## 6. ลำดับทำงาน

1. อ่าน signature frequency_table(items) และดูว่า parameter แต่ละตัวรับข้อมูลอะไร
2. แก้เฉพาะ body ที่โจทย์กำหนด และส่งผลด้วย return
3. ตรวจกรณีขอบที่ระบุ โดยคงชื่อฟังก์ชันและ signature
4. ใช้ run ดูค่าคืนจากกรณีแรก แล้วใช้ check ตรวจ test ทั้งหมด

## 7. ข้อมูลเข้าและผลลัพธ์

- **ข้อมูลเข้า:** grader เรียก frequency_table ด้วย parameters ตาม signature ที่ให้.
- **ผลลัพธ์:** ฟังก์ชันต้องคืนค่า (dict มี key: tea, rice); return ส่งค่ากลับ ส่วน print แสดงข้อความ.
- **ชุดตรวจ:** มี 2 กรณี รวมขอบเขตตามโจทย์

ข้อจำกัดที่ต้องรักษา: Python 3.12; list ว่างคืน {}; key ที่พบหนึ่งครั้งมีค่า 1; ใช้เฉพาะข้อมูลตามสัญญาโจทย์; ห้ามแก้ grader หรือเฉลย

## 8. Run และ Check

รันจากโฟลเดอร์โครงการที่มี practice.py:

Run ทดลองกรณีตัวอย่างแรก; Check เปรียบเทียบกับทุกกรณีและบันทึกสถานะการเรียน

## 9. ถ้าไม่ผ่าน
