# L01-E011 — เขียนโปรแกรมคำนวณกำไร BTC

## เป้าหมาย

ใช้ float, input และสูตรกำไรขั้นต้น

## แนวคิด

กำไรขั้นต้นของสถานะซื้อเท่ากับ (ราคาขาย - ราคาซื้อ) * จำนวน BTC ใช้ float กับราคาและจำนวนทศนิยม

## ตัวอย่าง

```python
ticket_cost = 40
ticket_refund = 43
tickets = 2
gain = (ticket_refund - ticket_cost) * tickets
print(f"{gain:.2f}")  # 6.00
```

## โจทย์

อ่านราคาซื้อ ราคาขาย และจำนวน BTC ทีละบรรทัด แล้วแสดงกำไรขั้นต้นเป็นทศนิยมสองตำแหน่ง ไม่รวมค่าธรรมเนียม

## รูปแบบ input/output

ซื้อ 60000 ขาย 61000 จำนวน 0.01 แสดง 10.00

ผลที่ต้องการ: (ราคาขาย - ราคาซื้อ) * จำนวน BTC

ข้อควรระวัง: ลืมคูณจำนวน BTC หรือสลับราคาซื้อกับราคาขาย
