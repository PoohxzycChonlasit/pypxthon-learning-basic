# L10-E013 — กู้คืนยอดเงินสด

**ระดับ:** Level 10 — วิศวกรรม paper bot ออฟไลน์<br>
**ความยาก:** Tier 2 — ง่าย — รวมแนวคิดคุ้นเคย<br>
**ชนิดคำตอบ:** เขียนฟังก์ชันและคืนค่าด้วย return

## 1. เรียนรู้อะไร

คืน cash ถ้าเป็น finite number >=0 มิฉะนั้นคืน 100.0

## 2. ก่อนเริ่ม

ทบทวน: [L10-E012](L10-E012.md). หากคำศัพท์ในโจทย์ยังไม่คุ้น ให้เริ่มจากคำอธิบายแนวคิดในหน้านี้ก่อน

**แนวคิดสำคัญ:** แนวคิด: คืน cash ถ้าเป็น finite number >=0 มิฉะนั้นคืน 100.0

ขั้นตอน: ตรวจชนิดและ isfinite; รับค่าที่ไม่ติดลบ; fallback เป็น 100.0 เมื่อผิดเงื่อนไข

## 3. ตัวอย่างสั้น

ตัวอย่างนี้ฝึกแนวคิดที่เกี่ยวข้อง แต่ใช้ค่าและสถานการณ์แยกจากโจทย์ที่ต้องส่ง

~~~python
raw = "  25 "
amount = int(raw.strip())
print(amount + 5)
~~~

อ่าน arguments ที่ส่งให้ฟังก์ชันแล้วตามค่าที่ return; ถ้าไม่มี print การคืนค่าไม่ได้แสดงใน Terminal

## 4. งานของคุณ

สถานการณ์: บอทกู้คืนเงินสดจาก state ที่บันทึกไว้และใช้ bankroll 100 เมื่อข้อมูลเสีย

เขียน restore_cash_state(event) ตามสัญญา: คืน cash ถ้าเป็น finite number >=0 มิฉะนั้นคืน 100.0.

กรณีขอบ: cash=0 เป็นค่าถูกต้อง; ปฏิเสธ bool, string, NaN, infinity และค่าลบ.
ใช้ข้อมูลจำลองออฟไลน์เท่านั้นและคืนค่าตามโจทย์

## 5. เขียนคำตอบที่ไหน

ไฟล์ส่งคำตอบ: [exercises/level_10/L10-E013.py](../exercises/level_10/L10-E013.py)

แก้ฟังก์ชัน restore_cash_state(event) ในไฟล์นี้. คงชื่อและ signature ไว้ และคืนผลด้วย return

## 6. ลำดับทำงาน

1. อ่าน signature restore_cash_state(event) และดูว่า parameter แต่ละตัวรับข้อมูลอะไร
2. แก้เฉพาะ body ที่โจทย์กำหนด และส่งผลด้วย return
3. ตรวจกรณีขอบที่ระบุ โดยคงชื่อฟังก์ชันและ signature
4. ใช้ run ดูค่าคืนจากกรณีแรก แล้วใช้ check ตรวจ test ทั้งหมด

## 7. ข้อมูลเข้าและผลลัพธ์

- **ข้อมูลเข้า:** grader เรียก restore_cash_state ด้วย parameters ตาม signature ที่ให้.
- **ผลลัพธ์:** ฟังก์ชันต้องคืนค่า (float); return ส่งค่ากลับ ส่วน print แสดงข้อความ.
- **ชุดตรวจ:** มี 2 กรณี รวมขอบเขตตามโจทย์

ข้อจำกัดที่ต้องรักษา: Python 3.12; cash=0 เป็นค่าถูกต้อง; ปฏิเสธ bool, string, NaN, infinity และค่าลบ; ไม่มีการเชื่อมต่อ exchange หรือ wallet
