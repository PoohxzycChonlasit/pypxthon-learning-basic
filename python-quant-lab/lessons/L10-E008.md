# L10-E008 — ปรับรูปแบบสัญลักษณ์ตลาด

**ระดับ:** Level 10 — วิศวกรรม paper bot ออฟไลน์<br>
**ความยาก:** Tier 2 — ง่าย — รวมแนวคิดคุ้นเคย<br>
**ชนิดคำตอบ:** เขียนฟังก์ชันและคืนค่าด้วย return

## 1. เรียนรู้อะไร

คืน symbol แบบ string ที่ตัดช่องว่างแล้วทำ uppercase

## 2. ก่อนเริ่ม

ทบทวน: [L10-E007](L10-E007.md). หากคำศัพท์ในโจทย์ยังไม่คุ้น ให้เริ่มจากคำอธิบายแนวคิดในหน้านี้ก่อน

**แนวคิดสำคัญ:** แนวคิด: คืน symbol แบบ string ที่ตัดช่องว่างแล้วทำ uppercase

ขั้นตอน: อ่าน symbol ด้วย default; แปลงค่าที่มีเป็น str; strip แล้ว upper

## 3. ตัวอย่างสั้น

ตัวอย่างนี้ฝึกแนวคิดที่เกี่ยวข้อง แต่ใช้ค่าและสถานการณ์แยกจากโจทย์ที่ต้องส่ง

~~~python
def add_tip(total, rate=0.05):
    return total + total * rate
print(add_tip(80))
~~~

อ่าน arguments ที่ส่งให้ฟังก์ชันแล้วตามค่าที่ return; ถ้าไม่มี print การคืนค่าไม่ได้แสดงใน Terminal

## 4. งานของคุณ

สถานการณ์: ระบบรวม event จากหลายไฟล์ทำชื่อ symbol ให้เป็นรูปแบบมาตรฐาน

เขียน market_event_symbol(event) ตามสัญญา: คืน symbol แบบ string ที่ตัดช่องว่างแล้วทำ uppercase.

กรณีขอบ: ไม่มี symbol หรือ None คืน ""; None ไม่กลายเป็น "NONE".
ใช้ข้อมูลจำลองออฟไลน์เท่านั้นและคืนค่าตามโจทย์

## 5. เขียนคำตอบที่ไหน

ไฟล์ส่งคำตอบ: [exercises/level_10/L10-E008.py](../exercises/level_10/L10-E008.py)

แก้ฟังก์ชัน market_event_symbol(event) ในไฟล์นี้. คงชื่อและ signature ไว้ และคืนผลด้วย return

## 6. ลำดับทำงาน

1. อ่าน signature market_event_symbol(event) และดูว่า parameter แต่ละตัวรับข้อมูลอะไร
2. แก้เฉพาะ body ที่โจทย์กำหนด และส่งผลด้วย return
3. ตรวจกรณีขอบที่ระบุ โดยคงชื่อฟังก์ชันและ signature
4. ใช้ run ดูค่าคืนจากกรณีแรก แล้วใช้ check ตรวจ test ทั้งหมด

## 7. ข้อมูลเข้าและผลลัพธ์

- **ข้อมูลเข้า:** grader เรียก market_event_symbol ด้วย parameters ตาม signature ที่ให้.
- **ผลลัพธ์:** ฟังก์ชันต้องคืนค่า (ข้อความ (str)); return ส่งค่ากลับ ส่วน print แสดงข้อความ.
- **ชุดตรวจ:** มี 2 กรณี รวมขอบเขตตามโจทย์

ข้อจำกัดที่ต้องรักษา: Python 3.12; ไม่มี symbol หรือ None คืน ""; None ไม่กลายเป็น "NONE"; ไม่มีการเชื่อมต่อ exchange หรือ wallet

## 9. ถ้าไม่ผ่าน
