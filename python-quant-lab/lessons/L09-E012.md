# L09-E012 — ปฏิเสธผลทดสอบติดลบ

**ระดับ:** Level 9 — วิจัย Quant และ backtest<br>
**ความยาก:** Tier 3 — ปานกลาง — หลายขั้นตอน<br>
**ชนิดคำตอบ:** เขียนฟังก์ชันและคืนค่าด้วย return

## 1. เรียนรู้อะไร

คืน continue เมื่อ list ไม่ว่างและ mean > 0; มิฉะนั้น reject

## 2. ก่อนเริ่ม

ทบทวน: [L09-E011](L09-E011.md). หากคำศัพท์ในโจทย์ยังไม่คุ้น ให้เริ่มจากคำอธิบายแนวคิดในหน้านี้ก่อน

**แนวคิดสำคัญ:** แนวคิด: คืน continue เมื่อ list ไม่ว่างและ mean > 0; มิฉะนั้น reject

ขั้นตอน: หาค่าเฉลี่ยเมื่อมีข้อมูล; เลือก continue เฉพาะกรณีบวก

## 3. ตัวอย่างสั้น

ตัวอย่างนี้ฝึกแนวคิดที่เกี่ยวข้อง แต่ใช้ค่าและสถานการณ์แยกจากโจทย์ที่ต้องส่ง

~~~python
message = "python"
print(message.title())  # Python
~~~

อ่าน arguments ที่ส่งให้ฟังก์ชันแล้วตามค่าที่ return; ถ้าไม่มี print การคืนค่าไม่ได้แสดงใน Terminal

## 4. งานของคุณ

สถานการณ์: ทีมวิจัยดำเนินการต่อเมื่อค่าเฉลี่ย return ในช่วงทดสอบเป็นบวก

เขียน reject_negative_test_result(values) ตามสัญญา: คืน continue เมื่อ list ไม่ว่างและ mean > 0; มิฉะนั้น reject.

กรณีขอบ: ค่าเฉลี่ยศูนย์และข้อมูลว่างให้ reject.
คืนค่าตามลำดับเวลาและอย่า shuffle time series

## 5. เขียนคำตอบที่ไหน

แก้ฟังก์ชัน reject_negative_test_result(values) ในไฟล์นี้. คงชื่อและ signature ไว้ และคืนผลด้วย return

## 6. ลำดับทำงาน

1. อ่าน signature reject_negative_test_result(values) และดูว่า parameter แต่ละตัวรับข้อมูลอะไร
2. แก้เฉพาะ body ที่โจทย์กำหนด และส่งผลด้วย return
3. ตรวจกรณีขอบที่ระบุ โดยคงชื่อฟังก์ชันและ signature
4. ใช้ run ดูค่าคืนจากกรณีแรก แล้วใช้ check ตรวจ test ทั้งหมด

## 7. ข้อมูลเข้าและผลลัพธ์

- **ข้อมูลเข้า:** grader เรียก reject_negative_test_result ด้วย parameters ตาม signature ที่ให้.
- **ผลลัพธ์:** ฟังก์ชันต้องคืนค่า (ข้อความ (str)); return ส่งค่ากลับ ส่วน print แสดงข้อความ.
- **ชุดตรวจ:** มี 2 กรณี รวมขอบเขตตามโจทย์

ข้อจำกัดที่ต้องรักษา: Python 3.12; ค่าเฉลี่ยศูนย์และข้อมูลว่างให้ reject; time series เรียงตามเวลา; ห้ามใช้ข้อมูลอนาคตสร้างผลในอดีต
