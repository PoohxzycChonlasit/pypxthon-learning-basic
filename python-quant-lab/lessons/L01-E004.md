# L01-E004 — แก้บั๊กการคูณราคา

## เป้าหมาย

ตรวจหาตัวดำเนินการที่ไม่ตรงกับโจทย์

## แนวคิด

`+` ใช้บวก ส่วน `*` ใช้คูณ เลือกตัวดำเนินการตามความหมายของโจทย์

## ตัวอย่าง

```python
3 * 4  # 12 ไม่ใช่ 7
```

## โจทย์

โค้ดเริ่มต้นแสดงผลผิด แก้โค้ดให้น้อยที่สุดเพื่อแสดงราคารวม 36 จากราคา 12 จำนวน 3 ชิ้น

## รูปแบบ input/output

price=12, quantity=3

ผลที่ต้องการ: 36

ข้อควรระวัง: แก้ค่าตัวเลขให้บังเอิญได้คำตอบ แทนที่จะแก้การคำนวณ
