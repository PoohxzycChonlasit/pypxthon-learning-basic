# L03-E001 — ค่าล่าสุด

**ระดับ:** Level 3 — โครงสร้างข้อมูล<br>
**ความยาก:** Tier 1 — ง่ายมาก — แนวคิดเดียว<br>
**ชนิดคำตอบ:** เขียนฟังก์ชันและคืนค่าด้วย return

## 1. เรียนรู้อะไร

คืนสมาชิกท้ายสุดของ list; ถ้าว่างคืน None

## 2. ก่อนเริ่ม

ทบทวน: [L02-E015](L02-E015.md). หากคำศัพท์ในโจทย์ยังไม่คุ้น ให้เริ่มจากคำอธิบายแนวคิดในหน้านี้ก่อน

**แนวคิดสำคัญ:** แนวคิด: คืนสมาชิกท้ายสุดของ list; ถ้าว่างคืน None

คิดทีละขั้น: ตรวจว่ามีข้อมูล; ใช้ items[-1] เมื่อมี และคืน None เมื่อไม่มี

## 3. ตัวอย่างสั้น

ตัวอย่างนี้ฝึกแนวคิดที่เกี่ยวข้อง แต่ใช้ค่าและสถานการณ์แยกจากโจทย์ที่ต้องส่ง

~~~python
import csv
import io
rows = list(csv.DictReader(io.StringIO("sku,qty\nA1,2\n")))
print(rows[0]["sku"], int(rows[0]["qty"]))
~~~

อ่าน arguments ที่ส่งให้ฟังก์ชันแล้วตามค่าที่ return; ถ้าไม่มี print การคืนค่าไม่ได้แสดงใน Terminal

## 4. งานของคุณ

สถานการณ์: ผู้ดูแลคลังอ่านจำนวนคงเหลือล่าสุดจากบันทึกเรียงตามเวลา

เขียน latest_observation(items) ให้ทำตามสัญญา: คืนสมาชิกท้ายสุดของ list; ถ้าว่างคืน None.

กรณีขอบ: ต้องตรวจ list ว่างก่อน index -1.
ส่งค่ากลับด้วย return และรักษาชนิดผลลัพธ์ตามตัวอย่าง

## 7. ข้อมูลเข้าและผลลัพธ์

- **ข้อมูลเข้า:** grader เรียก latest_observation ด้วย parameters ตาม signature ที่ให้.
- **ผลลัพธ์:** ฟังก์ชันต้องคืนค่า (int); return ส่งค่ากลับ ส่วน print แสดงข้อความ.
- **ชุดตรวจ:** มี 2 กรณี รวมขอบเขตตามโจทย์
