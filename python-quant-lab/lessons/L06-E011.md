# L06-E011 — ปรับข้อมูลให้อยู่รอบค่าเฉลี่ย

**ระดับ:** Level 6 — วิเคราะห์ข้อมูล<br>
**ความยาก:** Tier 2 — ง่าย — รวมแนวคิดคุ้นเคย<br>
**ชนิดคำตอบ:** เขียนฟังก์ชันและคืนค่าด้วย return

## 1. เรียนรู้อะไร

คืน list ที่แต่ละค่าเป็น value - population mean

## 2. ก่อนเริ่ม

ทบทวน: [L06-E010](L06-E010.md). หากคำศัพท์ในโจทย์ยังไม่คุ้น ให้เริ่มจากคำอธิบายแนวคิดในหน้านี้ก่อน

**แนวคิดสำคัญ:** แนวคิด: คืน list ที่แต่ละค่าเป็น value - population mean

ลำดับคิด: หาค่าเฉลี่ยของทุกค่า; ลบ mean ออกจากแต่ละสมาชิก

## 3. ตัวอย่างสั้น

ตัวอย่างนี้ฝึกแนวคิดที่เกี่ยวข้อง แต่ใช้ค่าและสถานการณ์แยกจากโจทย์ที่ต้องส่ง

~~~python
raw = "  25 "
amount = int(raw.strip())
print(amount + 5)
~~~

อ่าน arguments ที่ส่งให้ฟังก์ชันแล้วตามค่าที่ return; ถ้าไม่มี print การคืนค่าไม่ได้แสดงใน Terminal

## 4. งานของคุณ

สถานการณ์: นักวิเคราะห์ปรับข้อมูลรอบศูนย์ด้วยการลบค่าเฉลี่ยของชุดข้อมูล

เขียน demean_series(values) ตามกติกา: คืน list ที่แต่ละค่าเป็น value - population mean.

กรณีขอบ: list ว่างคืน []; ค่าผลรวมหลัง demean ควรใกล้ศูนย์เมื่อคำนวณด้วย float.
ส่งค่ากลับด้วย return และอย่าแก้ input ต้นฉบับ

## 5. เขียนคำตอบที่ไหน

ไฟล์ส่งคำตอบ: [exercises/level_06/L06-E011.py](../exercises/level_06/L06-E011.py)

แก้ฟังก์ชัน demean_series(values) ในไฟล์นี้. คงชื่อและ signature ไว้ และคืนผลด้วย return

## 6. ลำดับทำงาน

1. อ่าน signature demean_series(values) และดูว่า parameter แต่ละตัวรับข้อมูลอะไร
2. แก้เฉพาะ body ที่โจทย์กำหนด และส่งผลด้วย return
3. ตรวจกรณีขอบที่ระบุ โดยคงชื่อฟังก์ชันและ signature
4. ใช้ run ดูค่าคืนจากกรณีแรก แล้วใช้ check ตรวจ test ทั้งหมด

## 7. ข้อมูลเข้าและผลลัพธ์

- **ข้อมูลเข้า:** grader เรียก demean_series ด้วย parameters ตาม signature ที่ให้.
- **ผลลัพธ์:** ฟังก์ชันต้องคืนค่า (list); return ส่งค่ากลับ ส่วน print แสดงข้อความ.
- **ชุดตรวจ:** มี 2 กรณี รวมขอบเขตตามโจทย์

ข้อจำกัดที่ต้องรักษา: Python 3.12; list ว่างคืน []; ค่าผลรวมหลัง demean ควรใกล้ศูนย์เมื่อคำนวณด้วย float; ใช้ข้อมูลตามรูปแบบที่ระบุในโจทย์; output ต้องตรงทั้งชนิดและลำดับ
