# L08-E011 — เงินคงเหลือ paper หลังเทรด

**ระดับ:** Level 8 — การเงินและความเสี่ยง<br>
**ความยาก:** Tier 4 — ท้าทาย — เงื่อนไขและกรณีขอบ<br>
**ชนิดคำตอบ:** เขียนฟังก์ชันและคืนค่าด้วย return

## 1. เรียนรู้อะไร

equity = 100 + gross long profit - round-trip fee

## 2. ก่อนเริ่ม

ทบทวน: [L08-E010](L08-E010.md). หากคำศัพท์ในโจทย์ยังไม่คุ้น ให้เริ่มจากคำอธิบายแนวคิดในหน้านี้ก่อน

**แนวคิดสำคัญ:** แนวคิด: equity = 100 + gross long profit - round-trip fee

คิดทีละขั้น: คำนวณกำไรสุทธิของสถานะซื้อ; บวก bankroll

## 3. ตัวอย่างสั้น

ตัวอย่างนี้ฝึกแนวคิดที่เกี่ยวข้อง แต่ใช้ค่าและสถานการณ์แยกจากโจทย์ที่ต้องส่ง

~~~python
import csv
import io
rows = list(csv.DictReader(io.StringIO("sku,qty\nA1,2\n")))
print(rows[0]["sku"], int(rows[0]["qty"]))
~~~

อ่าน arguments ที่ส่งให้ฟังก์ชันแล้วตามค่าที่ return; ถ้าไม่มี print การคืนค่าไม่ได้แสดงใน Terminal

## 4. งานของคุณ

สถานการณ์: บัญชี paper สรุปเงินทุนเริ่มต้น 100 หลังสถานะซื้อปิดและหัก fee 0.1% สองขา

เขียน paper_equity_after_trade(entry, exit, quantity) ให้ทำตามสัญญา: equity = 100 + gross long profit - round-trip fee.

กรณีขอบ: bankroll คงที่ 100; fee คิดจาก entry และ exit notional.
คืนค่าเท่านั้น; งานทั้งหมดเป็นการจำลอง paper
