# L05-E010 — ตรวจแถวหัวตาราง

**ระดับ:** Level 5 — Python สำหรับงานจริง<br>

**ชนิดคำตอบ:** เขียนฟังก์ชันและคืนค่าด้วย return

## 1. เรียนรู้อะไร

คืน True เมื่อหลังตัดช่องว่างนำหน้าแล้วบรรทัดขึ้นต้นด้วย date, โดยไม่สนตัวพิมพ์เล็กใหญ่

## 2. ก่อนเริ่ม

ทบทวน: [L05-E009](L05-E009.md). หากคำศัพท์ในโจทย์ยังไม่คุ้น ให้เริ่มจากคำอธิบายแนวคิดในหน้านี้ก่อน

**แนวคิดสำคัญ:** แนวคิด: คืน True เมื่อหลังตัดช่องว่างนำหน้าแล้วบรรทัดขึ้นต้นด้วย date, โดยไม่สนตัวพิมพ์เล็กใหญ่

ลำดับคิด: strip แล้วแปลงเป็นตัวพิมพ์เล็ก; ตรวจ prefix date,

## 3. ตัวอย่างสั้น

ตัวอย่างนี้ฝึกแนวคิดที่เกี่ยวข้อง แต่ใช้ค่าและสถานการณ์แยกจากโจทย์ที่ต้องส่ง

~~~python
message = "python"
print(message.title())  # Python
~~~

อ่าน arguments ที่ส่งให้ฟังก์ชันแล้วตามค่าที่ return; ถ้าไม่มี print การคืนค่าไม่ได้แสดงใน Terminal

## 4. งานของคุณ

สถานการณ์: ระบบรายงานตรวจว่าบรรทัดแรกของไฟล์เป็น header ที่เริ่มด้วยคอลัมน์ date

เขียน detect_header_row(text) ตามกติกา: คืน True เมื่อหลังตัดช่องว่างนำหน้าแล้วบรรทัดขึ้นต้นด้วย date, โดยไม่สนตัวพิมพ์เล็กใหญ่.

กรณีขอบ: date ต้องตามด้วย comma; บรรทัดข้อมูลที่เริ่มด้วยวันที่จริงไม่ถือเป็น header.
ส่งค่ากลับด้วย return และอย่าแก้ input ต้นฉบับ

## 7. ข้อมูลเข้าและผลลัพธ์
