# L07-E015 — ประเมินสถิติ

**ระดับ:** Level 7 — คณิตศาสตร์และสถิติ<br>
**ความยาก:** Tier 5 — ประยุกต์ขั้นสูง — ใช้ความรู้เดิมกับโจทย์ใหม่<br>
**ชนิดคำตอบ:** เขียนฟังก์ชันและคืนค่าด้วย return

## 1. เรียนรู้อะไร

คำนวณสถิติที่ prompt ของ variant ที่เลือกกำหนด

## 2. ก่อนเริ่ม

ทบทวน: [L07-E014](L07-E014.md). หากคำศัพท์ในโจทย์ยังไม่คุ้น ให้เริ่มจากคำอธิบายแนวคิดในหน้านี้ก่อน

**แนวคิดสำคัญ:** ใช้ prompt ของ variant ปัจจุบันเป็น contract; ระบุว่าต้องคืนจำนวน ค่าเฉลี่ย ค่ากลาง พิสัย หรือสถิติใด กำหนดพฤติกรรมของ input ว่างก่อนคำนวณและรักษาข้อมูลต้นฉบับ.

## 3. ตัวอย่างสั้น

ตัวอย่างนี้ฝึกแนวคิดที่เกี่ยวข้อง แต่ใช้ค่าและสถานการณ์แยกจากโจทย์ที่ต้องส่ง

~~~python
grades = [72, 88, 91]
print(sorted(grades))
~~~

อ่าน arguments ที่ส่งให้ฟังก์ชันแล้วตามค่าที่ return; ถ้าไม่มี print การคืนค่าไม่ได้แสดงใน Terminal

## 4. งานของคุณ

แบบประเมิน A/B: เขียนฟังก์ชัน final_statistics_assessment(values) ตามโจทย์ของ variant ที่ระบบแสดงอยู่ ใช้ input ที่รับเข้ามาคำนวณและคืนผลตาม รูปแบบข้อมูล ที่กำหนด ห้าม hardcode คำตอบของตัวอย่าง

## 5. เขียนคำตอบที่ไหน

ไฟล์ส่งคำตอบ: [exercises/level_07/L07-E015.py](../exercises/level_07/L07-E015.py)

แก้ฟังก์ชัน final_statistics_assessment(values) ในไฟล์นี้. คงชื่อและ signature ไว้ และคืนผลด้วย return

## 6. ลำดับทำงาน

1. อ่าน signature final_statistics_assessment(values) และดูว่า parameter แต่ละตัวรับข้อมูลอะไร
2. แก้เฉพาะ body ที่โจทย์กำหนด และส่งผลด้วย return
3. ตรวจกรณีขอบที่ระบุ โดยคงชื่อฟังก์ชันและ signature
4. ใช้ run ดูค่าคืนจากกรณีแรก แล้วใช้ check ตรวจ test ทั้งหมด

## 7. ข้อมูลเข้าและผลลัพธ์

- **ข้อมูลเข้า:** grader เรียก final_statistics_assessment ด้วย parameters ตาม signature ที่ให้.
- **ผลลัพธ์:** ฟังก์ชันต้องคืนค่า (dict มี key: mean, n, min, max); return ส่งค่ากลับ ส่วน print แสดงข้อความ.
- **ชุดตรวจ:** มี 3 กรณี รวมขอบเขตตามโจทย์

ข้อจำกัดที่ต้องรักษา: ใช้ Python 3.12 และ standard library; ห้ามแก้ tests, curriculum หรือไฟล์เฉลย; ตัวอย่างการเทรดเป็น paper-only

## 8. Run และ Check

รันจากโฟลเดอร์โครงการที่มี practice.py:

~~~powershell
py -3.12 -B practice.py run L07-E015
py -3.12 -B practice.py check L07-E015
~~~

บน macOS Terminal ใช้ python3.12 แทน py -3.12:

~~~sh
python3.12 -B practice.py run L07-E015
python3.12 -B practice.py check L07-E015
~~~

การกด Run บนฟังก์ชันที่มีแต่ def อาจไม่แสดงอะไร เพราะยังไม่มีใครเรียกฟังก์ชัน; practice.py run เรียก test แรกให้ ส่วน check เรียกทุกกรณี

Run ทดลองกรณีตัวอย่างแรก; Check เปรียบเทียบกับทุกกรณีและบันทึกสถานะการเรียน

## 9. ถ้าไม่ผ่าน

สิ่งที่พลาดง่าย: ตรวจ input ว่าง จำนวนสมาชิกคี่/คู่ และค่าซ้ำตามสถิติที่ variant ปัจจุบันขอ. ตรวจค่าที่คืนและชนิดของมันก่อนตรวจการแสดงผล

หากต้องการความช่วยเหลือหลังลองเอง ให้ใช้ py -3.12 -B practice.py hint L07-E015 1. คำใบ้และการเปิดเฉลยจะถูกบันทึกใน progress

## 10. เสร็จเมื่อ

Check แสดงว่าทุกกรณีผ่าน และคุณอธิบายแนวคิดได้โดยไม่ดูตัวอย่างข้างบน

ตรวจความเข้าใจ: ลองอธิบายด้วยคำของคุณเองว่า “คำนวณสถิติที่ prompt ของ variant ที่เลือกกำหนด” ทำงานอย่างไร
