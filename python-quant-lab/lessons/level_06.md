# Level 6 — วิเคราะห์ข้อมูล

**เป้าหมาย:** อ่านข้อมูลออฟไลน์ ทำความสะอาด สรุป และเลือกกราฟที่ตอบคำถามได้

## พิมพ์ตาม: รวมยอดขายจาก CSV

### ขั้นที่ 1 — แนวคิด

เริ่มจากคำถามก่อนเลือกเครื่องมือ เช่น “สินค้าชนิดใดขายได้กี่ชิ้น” ตรวจ schema, missing values และชนิดข้อมูล แล้วจึงจัดกลุ่มและรวมค่า

### ขั้นที่ 2–3 — พิมพ์ตัวอย่างนี้

รันจากโฟลเดอร์โครงการซึ่งมี data/sales.csv:

~~~python
import csv
from collections import defaultdict

totals = defaultdict(float)
with open("data/sales.csv", encoding="utf-8", newline="") as file:
    for row in csv.DictReader(file):
        totals[row["product"]] += float(row["quantity"]) * float(row["unit_price"])

for product in sorted(totals):
    print(product, round(totals[product], 2))
~~~

### ขั้นที่ 4 — อ่านทีละส่วน

- DictReader อ่านหัวตารางเป็น key
- float แปลงข้อความราคาและจำนวนเป็นตัวเลข
- defaultdict เริ่มยอดของสินค้าใหม่ที่ศูนย์
- sorted ทำให้ผลลัพธ์เรียงแน่นอนทุกครั้ง

### ขั้นที่ 5 — ผลลัพธ์ที่คาด

จากชุดฝึกปัจจุบันควรเห็นรายชื่อสินค้าเรียงตามตัวอักษรและยอดขายรวมเป็นตัวเลข ไม่ควรมีค่า NaN หรือแถวหัวตารางปะปน

### ขั้นที่ 6–7 — ทดลองเปลี่ยน

กรองแถวให้เหลือวันที่หนึ่งวัน แล้วรันใหม่ ยอดรวมต้องเปลี่ยนตามข้อมูลที่เหลือเท่านั้น

### ขั้นที่ 8 — ลองเอง

นับจำนวนแถวที่ยอดขายผิดรูปแบบ แยกเป็น rejected count และอย่าลบแถวเงียบ ๆ โดยไม่บันทึกเหตุผล

**ไลบรารีเสริม:** NumPy และ pandas ช่วยทำงานกับข้อมูลขนาดใหญ่ขึ้น ส่วน Matplotlib/Plotly ช่วยวาดกราฟ ยังไม่จำเป็นสำหรับบทนี้และไม่ติดตั้งให้อัตโนมัติ
