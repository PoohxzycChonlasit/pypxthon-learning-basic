# L01-E013 — เติมการคำนวณกำไรหลังค่าธรรมเนียม

## เป้าหมาย

ใช้ตัวแปรและอัตราเปอร์เซ็นต์หักค่าธรรมเนียม

## แนวคิด

ค่าธรรมเนียมคำนวณจาก gross * rate / 100 แล้วหักออกจาก gross ฟังก์ชัน `abs(x)` คืนค่าขนาดที่ไม่ติดลบของ x จึงใช้คิดค่าธรรมเนียมได้แม้ gross เป็นขาดทุน

## ตัวอย่าง

```python
bill = 80
discount_percent = 5
discount = bill * discount_percent / 100
remaining = bill - discount
print(f"{remaining:.2f}")  # 76.00
```

## โจทย์

เติมบรรทัด TODO ให้โปรแกรมอ่านกำไรขั้นต้นและอัตราค่าธรรมเนียมเป็นเปอร์เซ็นต์ แล้วแสดงกำไรสุทธิสองตำแหน่ง

## รูปแบบ input/output

gross=10, fee_percent=1 แสดง 9.90

ผลที่ต้องการ: gross - gross * fee_percent / 100

ข้อควรระวัง: ลืมหารด้วย 100 หรือบวกค่าธรรมเนียมแทนการหัก
