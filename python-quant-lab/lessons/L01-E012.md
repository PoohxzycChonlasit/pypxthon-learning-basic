# L01-E012 — ทายผลคำนวณเปอร์เซ็นต์

**ระดับ:** Level 1 — Python พื้นฐาน<br>
**ความยาก:** Tier 2 — ง่าย — รวมแนวคิดคุ้นเคย<br>
**ชนิดคำตอบ:** ทำนายผลแล้วเขียนคำตอบในไฟล์ข้อความ

## 1. เรียนรู้อะไร

อ่านนิพจน์เปอร์เซ็นต์และทายผลชนิดตัวเลข

## 2. ก่อนเริ่ม

ทบทวน: [L01-E011](L01-E011.md). หากคำศัพท์ในโจทย์ยังไม่คุ้น ให้เริ่มจากคำอธิบายแนวคิดในหน้านี้ก่อน

**แนวคิดสำคัญ:** การหา 10 เปอร์เซ็นต์ของจำนวนคือจำนวน * 10 / 100 เครื่องหมาย `/` ให้ผลเป็น float

## 3. ตัวอย่างสั้น

ตัวอย่างนี้ฝึกแนวคิดที่เกี่ยวข้อง แต่ใช้ค่าและสถานการณ์แยกจากโจทย์ที่ต้องส่ง

~~~python
50 * 10 / 100  # 5.0
~~~

แยกการคำนวณในตัวอย่างตามลำดับเครื่องหมาย แล้วเทียบกับ comment; ค่าตัวอย่างนี้ไม่ใช่คำตอบของโจทย์

## 4. งานของคุณ

ทายค่าที่ print แสดงจาก amount = 80, percent = 10, print(amount * percent / 100) แล้วเขียนค่าหนึ่งบรรทัดลงไฟล์คำตอบ .txt

## 5. เขียนคำตอบที่ไหน

ไฟล์ส่งคำตอบ: [answers/level_01/L01-E012.txt](../answers/level_01/L01-E012.txt)

นี่คือโจทย์ทำนายผล ไม่ต้องเขียนโปรแกรมใหม่. ไฟล์ .py รุ่นเก่าเก็บไว้เพื่อความเข้ากันได้ แต่ไม่ใช่ไฟล์ส่งคำตอบและไม่ใช่ขั้นตอนตรวจงาน

## 6. ลำดับทำงาน

1. อ่านโค้ดในโจทย์จากบนลงล่างและจดค่าที่เปลี่ยนในแต่ละบรรทัด
2. คำนวณสิ่งที่แต่ละคำสั่งแสดง โดยรักษาลำดับคำสั่ง
3. พิมพ์เฉพาะผลลัพธ์ 1 บรรทัดลงไฟล์ .txt ที่ระบุ
4. บันทึกไฟล์ แล้วใช้คำสั่ง Check; ไม่ต้องสร้างหรือรันโปรแกรม Python

## 7. ข้อมูลเข้าและผลลัพธ์

- **ข้อมูลเข้า:** โค้ดในโจทย์; ให้อ่านและทำนายเอง ไม่ต้องป้อนค่าใน Terminal.
- **คำตอบ:** ข้อความธรรมดา 1 บรรทัด ตามจำนวนบรรทัดที่โจทย์ขอ.
- **รูปแบบ:** ใส่เฉพาะค่าที่แสดง ไม่ใส่โค้ด, ANSWER, comment, code fence หรือคำอธิบายเพิ่ม

ข้อจำกัดที่ต้องรักษา: Python 3.12; ใช้เฉพาะแนวคิดที่สอนถึงข้อนี้; การเทรดเป็นการจำลอง paper-only

## 8. ตรวจคำตอบด้วย Check

โจทย์นี้ให้ทำนายผลและส่งเป็นข้อความ จึงไม่ต้องกด VS Code Run Python File และไม่ต้องใช้ <code>practice.py run</code>. บันทึกไฟล์ .txt แล้วตรวจจาก project root:

~~~powershell
py -3.12 -B practice.py check L01-E012
~~~

บน macOS ใช้คำสั่งนี้แทน:

~~~sh
python3.12 -B practice.py check L01-E012
~~~

Check เปรียบเทียบข้อความในไฟล์ .txt กับผลที่คาดและบันทึกสถานะ. หากยังไม่ผ่าน ให้อ่านจำนวนบรรทัด รูปแบบ และลำดับการคำนวณจากโจทย์อีกครั้ง.

## 9. ถ้าไม่ผ่าน

สิ่งที่พลาดง่าย: ตอบ 8 โดยไม่สังเกตว่า `/` ให้ผลเป็น float หรือคิดว่าเป็น 10% ของ 100. เทียบจำนวนบรรทัด ช่องว่าง และเครื่องหมายคำพูดกับรูปแบบที่โจทย์กำหนด

หากต้องการความช่วยเหลือหลังลองเอง ให้ใช้ py -3.12 -B practice.py hint L01-E012 1. คำใบ้และการเปิดเฉลยจะถูกบันทึกใน progress
