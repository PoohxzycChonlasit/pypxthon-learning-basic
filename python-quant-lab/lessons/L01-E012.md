# L01-E012 — ทายผลคำนวณเปอร์เซ็นต์

## เป้าหมาย

อ่านนิพจน์เปอร์เซ็นต์และทายผลชนิดตัวเลข

## แนวคิด

การหา 10 เปอร์เซ็นต์ของจำนวนคือจำนวน * 10 / 100 เครื่องหมาย `/` ให้ผลเป็น float

## ตัวอย่าง

```python
50 * 10 / 100  # 5.0
```

## โจทย์

ทายค่าที่ print แสดงจาก amount = 80, percent = 10, print(amount * percent / 100) แล้วเขียนค่าหนึ่งบรรทัดลงไฟล์คำตอบ .txt

## รูปแบบ input/output

เขียนผลลัพธ์ที่คาดลงไฟล์ข้อความคำตอบตามจำนวนบรรทัดของ stdout

ผลที่ต้องการ: 8.0

ข้อควรระวัง: ตอบ 8 โดยไม่สังเกตว่า `/` ให้ผลเป็น float หรือคิดว่าเป็น 10% ของ 100
