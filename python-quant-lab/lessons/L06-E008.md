# L06-E008 — ผลรวมสะสม

**ระดับ:** Level 6 — วิเคราะห์ข้อมูล<br>
**ความยาก:** Tier 3 — ปานกลาง — หลายขั้นตอน<br>
**ชนิดคำตอบ:** เขียนฟังก์ชันและคืนค่าด้วย return

## 1. เรียนรู้อะไร

คืน list ยอดสะสมตั้งแต่แถวแรกถึงแถวปัจจุบัน

## 2. ก่อนเริ่ม

ทบทวน: [L06-E007](L06-E007.md). หากคำศัพท์ในโจทย์ยังไม่คุ้น ให้เริ่มจากคำอธิบายแนวคิดในหน้านี้ก่อน

**แนวคิดสำคัญ:** แนวคิด: คืน list ยอดสะสมตั้งแต่แถวแรกถึงแถวปัจจุบัน

ลำดับคิด: เริ่ม total ที่ 0; เพิ่มแต่ละค่าแล้วบันทึก total

## 3. ตัวอย่างสั้น

ตัวอย่างนี้ฝึกแนวคิดที่เกี่ยวข้อง แต่ใช้ค่าและสถานการณ์แยกจากโจทย์ที่ต้องส่ง

~~~python
point = (3, 4)
x, y = point
print(x + y)
~~~

อ่าน arguments ที่ส่งให้ฟังก์ชันแล้วตามค่าที่ return; ถ้าไม่มี print การคืนค่าไม่ได้แสดงใน Terminal

## 4. งานของคุณ

สถานการณ์: นักวิเคราะห์สร้างยอดสะสมของปริมาณขายตามลำดับเวลา

เขียน cumulative_sum(values) ตามกติกา: คืน list ยอดสะสมตั้งแต่แถวแรกถึงแถวปัจจุบัน.

กรณีขอบ: list ว่างคืน []; รองรับค่าติดลบตามข้อมูลปรับปรุงยอด.
ส่งค่ากลับด้วย return และอย่าแก้ input ต้นฉบับ

## 5. เขียนคำตอบที่ไหน

ไฟล์ส่งคำตอบ: [exercises/level_06/L06-E008.py](../exercises/level_06/L06-E008.py)

แก้ฟังก์ชัน cumulative_sum(values) ในไฟล์นี้. คงชื่อและ signature ไว้ และคืนผลด้วย return

## 6. ลำดับทำงาน

1. อ่าน signature cumulative_sum(values) และดูว่า parameter แต่ละตัวรับข้อมูลอะไร
2. แก้เฉพาะ body ที่โจทย์กำหนด และส่งผลด้วย return
3. ตรวจกรณีขอบที่ระบุ โดยคงชื่อฟังก์ชันและ signature
4. ใช้ run ดูค่าคืนจากกรณีแรก แล้วใช้ check ตรวจ test ทั้งหมด

## 7. ข้อมูลเข้าและผลลัพธ์

- **ข้อมูลเข้า:** grader เรียก cumulative_sum ด้วย parameters ตาม signature ที่ให้.
- **ผลลัพธ์:** ฟังก์ชันต้องคืนค่า (list); return ส่งค่ากลับ ส่วน print แสดงข้อความ.
- **ชุดตรวจ:** มี 2 กรณี รวมขอบเขตตามโจทย์

ข้อจำกัดที่ต้องรักษา: Python 3.12; list ว่างคืน []; รองรับค่าติดลบตามข้อมูลปรับปรุงยอด; ใช้ข้อมูลตามรูปแบบที่ระบุในโจทย์; output ต้องตรงทั้งชนิดและลำดับ
