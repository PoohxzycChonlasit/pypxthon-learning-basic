# L09-E011 — สร้างสัญญาณตามเกณฑ์

**ระดับ:** Level 9 — วิจัย Quant และ backtest<br>
**ความยาก:** Tier 3 — ปานกลาง — หลายขั้นตอน<br>
**ชนิดคำตอบ:** เขียนฟังก์ชันและคืนค่าด้วย return

## 1. เรียนรู้อะไร

คืน 1 เมื่อ current/previous-1 > minimum_return มิฉะนั้น 0

## 2. ก่อนเริ่ม

ทบทวน: [L09-E010](L09-E010.md). หากคำศัพท์ในโจทย์ยังไม่คุ้น ให้เริ่มจากคำอธิบายแนวคิดในหน้านี้ก่อน

**แนวคิดสำคัญ:** แนวคิด: คืน 1 เมื่อ current/previous-1 > minimum_return มิฉะนั้น 0

ขั้นตอน: คำนวณ simple return แต่ละคู่; เปรียบเทียบแบบ strict greater-than

## 3. ตัวอย่างสั้น

ตัวอย่างนี้ฝึกแนวคิดที่เกี่ยวข้อง แต่ใช้ค่าและสถานการณ์แยกจากโจทย์ที่ต้องส่ง

~~~python
values = [2, 5, 3]
total = 0
for value in values:
    total += value
print(total)
~~~

อ่าน arguments ที่ส่งให้ฟังก์ชันแล้วตามค่าที่ return; ถ้าไม่มี print การคืนค่าไม่ได้แสดงใน Terminal

## 4. งานของคุณ

สถานการณ์: นักวิจัยสร้าง long signal เมื่อ simple return ระหว่างราคาติดกันเกิน threshold

เขียน threshold_signals(prices, minimum_return) ตามสัญญา: คืน 1 เมื่อ current/previous-1 > minimum_return มิฉะนั้น 0.

กรณีขอบ: เท่ากับ threshold ไม่ผ่าน; output ยาว n-1; previous<=0 ให้ 0.
คืนค่าตามลำดับเวลาและอย่า shuffle time series

## 7. ข้อมูลเข้าและผลลัพธ์

- **ข้อมูลเข้า:** grader เรียก threshold_signals ด้วย parameters ตาม signature ที่ให้.
- **ผลลัพธ์:** ฟังก์ชันต้องคืนค่า (list); return ส่งค่ากลับ ส่วน print แสดงข้อความ.
- **ชุดตรวจ:** มี 2 กรณี รวมขอบเขตตามโจทย์
