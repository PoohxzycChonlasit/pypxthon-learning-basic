# L03-E009 — เพิ่มหมายเลขลำดับ

**ระดับ:** Level 3 — โครงสร้างข้อมูล<br>
**ความยาก:** Tier 3 — ปานกลาง — หลายขั้นตอน<br>
**ชนิดคำตอบ:** เขียนฟังก์ชันและคืนค่าด้วย return

## 1. เรียนรู้อะไร

คืน list ของคู่ (index,value) โดย index เริ่มจาก 0

## 2. ก่อนเริ่ม

ทบทวน: [L03-E008](L03-E008.md). หากคำศัพท์ในโจทย์ยังไม่คุ้น ให้เริ่มจากคำอธิบายแนวคิดในหน้านี้ก่อน

**แนวคิดสำคัญ:** แนวคิด: คืน list ของคู่ (index,value) โดย index เริ่มจาก 0

คิดทีละขั้น: ใช้ enumerate แล้วแปลงผลให้เป็น list

## 3. ตัวอย่างสั้น

ตัวอย่างนี้ฝึกแนวคิดที่เกี่ยวข้อง แต่ใช้ค่าและสถานการณ์แยกจากโจทย์ที่ต้องส่ง

~~~python
message = "python"
print(message.title())  # Python
~~~

อ่าน arguments ที่ส่งให้ฟังก์ชันแล้วตามค่าที่ return; ถ้าไม่มี print การคืนค่าไม่ได้แสดงใน Terminal

## 4. งานของคุณ

สถานการณ์: ทีมคลังติดหมายเลขตำแหน่งให้แถวข้อมูลที่อ่านจากไฟล์

เขียน indexed_observations(items) ให้ทำตามสัญญา: คืน list ของคู่ (index,value) โดย index เริ่มจาก 0.

กรณีขอบ: list ว่างคืน []; ค่าซ้ำยังคงมี index แยกกัน.
ส่งค่ากลับด้วย return และรักษาชนิดผลลัพธ์ตามตัวอย่าง

## 5. เขียนคำตอบที่ไหน

ไฟล์ส่งคำตอบ: [exercises/level_03/L03-E009.py](../exercises/level_03/L03-E009.py)

แก้ฟังก์ชัน indexed_observations(items) ในไฟล์นี้. คงชื่อและ signature ไว้ และคืนผลด้วย return

## 6. ลำดับทำงาน

1. อ่าน signature indexed_observations(items) และดูว่า parameter แต่ละตัวรับข้อมูลอะไร
2. แก้เฉพาะ body ที่โจทย์กำหนด และส่งผลด้วย return
3. ตรวจกรณีขอบที่ระบุ โดยคงชื่อฟังก์ชันและ signature
4. ใช้ run ดูค่าคืนจากกรณีแรก แล้วใช้ check ตรวจ test ทั้งหมด

## 7. ข้อมูลเข้าและผลลัพธ์

- **ข้อมูลเข้า:** grader เรียก indexed_observations ด้วย parameters ตาม signature ที่ให้.
- **ผลลัพธ์:** ฟังก์ชันต้องคืนค่า (list); return ส่งค่ากลับ ส่วน print แสดงข้อความ.
- **ชุดตรวจ:** มี 2 กรณี รวมขอบเขตตามโจทย์
