# L02-E008 — วัดการลดลงระหว่างจุด

**ระดับ:** Level 2 — เงื่อนไขและลูป<br>
**ความยาก:** Tier 3 — ปานกลาง — หลายขั้นตอน<br>
**ชนิดคำตอบ:** เขียนฟังก์ชันและคืนค่าด้วย return

## 1. เรียนรู้อะไร

คำนวณ b/a - 1 ของคู่ติดกันที่ a ไม่เป็นศูนย์; คืนค่าต่ำสุดที่พบ หรือ 0 หากไม่มีการลดลง

## 2. ก่อนเริ่ม

ทบทวน: [L02-E007](L02-E007.md). หากคำศัพท์ในโจทย์ยังไม่คุ้น ให้เริ่มจากคำอธิบายแนวคิดในหน้านี้ก่อน

**แนวคิดสำคัญ:** แนวคิด: คำนวณ b/a - 1 ของคู่ติดกันที่ a ไม่เป็นศูนย์; คืนค่าต่ำสุดที่พบ หรือ 0 หากไม่มีการลดลง

คิดทีละขั้น: จับคู่ยอดแต่ละวันกับวันถัดไป; ข้ามตัวหารศูนย์; เลือกสัดส่วนการเปลี่ยนแปลงที่ต่ำสุด

## 3. ตัวอย่างสั้น

ตัวอย่างนี้ฝึกแนวคิดที่เกี่ยวข้อง แต่ใช้ค่าและสถานการณ์แยกจากโจทย์ที่ต้องส่ง

~~~python
import csv
import io
rows = list(csv.DictReader(io.StringIO("sku,qty\nA1,2\n")))
print(rows[0]["sku"], int(rows[0]["qty"]))
~~~

อ่าน arguments ที่ส่งให้ฟังก์ชันแล้วตามค่าที่ return; ถ้าไม่มี print การคืนค่าไม่ได้แสดงใน Terminal

## 4. งานของคุณ

สถานการณ์: ผู้ดูแลบัญชี paper วัดการเปลี่ยนแปลงร้อยละระหว่างยอดที่อยู่ติดกัน

เขียน maximum_drawdown_step(values) ให้ทำตามสัญญา: คำนวณ b/a - 1 ของคู่ติดกันที่ a ไม่เป็นศูนย์; คืนค่าต่ำสุดที่พบ หรือ 0 หากไม่มีการลดลง.

กรณีขอบ: รายการสั้นกว่าสองค่าและกรณีไม่มีค่าลดลงคืน 0.
ส่งค่ากลับด้วย return และรักษาชนิดผลลัพธ์ตามตัวอย่าง

## 6. ลำดับทำงาน

1. อ่าน signature maximum_drawdown_step(values) และดูว่า parameter แต่ละตัวรับข้อมูลอะไร
2. แก้เฉพาะ body ที่โจทย์กำหนด และส่งผลด้วย return
3. ตรวจกรณีขอบที่ระบุ โดยคงชื่อฟังก์ชันและ signature
4. ใช้ run ดูค่าคืนจากกรณีแรก แล้วใช้ check ตรวจ test ทั้งหมด

## 7. ข้อมูลเข้าและผลลัพธ์

- **ข้อมูลเข้า:** grader เรียก maximum_drawdown_step ด้วย parameters ตาม signature ที่ให้.
- **ผลลัพธ์:** ฟังก์ชันต้องคืนค่า (float); return ส่งค่ากลับ ส่วน print แสดงข้อความ.
- **ชุดตรวจ:** มี 2 กรณี รวมขอบเขตตามโจทย์

ข้อจำกัดที่ต้องรักษา: Python 3.12; รายการสั้นกว่าสองค่าและกรณีไม่มีค่าลดลงคืน 0; ใช้เฉพาะข้อมูลตามสัญญาโจทย์; ห้ามแก้ grader หรือเฉลย
