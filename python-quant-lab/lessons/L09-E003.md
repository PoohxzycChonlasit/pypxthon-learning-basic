# L09-E003 — เติมค่าเฉลี่ยจากข้อมูลก่อน index

**ระดับ:** Level 9 — วิจัย Quant และ backtest<br>
**ความยาก:** Tier 1 — ง่ายมาก — แนวคิดเดียว<br>
**ชนิดคำตอบ:** โปรแกรม Python แสดงผล (stdout)

## 1. เรียนรู้อะไร

สร้างฟังก์ชันที่ใช้เฉพาะ trailing window ก่อนจุดตัดสินใจ

## 2. ก่อนเริ่ม

ทบทวน: [L09-E002](L09-E002.md). หากคำศัพท์ในโจทย์ยังไม่คุ้น ให้เริ่มจากคำอธิบายแนวคิดในหน้านี้ก่อน

**แนวคิดสำคัญ:** ฟังก์ชันให้สัญญาชัดว่าข้อมูลอนาคตและค่าที่ index จะไม่เข้า window

## 3. ตัวอย่างสั้น

ตัวอย่างนี้ฝึกแนวคิดที่เกี่ยวข้อง แต่ใช้ค่าและสถานการณ์แยกจากโจทย์ที่ต้องส่ง

~~~python
import json
settings = json.loads('{"mode": "offline", "retry": 2}')
print(settings["mode"], settings["retry"])
~~~

ในตัวอย่างนี้ ให้ดูว่าคำสั่ง print ส่งค่าใดไปยังหน้าจอ; ข้อความหลังเครื่องหมาย # เป็นคำอธิบาย output ของตัวอย่าง

## 4. งานของคุณ

เติม prior_mean(values, index, window) ให้คืนค่าเฉลี่ยของ window ค่าที่อยู่ก่อน index เท่านั้น คืน None เมื่อข้อมูลก่อนหน้าไม่ครบหรือ window ไม่เป็นบวก รับ list คั่นด้วย comma, index และ window

1. อ่านโจทย์และตัวอย่างแยก แล้วหา TODO หรือบรรทัดที่ต้องแก้ในไฟล์ Python

## 7. ข้อมูลเข้าและผลลัพธ์

- **ข้อมูลเข้า:** ใช้ input ที่โจทย์หรือ test ส่งให้; ถ้าไม่มี stdin ก็ไม่ต้องพิมพ์ค่าเพิ่ม.
- **ผลลัพธ์:** ข้อความที่โปรแกรมส่งไป stdout ต้องมีลำดับ บรรทัด และรูปแบบตรงตามโจทย์.
- **การแสดงผล:** print() แสดงค่าที่ Terminal; การกำหนดตัวแปรอย่างเดียวไม่ทำให้เกิด output

ข้อจำกัดที่ต้องรักษา: ใช้ Python 3.12 และ standard library; ห้ามแก้ tests, curriculum หรือไฟล์เฉลย; ตัวอย่างการเทรดเป็น paper-only

## 9. ถ้าไม่ผ่าน

สิ่งที่พลาดง่าย: ใช้ values[index-window:index+1] จนรวมค่าปัจจุบันและสร้าง leakage. ตรวจเครื่องหมายคำพูด การขึ้นบรรทัดใหม่ และค่าที่ print ทีละบรรทัด
