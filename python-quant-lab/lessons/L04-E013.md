# L04-E013 — จำกัดผลตอบแทนติดลบ

**ระดับ:** Level 4 — ฟังก์ชันและโมดูล<br>
**ความยาก:** Tier 5 — ประยุกต์ขั้นสูง — ใช้ความรู้เดิมกับโจทย์ใหม่<br>
**ชนิดคำตอบ:** เขียนฟังก์ชันและคืนค่าด้วย return

## 1. เรียนรู้อะไร

รับ candidate x และ upper cap y; คืนค่าที่ clamp อยู่ในช่วง [-1,y]

## 2. ก่อนเริ่ม

ทบทวน: [L04-E012](L04-E012.md). หากคำศัพท์ในโจทย์ยังไม่คุ้น ให้เริ่มจากคำอธิบายแนวคิดในหน้านี้ก่อน

**แนวคิดสำคัญ:** แนวคิด: รับ candidate x และ upper cap y; คืนค่าที่ clamp อยู่ในช่วง [-1,y]

คิดทีละขั้น: ใช้ min กันค่าเกินเพดาน แล้วใช้ max กันค่าต่ำกว่า -1

## 3. ตัวอย่างสั้น

ตัวอย่างนี้ฝึกแนวคิดที่เกี่ยวข้อง แต่ใช้ค่าและสถานการณ์แยกจากโจทย์ที่ต้องส่ง

~~~python
from math import sqrt
print(sqrt(81))
~~~

อ่าน arguments ที่ส่งให้ฟังก์ชันแล้วตามค่าที่ return; ถ้าไม่มี print การคืนค่าไม่ได้แสดงใน Terminal

## 4. งานของคุณ

สถานการณ์: ผู้ดูแลความเสี่ยงจำกัด return ไว้ระหว่าง -100% กับเพดานที่กำหนด

เขียน clamp_signed_return(x, y) ให้ทำตามสัญญา: รับ candidate x และ upper cap y; คืนค่าที่ clamp อยู่ในช่วง [-1,y].

กรณีขอบ: สมมติ y >= -1; ค่าภายในช่วงไม่เปลี่ยน.
ส่งค่ากลับด้วย return และรักษาชนิดผลลัพธ์ตามตัวอย่าง

## 5. เขียนคำตอบที่ไหน

แก้ฟังก์ชัน clamp_signed_return(x, y) ในไฟล์นี้. คงชื่อและ signature ไว้ และคืนผลด้วย return

## 6. ลำดับทำงาน

1. อ่าน signature clamp_signed_return(x, y) และดูว่า parameter แต่ละตัวรับข้อมูลอะไร
2. แก้เฉพาะ body ที่โจทย์กำหนด และส่งผลด้วย return
3. ตรวจกรณีขอบที่ระบุ โดยคงชื่อฟังก์ชันและ signature
4. ใช้ run ดูค่าคืนจากกรณีแรก แล้วใช้ check ตรวจ test ทั้งหมด

## 7. ข้อมูลเข้าและผลลัพธ์

- **ข้อมูลเข้า:** grader เรียก clamp_signed_return ด้วย parameters ตาม signature ที่ให้.
- **ผลลัพธ์:** ฟังก์ชันต้องคืนค่า (float); return ส่งค่ากลับ ส่วน print แสดงข้อความ.
- **ชุดตรวจ:** มี 2 กรณี รวมขอบเขตตามโจทย์

ข้อจำกัดที่ต้องรักษา: Python 3.12; สมมติ y >= -1; ค่าภายในช่วงไม่เปลี่ยน; ใช้เฉพาะข้อมูลตามสัญญาโจทย์; ห้ามแก้ grader หรือเฉลย

## 9. ถ้าไม่ผ่าน
