# L02-E004 — แก้เกณฑ์ส่งฟรีที่ขอบเขต

**ระดับ:** Level 2 — เงื่อนไขและลูป<br>
**ความยาก:** Tier 2 — ง่าย — รวมแนวคิดคุ้นเคย<br>
**ชนิดคำตอบ:** โปรแกรม Python แสดงผล (stdout)

## 1. เรียนรู้อะไร

หาบั๊กเงื่อนไข threshold ที่พลาดค่าตรงขอบ

## 2. ก่อนเริ่ม

ทบทวน: [L02-E003](L02-E003.md). หากคำศัพท์ในโจทย์ยังไม่คุ้น ให้เริ่มจากคำอธิบายแนวคิดในหน้านี้ก่อน

**แนวคิดสำคัญ:** เครื่องหมาย > ไม่รวมค่าที่เท่ากับเกณฑ์ จึงต้องแยกกรณี boundary ออกจากค่าทั่วไป

## 3. ตัวอย่างสั้น

ตัวอย่างนี้ฝึกแนวคิดที่เกี่ยวข้อง แต่ใช้ค่าและสถานการณ์แยกจากโจทย์ที่ต้องส่ง

~~~python
def add_tip(total, rate=0.05):
    return total + total * rate
print(add_tip(80))
~~~

ในตัวอย่างนี้ ให้ดูว่าคำสั่ง print ส่งค่าใดไปยังหน้าจอ; ข้อความหลังเครื่องหมาย # เป็นคำอธิบาย output ของตัวอย่าง

## 4. งานของคุณ

ร้านค้าส่งฟรีเมื่อยอดตั้งแต่ 500 บาทขึ้นไป โปรแกรมที่ให้มาทำงานผิดตรง threshold แก้ให้กรณี 499, 500 และ 501 ได้ผลถูกต้อง รับยอดหนึ่งบรรทัดและแสดงค่าส่งเป็นจำนวนเต็ม

## 5. เขียนคำตอบที่ไหน

ไฟล์ส่งคำตอบ: [exercises/level_02/L02-E004.py](../exercises/level_02/L02-E004.py)

แก้ไฟล์ Python นี้ตรงตำแหน่งงานที่โจทย์ระบุ; อย่าแก้ไฟล์ tests หรือ solutions

## 6. ลำดับทำงาน

1. อ่านโจทย์และตัวอย่างแยก แล้วหา TODO หรือบรรทัดที่ต้องแก้ในไฟล์ Python
2. เขียนคำสั่งให้แสดงผลตรงตามรูปแบบที่โจทย์ขอ
3. บันทึกไฟล์ แล้วใช้ run ดูกรณีตัวอย่างแรก
4. ใช้ check ตรวจทุกกรณี; อ่านชื่อ test แรกที่ไม่ผ่านก่อนแก้

## 7. ข้อมูลเข้าและผลลัพธ์

- **ข้อมูลเข้า:** ใช้ input ที่โจทย์หรือ test ส่งให้; ถ้าไม่มี stdin ก็ไม่ต้องพิมพ์ค่าเพิ่ม.
- **ผลลัพธ์:** ข้อความที่โปรแกรมส่งไป stdout ต้องมีลำดับ บรรทัด และรูปแบบตรงตามโจทย์.
- **การแสดงผล:** print() แสดงค่าที่ Terminal; การกำหนดตัวแปรอย่างเดียวไม่ทำให้เกิด output

ข้อจำกัดที่ต้องรักษา: ใช้ Python 3.12 และ standard library; ห้ามแก้ tests, curriculum หรือไฟล์เฉลย; ตัวอย่างการเทรดเป็น paper-only

## 8. Run และ Check

รันจากโฟลเดอร์โครงการที่มี practice.py:

~~~powershell
py -3.12 -B practice.py run L02-E004
py -3.12 -B practice.py check L02-E004
~~~

บน macOS Terminal ใช้ python3.12 แทน py -3.12:

~~~sh
python3.12 -B practice.py run L02-E004
python3.12 -B practice.py check L02-E004
~~~

VS Code Run Python File รันไฟล์ตรงและแสดง stdout ใน Terminal; practice.py run ทดลอง test แรก; practice.py check ตรวจทุกกรณี

Run ทดลองกรณีตัวอย่างแรก; Check เปรียบเทียบกับทุกกรณีและบันทึกสถานะการเรียน

## 9. ถ้าไม่ผ่าน

สิ่งที่พลาดง่าย: ทดสอบเฉพาะยอด 600 แล้วไม่เห็นบั๊กที่ 500. ตรวจเครื่องหมายคำพูด การขึ้นบรรทัดใหม่ และค่าที่ print ทีละบรรทัด

หากต้องการความช่วยเหลือหลังลองเอง ให้ใช้ py -3.12 -B practice.py hint L02-E004 1. คำใบ้และการเปิดเฉลยจะถูกบันทึกใน progress
