# L06-E009 — เลือกทุกแถวที่สอง

**ระดับ:** Level 6 — วิเคราะห์ข้อมูล<br>
**ความยาก:** Tier 2 — ง่าย — รวมแนวคิดคุ้นเคย<br>
**ชนิดคำตอบ:** เขียนฟังก์ชันและคืนค่าด้วย return

## 1. เรียนรู้อะไร

คืน index 0,2,4,... ของข้อมูลตามลำดับ

## 2. ก่อนเริ่ม

ทบทวน: [L06-E008](L06-E008.md). หากคำศัพท์ในโจทย์ยังไม่คุ้น ให้เริ่มจากคำอธิบายแนวคิดในหน้านี้ก่อน

**แนวคิดสำคัญ:** แนวคิด: คืน index 0,2,4,... ของข้อมูลตามลำดับ

ลำดับคิด: ใช้ slicing step 2 ที่เริ่ม index 0

## 3. ตัวอย่างสั้น

ตัวอย่างนี้ฝึกแนวคิดที่เกี่ยวข้อง แต่ใช้ค่าและสถานการณ์แยกจากโจทย์ที่ต้องส่ง

~~~python
import json
settings = json.loads('{"mode": "offline", "retry": 2}')
print(settings["mode"], settings["retry"])
~~~

อ่าน arguments ที่ส่งให้ฟังก์ชันแล้วตามค่าที่ return; ถ้าไม่มี print การคืนค่าไม่ได้แสดงใน Terminal

## 4. งานของคุณ

สถานการณ์: ทีม dashboard เลือกทุกแถวคู่เพื่อทำตัวอย่างย่อโดยเริ่มที่แถวแรก

เขียน downsample_every_second_row(values) ตามกติกา: คืน index 0,2,4,... ของข้อมูลตามลำดับ.

กรณีขอบ: ไม่สุ่มและไม่แก้ list เดิม; list ว่างคืน [].
ส่งค่ากลับด้วย return และอย่าแก้ input ต้นฉบับ

## 5. เขียนคำตอบที่ไหน

ไฟล์ส่งคำตอบ: [exercises/level_06/L06-E009.py](../exercises/level_06/L06-E009.py)

แก้ฟังก์ชัน downsample_every_second_row(values) ในไฟล์นี้. คงชื่อและ signature ไว้ และคืนผลด้วย return

## 6. ลำดับทำงาน

1. อ่าน signature downsample_every_second_row(values) และดูว่า parameter แต่ละตัวรับข้อมูลอะไร
2. แก้เฉพาะ body ที่โจทย์กำหนด และส่งผลด้วย return
3. ตรวจกรณีขอบที่ระบุ โดยคงชื่อฟังก์ชันและ signature
4. ใช้ run ดูค่าคืนจากกรณีแรก แล้วใช้ check ตรวจ test ทั้งหมด

## 7. ข้อมูลเข้าและผลลัพธ์

- **ข้อมูลเข้า:** grader เรียก downsample_every_second_row ด้วย parameters ตาม signature ที่ให้.
- **ผลลัพธ์:** ฟังก์ชันต้องคืนค่า (list); return ส่งค่ากลับ ส่วน print แสดงข้อความ.
- **ชุดตรวจ:** มี 2 กรณี รวมขอบเขตตามโจทย์

ข้อจำกัดที่ต้องรักษา: Python 3.12; ไม่สุ่มและไม่แก้ list เดิม; list ว่างคืน []; ใช้ข้อมูลตามรูปแบบที่ระบุในโจทย์; output ต้องตรงทั้งชนิดและลำดับ

## 9. ถ้าไม่ผ่าน
