# L06-E014 — จับคู่ลำดับกับค่า

**ระดับ:** Level 6 — วิเคราะห์ข้อมูล<br>
**ความยาก:** Tier 2 — ง่าย — รวมแนวคิดคุ้นเคย<br>
**ชนิดคำตอบ:** เขียนฟังก์ชันและคืนค่าด้วย return

## 1. เรียนรู้อะไร

คืน list ของ (index,value) โดยเริ่ม index ที่ 0 และเก็บ None ตามจริง

## 2. ก่อนเริ่ม

ทบทวน: [L06-E013](L06-E013.md). หากคำศัพท์ในโจทย์ยังไม่คุ้น ให้เริ่มจากคำอธิบายแนวคิดในหน้านี้ก่อน

**แนวคิดสำคัญ:** แนวคิด: คืน list ของ (index,value) โดยเริ่ม index ที่ 0 และเก็บ None ตามจริง

ลำดับคิด: ใช้ enumerate เพื่อสร้างคู่ index/value

## 3. ตัวอย่างสั้น

ตัวอย่างนี้ฝึกแนวคิดที่เกี่ยวข้อง แต่ใช้ค่าและสถานการณ์แยกจากโจทย์ที่ต้องส่ง

~~~python
from math import sqrt
print(sqrt(81))
~~~

อ่าน arguments ที่ส่งให้ฟังก์ชันแล้วตามค่าที่ return; ถ้าไม่มี print การคืนค่าไม่ได้แสดงใน Terminal

## 4. งานของคุณ

สถานการณ์: นักวิเคราะห์เก็บหมายเลขแถวคู่กับค่าที่โหลดจากไฟล์

เขียน pair_indexes_and_values(values) ตามกติกา: คืน list ของ (index,value) โดยเริ่ม index ที่ 0 และเก็บ None ตามจริง.

กรณีขอบ: ข้อมูลว่างคืน []; ไม่กรอง missing.
ส่งค่ากลับด้วย return และอย่าแก้ input ต้นฉบับ
