# L07-E010 — ผลตอบแทนลอการิทึม

**ระดับ:** Level 7 — คณิตศาสตร์และสถิติ<br>
**ความยาก:** Tier 4 — ท้าทาย — เงื่อนไขและกรณีขอบ<br>
**ชนิดคำตอบ:** เขียนฟังก์ชันและคืนค่าด้วย return

## 1. เรียนรู้อะไร

สำหรับราคาติดกันที่เป็นบวก คืน ln(current/previous)

## 2. ก่อนเริ่ม

ทบทวน: [L07-E009](L07-E009.md). หากคำศัพท์ในโจทย์ยังไม่คุ้น ให้เริ่มจากคำอธิบายแนวคิดในหน้านี้ก่อน

**แนวคิดสำคัญ:** แนวคิด: สำหรับราคาติดกันที่เป็นบวก คืน ln(current/previous)

ลำดับคิด: ตรวจราคาทั้งสองเป็นบวก; ใช้ natural log ของอัตราส่วน

## 3. ตัวอย่างสั้น

ตัวอย่างนี้ฝึกแนวคิดที่เกี่ยวข้อง แต่ใช้ค่าและสถานการณ์แยกจากโจทย์ที่ต้องส่ง

~~~python
values = [2, 5, 3]
total = 0
for value in values:
    total += value
print(total)
~~~

อ่าน arguments ที่ส่งให้ฟังก์ชันแล้วตามค่าที่ return; ถ้าไม่มี print การคืนค่าไม่ได้แสดงใน Terminal

## 4. งานของคุณ

สถานการณ์: นักวิเคราะห์คำนวณ log return ระหว่างราคาปิดที่เรียงตามเวลา

เขียน log_returns(values) ตามกติกา: สำหรับราคาติดกันที่เป็นบวก คืน ln(current/previous).

กรณีขอบ: ข้ามคู่ที่ราคาใดไม่มากกว่า 0; ค่าผลลัพธ์เป็น log return ไม่ใช่เปอร์เซ็นต์อย่างง่าย.
ส่งค่ากลับด้วย return และอย่าแก้ input ต้นฉบับ

## 6. ลำดับทำงาน

1. อ่าน signature log_returns(values) และดูว่า parameter แต่ละตัวรับข้อมูลอะไร
2. แก้เฉพาะ body ที่โจทย์กำหนด และส่งผลด้วย return
3. ตรวจกรณีขอบที่ระบุ โดยคงชื่อฟังก์ชันและ signature
4. ใช้ run ดูค่าคืนจากกรณีแรก แล้วใช้ check ตรวจ test ทั้งหมด

## 7. ข้อมูลเข้าและผลลัพธ์

- **ข้อมูลเข้า:** grader เรียก log_returns ด้วย parameters ตาม signature ที่ให้.
- **ผลลัพธ์:** ฟังก์ชันต้องคืนค่า (list); return ส่งค่ากลับ ส่วน print แสดงข้อความ.
- **ชุดตรวจ:** มี 2 กรณี รวมขอบเขตตามโจทย์

ข้อจำกัดที่ต้องรักษา: Python 3.12; ข้ามคู่ที่ราคาใดไม่มากกว่า 0; ค่าผลลัพธ์เป็น log return ไม่ใช่เปอร์เซ็นต์อย่างง่าย; ใช้ข้อมูลตามรูปแบบที่ระบุในโจทย์; output ต้องตรงทั้งชนิดและลำดับ
