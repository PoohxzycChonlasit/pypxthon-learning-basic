# L10-E001 — ตรวจคำสั่ง paper

**ระดับ:** Level 10 — วิศวกรรม paper bot ออฟไลน์<br>
**ความยาก:** Tier 1 — ง่ายมาก — แนวคิดเดียว<br>
**ชนิดคำตอบ:** เขียนฟังก์ชันและคืนค่าด้วย return

## 1. เรียนรู้อะไร

True เมื่อ event เป็น dict, side ถูกต้อง, quantity/price finite และบวก, cash finite ไม่ติดลบ; buy ต้องไม่เกิน cash

## 2. ก่อนเริ่ม

ทบทวน: [L09-E015](L09-E015.md). หากคำศัพท์ในโจทย์ยังไม่คุ้น ให้เริ่มจากคำอธิบายแนวคิดในหน้านี้ก่อน

**แนวคิดสำคัญ:** แนวคิด: True เมื่อ event เป็น dict, side ถูกต้อง, quantity/price finite และบวก, cash finite ไม่ติดลบ; buy ต้องไม่เกิน cash

ขั้นตอน: ตรวจชนิด event; ตรวจ side; ตรวจตัวเลขและ isfinite; เช็ก notional เทียบ cash เฉพาะ buy

## 3. ตัวอย่างสั้น

ตัวอย่างนี้ฝึกแนวคิดที่เกี่ยวข้อง แต่ใช้ค่าและสถานการณ์แยกจากโจทย์ที่ต้องส่ง

~~~python
from math import sqrt
print(sqrt(81))
~~~

อ่าน arguments ที่ส่งให้ฟังก์ชันแล้วตามค่าที่ return; ถ้าไม่มี print การคืนค่าไม่ได้แสดงใน Terminal

## 4. งานของคุณ

สถานการณ์: ระบบ paper bot รับคำสั่ง buy/sell ที่ราคาและจำนวนถูกต้องและผ่านวงเงินเงินสด

เขียน validate_paper_order(event) ตามสัญญา: True เมื่อ event เป็น dict, side ถูกต้อง, quantity/price finite และบวก, cash finite ไม่ติดลบ; buy ต้องไม่เกิน cash.

กรณีขอบ: ขายไม่ลด cash ล่วงหน้า; bool ไม่ถือเป็นจำนวนเงิน; ไม่มีการส่ง order จริง.
ใช้ข้อมูลจำลองออฟไลน์เท่านั้นและคืนค่าตามโจทย์

## 5. เขียนคำตอบที่ไหน

ไฟล์ส่งคำตอบ: [exercises/level_10/L10-E001.py](../exercises/level_10/L10-E001.py)

แก้ฟังก์ชัน validate_paper_order(event) ในไฟล์นี้. คงชื่อและ signature ไว้ และคืนผลด้วย return

## 6. ลำดับทำงาน

1. อ่าน signature validate_paper_order(event) และดูว่า parameter แต่ละตัวรับข้อมูลอะไร
2. แก้เฉพาะ body ที่โจทย์กำหนด และส่งผลด้วย return
3. ตรวจกรณีขอบที่ระบุ โดยคงชื่อฟังก์ชันและ signature
4. ใช้ run ดูค่าคืนจากกรณีแรก แล้วใช้ check ตรวจ test ทั้งหมด

## 7. ข้อมูลเข้าและผลลัพธ์

- **ข้อมูลเข้า:** grader เรียก validate_paper_order ด้วย parameters ตาม signature ที่ให้.
- **ผลลัพธ์:** ฟังก์ชันต้องคืนค่า (bool); return ส่งค่ากลับ ส่วน print แสดงข้อความ.
- **ชุดตรวจ:** มี 2 กรณี รวมขอบเขตตามโจทย์

ข้อจำกัดที่ต้องรักษา: Python 3.12; ขายไม่ลด cash ล่วงหน้า; bool ไม่ถือเป็นจำนวนเงิน; ไม่มีการส่ง order จริง; ไม่มีการเชื่อมต่อ exchange หรือ wallet

## 8. Run และ Check

รันจากโฟลเดอร์โครงการที่มี practice.py:

~~~powershell

py -3.12 -B practice.py check L10-E001
~~~


การกด Run บนฟังก์ชันที่มีแต่ def อาจไม่แสดงอะไร เพราะยังไม่มีใครเรียกฟังก์ชัน; practice.py run เรียก test แรกให้ ส่วน check เรียกทุกกรณี

Run ทดลองกรณีตัวอย่างแรก; Check เปรียบเทียบกับทุกกรณีและบันทึกสถานะการเรียน

## 9. ถ้าไม่ผ่าน

สิ่งที่พลาดง่าย: ขายไม่ลด cash ล่วงหน้า; bool ไม่ถือเป็นจำนวนเงิน; ไม่มีการส่ง order จริง ห้ามแปลงงานจำลองเป็นคำสั่งเงินจริง. ตรวจค่าที่คืนและชนิดของมันก่อนตรวจการแสดงผล
