# L05-E008 — ลบช่องว่างจากฟิลด์

**ระดับ:** Level 5 — Python สำหรับงานจริง<br>
**ความยาก:** Tier 3 — ปานกลาง — หลายขั้นตอน<br>
**ชนิดคำตอบ:** เขียนฟังก์ชันและคืนค่าด้วย return

## 1. เรียนรู้อะไร

แยกด้วย comma; strip ค่า; ทิ้ง field ที่ว่างหลัง strip

## 2. ก่อนเริ่ม

ทบทวน: [L05-E007](L05-E007.md). หากคำศัพท์ในโจทย์ยังไม่คุ้น ให้เริ่มจากคำอธิบายแนวคิดในหน้านี้ก่อน

**แนวคิดสำคัญ:** แนวคิด: แยกด้วย comma; strip ค่า; ทิ้ง field ที่ว่างหลัง strip

ลำดับคิด: กรอง field หลัง strip แล้วสร้าง list

## 3. ตัวอย่างสั้น

ตัวอย่างนี้ฝึกแนวคิดที่เกี่ยวข้อง แต่ใช้ค่าและสถานการณ์แยกจากโจทย์ที่ต้องส่ง

~~~python
class Product:
    def __init__(self, name, price):
        self.name = name
        self.price = price
tea = Product("tea", 20)
print(tea.name, tea.price)
~~~

อ่าน arguments ที่ส่งให้ฟังก์ชันแล้วตามค่าที่ return; ถ้าไม่มี print การคืนค่าไม่ได้แสดงใน Terminal

## 4. งานของคุณ

สถานการณ์: ทีมจัดซื้อแปลงช่องรายการที่ไม่ว่างจากบรรทัดคำสั่งซื้อให้เป็น list

เขียน remove_blank_fields(text) ตามกติกา: แยกด้วย comma; strip ค่า; ทิ้ง field ที่ว่างหลัง strip.

กรณีขอบ: input ว่างคืน []; คงลำดับและค่าซ้ำ.
ส่งค่ากลับด้วย return และอย่าแก้ input ต้นฉบับ

## 6. ลำดับทำงาน

1. อ่าน signature remove_blank_fields(text) และดูว่า parameter แต่ละตัวรับข้อมูลอะไร
2. แก้เฉพาะ body ที่โจทย์กำหนด และส่งผลด้วย return
3. ตรวจกรณีขอบที่ระบุ โดยคงชื่อฟังก์ชันและ signature
4. ใช้ run ดูค่าคืนจากกรณีแรก แล้วใช้ check ตรวจ test ทั้งหมด

## 7. ข้อมูลเข้าและผลลัพธ์

- **ข้อมูลเข้า:** grader เรียก remove_blank_fields ด้วย parameters ตาม signature ที่ให้.
- **ผลลัพธ์:** ฟังก์ชันต้องคืนค่า (list); return ส่งค่ากลับ ส่วน print แสดงข้อความ.
- **ชุดตรวจ:** มี 2 กรณี รวมขอบเขตตามโจทย์

ข้อจำกัดที่ต้องรักษา: Python 3.12; input ว่างคืน []; คงลำดับและค่าซ้ำ; ใช้ข้อมูลตามรูปแบบที่ระบุในโจทย์; output ต้องตรงทั้งชนิดและลำดับ
