# L08-E005 — ตรวจ exposure รวมของพอร์ตจำลอง

**ระดับ:** Level 8 — การเงินและความเสี่ยง<br>
**ความยาก:** Tier 2 — ง่าย — รวมแนวคิดคุ้นเคย<br>
**ชนิดคำตอบ:** โปรแกรม Python แสดงผล (stdout)

## 1. เรียนรู้อะไร

รวมมูลค่าสถานะและเทียบกับสัดส่วนเพดานของ equity

## 2. ก่อนเริ่ม

ทบทวน: [L08-E004](L08-E004.md). หากคำศัพท์ในโจทย์ยังไม่คุ้น ให้เริ่มจากคำอธิบายแนวคิดในหน้านี้ก่อน

**แนวคิดสำคัญ:** exposure คือมูลค่าที่ถืออยู่รวม ไม่ใช่เงินสด; allowed เป็นเพียงการตรวจ risk limit ตามกติกานี้

## 3. ตัวอย่างสั้น

ตัวอย่างนี้ฝึกแนวคิดที่เกี่ยวข้อง แต่ใช้ค่าและสถานการณ์แยกจากโจทย์ที่ต้องส่ง

~~~python
for step in range(3):
    print("step", step + 1)
~~~

ในตัวอย่างนี้ ให้ดูว่าคำสั่ง print ส่งค่าใดไปยังหน้าจอ; ข้อความหลังเครื่องหมาย # เป็นคำอธิบาย output ของตัวอย่าง

## 4. งานของคุณ

ผู้ดูแล paper portfolio มี equity และมูลค่าสถานะตามสินทรัพย์ ตรวจ exposure รวมเทียบ max_fraction ของ equity ถ้าค่าเป็นลบ, equity ไม่บวก หรือ max_fraction นอกช่วง 0 ถึง 1 ให้แสดง INVALID มิฉะนั้นรายงาน exposure และ allowed

1. อ่านโจทย์และตัวอย่างแยก แล้วหา TODO หรือบรรทัดที่ต้องแก้ในไฟล์ Python

## 7. ข้อมูลเข้าและผลลัพธ์

- **ข้อมูลเข้า:** ใช้ input ที่โจทย์หรือ test ส่งให้; ถ้าไม่มี stdin ก็ไม่ต้องพิมพ์ค่าเพิ่ม.
- **ผลลัพธ์:** ข้อความที่โปรแกรมส่งไป stdout ต้องมีลำดับ บรรทัด และรูปแบบตรงตามโจทย์.
- **การแสดงผล:** print() แสดงค่าที่ Terminal; การกำหนดตัวแปรอย่างเดียวไม่ทำให้เกิด output
