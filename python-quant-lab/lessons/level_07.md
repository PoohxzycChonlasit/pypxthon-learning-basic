**เป้าหมาย:** เข้าใจความหมายของตัวชี้วัดก่อนเขียนสูตร และแยกความผันผวนออกจากความแน่นอน

## พิมพ์ตาม: ค่าเฉลี่ยและความแปรปรวนประชากร

### ขั้นที่ 1 — แนวคิด

ค่าเฉลี่ยบอกจุดกึ่งกลางแบบหนึ่ง แต่ค่าผิดปกติอาจดึงค่าเฉลี่ย ความแปรปรวนประชากรเฉลี่ยระยะห่างกำลังสองจากค่าเฉลี่ย จึงบอกการกระจายของชุดข้อมูลที่มีอยู่

### ขั้นที่ 2–3 — พิมพ์ตัวอย่างนี้

~~~python
values = [2, 4, 4, 6]
mean = sum(values) / len(values)
squared_distances = []

for value in values:
    squared_distances.append((value - mean) ** 2)

population_variance = sum(squared_distances) / len(values)
print(mean)
print(population_variance)
~~~

### ขั้นที่ 4 — อ่านทีละส่วน

- sum/len คำนวณค่าเฉลี่ย
- ลูปหาค่าคลาดจาก mean แล้วยกกำลังสอง
- หารด้วยจำนวนข้อมูลทั้งหมดเพื่อหาความแปรปรวนประชากร

### ขั้นที่ 5 — ผลลัพธ์ที่คาด

### ขั้นที่ 6–7 — ทดลองเปลี่ยน

เพิ่มค่า 4 เข้าไปใน values ค่าเฉลี่ยยังเป็น 4 แต่ความแปรปรวนลดลง เพราะมีข้อมูลอยู่ใกล้ค่าเฉลี่ยมากขึ้น

### ขั้นที่ 8 — ลองเอง

เขียนการหาค่ามัธยฐานของ [1, 2, 100] แล้วอธิบายว่าทำไมค่ามัธยฐานต่างจากค่าเฉลี่ย ลองเปลี่ยนหน่วยข้อมูลแล้วดูว่าสถิติใดเปลี่ยนตาม

**แนวคิดของระดับนี้:** ส่วนเบี่ยงเบนมาตรฐานมีหน่วยเดียวกับข้อมูล; correlation ไม่ได้แปลว่าเหตุหนึ่งทำให้อีกเหตุเกิด; ช่วงความเชื่อมั่นและการทดสอบสมมติฐานขึ้นกับวิธีสุ่มและข้อสมมติ
