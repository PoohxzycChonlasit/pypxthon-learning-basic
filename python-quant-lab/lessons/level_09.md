# Level 9 — วิจัย Quant และ backtest

**เป้าหมาย:** สร้างสมมติฐานที่ตรวจสอบได้ และป้องกันการใช้ข้อมูลอนาคตระหว่างทดสอบ

## พิมพ์ตาม: ใช้เฉพาะข้อมูลที่รู้ก่อนเวลาตัดสินใจ

### ขั้นที่ 1 — แนวคิด

ถ้าต้องตัดสินใจ ณ แถวปัจจุบัน สัญญาณควรใช้เฉพาะข้อมูลที่เกิดก่อนหรือถึงเวลาที่กำหนด อย่าใช้ราคาปิดอนาคตเพื่อสร้างสัญญาณย้อนหลัง

### ขั้นที่ 2–3 — พิมพ์ตัวอย่างนี้

~~~python
closes = [100, 102, 101, 104]

for index in range(2, len(closes)):
    previous_two = closes[index - 2:index]
    reference = sum(previous_two) / len(previous_two)
    current = closes[index]
    print(index, current, round(reference, 1))
~~~

### ขั้นที่ 4 — อ่านทีละส่วน

- index คือจุดที่กำลังประเมิน
- slice หยุดก่อน index จึงไม่มีราคาปัจจุบันหรืออนาคตใน reference
- current ใช้เปรียบเทียบกับค่าอ้างอิงเพื่อทดสอบสมมติฐาน

### ขั้นที่ 5 — ผลลัพธ์ที่คาด

~~~text
2 101 101.0
3 104 101.5
~~~

### ขั้นที่ 6–7 — ทดลองเปลี่ยน

เปลี่ยนราคาสุดท้าย 104 เป็น 90 แถว index 2 ต้องได้ผลเหมือนเดิม เพราะยังไม่ควรรู้ค่าของแถวสุดท้าย

### ขั้นที่ 8 — ลองเอง

เขียนเกณฑ์ง่าย ๆ ว่าราคาปัจจุบันสูงกว่าค่าเฉลี่ยของข้อมูลก่อนหน้าหรือไม่ จากนั้นเทียบกับ benchmark ที่ไม่ใช้สัญญาณ รายงานจำนวนครั้งและต้นทุนที่ยังไม่รวม

**แนวคิดของระดับนี้:** แยก in-sample/out-of-sample ก่อนทดลอง ป้องกัน leakage และบันทึกสมมติฐานก่อนเลือกพารามิเตอร์; ผลย้อนหลังไม่ยืนยัน edge
