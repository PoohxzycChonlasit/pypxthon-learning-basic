# L02-E001 — นับวันที่กำไร

**ระดับ:** Level 2 — เงื่อนไขและลูป<br>
**ความยาก:** Tier 1 — ง่ายมาก — แนวคิดเดียว<br>
**ชนิดคำตอบ:** เขียนฟังก์ชันและคืนค่าด้วย return

## 1. เรียนรู้อะไร

นับสมาชิกที่มากกว่า 0; ศูนย์ไม่ใช่กำไร

## 2. ก่อนเริ่ม

ทบทวน: [L01-E015](L01-E015.md). หากคำศัพท์ในโจทย์ยังไม่คุ้น ให้เริ่มจากคำอธิบายแนวคิดในหน้านี้ก่อน

**แนวคิดสำคัญ:** เริ่มตัวนับที่ 0; `for` อ่านค่าทีละตัว; `if` เลือกค่าที่มากกว่า 0; `count += 1` เพิ่มตัวนับหนึ่ง

จำลำดับนี้: เริ่ม count ที่ 0; ตรวจทีละค่า; เพิ่ม count เมื่อ value > 0; รายการว่างให้คืน 0

## 3. ตัวอย่างสั้น

ตัวอย่างนี้ฝึกแนวคิดที่เกี่ยวข้อง แต่ใช้ค่าและสถานการณ์แยกจากโจทย์ที่ต้องส่ง

~~~python
scores = [-2, 5, 0]
positive_count = 0
for score in scores:
    if score > 0:
        positive_count += 1
print(positive_count)  # 1
~~~

วนตรวจสมาชิกทีละค่าและเพิ่มตัวนับเมื่อ score > 0; ตัวอย่างนี้ได้ 1. งานจริงของคุณต้องคืนผลด้วย `return` จากฟังก์ชัน

## 4. งานของคุณ

สถานการณ์: ผู้จัดการร้านสรุปวันที่บัญชีรายวันมีกำไรสุทธิ

เขียน count_profitable_days(values) ให้ทำตามสัญญา: นับสมาชิกที่มากกว่า 0; ศูนย์ไม่ใช่กำไร.

กรณีขอบ: รายการว่างคืน 0.
ส่งค่ากลับด้วย return และรักษาชนิดผลลัพธ์ตามตัวอย่าง

## 5. เขียนคำตอบที่ไหน

ไฟล์ส่งคำตอบ: [exercises/level_02/L02-E001.py](../exercises/level_02/L02-E001.py)

แก้ฟังก์ชัน count_profitable_days(values) ในไฟล์นี้. คงชื่อและ signature ไว้ และคืนผลด้วย return

## 6. ลำดับทำงาน

1. อ่าน signature count_profitable_days(values) และดูว่า parameter แต่ละตัวรับข้อมูลอะไร
2. แก้เฉพาะ body ที่โจทย์กำหนด และส่งผลด้วย return
3. ตรวจกรณีขอบที่ระบุ โดยคงชื่อฟังก์ชันและ signature
4. ใช้ run ดูค่าคืนจากกรณีแรก แล้วใช้ check ตรวจ test ทั้งหมด

## 7. ข้อมูลเข้าและผลลัพธ์

- **ข้อมูลเข้า:** grader เรียก count_profitable_days ด้วย parameters ตาม signature ที่ให้.
- **ผลลัพธ์:** ฟังก์ชันต้องคืนค่า (int); return ส่งค่ากลับ ส่วน print แสดงข้อความ.
- **ชุดตรวจ:** มี 2 กรณี รวมขอบเขตตามโจทย์

ข้อจำกัดที่ต้องรักษา: Python 3.12; รายการว่างคืน 0; ใช้เฉพาะข้อมูลตามสัญญาโจทย์; ห้ามแก้ grader หรือเฉลย
