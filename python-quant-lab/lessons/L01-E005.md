# L01-E005 — คำนวณยอดซื้ออย่างง่าย

## เป้าหมาย

ประยุกต์ตัวแปรและการคูณกับยอดซื้อ

## แนวคิด

เมื่อราคาต่อชิ้นเท่ากัน ยอดก่อนค่าธรรมเนียมเท่ากับราคา * จำนวน

## ตัวอย่าง

```python
unit_price = 5
count = 2
subtotal = unit_price * count
```

## โจทย์

เขียนโปรแกรมกำหนดราคาต่อชิ้น 25 บาทและจำนวน 4 ชิ้น แล้วแสดงยอดรวมเป็น `100`

## รูปแบบ input/output

กำหนดค่าตามโจทย์ในโปรแกรม

ผลที่ต้องการ: 100

ข้อควรระวัง: แสดงแค่ราคาต่อชิ้น ไม่ใช่ยอดรวม
