# L06-E010 — คำนวณพิสัย

**ระดับ:** Level 6 — วิเคราะห์ข้อมูล<br>
**ความยาก:** Tier 2 — ง่าย — รวมแนวคิดคุ้นเคย<br>
**ชนิดคำตอบ:** เขียนฟังก์ชันและคืนค่าด้วย return

## 1. เรียนรู้อะไร

คืน max(valid)-min(valid) โดยละเว้น None; ถ้าไม่มีค่าคืน None

## 2. ก่อนเริ่ม

ทบทวน: [L06-E009](L06-E009.md). หากคำศัพท์ในโจทย์ยังไม่คุ้น ให้เริ่มจากคำอธิบายแนวคิดในหน้านี้ก่อน

**แนวคิดสำคัญ:** แนวคิด: คืน max(valid)-min(valid) โดยละเว้น None; ถ้าไม่มีค่าคืน None

ลำดับคิด: สร้างชุดค่าที่ไม่ใช่ None; ถ้ามีให้ลบ min ออกจาก max

## 3. ตัวอย่างสั้น

ตัวอย่างนี้ฝึกแนวคิดที่เกี่ยวข้อง แต่ใช้ค่าและสถานการณ์แยกจากโจทย์ที่ต้องส่ง

~~~python
import csv
import io
rows = list(csv.DictReader(io.StringIO("sku,qty\nA1,2\n")))
print(rows[0]["sku"], int(rows[0]["qty"]))
~~~

อ่าน arguments ที่ส่งให้ฟังก์ชันแล้วตามค่าที่ return; ถ้าไม่มี print การคืนค่าไม่ได้แสดงใน Terminal

## 4. งานของคุณ

สถานการณ์: นักวิเคราะห์สรุปช่วงการแกว่งของคอลัมน์ยอดขายที่มี missing values

เขียน compute_range(values) ตามกติกา: คืน max(valid)-min(valid) โดยละเว้น None; ถ้าไม่มีค่าคืน None.

กรณีขอบ: ค่าเดียวมี range 0; zero เป็นข้อมูลจริง.
ส่งค่ากลับด้วย return และอย่าแก้ input ต้นฉบับ

## 6. ลำดับทำงาน

1. อ่าน signature compute_range(values) และดูว่า parameter แต่ละตัวรับข้อมูลอะไร

3. ตรวจกรณีขอบที่ระบุ โดยคงชื่อฟังก์ชันและ signature
4. ใช้ run ดูค่าคืนจากกรณีแรก แล้วใช้ check ตรวจ test ทั้งหมด

## 7. ข้อมูลเข้าและผลลัพธ์

- **ข้อมูลเข้า:** grader เรียก compute_range ด้วย parameters ตาม signature ที่ให้.
- **ผลลัพธ์:** ฟังก์ชันต้องคืนค่า (int); return ส่งค่ากลับ ส่วน print แสดงข้อความ.
- **ชุดตรวจ:** มี 2 กรณี รวมขอบเขตตามโจทย์
