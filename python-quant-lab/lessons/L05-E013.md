# L05-E013 — ตรวจจำนวนฟิลด์

**ระดับ:** Level 5 — Python สำหรับงานจริง<br>
**ความยาก:** Tier 2 — ง่าย — รวมแนวคิดคุ้นเคย<br>
**ชนิดคำตอบ:** เขียนฟังก์ชันและคืนค่าด้วย return

## 1. เรียนรู้อะไร

คืน True เมื่อจำนวน comma-separated field เท่ากับ 3 มิฉะนั้น False

## 2. ก่อนเริ่ม

ทบทวน: [L05-E012](L05-E012.md). หากคำศัพท์ในโจทย์ยังไม่คุ้น ให้เริ่มจากคำอธิบายแนวคิดในหน้านี้ก่อน

**แนวคิดสำคัญ:** แนวคิด: คืน True เมื่อจำนวน comma-separated field เท่ากับ 3 มิฉะนั้น False

ลำดับคิด: นับจำนวนส่วนที่ได้จาก split comma และเทียบกับ 3

## 3. ตัวอย่างสั้น

ตัวอย่างนี้ฝึกแนวคิดที่เกี่ยวข้อง แต่ใช้ค่าและสถานการณ์แยกจากโจทย์ที่ต้องส่ง

~~~python
def add_tip(total, rate=0.05):
    return total + total * rate
print(add_tip(80))
~~~

อ่าน arguments ที่ส่งให้ฟังก์ชันแล้วตามค่าที่ return; ถ้าไม่มี print การคืนค่าไม่ได้แสดงใน Terminal

## 4. งานของคุณ

สถานการณ์: ทีมตรวจข้อมูลก่อน import ต้องยืนยันว่า record มีสาม field คั่นด้วย comma

เขียน validate_three_fields(text) ตามกติกา: คืน True เมื่อจำนวน comma-separated field เท่ากับ 3 มิฉะนั้น False.

กรณีขอบ: รองรับ field ว่างได้หากยังมีสามช่อง; ไม่รองรับ comma ที่ quote ครอบ.
ส่งค่ากลับด้วย return และอย่าแก้ input ต้นฉบับ

## 5. เขียนคำตอบที่ไหน

ไฟล์ส่งคำตอบ: [exercises/level_05/L05-E013.py](../exercises/level_05/L05-E013.py)

แก้ฟังก์ชัน validate_three_fields(text) ในไฟล์นี้. คงชื่อและ signature ไว้ และคืนผลด้วย return

## 6. ลำดับทำงาน

1. อ่าน signature validate_three_fields(text) และดูว่า parameter แต่ละตัวรับข้อมูลอะไร
2. แก้เฉพาะ body ที่โจทย์กำหนด และส่งผลด้วย return
3. ตรวจกรณีขอบที่ระบุ โดยคงชื่อฟังก์ชันและ signature
4. ใช้ run ดูค่าคืนจากกรณีแรก แล้วใช้ check ตรวจ test ทั้งหมด

## 7. ข้อมูลเข้าและผลลัพธ์

- **ข้อมูลเข้า:** grader เรียก validate_three_fields ด้วย parameters ตาม signature ที่ให้.
- **ผลลัพธ์:** ฟังก์ชันต้องคืนค่า (bool); return ส่งค่ากลับ ส่วน print แสดงข้อความ.
- **ชุดตรวจ:** มี 2 กรณี รวมขอบเขตตามโจทย์

ข้อจำกัดที่ต้องรักษา: Python 3.12; รองรับ field ว่างได้หากยังมีสามช่อง; ไม่รองรับ comma ที่ quote ครอบ; ใช้ข้อมูลตามรูปแบบที่ระบุในโจทย์; output ต้องตรงทั้งชนิดและลำดับ

## 9. ถ้าไม่ผ่าน

สิ่งที่พลาดง่าย: รองรับ field ว่างได้หากยังมีสามช่อง; ไม่รองรับ comma ที่ quote ครอบ ตรวจชนิดข้อมูลและลำดับผลลัพธ์ก่อน return. ตรวจค่าที่คืนและชนิดของมันก่อนตรวจการแสดงผล
