# L10-E006 — หยุดเมื่อเงินถึงขีดจำกัด

**ระดับ:** Level 10 — วิศวกรรม paper bot ออฟไลน์<br>
**ความยาก:** Tier 2 — ง่าย — รวมแนวคิดคุ้นเคย<br>
**ชนิดคำตอบ:** เขียนฟังก์ชันและคืนค่าด้วย return

## 1. เรียนรู้อะไร

คืน True เมื่อ cash <= risk_floor; ถ้าไม่มี floor ให้ใช้ 0

## 2. ก่อนเริ่ม

ทบทวน: [L10-E005](L10-E005.md). หากคำศัพท์ในโจทย์ยังไม่คุ้น ให้เริ่มจากคำอธิบายแนวคิดในหน้านี้ก่อน

**แนวคิดสำคัญ:** แนวคิด: คืน True เมื่อ cash <= risk_floor; ถ้าไม่มี floor ให้ใช้ 0

ขั้นตอน: อ่าน cash และ risk_floor; เปรียบเทียบด้วย <=

## 3. ตัวอย่างสั้น

ตัวอย่างนี้ฝึกแนวคิดที่เกี่ยวข้อง แต่ใช้ค่าและสถานการณ์แยกจากโจทย์ที่ต้องส่ง

~~~python
for step in range(3):
    print("step", step + 1)
~~~

อ่าน arguments ที่ส่งให้ฟังก์ชันแล้วตามค่าที่ return; ถ้าไม่มี print การคืนค่าไม่ได้แสดงใน Terminal

## 4. งานของคุณ

สถานการณ์: risk gate หยุดการจำลองเมื่อ paper cash ลดถึง floor ที่กำหนด

เขียน risk_floor_stop(event) ตามสัญญา: คืน True เมื่อ cash <= risk_floor; ถ้าไม่มี floor ให้ใช้ 0.

กรณีขอบ: ค่าเท่ากับ floor ต้องหยุด; cash สูงกว่า floor ยังทำต่อ.
ใช้ข้อมูลจำลองออฟไลน์เท่านั้นและคืนค่าตามโจทย์

## 5. เขียนคำตอบที่ไหน

ไฟล์ส่งคำตอบ: [exercises/level_10/L10-E006.py](../exercises/level_10/L10-E006.py)

แก้ฟังก์ชัน risk_floor_stop(event) ในไฟล์นี้. คงชื่อและ signature ไว้ และคืนผลด้วย return

## 6. ลำดับทำงาน

1. อ่าน signature risk_floor_stop(event) และดูว่า parameter แต่ละตัวรับข้อมูลอะไร
2. แก้เฉพาะ body ที่โจทย์กำหนด และส่งผลด้วย return
3. ตรวจกรณีขอบที่ระบุ โดยคงชื่อฟังก์ชันและ signature
4. ใช้ run ดูค่าคืนจากกรณีแรก แล้วใช้ check ตรวจ test ทั้งหมด

## 7. ข้อมูลเข้าและผลลัพธ์

- **ข้อมูลเข้า:** grader เรียก risk_floor_stop ด้วย parameters ตาม signature ที่ให้.
- **ผลลัพธ์:** ฟังก์ชันต้องคืนค่า (bool); return ส่งค่ากลับ ส่วน print แสดงข้อความ.
- **ชุดตรวจ:** มี 2 กรณี รวมขอบเขตตามโจทย์

ข้อจำกัดที่ต้องรักษา: Python 3.12; ค่าเท่ากับ floor ต้องหยุด; cash สูงกว่า floor ยังทำต่อ; ไม่มีการเชื่อมต่อ exchange หรือ wallet

## 9. ถ้าไม่ผ่าน
