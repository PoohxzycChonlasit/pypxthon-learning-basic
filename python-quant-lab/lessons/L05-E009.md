# L05-E009 — แยกคู่กุญแจและค่า

**ระดับ:** Level 5 — Python สำหรับงานจริง<br>
**ความยาก:** Tier 3 — ปานกลาง — หลายขั้นตอน<br>
**ชนิดคำตอบ:** เขียนฟังก์ชันและคืนค่าด้วย return

## 1. เรียนรู้อะไร

แปลงคู่ key=value เป็น dict; strip key/value; ถ้าซ้ำให้คู่หลังสุดชนะ; ข้ามส่วนที่ไม่มี =

## 2. ก่อนเริ่ม

ทบทวน: [L05-E008](L05-E008.md). หากคำศัพท์ในโจทย์ยังไม่คุ้น ให้เริ่มจากคำอธิบายแนวคิดในหน้านี้ก่อน

**แนวคิดสำคัญ:** แนวคิด: แปลงคู่ key=value เป็น dict; strip key/value; ถ้าซ้ำให้คู่หลังสุดชนะ; ข้ามส่วนที่ไม่มี =

ลำดับคิด: วนส่วนที่แบ่งด้วย semicolon; แบ่งแต่ละส่วนด้วย = หนึ่งครั้ง; strip และกำหนดค่าใน dict

## 3. ตัวอย่างสั้น

ตัวอย่างนี้ฝึกแนวคิดที่เกี่ยวข้อง แต่ใช้ค่าและสถานการณ์แยกจากโจทย์ที่ต้องส่ง

~~~python
values = [2, 5, 3]
total = 0
for value in values:
    total += value
print(total)
~~~

อ่าน arguments ที่ส่งให้ฟังก์ชันแล้วตามค่าที่ return; ถ้าไม่มี print การคืนค่าไม่ได้แสดงใน Terminal

## 4. งานของคุณ

สถานการณ์: สคริปต์นำเข้าอ่านการตั้งค่ารูปแบบ key=value คั่นด้วย semicolon

เขียน parse_key_value(text) ตามกติกา: แปลงคู่ key=value เป็น dict; strip key/value; ถ้าซ้ำให้คู่หลังสุดชนะ; ข้ามส่วนที่ไม่มี =.

กรณีขอบ: value อาจมีเครื่องหมาย = ภายใน; split ที่เครื่องหมายแรกเท่านั้น.
ส่งค่ากลับด้วย return และอย่าแก้ input ต้นฉบับ
