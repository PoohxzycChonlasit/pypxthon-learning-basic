# L08-E006 — กำไรสุทธิหลังค่าธรรมเนียม

**ระดับ:** Level 8 — การเงินและความเสี่ยง<br>
**ความยาก:** Tier 2 — ง่าย — รวมแนวคิดคุ้นเคย<br>
**ชนิดคำตอบ:** เขียนฟังก์ชันและคืนค่าด้วย return

## 1. เรียนรู้อะไร

net = (exit-entry)*quantity - (entry+exit)*quantity*0.001

## 2. ก่อนเริ่ม

ทบทวน: [L08-E005](L08-E005.md). หากคำศัพท์ในโจทย์ยังไม่คุ้น ให้เริ่มจากคำอธิบายแนวคิดในหน้านี้ก่อน

**แนวคิดสำคัญ:** แนวคิด: net = (exit-entry)*quantity - (entry+exit)*quantity*0.001

คิดทีละขั้น: คำนวณ gross ก่อน; หัก fee ของ notional ทั้งสองขา

## 3. ตัวอย่างสั้น

ตัวอย่างนี้ฝึกแนวคิดที่เกี่ยวข้อง แต่ใช้ค่าและสถานการณ์แยกจากโจทย์ที่ต้องส่ง

~~~python
person = {"name": "Mali", "active": True}
print(person.get("active", False))
~~~

อ่าน arguments ที่ส่งให้ฟังก์ชันแล้วตามค่าที่ return; ถ้าไม่มี print การคืนค่าไม่ได้แสดงใน Terminal

## 4. งานของคุณ

สถานการณ์: นักวิจัยคำนวณกำไรสถานะซื้อหลังเสีย fee 0.1% ของ notional ทั้งขาเข้าและขาออก

เขียน net_long_profit(entry, exit, quantity) ให้ทำตามสัญญา: net = (exit-entry)*quantity - (entry+exit)*quantity*0.001.

กรณีขอบ: ราคาไม่เปลี่ยนยังขาดทุนค่าธรรมเนียม; quantity 0 ให้ผล 0.
คืนค่าเท่านั้น; งานทั้งหมดเป็นการจำลอง paper

แก้ฟังก์ชัน net_long_profit(entry, exit, quantity) ในไฟล์นี้. คงชื่อและ signature ไว้ และคืนผลด้วย return

## 6. ลำดับทำงาน

1. อ่าน signature net_long_profit(entry, exit, quantity) และดูว่า parameter แต่ละตัวรับข้อมูลอะไร
2. แก้เฉพาะ body ที่โจทย์กำหนด และส่งผลด้วย return
3. ตรวจกรณีขอบที่ระบุ โดยคงชื่อฟังก์ชันและ signature
4. ใช้ run ดูค่าคืนจากกรณีแรก แล้วใช้ check ตรวจ test ทั้งหมด

## 7. ข้อมูลเข้าและผลลัพธ์

- **ข้อมูลเข้า:** grader เรียก net_long_profit ด้วย parameters ตาม signature ที่ให้.
- **ผลลัพธ์:** ฟังก์ชันต้องคืนค่า (float); return ส่งค่ากลับ ส่วน print แสดงข้อความ.
- **ชุดตรวจ:** มี 2 กรณี รวมขอบเขตตามโจทย์
