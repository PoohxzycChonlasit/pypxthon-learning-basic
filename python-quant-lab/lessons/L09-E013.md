# L09-E013 — นับจำนวนข้อมูล

**ระดับ:** Level 9 — วิจัย Quant และ backtest<br>
**ความยาก:** Tier 1 — ง่ายมาก — แนวคิดเดียว<br>
**ชนิดคำตอบ:** เขียนฟังก์ชันและคืนค่าด้วย return

## 1. เรียนรู้อะไร

คืนจำนวนสมาชิกใน list รวม missing/zero ตามที่มี

## 2. ก่อนเริ่ม

ทบทวน: [L09-E012](L09-E012.md). หากคำศัพท์ในโจทย์ยังไม่คุ้น ให้เริ่มจากคำอธิบายแนวคิดในหน้านี้ก่อน

**แนวคิดสำคัญ:** แนวคิด: คืนจำนวนสมาชิกใน list รวม missing/zero ตามที่มี

ขั้นตอน: ใช้ len กับรายการต้นฉบับ

## 3. ตัวอย่างสั้น

ตัวอย่างนี้ฝึกแนวคิดที่เกี่ยวข้อง แต่ใช้ค่าและสถานการณ์แยกจากโจทย์ที่ต้องส่ง

~~~python
for step in range(3):
    print("step", step + 1)
~~~

อ่าน arguments ที่ส่งให้ฟังก์ชันแล้วตามค่าที่ return; ถ้าไม่มี print การคืนค่าไม่ได้แสดงใน Terminal

## 4. งานของคุณ

สถานการณ์: นักวิจัยตรวจจำนวน observation ก่อนเปรียบเทียบกลยุทธ์

เขียน count_observations(values) ตามสัญญา: คืนจำนวนสมาชิกใน list รวม missing/zero ตามที่มี.

กรณีขอบ: list ว่างคืน 0.
คืนค่าตามลำดับเวลาและอย่า shuffle time series

## 5. เขียนคำตอบที่ไหน

ไฟล์ส่งคำตอบ: [exercises/level_09/L09-E013.py](../exercises/level_09/L09-E013.py)

แก้ฟังก์ชัน count_observations(values) ในไฟล์นี้. คงชื่อและ signature ไว้ และคืนผลด้วย return

## 6. ลำดับทำงาน

1. อ่าน signature count_observations(values) และดูว่า parameter แต่ละตัวรับข้อมูลอะไร
2. แก้เฉพาะ body ที่โจทย์กำหนด และส่งผลด้วย return
3. ตรวจกรณีขอบที่ระบุ โดยคงชื่อฟังก์ชันและ signature
4. ใช้ run ดูค่าคืนจากกรณีแรก แล้วใช้ check ตรวจ test ทั้งหมด

## 7. ข้อมูลเข้าและผลลัพธ์

- **ข้อมูลเข้า:** grader เรียก count_observations ด้วย parameters ตาม signature ที่ให้.
- **ผลลัพธ์:** ฟังก์ชันต้องคืนค่า (int); return ส่งค่ากลับ ส่วน print แสดงข้อความ.
- **ชุดตรวจ:** มี 2 กรณี รวมขอบเขตตามโจทย์

ข้อจำกัดที่ต้องรักษา: Python 3.12; list ว่างคืน 0; time series เรียงตามเวลา; ห้ามใช้ข้อมูลอนาคตสร้างผลในอดีต
