# L01-E015 — ภารกิจสรุป paper trade

## เป้าหมาย

รวม input, float, ตัวแปร, สูตรกำไร, ค่าธรรมเนียม และ f-string

## แนวคิด

อ่านข้อมูลตามลำดับ เก็บแต่ละค่าในตัวแปร คำนวณ gross และ fees แยกกัน แล้วแสดงผลอย่างมีป้ายกำกับ

## ตัวอย่าง

```python
sales_revenue = 300
supplies_cost = 45
postage_cost = 8
profit = sales_revenue - supplies_cost - postage_cost
print(f"Profit: {profit:.2f}")  # Profit: 247.00
```

## โจทย์

ภารกิจใหม่: เขียนโปรแกรมสรุป paper trade โดยอ่านราคาซื้อ ราคาขาย จำนวนเหรียญ และ fee_percent (เปอร์เซ็นต์) คนละบรรทัด แล้วแสดงสามบรรทัดตามรูปแบบ `Gross: 10.00`, `Fees: 1.21`, `Net: 8.79` คำนวณค่าธรรมเนียมทั้งขาซื้อและขาย ห้ามใช้ข้อมูลหรือคำตอบตายตัว

## รูปแบบ input/output

Variant A ตัวอย่าง: 100, 110, 0.1, 1

ผลที่ต้องการ: gross=(sell-buy)*quantity; fees=(buy+sell)*quantity*fee_percent/100; net=gross-fees

ข้อควรระวัง: hardcode ผลตัวอย่าง, ลืมจำนวนเหรียญ หรือคิดค่าธรรมเนียมเพียงครั้งเดียว
