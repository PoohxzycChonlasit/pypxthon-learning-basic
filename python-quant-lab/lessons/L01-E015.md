# L01-E015 — การประเมิน Level 1

## เป้าหมาย

อ่านข้อมูลตาม variant ที่แสดง คำนวณค่าที่โจทย์ร้องขอจาก input จริง และจัดรูปแบบผลลัพธ์ตามป้ายกำกับ

## วิธีทำ

1. อ่าน prompt และจำนวน input ของ variant ปัจจุบัน
2. แปลง input เป็นตัวเลขก่อนคำนวณ
3. ตั้งชื่อตัวแปรสำหรับผลย่อยและตรวจหน่วย
4. พิมพ์เฉพาะบรรทัดและป้ายกำกับที่ variant นั้นกำหนด โดยใช้ทศนิยมสองตำแหน่ง

ตัวอย่างและสูตรของ variant A ใช้กับ variant B ไม่ได้ ให้ยึดโจทย์และ reference ของ variant ที่กำลังทำ
