# L01-E015 — ภารกิจสรุป paper trade

**ระดับ:** Level 1 — Python พื้นฐาน<br>
**ความยาก:** Tier 5 — ประยุกต์ขั้นสูง — ใช้ความรู้เดิมกับโจทย์ใหม่<br>
**ชนิดคำตอบ:** โปรแกรม Python แสดงผล (stdout)

## 1. เรียนรู้อะไร

รวม input, การแปลงชนิดข้อมูล, การคำนวณ และการจัดรูปแบบผลลัพธ์ตาม variant ที่เลือก

## 2. ก่อนเริ่ม

ทบทวน: [L01-E014](L01-E014.md). หากคำศัพท์ในโจทย์ยังไม่คุ้น ให้เริ่มจากคำอธิบายแนวคิดในหน้านี้ก่อน

**แนวคิดสำคัญ:** ใช้ prompt ของ variant ปัจจุบันเป็นข้อกำหนดหลัก เพราะ A และ B ต่างกัน อ่าน input และ output ที่ระบุ แยกค่าระหว่างทางเพื่อตรวจสูตรและหน่วย แล้วพิมพ์เฉพาะป้ายกำกับและรูปแบบที่โจทย์กำหนด.

## 3. ตัวอย่างสั้น

ตัวอย่างนี้ฝึกแนวคิดที่เกี่ยวข้อง แต่ใช้ค่าและสถานการณ์แยกจากโจทย์ที่ต้องส่ง

~~~python
value = 2.5
print(f"Value: {value:.2f}")  # Value: 2.50
~~~

ในตัวอย่างนี้ ให้ดูว่าคำสั่ง print ส่งค่าใดไปยังหน้าจอ; ข้อความหลังเครื่องหมาย # เป็นคำอธิบาย output ของตัวอย่าง

## 4. งานของคุณ

ภารกิจใหม่: เขียนโปรแกรมสรุป paper trade โดยอ่านราคาซื้อ ราคาขาย จำนวนเหรียญ และ fee_percent (เปอร์เซ็นต์) คนละบรรทัด แล้วแสดงสามบรรทัดตามรูปแบบ `Gross: 10.00`, `Fees: 1.21`, `Net: 8.79` คำนวณค่าธรรมเนียมทั้งขาซื้อและขาย ห้ามใช้ข้อมูลหรือคำตอบตายตัว

## 5. เขียนคำตอบที่ไหน

ไฟล์ส่งคำตอบ: [exercises/level_01/L01-E015.py](../exercises/level_01/L01-E015.py)

แก้ไฟล์ Python นี้ตรงตำแหน่งงานที่โจทย์ระบุ; อย่าแก้ไฟล์ tests หรือ solutions

## 6. ลำดับทำงาน

1. อ่านโจทย์และตัวอย่างแยก แล้วหา TODO หรือบรรทัดที่ต้องแก้ในไฟล์ Python
2. เขียนคำสั่งให้แสดงผลตรงตามรูปแบบที่โจทย์ขอ
3. บันทึกไฟล์ แล้วใช้ run ดูกรณีตัวอย่างแรก
4. ใช้ check ตรวจทุกกรณี; อ่านชื่อ test แรกที่ไม่ผ่านก่อนแก้

## 7. ข้อมูลเข้าและผลลัพธ์

- **ข้อมูลเข้า:** ใช้ input ที่โจทย์หรือ test ส่งให้; ถ้าไม่มี stdin ก็ไม่ต้องพิมพ์ค่าเพิ่ม.
- **ผลลัพธ์:** ข้อความที่โปรแกรมส่งไป stdout ต้องมีลำดับ บรรทัด และรูปแบบตรงตามโจทย์.
- **การแสดงผล:** print() แสดงค่าที่ Terminal; การกำหนดตัวแปรอย่างเดียวไม่ทำให้เกิด output

ข้อจำกัดที่ต้องรักษา: Python 3.12; ใช้เฉพาะแนวคิดที่สอนถึงข้อนี้; การเทรดเป็นการจำลอง paper-only; ราคาซื้อ/ขายและจำนวนต้องไม่ติดลบ; fee_percent ต้องไม่ติดลบ

## 8. Run และ Check

รันจากโฟลเดอร์โครงการที่มี practice.py:


~~~sh
python3.12 -B practice.py run L01-E015

~~~

Run ทดลองกรณีตัวอย่างแรก; Check เปรียบเทียบกับทุกกรณีและบันทึกสถานะการเรียน

## 9. ถ้าไม่ผ่าน

สิ่งที่พลาดง่าย: ใช้หน่วยและ input ตาม prompt; ตรวจชื่อป้าย จำนวนบรรทัด และรูปแบบทศนิยมของ variant ปัจจุบัน. ตรวจเครื่องหมายคำพูด การขึ้นบรรทัดใหม่ และค่าที่ print ทีละบรรทัด
