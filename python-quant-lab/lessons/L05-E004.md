# L05-E004 — แก้ตัวนับช่อง CSV ที่มี comma ใน quote

**ระดับ:** Level 5 — Python สำหรับงานจริง<br>
**ความยาก:** Tier 2 — ง่าย — รวมแนวคิดคุ้นเคย<br>
**ชนิดคำตอบ:** โปรแกรม Python แสดงผล (stdout)

## 1. เรียนรู้อะไร

ใช้ csv.reader แทนการแยกข้อความด้วย comma อย่างง่าย

## 2. ก่อนเริ่ม

ทบทวน: [L05-E003](L05-E003.md). หากคำศัพท์ในโจทย์ยังไม่คุ้น ให้เริ่มจากคำอธิบายแนวคิดในหน้านี้ก่อน

**แนวคิดสำคัญ:** CSV มีกติกา quote และ escape; split(',') ไม่ทราบว่า comma อยู่ในข้อมูลหรือเป็นตัวแบ่ง

## 3. ตัวอย่างสั้น

ตัวอย่างนี้ฝึกแนวคิดที่เกี่ยวข้อง แต่ใช้ค่าและสถานการณ์แยกจากโจทย์ที่ต้องส่ง

~~~python
numbers = [7, 2, 7, 4]
unique = list(dict.fromkeys(numbers))
print(unique)
~~~

ในตัวอย่างนี้ ให้ดูว่าคำสั่ง print ส่งค่าใดไปยังหน้าจอ; ข้อความหลังเครื่องหมาย # เป็นคำอธิบาย output ของตัวอย่าง

## 4. งานของคุณ

ตัวนับต้องคืนจำนวนช่องของบรรทัด CSV แม้ค่าหนึ่งช่องจะมี comma อยู่ในเครื่องหมายคำพูด แก้โปรแกรมที่ใช้ split(',') รับ CSV หนึ่งบรรทัดและแสดงจำนวนช่อง
