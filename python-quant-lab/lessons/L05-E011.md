# L05-E011 — จัดการข้อความว่าง

**ระดับ:** Level 5 — Python สำหรับงานจริง<br>
**ความยาก:** Tier 2 — ง่าย — รวมแนวคิดคุ้นเคย<br>
**ชนิดคำตอบ:** เขียนฟังก์ชันและคืนค่าด้วย return

## 1. เรียนรู้อะไร

คืนข้อความเดิมถ้ามีอักขระที่ไม่ใช่ช่องว่าง; ถ้าว่างหลัง strip ให้คืน None

## 2. ก่อนเริ่ม

ทบทวน: [L05-E010](L05-E010.md). หากคำศัพท์ในโจทย์ยังไม่คุ้น ให้เริ่มจากคำอธิบายแนวคิดในหน้านี้ก่อน

**แนวคิดสำคัญ:** แนวคิด: คืนข้อความเดิมถ้ามีอักขระที่ไม่ใช่ช่องว่าง; ถ้าว่างหลัง strip ให้คืน None

ลำดับคิด: ตรวจ text.strip(); เลือกคืน None หรือข้อความ input เดิม

## 3. ตัวอย่างสั้น

ตัวอย่างนี้ฝึกแนวคิดที่เกี่ยวข้อง แต่ใช้ค่าและสถานการณ์แยกจากโจทย์ที่ต้องส่ง

~~~python
for step in range(3):
    print("step", step + 1)
~~~

อ่าน arguments ที่ส่งให้ฟังก์ชันแล้วตามค่าที่ return; ถ้าไม่มี print การคืนค่าไม่ได้แสดงใน Terminal

## 4. งานของคุณ

สถานการณ์: ระบบรับข้อความบันทึกเหตุการณ์และแทน input ว่างด้วย None เพื่อสื่อว่าไม่มีข้อมูล

เขียน redact_empty_input(text) ตามกติกา: คืนข้อความเดิมถ้ามีอักขระที่ไม่ใช่ช่องว่าง; ถ้าว่างหลัง strip ให้คืน None.

กรณีขอบ: เมื่อข้อความไม่ว่างต้องคืนข้อความเดิมรวมช่องว่างเดิม.
ส่งค่ากลับด้วย return และอย่าแก้ input ต้นฉบับ

## 5. เขียนคำตอบที่ไหน

ไฟล์ส่งคำตอบ: [exercises/level_05/L05-E011.py](../exercises/level_05/L05-E011.py)

แก้ฟังก์ชัน redact_empty_input(text) ในไฟล์นี้. คงชื่อและ signature ไว้ และคืนผลด้วย return

## 6. ลำดับทำงาน

1. อ่าน signature redact_empty_input(text) และดูว่า parameter แต่ละตัวรับข้อมูลอะไร
2. แก้เฉพาะ body ที่โจทย์กำหนด และส่งผลด้วย return
3. ตรวจกรณีขอบที่ระบุ โดยคงชื่อฟังก์ชันและ signature
4. ใช้ run ดูค่าคืนจากกรณีแรก แล้วใช้ check ตรวจ test ทั้งหมด

## 7. ข้อมูลเข้าและผลลัพธ์

- **ข้อมูลเข้า:** grader เรียก redact_empty_input ด้วย parameters ตาม signature ที่ให้.
- **ผลลัพธ์:** ฟังก์ชันต้องคืนค่า (ข้อความ (str)); return ส่งค่ากลับ ส่วน print แสดงข้อความ.
- **ชุดตรวจ:** มี 2 กรณี รวมขอบเขตตามโจทย์

ข้อจำกัดที่ต้องรักษา: Python 3.12; เมื่อข้อความไม่ว่างต้องคืนข้อความเดิมรวมช่องว่างเดิม; ใช้ข้อมูลตามรูปแบบที่ระบุในโจทย์; output ต้องตรงทั้งชนิดและลำดับ
