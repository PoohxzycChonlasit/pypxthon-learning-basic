# L06-E007 — เลือกค่าที่สูงกว่าค่าเฉลี่ย

**ระดับ:** Level 6 — วิเคราะห์ข้อมูล<br>
**ความยาก:** Tier 3 — ปานกลาง — หลายขั้นตอน<br>
**ชนิดคำตอบ:** เขียนฟังก์ชันและคืนค่าด้วย return

## 1. เรียนรู้อะไร

คำนวณ mean โดยไม่รวม None แล้วคืนค่าจริงทุกตัวที่มากกว่า mean

## 2. ก่อนเริ่ม

ทบทวน: [L06-E006](L06-E006.md). หากคำศัพท์ในโจทย์ยังไม่คุ้น ให้เริ่มจากคำอธิบายแนวคิดในหน้านี้ก่อน

**แนวคิดสำคัญ:** แนวคิด: คำนวณ mean โดยไม่รวม None แล้วคืนค่าจริงทุกตัวที่มากกว่า mean

ลำดับคิด: กรอง None เพื่อหาค่าเฉลี่ย; วนต้นฉบับเพื่อเลือกค่าที่มากกว่า mean

## 3. ตัวอย่างสั้น

ตัวอย่างนี้ฝึกแนวคิดที่เกี่ยวข้อง แต่ใช้ค่าและสถานการณ์แยกจากโจทย์ที่ต้องส่ง

~~~python
items = ["tea", "rice"]
items.append("coffee")
print(items)
~~~

อ่าน arguments ที่ส่งให้ฟังก์ชันแล้วตามค่าที่ return; ถ้าไม่มี print การคืนค่าไม่ได้แสดงใน Terminal

## 4. งานของคุณ

สถานการณ์: ทีมขายหายอดขายที่สูงกว่าค่าเฉลี่ยของค่าที่มีอยู่

เขียน select_above_average(values) ตามกติกา: คำนวณ mean โดยไม่รวม None แล้วคืนค่าจริงทุกตัวที่มากกว่า mean.

กรณีขอบ: ถ้าไม่มีค่าที่ใช้ได้คืน []; ค่าเท่าค่าเฉลี่ยไม่ผ่าน.
ส่งค่ากลับด้วย return และอย่าแก้ input ต้นฉบับ

## 5. เขียนคำตอบที่ไหน

ไฟล์ส่งคำตอบ: [exercises/level_06/L06-E007.py](../exercises/level_06/L06-E007.py)

แก้ฟังก์ชัน select_above_average(values) ในไฟล์นี้. คงชื่อและ signature ไว้ และคืนผลด้วย return

## 6. ลำดับทำงาน

1. อ่าน signature select_above_average(values) และดูว่า parameter แต่ละตัวรับข้อมูลอะไร
2. แก้เฉพาะ body ที่โจทย์กำหนด และส่งผลด้วย return
3. ตรวจกรณีขอบที่ระบุ โดยคงชื่อฟังก์ชันและ signature
4. ใช้ run ดูค่าคืนจากกรณีแรก แล้วใช้ check ตรวจ test ทั้งหมด

## 7. ข้อมูลเข้าและผลลัพธ์

- **ข้อมูลเข้า:** grader เรียก select_above_average ด้วย parameters ตาม signature ที่ให้.
- **ผลลัพธ์:** ฟังก์ชันต้องคืนค่า (list); return ส่งค่ากลับ ส่วน print แสดงข้อความ.
- **ชุดตรวจ:** มี 2 กรณี รวมขอบเขตตามโจทย์

ข้อจำกัดที่ต้องรักษา: Python 3.12; ถ้าไม่มีค่าที่ใช้ได้คืน []; ค่าเท่าค่าเฉลี่ยไม่ผ่าน; ใช้ข้อมูลตามรูปแบบที่ระบุในโจทย์; output ต้องตรงทั้งชนิดและลำดับ
