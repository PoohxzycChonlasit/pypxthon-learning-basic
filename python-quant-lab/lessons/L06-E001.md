# L06-E001 — คำนวณผลตอบแทนรายวัน

**ระดับ:** Level 6 — วิเคราะห์ข้อมูล<br>
**ความยาก:** Tier 3 — ปานกลาง — หลายขั้นตอน<br>
**ชนิดคำตอบ:** เขียนฟังก์ชันและคืนค่าด้วย return

## 1. เรียนรู้อะไร

สำหรับคู่ติดกันที่ค่าทั้งสองมีข้อมูลและราคาก่อนหน้าไม่เป็นศูนย์ คืน current/previous - 1

## 2. ก่อนเริ่ม

ทบทวน: [L05-E015](L05-E015.md). หากคำศัพท์ในโจทย์ยังไม่คุ้น ให้เริ่มจากคำอธิบายแนวคิดในหน้านี้ก่อน

**แนวคิดสำคัญ:** แนวคิด: สำหรับคู่ติดกันที่ค่าทั้งสองมีข้อมูลและราคาก่อนหน้าไม่เป็นศูนย์ คืน current/previous - 1

ลำดับคิด: จับคู่ราคาติดกัน; ตรวจ missing และตัวหาร; คำนวณ return แบบสัดส่วน

## 3. ตัวอย่างสั้น

ตัวอย่างนี้ฝึกแนวคิดที่เกี่ยวข้อง แต่ใช้ค่าและสถานการณ์แยกจากโจทย์ที่ต้องส่ง

~~~python
class Product:
    def __init__(self, name, price):
        self.name = name
        self.price = price
tea = Product("tea", 20)
print(tea.name, tea.price)
~~~

อ่าน arguments ที่ส่งให้ฟังก์ชันแล้วตามค่าที่ return; ถ้าไม่มี print การคืนค่าไม่ได้แสดงใน Terminal

## 4. งานของคุณ

สถานการณ์: นักวิเคราะห์ทำ return ต่อวันจากราคาปิดที่เรียงตามเวลา

เขียน daily_returns(values) ตามกติกา: สำหรับคู่ติดกันที่ค่าทั้งสองมีข้อมูลและราคาก่อนหน้าไม่เป็นศูนย์ คืน current/previous - 1.

กรณีขอบ: ข้ามคู่ที่มี None หรือ previous=0; current=0 ให้ผล -1.
ส่งค่ากลับด้วย return และอย่าแก้ input ต้นฉบับ

## 6. ลำดับทำงาน

1. อ่าน signature daily_returns(values) และดูว่า parameter แต่ละตัวรับข้อมูลอะไร
2. แก้เฉพาะ body ที่โจทย์กำหนด และส่งผลด้วย return
3. ตรวจกรณีขอบที่ระบุ โดยคงชื่อฟังก์ชันและ signature
4. ใช้ run ดูค่าคืนจากกรณีแรก แล้วใช้ check ตรวจ test ทั้งหมด

## 7. ข้อมูลเข้าและผลลัพธ์

- **ข้อมูลเข้า:** grader เรียก daily_returns ด้วย parameters ตาม signature ที่ให้.
- **ผลลัพธ์:** ฟังก์ชันต้องคืนค่า (list); return ส่งค่ากลับ ส่วน print แสดงข้อความ.
- **ชุดตรวจ:** มี 2 กรณี รวมขอบเขตตามโจทย์
