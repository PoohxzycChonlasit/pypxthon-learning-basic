# L04-E012 — คืนผลลัพธ์แบบมีชื่อ

**ระดับ:** Level 4 — ฟังก์ชันและโมดูล<br>
**ความยาก:** Tier 4 — ท้าทาย — เงื่อนไขและกรณีขอบ<br>
**ชนิดคำตอบ:** เขียนฟังก์ชันและคืนค่าด้วย return

## 1. เรียนรู้อะไร

คืน dict {"input":x,"output":y,"valid":x>=0 and y>=0}

## 2. ก่อนเริ่ม

ทบทวน: [L04-E011](L04-E011.md). หากคำศัพท์ในโจทย์ยังไม่คุ้น ให้เริ่มจากคำอธิบายแนวคิดในหน้านี้ก่อน

**แนวคิดสำคัญ:** แนวคิด: คืน dict {"input":x,"output":y,"valid":x>=0 and y>=0}

คิดทีละขั้น: บันทึก input/output ตามลำดับ; ใช้ and กับเงื่อนไขไม่ติดลบ

## 3. ตัวอย่างสั้น

ตัวอย่างนี้ฝึกแนวคิดที่เกี่ยวข้อง แต่ใช้ค่าและสถานการณ์แยกจากโจทย์ที่ต้องส่ง

~~~python
grades = [72, 88, 91]
print(sorted(grades))
~~~

อ่าน arguments ที่ส่งให้ฟังก์ชันแล้วตามค่าที่ return; ถ้าไม่มี print การคืนค่าไม่ได้แสดงใน Terminal

## 4. งานของคุณ

สถานการณ์: ระบบตรวจนำเข้าคืนค่าพร้อมชื่อ field และสถานะการตรวจ

เขียน return_keyed_result(x, y) ให้ทำตามสัญญา: คืน dict {"input":x,"output":y,"valid":x>=0 and y>=0}.

กรณีขอบ: ศูนย์ถูกต้อง; ค่าลบตัวใดตัวหนึ่งทำให้ valid=False.
ส่งค่ากลับด้วย return และรักษาชนิดผลลัพธ์ตามตัวอย่าง

## 5. เขียนคำตอบที่ไหน

ไฟล์ส่งคำตอบ: [exercises/level_04/L04-E012.py](../exercises/level_04/L04-E012.py)

แก้ฟังก์ชัน return_keyed_result(x, y) ในไฟล์นี้. คงชื่อและ signature ไว้ และคืนผลด้วย return

## 6. ลำดับทำงาน

1. อ่าน signature return_keyed_result(x, y) และดูว่า parameter แต่ละตัวรับข้อมูลอะไร
2. แก้เฉพาะ body ที่โจทย์กำหนด และส่งผลด้วย return
3. ตรวจกรณีขอบที่ระบุ โดยคงชื่อฟังก์ชันและ signature
4. ใช้ run ดูค่าคืนจากกรณีแรก แล้วใช้ check ตรวจ test ทั้งหมด

## 7. ข้อมูลเข้าและผลลัพธ์

- **ข้อมูลเข้า:** grader เรียก return_keyed_result ด้วย parameters ตาม signature ที่ให้.
- **ผลลัพธ์:** ฟังก์ชันต้องคืนค่า (dict มี key: input, output, valid); return ส่งค่ากลับ ส่วน print แสดงข้อความ.
- **ชุดตรวจ:** มี 2 กรณี รวมขอบเขตตามโจทย์

ข้อจำกัดที่ต้องรักษา: Python 3.12; ศูนย์ถูกต้อง; ค่าลบตัวใดตัวหนึ่งทำให้ valid=False; ใช้เฉพาะข้อมูลตามสัญญาโจทย์; ห้ามแก้ grader หรือเฉลย

รันจากโฟลเดอร์โครงการที่มี practice.py:


Run ทดลองกรณีตัวอย่างแรก; Check เปรียบเทียบกับทุกกรณีและบันทึกสถานะการเรียน

## 9. ถ้าไม่ผ่าน

สิ่งที่พลาดง่าย: ศูนย์ถูกต้อง; ค่าลบตัวใดตัวหนึ่งทำให้ valid=False ตรวจชนิดและลำดับของผลลัพธ์ก่อนคืนค่า. ตรวจค่าที่คืนและชนิดของมันก่อนตรวจการแสดงผล
