# L03-E008 — แบ่งค่าบวกและค่าที่เหลือ

**ระดับ:** Level 3 — โครงสร้างข้อมูล<br>
**ความยาก:** Tier 3 — ปานกลาง — หลายขั้นตอน<br>
**ชนิดคำตอบ:** เขียนฟังก์ชันและคืนค่าด้วย return

## 1. เรียนรู้อะไร

คืน tuple (positives, rest); ค่า > 0 อยู่กลุ่มแรก; ค่า <= 0 อยู่กลุ่มสอง

## 2. ก่อนเริ่ม

ทบทวน: [L03-E007](L03-E007.md). หากคำศัพท์ในโจทย์ยังไม่คุ้น ให้เริ่มจากคำอธิบายแนวคิดในหน้านี้ก่อน

**แนวคิดสำคัญ:** แนวคิด: คืน tuple (positives, rest); ค่า > 0 อยู่กลุ่มแรก; ค่า <= 0 อยู่กลุ่มสอง

คิดทีละขั้น: คัดสมาชิกด้วยเงื่อนไข > 0 และ <= 0 แยกกัน

## 3. ตัวอย่างสั้น

ตัวอย่างนี้ฝึกแนวคิดที่เกี่ยวข้อง แต่ใช้ค่าและสถานการณ์แยกจากโจทย์ที่ต้องส่ง

~~~python
values = [2, 5, 3]
total = 0
for value in values:
    total += value
print(total)
~~~

อ่าน arguments ที่ส่งให้ฟังก์ชันแล้วตามค่าที่ return; ถ้าไม่มี print การคืนค่าไม่ได้แสดงใน Terminal

## 4. งานของคุณ

สถานการณ์: ผู้ดูแลแบบสำรวจแยกคะแนนบวกจากศูนย์และค่าติดลบ

เขียน split_into_positives_and_rest(items) ให้ทำตามสัญญา: คืน tuple (positives, rest); ค่า > 0 อยู่กลุ่มแรก; ค่า <= 0 อยู่กลุ่มสอง.

กรณีขอบ: ศูนย์อยู่ rest; ค่าซ้ำและลำดับต้องคงเดิม.
ส่งค่ากลับด้วย return และรักษาชนิดผลลัพธ์ตามตัวอย่าง

## 6. ลำดับทำงาน

1. อ่าน signature split_into_positives_and_rest(items) และดูว่า parameter แต่ละตัวรับข้อมูลอะไร
2. แก้เฉพาะ body ที่โจทย์กำหนด และส่งผลด้วย return
3. ตรวจกรณีขอบที่ระบุ โดยคงชื่อฟังก์ชันและ signature
4. ใช้ run ดูค่าคืนจากกรณีแรก แล้วใช้ check ตรวจ test ทั้งหมด

## 7. ข้อมูลเข้าและผลลัพธ์

- **ข้อมูลเข้า:** grader เรียก split_into_positives_and_rest ด้วย parameters ตาม signature ที่ให้.
- **ผลลัพธ์:** ฟังก์ชันต้องคืนค่า (list); return ส่งค่ากลับ ส่วน print แสดงข้อความ.
- **ชุดตรวจ:** มี 2 กรณี รวมขอบเขตตามโจทย์
