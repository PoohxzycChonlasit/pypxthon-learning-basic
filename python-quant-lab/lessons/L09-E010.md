# L09-E010 — กำหนดขอบเขตช่วงทดสอบ

**ระดับ:** Level 9 — วิจัย Quant และ backtest<br>
**ความยาก:** Tier 4 — ท้าทาย — เงื่อนไขและกรณีขอบ<br>
**ชนิดคำตอบ:** เขียนฟังก์ชันและคืนค่าด้วย return

## 1. เรียนรู้อะไร

คืนคู่ (start,stop) สำหรับ slice [start:stop] ที่ step 2

## 2. ก่อนเริ่ม

ทบทวน: [L09-E009](L09-E009.md). หากคำศัพท์ในโจทย์ยังไม่คุ้น ให้เริ่มจากคำอธิบายแนวคิดในหน้านี้ก่อน

**แนวคิดสำคัญ:** แนวคิด: คืนคู่ (start,stop) สำหรับ slice [start:stop] ที่ step 2

ขั้นตอน: เริ่ม start=0 แล้วเพิ่มสอง; stop=min(start+2,n)

## 3. ตัวอย่างสั้น

ตัวอย่างนี้ฝึกแนวคิดที่เกี่ยวข้อง แต่ใช้ค่าและสถานการณ์แยกจากโจทย์ที่ต้องส่ง

~~~python
class Product:
    def __init__(self, name, price):
        self.name = name
        self.price = price
tea = Product("tea", 20)
print(tea.name, tea.price)
~~~

อ่าน arguments ที่ส่งให้ฟังก์ชันแล้วตามค่าที่ return; ถ้าไม่มี print การคืนค่าไม่ได้แสดงใน Terminal

## 4. งานของคุณ

สถานการณ์: ผู้จัดทำรายงานแบ่งแถวเป็น fold ต่อเนื่องขนาดไม่เกินสองโดยไม่ shuffle

เขียน reproducible_fold_boundaries(values) ตามสัญญา: คืนคู่ (start,stop) สำหรับ slice [start:stop] ที่ step 2.

กรณีขอบ: stop ไม่รวม; fold สุดท้ายอาจมีแถวเดียว.
คืนค่าตามลำดับเวลาและอย่า shuffle time series

## 6. ลำดับทำงาน

1. อ่าน signature reproducible_fold_boundaries(values) และดูว่า parameter แต่ละตัวรับข้อมูลอะไร
2. แก้เฉพาะ body ที่โจทย์กำหนด และส่งผลด้วย return
3. ตรวจกรณีขอบที่ระบุ โดยคงชื่อฟังก์ชันและ signature
4. ใช้ run ดูค่าคืนจากกรณีแรก แล้วใช้ check ตรวจ test ทั้งหมด

## 7. ข้อมูลเข้าและผลลัพธ์

- **ข้อมูลเข้า:** grader เรียก reproducible_fold_boundaries ด้วย parameters ตาม signature ที่ให้.
- **ผลลัพธ์:** ฟังก์ชันต้องคืนค่า (list); return ส่งค่ากลับ ส่วน print แสดงข้อความ.
- **ชุดตรวจ:** มี 2 กรณี รวมขอบเขตตามโจทย์

ข้อจำกัดที่ต้องรักษา: Python 3.12; stop ไม่รวม; fold สุดท้ายอาจมีแถวเดียว; time series เรียงตามเวลา; ห้ามใช้ข้อมูลอนาคตสร้างผลในอดีต
