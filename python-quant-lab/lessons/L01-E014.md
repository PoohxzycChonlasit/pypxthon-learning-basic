# L01-E014 — แก้บั๊กการหักค่าธรรมเนียมซื้อขาย

## เป้าหมาย

ตรวจสูตรกำไรสุทธิและทดสอบหลายกรณี

## แนวคิด

สถานะซื้อมี gross profit = (sell-buy)*quantity ค่าธรรมเนียมตัวอย่างคิดทั้งขาซื้อและขาย: (buy+sell)*quantity*rate/100

## ตัวอย่าง

```python
account_balance = 150
withdrawal = 40
balance_after = account_balance - withdrawal
print(balance_after)  # 110
```

## โจทย์

โค้ดเริ่มต้นบวกค่าธรรมเนียมเข้าไปแทนที่จะหัก แก้ให้แสดงกำไรสุทธิ โดยอ่าน buy, sell, quantity และ fee_percent ทีละบรรทัด อัตราเป็นเปอร์เซ็นต์

## รูปแบบ input/output

100, 110, 2, 1 ให้ gross=20, fees=4.20, net=15.80

ผลที่ต้องการ: (sell-buy)*quantity - (buy+sell)*quantity*fee_percent/100

ข้อควรระวัง: สับสนระหว่างเปอร์เซ็นต์กับอัตราทศนิยม หรือหัก fee แค่ขาเดียว
