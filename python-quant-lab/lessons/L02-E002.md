# L02-E002 — ทำนายผลลูปข้ามศูนย์

**ระดับ:** Level 2 — เงื่อนไขและลูป<br>
**ความยาก:** Tier 1 — ง่ายมาก — แนวคิดเดียว<br>
**ชนิดคำตอบ:** ทำนายผลแล้วเขียนคำตอบในไฟล์ข้อความ

## 1. เรียนรู้อะไร

อ่าน for, continue และการสะสมยอด

## 2. ก่อนเริ่ม

ทบทวน: [L02-E001](L02-E001.md). หากคำศัพท์ในโจทย์ยังไม่คุ้น ให้เริ่มจากคำอธิบายแนวคิดในหน้านี้ก่อน

**แนวคิดสำคัญ:** ลูปอ่าน list ทีละค่า continue ข้ามรอบปัจจุบันโดยไม่ลบข้อมูลจาก list

## 3. ตัวอย่างสั้น

ตัวอย่างนี้ฝึกแนวคิดที่เกี่ยวข้อง แต่ใช้ค่าและสถานการณ์แยกจากโจทย์ที่ต้องส่ง

~~~python
for step in range(3):
    print("step", step + 1)
~~~

แยกการคำนวณในตัวอย่างตามลำดับเครื่องหมาย แล้วเทียบกับ comment; ค่าตัวอย่างนี้ไม่ใช่คำตอบของโจทย์

## 4. งานของคุณ

ยังไม่ต้องรัน ให้ทำนายข้อความที่จะแสดง แล้วเขียนทุกบรรทัดตามลำดับลงไฟล์คำตอบ.

~~~python
values = [3, 0, 2]
total = 0
for value in values:
    if value == 0:
        continue
    total += value
print(total)
print(values[-1])
~~~

ผลลัพธ์มีสองบรรทัด

## 6. ลำดับทำงาน

1. อ่านโค้ดในโจทย์จากบนลงล่างและจดค่าที่เปลี่ยนในแต่ละบรรทัด
2. คำนวณสิ่งที่แต่ละคำสั่งแสดง โดยรักษาลำดับคำสั่ง
3. พิมพ์เฉพาะผลลัพธ์ 2 บรรทัดลงไฟล์ .txt ที่ระบุ
4. บันทึกไฟล์ แล้วใช้คำสั่ง Check; ไม่ต้องสร้างหรือรันโปรแกรม Python

## 7. ข้อมูลเข้าและผลลัพธ์

- **ข้อมูลเข้า:** โค้ดในโจทย์; ให้อ่านและทำนายเอง ไม่ต้องป้อนค่าใน Terminal.
- **คำตอบ:** ข้อความธรรมดา 2 บรรทัด ตามจำนวนบรรทัดที่โจทย์ขอ.
- **รูปแบบ:** ใส่เฉพาะค่าที่แสดง ไม่ใส่โค้ด, ANSWER, comment, code fence หรือคำอธิบายเพิ่ม

ข้อจำกัดที่ต้องรักษา: ใช้ Python 3.12 และ standard library; ห้ามแก้ tests, curriculum หรือไฟล์เฉลย; ตัวอย่างการเทรดเป็น paper-only

## 8. ตรวจคำตอบด้วย Check

โจทย์นี้ให้ทำนายผลและส่งเป็นข้อความ จึงไม่ต้องกด VS Code Run Python File และไม่ต้องใช้ <code>practice.py run</code>. บันทึกไฟล์ .txt แล้วตรวจจาก project root:

~~~powershell
py -3.12 -B practice.py check L02-E002
~~~

บน macOS ใช้คำสั่งนี้แทน:

~~~sh
python3.12 -B practice.py check L02-E002
~~~

Check เปรียบเทียบข้อความในไฟล์ .txt กับผลที่คาดและบันทึกสถานะ. หากยังไม่ผ่าน ให้อ่านจำนวนบรรทัด รูปแบบ และลำดับการคำนวณจากโจทย์อีกครั้ง.

## 9. ถ้าไม่ผ่าน

สิ่งที่พลาดง่าย: สับสนว่า continue หยุดลูปทั้งหมด หรือคิดว่า list ถูกแก้ไข. เทียบจำนวนบรรทัด ช่องว่าง และเครื่องหมายคำพูดกับรูปแบบที่โจทย์กำหนด

หากต้องการความช่วยเหลือหลังลองเอง ให้ใช้ py -3.12 -B practice.py hint L02-E002 1. คำใบ้และการเปิดเฉลยจะถูกบันทึกใน progress
