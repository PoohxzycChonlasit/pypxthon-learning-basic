# L07-E009 — คะแนนมาตรฐานค่าล่าสุด

**ระดับ:** Level 7 — คณิตศาสตร์และสถิติ<br>
**ความยาก:** Tier 3 — ปานกลาง — หลายขั้นตอน<br>
**ชนิดคำตอบ:** เขียนฟังก์ชันและคืนค่าด้วย return

## 1. เรียนรู้อะไร

คำนวณ (last-mean)/population_std; คืน None ถ้าว่างหรือส่วนเบี่ยงเบนมาตรฐานเป็น 0

## 2. ก่อนเริ่ม

ทบทวน: [L07-E008](L07-E008.md). หากคำศัพท์ในโจทย์ยังไม่คุ้น ให้เริ่มจากคำอธิบายแนวคิดในหน้านี้ก่อน

**แนวคิดสำคัญ:** แนวคิด: คำนวณ (last-mean)/population_std; คืน None ถ้าว่างหรือส่วนเบี่ยงเบนมาตรฐานเป็น 0

ลำดับคิด: คำนวณ mean; หารผลรวมกำลังสองด้วย n แล้ว sqrt; เทียบค่าสุดท้าย

## 3. ตัวอย่างสั้น

ตัวอย่างนี้ฝึกแนวคิดที่เกี่ยวข้อง แต่ใช้ค่าและสถานการณ์แยกจากโจทย์ที่ต้องส่ง

~~~python
class Product:
    def __init__(self, name, price):
        self.name = name
        self.price = price
tea = Product("tea", 20)
print(tea.name, tea.price)
~~~

อ่าน arguments ที่ส่งให้ฟังก์ชันแล้วตามค่าที่ return; ถ้าไม่มี print การคืนค่าไม่ได้แสดงใน Terminal

## 4. งานของคุณ

สถานการณ์: นักวิเคราะห์เปรียบเทียบค่าล่าสุดกับค่าเฉลี่ยด้วย population z-score

เขียน standard_score_last_value(values) ตามกติกา: คำนวณ (last-mean)/population_std; คืน None ถ้าว่างหรือส่วนเบี่ยงเบนมาตรฐานเป็น 0.

กรณีขอบ: ทุกค่าคงที่ให้ None เพราะหารด้วยศูนย์; ใช้ population variance หารด้วย n.
ส่งค่ากลับด้วย return และอย่าแก้ input ต้นฉบับ
