# L07-E014 — ค่าเฉลี่ยเคลื่อนที่สามจุด

**ระดับ:** Level 7 — คณิตศาสตร์และสถิติ<br>
**ความยาก:** Tier 3 — ปานกลาง — หลายขั้นตอน<br>
**ชนิดคำตอบ:** เขียนฟังก์ชันและคืนค่าด้วย return

## 1. เรียนรู้อะไร

คืนค่าเฉลี่ยสามจุดสำหรับทุกหน้าต่างเต็ม โดยเลื่อนไปครั้งละหนึ่ง

## 2. ก่อนเริ่ม

ทบทวน: [L07-E013](L07-E013.md). หากคำศัพท์ในโจทย์ยังไม่คุ้น ให้เริ่มจากคำอธิบายแนวคิดในหน้านี้ก่อน

**แนวคิดสำคัญ:** แนวคิด: คืนค่าเฉลี่ยสามจุดสำหรับทุกหน้าต่างเต็ม โดยเลื่อนไปครั้งละหนึ่ง

ลำดับคิด: เลือกสามค่าที่ index i-1,i,i+1; รวมแล้วหาร 3

## 3. ตัวอย่างสั้น

ตัวอย่างนี้ฝึกแนวคิดที่เกี่ยวข้อง แต่ใช้ค่าและสถานการณ์แยกจากโจทย์ที่ต้องส่ง

~~~python
def add_tip(total, rate=0.05):
    return total + total * rate
print(add_tip(80))
~~~

อ่าน arguments ที่ส่งให้ฟังก์ชันแล้วตามค่าที่ return; ถ้าไม่มี print การคืนค่าไม่ได้แสดงใน Terminal

## 4. งานของคุณ

สถานการณ์: นักวิเคราะห์ smooth series ด้วยค่าเฉลี่ยของหน้าต่างสามข้อมูลติดกัน

เขียน rolling_mean(values) ตามกติกา: คืนค่าเฉลี่ยสามจุดสำหรับทุกหน้าต่างเต็ม โดยเลื่อนไปครั้งละหนึ่ง.

กรณีขอบ: น้อยกว่าสามค่าให้คืน []; ผลลัพธ์ยาว n-2.
ส่งค่ากลับด้วย return และอย่าแก้ input ต้นฉบับ

## 6. ลำดับทำงาน

1. อ่าน signature rolling_mean(values) และดูว่า parameter แต่ละตัวรับข้อมูลอะไร
2. แก้เฉพาะ body ที่โจทย์กำหนด และส่งผลด้วย return
3. ตรวจกรณีขอบที่ระบุ โดยคงชื่อฟังก์ชันและ signature
4. ใช้ run ดูค่าคืนจากกรณีแรก แล้วใช้ check ตรวจ test ทั้งหมด

## 7. ข้อมูลเข้าและผลลัพธ์

- **ข้อมูลเข้า:** grader เรียก rolling_mean ด้วย parameters ตาม signature ที่ให้.
- **ผลลัพธ์:** ฟังก์ชันต้องคืนค่า (list); return ส่งค่ากลับ ส่วน print แสดงข้อความ.
- **ชุดตรวจ:** มี 2 กรณี รวมขอบเขตตามโจทย์

ข้อจำกัดที่ต้องรักษา: Python 3.12; น้อยกว่าสามค่าให้คืน []; ผลลัพธ์ยาว n-2; ใช้ข้อมูลตามรูปแบบที่ระบุในโจทย์; output ต้องตรงทั้งชนิดและลำดับ
