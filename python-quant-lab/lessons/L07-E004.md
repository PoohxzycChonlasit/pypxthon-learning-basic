# L07-E004 — แก้เศษส่วน conversion rate

**ระดับ:** Level 7 — คณิตศาสตร์และสถิติ<br>
**ความยาก:** Tier 2 — ง่าย — รวมแนวคิดคุ้นเคย<br>
**ชนิดคำตอบ:** โปรแกรม Python แสดงผล (stdout)

## 1. เรียนรู้อะไร

ตรวจลำดับ numerator/denominator และกรณีจำนวนผู้เข้าชมเป็นศูนย์

## 2. ก่อนเริ่ม

ทบทวน: [L07-E003](L07-E003.md). หากคำศัพท์ในโจทย์ยังไม่คุ้น ให้เริ่มจากคำอธิบายแนวคิดในหน้านี้ก่อน

**แนวคิดสำคัญ:** conversion rate หารจำนวนที่ทำสำเร็จด้วยจำนวนโอกาสทั้งหมด

## 3. ตัวอย่างสั้น

ตัวอย่างนี้ฝึกแนวคิดที่เกี่ยวข้อง แต่ใช้ค่าและสถานการณ์แยกจากโจทย์ที่ต้องส่ง

~~~python
raw = "  25 "
amount = int(raw.strip())
print(amount + 5)
~~~

ในตัวอย่างนี้ ให้ดูว่าคำสั่ง print ส่งค่าใดไปยังหน้าจอ; ข้อความหลังเครื่องหมาย # เป็นคำอธิบาย output ของตัวอย่าง

## 4. งานของคุณ

ฟังก์ชัน conversion_rate(signups, visits) ต้องคืน signups / visits หรือ None เมื่อ visits เป็นศูนย์ โค้ดปัจจุบันกลับด้านเศษส่วนและตรวจ signup แทนตัวหาร แก้ให้ถูกต้อง
