# L04-E010 — จัดรูปแบบเปอร์เซ็นต์

**ระดับ:** Level 4 — ฟังก์ชันและโมดูล<br>
**ความยาก:** Tier 4 — ท้าทาย — เงื่อนไขและกรณีขอบ<br>
**ชนิดคำตอบ:** เขียนฟังก์ชันและคืนค่าด้วย return

## 1. เรียนรู้อะไร

รับ fraction และ digits; คืนข้อความเปอร์เซ็นต์โดย digits อยู่ระหว่าง 0 ถึง 4

## 2. ก่อนเริ่ม

ทบทวน: [L04-E009](L04-E009.md). หากคำศัพท์ในโจทย์ยังไม่คุ้น ให้เริ่มจากคำอธิบายแนวคิดในหน้านี้ก่อน

**แนวคิดสำคัญ:** แนวคิด: รับ fraction และ digits; คืนข้อความเปอร์เซ็นต์โดย digits อยู่ระหว่าง 0 ถึง 4

คิดทีละขั้น: ใช้ precision แบบ dynamic ใน f-string; format % คูณค่า 100 ให้เอง

## 3. ตัวอย่างสั้น

ตัวอย่างนี้ฝึกแนวคิดที่เกี่ยวข้อง แต่ใช้ค่าและสถานการณ์แยกจากโจทย์ที่ต้องส่ง

~~~python
raw = "  25 "
amount = int(raw.strip())
print(amount + 5)
~~~

อ่าน arguments ที่ส่งให้ฟังก์ชันแล้วตามค่าที่ return; ถ้าไม่มี print การคืนค่าไม่ได้แสดงใน Terminal

## 4. งานของคุณ

สถานการณ์: เจ้าหน้าที่รายงานแสดงสัดส่วนเป็นเปอร์เซ็นต์ตามจำนวนทศนิยมที่เลือก

เขียน format_percent(x, y) ให้ทำตามสัญญา: รับ fraction และ digits; คืนข้อความเปอร์เซ็นต์โดย digits อยู่ระหว่าง 0 ถึง 4.

กรณีขอบ: 0.125 กับ 1 หลักต้องได้ 12.5%; digits เป็นจำนวนเต็ม.
ส่งค่ากลับด้วย return และรักษาชนิดผลลัพธ์ตามตัวอย่าง

## 5. เขียนคำตอบที่ไหน

ไฟล์ส่งคำตอบ: [exercises/level_04/L04-E010.py](../exercises/level_04/L04-E010.py)

แก้ฟังก์ชัน format_percent(x, y) ในไฟล์นี้. คงชื่อและ signature ไว้ และคืนผลด้วย return

## 6. ลำดับทำงาน

1. อ่าน signature format_percent(x, y) และดูว่า parameter แต่ละตัวรับข้อมูลอะไร
2. แก้เฉพาะ body ที่โจทย์กำหนด และส่งผลด้วย return
3. ตรวจกรณีขอบที่ระบุ โดยคงชื่อฟังก์ชันและ signature
4. ใช้ run ดูค่าคืนจากกรณีแรก แล้วใช้ check ตรวจ test ทั้งหมด

## 7. ข้อมูลเข้าและผลลัพธ์

- **ข้อมูลเข้า:** grader เรียก format_percent ด้วย parameters ตาม signature ที่ให้.
- **ผลลัพธ์:** ฟังก์ชันต้องคืนค่า (ข้อความ (str)); return ส่งค่ากลับ ส่วน print แสดงข้อความ.
- **ชุดตรวจ:** มี 2 กรณี รวมขอบเขตตามโจทย์

ข้อจำกัดที่ต้องรักษา: Python 3.12; 0.125 กับ 1 หลักต้องได้ 12.5%; digits เป็นจำนวนเต็ม; ใช้เฉพาะข้อมูลตามสัญญาโจทย์; ห้ามแก้ grader หรือเฉลย
