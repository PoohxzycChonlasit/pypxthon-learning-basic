# L01-E007 — ทายผลจากตัวแปร

## เป้าหมาย

ติดตามค่าตัวแปรและลำดับ print()

## แนวคิด

เมื่อกำหนดค่าตัวแปรแล้ว Python ใช้ค่านั้นในการคำนวณ และ `print()` แสดงตามลำดับบรรทัด

## ตัวอย่าง

```python
coins = 2
price = 3
print(coins * price)
```

## โจทย์

ทายผลลัพธ์ของโค้ดในโจทย์ แล้วเขียนค่าที่แสดงลงไฟล์คำตอบ .txt โดยหนึ่งผลลัพธ์ต่อบรรทัด

## รูปแบบ input/output

เขียนผลลัพธ์ที่คาดลงไฟล์ข้อความคำตอบตามจำนวนบรรทัดของ stdout

ผลที่ต้องการ: 6
BTC

ข้อควรระวัง: คิดว่า print แสดงคำสั่งหรือชื่อตัวแปรแทนค่าของมัน
