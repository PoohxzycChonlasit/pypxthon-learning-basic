# L01-E007 — ทายผลจากตัวแปร

## เป้าหมาย

ติดตามค่าตัวแปรและลำดับคำสั่ง `print()` โดยไม่ต้องรันโค้ด

## แนวคิด

Python ประเมินนิพจน์ก่อนแสดงผล และ string จะแสดงข้อความโดยไม่มีเครื่องหมายคำพูด แต่ละคำสั่ง `print()` เพิ่มหนึ่งบรรทัด

## ตัวอย่างที่ไม่ใช่คำตอบโจทย์

```python
boxes = 3
items_per_box = 4
print(boxes * items_per_box)
```

อ่านโจทย์ในหน้าหลักแล้วส่งเฉพาะค่าที่แสดงตามลำดับลงในไฟล์คำตอบ ไม่ต้องเขียนโปรแกรม
