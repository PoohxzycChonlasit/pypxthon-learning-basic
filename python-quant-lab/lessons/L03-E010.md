# L03-E010 — ลบค่าซ้ำโดยคงลำดับ

**ระดับ:** Level 3 — โครงสร้างข้อมูล<br>
**ความยาก:** Tier 4 — ท้าทาย — เงื่อนไขและกรณีขอบ<br>
**ชนิดคำตอบ:** เขียนฟังก์ชันและคืนค่าด้วย return

## 1. เรียนรู้อะไร

คืน list ที่มี occurrence แรกของแต่ละค่าเรียงตาม input

## 2. ก่อนเริ่ม

ทบทวน: [L03-E009](L03-E009.md). หากคำศัพท์ในโจทย์ยังไม่คุ้น ให้เริ่มจากคำอธิบายแนวคิดในหน้านี้ก่อน

**แนวคิดสำคัญ:** แนวคิด: คืน list ที่มี occurrence แรกของแต่ละค่าเรียงตาม input

คิดทีละขั้น: เก็บค่าที่เคยเห็นและเพิ่มเข้าผลลัพธ์เฉพาะครั้งแรก

## 3. ตัวอย่างสั้น

ตัวอย่างนี้ฝึกแนวคิดที่เกี่ยวข้อง แต่ใช้ค่าและสถานการณ์แยกจากโจทย์ที่ต้องส่ง

~~~python
for step in range(3):
    print("step", step + 1)
~~~

อ่าน arguments ที่ส่งให้ฟังก์ชันแล้วตามค่าที่ return; ถ้าไม่มี print การคืนค่าไม่ได้แสดงใน Terminal

## 4. งานของคุณ

สถานการณ์: เจ้าหน้าที่ทำความสะอาดรายชื่อลูกค้าตัดชื่อซ้ำโดยเก็บครั้งแรก

เขียน remove_duplicate_preserving_order(items) ให้ทำตามสัญญา: คืน list ที่มี occurrence แรกของแต่ละค่าเรียงตาม input.

กรณีขอบ: list ว่างคืน []; สมาชิกต้อง hashable.
ส่งค่ากลับด้วย return และรักษาชนิดผลลัพธ์ตามตัวอย่าง

## 5. เขียนคำตอบที่ไหน

ไฟล์ส่งคำตอบ: [exercises/level_03/L03-E010.py](../exercises/level_03/L03-E010.py)

แก้ฟังก์ชัน remove_duplicate_preserving_order(items) ในไฟล์นี้. คงชื่อและ signature ไว้ และคืนผลด้วย return

## 6. ลำดับทำงาน

1. อ่าน signature remove_duplicate_preserving_order(items) และดูว่า parameter แต่ละตัวรับข้อมูลอะไร
2. แก้เฉพาะ body ที่โจทย์กำหนด และส่งผลด้วย return
3. ตรวจกรณีขอบที่ระบุ โดยคงชื่อฟังก์ชันและ signature
4. ใช้ run ดูค่าคืนจากกรณีแรก แล้วใช้ check ตรวจ test ทั้งหมด

## 7. ข้อมูลเข้าและผลลัพธ์

- **ข้อมูลเข้า:** grader เรียก remove_duplicate_preserving_order ด้วย parameters ตาม signature ที่ให้.
- **ผลลัพธ์:** ฟังก์ชันต้องคืนค่า (list); return ส่งค่ากลับ ส่วน print แสดงข้อความ.
- **ชุดตรวจ:** มี 2 กรณี รวมขอบเขตตามโจทย์

ข้อจำกัดที่ต้องรักษา: Python 3.12; list ว่างคืน []; สมาชิกต้อง hashable; ใช้เฉพาะข้อมูลตามสัญญาโจทย์; ห้ามแก้ grader หรือเฉลย

## 9. ถ้าไม่ผ่าน
