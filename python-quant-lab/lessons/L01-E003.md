# L01-E003 — เติมการคำนวณด้วยตัวแปร

**ระดับ:** Level 1 — Python พื้นฐาน<br>
**ความยาก:** Tier 1 — ง่ายมาก — แนวคิดเดียว<br>
**ชนิดคำตอบ:** โปรแกรม Python แสดงผล (stdout)

## 1. เรียนรู้อะไร

เก็บตัวเลขในตัวแปรแล้วใช้คำนวณ

## 2. ก่อนเริ่ม

ทบทวน: [L01-E002](L01-E002.md). หากคำศัพท์ในโจทย์ยังไม่คุ้น ให้เริ่มจากคำอธิบายแนวคิดในหน้านี้ก่อน

**แนวคิดสำคัญ:** ตัวแปรเป็นชื่อที่อ้างถึงค่า `=` กำหนดค่าให้ตัวแปร ส่วน `*` คูณตัวเลข

## 3. ตัวอย่างสั้น

ตัวอย่างนี้ฝึกแนวคิดที่เกี่ยวข้อง แต่ใช้ค่าและสถานการณ์แยกจากโจทย์ที่ต้องส่ง

~~~python
apples_per_bag = 4
bag_count = 3
apple_count = apples_per_bag * bag_count
print(apple_count)  # แสดง 12
~~~

ในตัวอย่างนี้ ให้ดูว่าคำสั่ง print ส่งค่าใดไปยังหน้าจอ; ข้อความหลังเครื่องหมาย # เป็นคำอธิบาย output ของตัวอย่าง

## 4. งานของคุณ

เติมบรรทัด TODO ให้ total เป็นผลคูณของ price กับ quantity แล้วให้โปรแกรมแสดง total

## 5. เขียนคำตอบที่ไหน

ไฟล์ส่งคำตอบ: [exercises/level_01/L01-E003.py](../exercises/level_01/L01-E003.py)

แก้ไฟล์ Python นี้ตรงตำแหน่งงานที่โจทย์ระบุ; อย่าแก้ไฟล์ tests หรือ solutions

## 6. ลำดับทำงาน

1. อ่านโจทย์และตัวอย่างแยก แล้วหา TODO หรือบรรทัดที่ต้องแก้ในไฟล์ Python
2. เขียนคำสั่งให้แสดงผลตรงตามรูปแบบที่โจทย์ขอ
3. บันทึกไฟล์ แล้วใช้ run ดูกรณีตัวอย่างแรก
4. ใช้ check ตรวจทุกกรณี; อ่านชื่อ test แรกที่ไม่ผ่านก่อนแก้

## 7. ข้อมูลเข้าและผลลัพธ์

- **ข้อมูลเข้า:** ใช้ input ที่โจทย์หรือ test ส่งให้; ถ้าไม่มี stdin ก็ไม่ต้องพิมพ์ค่าเพิ่ม.
- **ผลลัพธ์:** ข้อความที่โปรแกรมส่งไป stdout ต้องมีลำดับ บรรทัด และรูปแบบตรงตามโจทย์.
- **การแสดงผล:** print() แสดงค่าที่ Terminal; การกำหนดตัวแปรอย่างเดียวไม่ทำให้เกิด output

ข้อจำกัดที่ต้องรักษา: Python 3.12; ใช้เฉพาะแนวคิดที่สอนถึงข้อนี้; การเทรดเป็นการจำลอง paper-only

## 8. Run และ Check

รันจากโฟลเดอร์โครงการที่มี practice.py:

~~~powershell
py -3.12 -B practice.py run L01-E003
py -3.12 -B practice.py check L01-E003
~~~

บน macOS Terminal ใช้ python3.12 แทน py -3.12:

~~~sh
python3.12 -B practice.py run L01-E003
python3.12 -B practice.py check L01-E003
~~~

VS Code Run Python File รันไฟล์ตรงและแสดง stdout ใน Terminal; practice.py run ทดลอง test แรก; practice.py check ตรวจทุกกรณี

Run ทดลองกรณีตัวอย่างแรก; Check เปรียบเทียบกับทุกกรณีและบันทึกสถานะการเรียน

## 9. ถ้าไม่ผ่าน

สิ่งที่พลาดง่าย: ใช้ `+` แทน `*` หรือพิมพ์ชื่อ total ก่อนกำหนดค่า. ตรวจเครื่องหมายคำพูด การขึ้นบรรทัดใหม่ และค่าที่ print ทีละบรรทัด

หากต้องการความช่วยเหลือหลังลองเอง ให้ใช้ py -3.12 -B practice.py hint L01-E003 1. คำใบ้และการเปิดเฉลยจะถูกบันทึกใน progress

## 10. เสร็จเมื่อ

Check แสดงว่าทุกกรณีผ่าน และคุณอธิบายแนวคิดได้โดยไม่ดูตัวอย่างข้างบน

ตรวจความเข้าใจ: ลองอธิบายด้วยคำของคุณเองว่า “เก็บตัวเลขในตัวแปรแล้วใช้คำนวณ” ทำงานอย่างไร
