# L05-E006 — แปลงจำนวนอย่างปลอดภัย

**ระดับ:** Level 5 — Python สำหรับงานจริง<br>
**ความยาก:** Tier 2 — ง่าย — รวมแนวคิดคุ้นเคย<br>
**ชนิดคำตอบ:** เขียนฟังก์ชันและคืนค่าด้วย return

## 1. เรียนรู้อะไร

คืน float ของ field ที่สองเมื่อมีสอง field และแปลงได้; มิฉะนั้นคืน None

## 2. ก่อนเริ่ม

ทบทวน: [L05-E005](L05-E005.md). หากคำศัพท์ในโจทย์ยังไม่คุ้น ให้เริ่มจากคำอธิบายแนวคิดในหน้านี้ก่อน

**แนวคิดสำคัญ:** แนวคิด: คืน float ของ field ที่สองเมื่อมีสอง field และแปลงได้; มิฉะนั้นคืน None

ลำดับคิด: แยก comma; ตรวจจำนวน field; แปลง field ที่สองใน try/except ValueError

## 3. ตัวอย่างสั้น

ตัวอย่างนี้ฝึกแนวคิดที่เกี่ยวข้อง แต่ใช้ค่าและสถานการณ์แยกจากโจทย์ที่ต้องส่ง

~~~python
from math import sqrt
print(sqrt(81))
~~~

อ่าน arguments ที่ส่งให้ฟังก์ชันแล้วตามค่าที่ return; ถ้าไม่มี print การคืนค่าไม่ได้แสดงใน Terminal

## 4. งานของคุณ

สถานการณ์: เจ้าหน้าที่บัญชีอ่านบรรทัด CSV รูปแบบ invoice_id,amount เพื่อดึงยอดเงิน

เขียน safe_parse_amount(text) ตามกติกา: คืน float ของ field ที่สองเมื่อมีสอง field และแปลงได้; มิฉะนั้นคืน None.

กรณีขอบ: ตัดช่องว่างรอบยอดก่อนแปลง; input เสียต้องไม่ทำให้โปรแกรมล้ม.
ส่งค่ากลับด้วย return และอย่าแก้ input ต้นฉบับ

## 7. ข้อมูลเข้าและผลลัพธ์

- **ข้อมูลเข้า:** grader เรียก safe_parse_amount ด้วย parameters ตาม signature ที่ให้.
