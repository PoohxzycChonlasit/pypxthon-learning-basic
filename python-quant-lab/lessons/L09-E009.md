# L09-E009 — ตรวจการรั่วไหลของข้อมูล

**ระดับ:** Level 9 — วิจัย Quant และ backtest<br>
**ความยาก:** Tier 3 — ปานกลาง — หลายขั้นตอน<br>
**ชนิดคำตอบ:** เขียนฟังก์ชันและคืนค่าด้วย return

## 1. เรียนรู้อะไร

คืน True หาก feature_time >= decision_time อย่างน้อยหนึ่งคู่

## 2. ก่อนเริ่ม

ทบทวน: [L09-E008](L09-E008.md). หากคำศัพท์ในโจทย์ยังไม่คุ้น ให้เริ่มจากคำอธิบายแนวคิดในหน้านี้ก่อน

**แนวคิดสำคัญ:** แนวคิด: คืน True หาก feature_time >= decision_time อย่างน้อยหนึ่งคู่

ขั้นตอน: ตรวจทุกคู่เวลา; feature ต้องมาก่อน decision อย่างเคร่งครัด

## 3. ตัวอย่างสั้น

ตัวอย่างนี้ฝึกแนวคิดที่เกี่ยวข้อง แต่ใช้ค่าและสถานการณ์แยกจากโจทย์ที่ต้องส่ง

~~~python
text = "  offline paper  "
print(text.strip().upper())
~~~

อ่าน arguments ที่ส่งให้ฟังก์ชันแล้วตามค่าที่ return; ถ้าไม่มี print การคืนค่าไม่ได้แสดงใน Terminal

## 4. งานของคุณ

สถานการณ์: ผู้ตรวจ backtest flag feature timestamp ที่ไม่มาก่อนเวลาใช้ตัดสินใจ

เขียน identify_future_leakage(values) ตามสัญญา: คืน True หาก feature_time >= decision_time อย่างน้อยหนึ่งคู่.

กรณีขอบ: ความเท่ากันถูก flag; รายการว่างหรือ feature เก่าทั้งหมดคืน False.
คืนค่าตามลำดับเวลาและอย่า shuffle time series

## 5. เขียนคำตอบที่ไหน

ไฟล์ส่งคำตอบ: [exercises/level_09/L09-E009.py](../exercises/level_09/L09-E009.py)

แก้ฟังก์ชัน identify_future_leakage(values) ในไฟล์นี้. คงชื่อและ signature ไว้ และคืนผลด้วย return

## 6. ลำดับทำงาน

1. อ่าน signature identify_future_leakage(values) และดูว่า parameter แต่ละตัวรับข้อมูลอะไร
2. แก้เฉพาะ body ที่โจทย์กำหนด และส่งผลด้วย return
3. ตรวจกรณีขอบที่ระบุ โดยคงชื่อฟังก์ชันและ signature
4. ใช้ run ดูค่าคืนจากกรณีแรก แล้วใช้ check ตรวจ test ทั้งหมด

## 7. ข้อมูลเข้าและผลลัพธ์

- **ข้อมูลเข้า:** grader เรียก identify_future_leakage ด้วย parameters ตาม signature ที่ให้.
- **ผลลัพธ์:** ฟังก์ชันต้องคืนค่า (bool); return ส่งค่ากลับ ส่วน print แสดงข้อความ.
- **ชุดตรวจ:** มี 2 กรณี รวมขอบเขตตามโจทย์

ข้อจำกัดที่ต้องรักษา: Python 3.12; ความเท่ากันถูก flag; รายการว่างหรือ feature เก่าทั้งหมดคืน False; time series เรียงตามเวลา; ห้ามใช้ข้อมูลอนาคตสร้างผลในอดีต

## 8. Run และ Check

รันจากโฟลเดอร์โครงการที่มี practice.py:

~~~powershell
py -3.12 -B practice.py run L09-E009
py -3.12 -B practice.py check L09-E009
~~~

บน macOS Terminal ใช้ python3.12 แทน py -3.12:

~~~sh
python3.12 -B practice.py run L09-E009

~~~

การกด Run บนฟังก์ชันที่มีแต่ def อาจไม่แสดงอะไร เพราะยังไม่มีใครเรียกฟังก์ชัน; practice.py run เรียก test แรกให้ ส่วน check เรียกทุกกรณี

Run ทดลองกรณีตัวอย่างแรก; Check เปรียบเทียบกับทุกกรณีและบันทึกสถานะการเรียน

## 9. ถ้าไม่ผ่าน

สิ่งที่พลาดง่าย: ความเท่ากันถูก flag; รายการว่างหรือ feature เก่าทั้งหมดคืน False ตรวจลำดับเวลาและขอบเขตของ slice. ตรวจค่าที่คืนและชนิดของมันก่อนตรวจการแสดงผล
