# L04-E008 — มูลค่าสถานะ

**ระดับ:** Level 4 — ฟังก์ชันและโมดูล<br>
**ความยาก:** Tier 3 — ปานกลาง — หลายขั้นตอน<br>
**ชนิดคำตอบ:** เขียนฟังก์ชันและคืนค่าด้วย return

## 1. เรียนรู้อะไร

คืน price * quantity; ไม่ปัดเศษ

## 2. ก่อนเริ่ม

ทบทวน: [L04-E007](L04-E007.md). หากคำศัพท์ในโจทย์ยังไม่คุ้น ให้เริ่มจากคำอธิบายแนวคิดในหน้านี้ก่อน

**แนวคิดสำคัญ:** แนวคิด: คืน price * quantity; ไม่ปัดเศษ

คิดทีละขั้น: คูณราคาต่อหน่วยด้วยจำนวนหน่วย

## 3. ตัวอย่างสั้น

ตัวอย่างนี้ฝึกแนวคิดที่เกี่ยวข้อง แต่ใช้ค่าและสถานการณ์แยกจากโจทย์ที่ต้องส่ง

~~~python
import json
settings = json.loads('{"mode": "offline", "retry": 2}')
print(settings["mode"], settings["retry"])
~~~

อ่าน arguments ที่ส่งให้ฟังก์ชันแล้วตามค่าที่ return; ถ้าไม่มี print การคืนค่าไม่ได้แสดงใน Terminal

## 4. งานของคุณ

สถานการณ์: ผู้จัดการสต็อกประเมินมูลค่าสินค้าจากราคาต่อหน่วยและจำนวนหน่วย

เขียน position_notional(x, y) ให้ทำตามสัญญา: คืน price * quantity; ไม่ปัดเศษ.

กรณีขอบ: จำนวนหน่วยศูนย์ให้มูลค่า 0; รองรับเศษส่วน.
ส่งค่ากลับด้วย return และรักษาชนิดผลลัพธ์ตามตัวอย่าง

## 5. เขียนคำตอบที่ไหน

ไฟล์ส่งคำตอบ: [exercises/level_04/L04-E008.py](../exercises/level_04/L04-E008.py)

แก้ฟังก์ชัน position_notional(x, y) ในไฟล์นี้. คงชื่อและ signature ไว้ และคืนผลด้วย return

## 6. ลำดับทำงาน

1. อ่าน signature position_notional(x, y) และดูว่า parameter แต่ละตัวรับข้อมูลอะไร
2. แก้เฉพาะ body ที่โจทย์กำหนด และส่งผลด้วย return
3. ตรวจกรณีขอบที่ระบุ โดยคงชื่อฟังก์ชันและ signature
4. ใช้ run ดูค่าคืนจากกรณีแรก แล้วใช้ check ตรวจ test ทั้งหมด

## 7. ข้อมูลเข้าและผลลัพธ์

- **ข้อมูลเข้า:** grader เรียก position_notional ด้วย parameters ตาม signature ที่ให้.
- **ผลลัพธ์:** ฟังก์ชันต้องคืนค่า (int); return ส่งค่ากลับ ส่วน print แสดงข้อความ.
- **ชุดตรวจ:** มี 2 กรณี รวมขอบเขตตามโจทย์

ข้อจำกัดที่ต้องรักษา: Python 3.12; จำนวนหน่วยศูนย์ให้มูลค่า 0; รองรับเศษส่วน; ใช้เฉพาะข้อมูลตามสัญญาโจทย์; ห้ามแก้ grader หรือเฉลย

## 9. ถ้าไม่ผ่าน

สิ่งที่พลาดง่าย: จำนวนหน่วยศูนย์ให้มูลค่า 0; รองรับเศษส่วน ตรวจชนิดและลำดับของผลลัพธ์ก่อนคืนค่า. ตรวจค่าที่คืนและชนิดของมันก่อนตรวจการแสดงผล
