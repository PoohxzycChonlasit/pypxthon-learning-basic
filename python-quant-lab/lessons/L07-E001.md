# L07-E001 — ค่าเฉลี่ยเลขคณิต

**ระดับ:** Level 7 — คณิตศาสตร์และสถิติ<br>
**ความยาก:** Tier 1 — ง่ายมาก — แนวคิดเดียว<br>
**ชนิดคำตอบ:** เขียนฟังก์ชันและคืนค่าด้วย return

## 1. เรียนรู้อะไร

คืน sum(values)/len(values); คืน None เมื่อไม่มีค่าที่วัดได้

## 2. ก่อนเริ่ม

ทบทวน: [L06-E015](L06-E015.md). หากคำศัพท์ในโจทย์ยังไม่คุ้น ให้เริ่มจากคำอธิบายแนวคิดในหน้านี้ก่อน

**แนวคิดสำคัญ:** แนวคิด: คืน sum(values)/len(values); คืน None เมื่อไม่มีค่าที่วัดได้

ลำดับคิด: หาผลรวม; หารด้วยจำนวนสมาชิก; แยกกรณีว่างก่อนหาร

## 3. ตัวอย่างสั้น

ตัวอย่างนี้ฝึกแนวคิดที่เกี่ยวข้อง แต่ใช้ค่าและสถานการณ์แยกจากโจทย์ที่ต้องส่ง

~~~python
point = (3, 4)
x, y = point
print(x + y)
~~~

อ่าน arguments ที่ส่งให้ฟังก์ชันแล้วตามค่าที่ return; ถ้าไม่มี print การคืนค่าไม่ได้แสดงใน Terminal

## 4. งานของคุณ

สถานการณ์: ทีมสำรวจสรุปค่าเฉลี่ยเลขคณิตของผลการวัด

เขียน arithmetic_mean(values) ตามกติกา: คืน sum(values)/len(values); คืน None เมื่อไม่มีค่าที่วัดได้.

กรณีขอบ: list ว่างคืน None; แต่ละค่ามีน้ำหนักเท่ากัน.
ส่งค่ากลับด้วย return และอย่าแก้ input ต้นฉบับ

## 6. ลำดับทำงาน

1. อ่าน signature arithmetic_mean(values) และดูว่า parameter แต่ละตัวรับข้อมูลอะไร
2. แก้เฉพาะ body ที่โจทย์กำหนด และส่งผลด้วย return
3. ตรวจกรณีขอบที่ระบุ โดยคงชื่อฟังก์ชันและ signature
4. ใช้ run ดูค่าคืนจากกรณีแรก แล้วใช้ check ตรวจ test ทั้งหมด

## 7. ข้อมูลเข้าและผลลัพธ์

- **ข้อมูลเข้า:** grader เรียก arithmetic_mean ด้วย parameters ตาม signature ที่ให้.
- **ผลลัพธ์:** ฟังก์ชันต้องคืนค่า (float); return ส่งค่ากลับ ส่วน print แสดงข้อความ.
- **ชุดตรวจ:** มี 2 กรณี รวมขอบเขตตามโจทย์
