# L04-E001 — ผลตอบแทนอย่างง่าย

**ระดับ:** Level 4 — ฟังก์ชันและโมดูล<br>
**ความยาก:** Tier 1 — ง่ายมาก — แนวคิดเดียว<br>
**ชนิดคำตอบ:** เขียนฟังก์ชันและคืนค่าด้วย return

## 1. เรียนรู้อะไร

คืน (end-start)/start; ถ้า start เป็นศูนย์คืน None

## 2. ก่อนเริ่ม

ทบทวน: [L03-E015](L03-E015.md). หากคำศัพท์ในโจทย์ยังไม่คุ้น ให้เริ่มจากคำอธิบายแนวคิดในหน้านี้ก่อน

**แนวคิดสำคัญ:** แนวคิด: คืน (end-start)/start; ถ้า start เป็นศูนย์คืน None

คิดทีละขั้น: หาผลต่าง; หารด้วย start; แยก start==0 ก่อนหาร

## 3. ตัวอย่างสั้น

ตัวอย่างนี้ฝึกแนวคิดที่เกี่ยวข้อง แต่ใช้ค่าและสถานการณ์แยกจากโจทย์ที่ต้องส่ง

~~~python
values = [2, 5, 3]
total = 0
for value in values:
    total += value
print(total)
~~~

อ่าน arguments ที่ส่งให้ฟังก์ชันแล้วตามค่าที่ return; ถ้าไม่มี print การคืนค่าไม่ได้แสดงใน Terminal

## 4. งานของคุณ

สถานการณ์: นักวิเคราะห์เปรียบเทียบราคาเริ่มกับราคาสิ้นสุดเพื่อคำนวณ return

เขียน simple_return(x, y) ให้ทำตามสัญญา: คืน (end-start)/start; ถ้า start เป็นศูนย์คืน None.

กรณีขอบ: ราคาเท่ากันคืน 0; ศูนย์ห้ามเป็นตัวหาร.
ส่งค่ากลับด้วย return และรักษาชนิดผลลัพธ์ตามตัวอย่าง

## 5. เขียนคำตอบที่ไหน

ไฟล์ส่งคำตอบ: [exercises/level_04/L04-E001.py](../exercises/level_04/L04-E001.py)

แก้ฟังก์ชัน simple_return(x, y) ในไฟล์นี้. คงชื่อและ signature ไว้ และคืนผลด้วย return

## 6. ลำดับทำงาน

1. อ่าน signature simple_return(x, y) และดูว่า parameter แต่ละตัวรับข้อมูลอะไร
2. แก้เฉพาะ body ที่โจทย์กำหนด และส่งผลด้วย return
3. ตรวจกรณีขอบที่ระบุ โดยคงชื่อฟังก์ชันและ signature
4. ใช้ run ดูค่าคืนจากกรณีแรก แล้วใช้ check ตรวจ test ทั้งหมด

## 7. ข้อมูลเข้าและผลลัพธ์

- **ข้อมูลเข้า:** grader เรียก simple_return ด้วย parameters ตาม signature ที่ให้.
- **ผลลัพธ์:** ฟังก์ชันต้องคืนค่า (float); return ส่งค่ากลับ ส่วน print แสดงข้อความ.
- **ชุดตรวจ:** มี 2 กรณี รวมขอบเขตตามโจทย์

ข้อจำกัดที่ต้องรักษา: Python 3.12; ราคาเท่ากันคืน 0; ศูนย์ห้ามเป็นตัวหาร; ใช้เฉพาะข้อมูลตามสัญญาโจทย์; ห้ามแก้ grader หรือเฉลย

## 9. ถ้าไม่ผ่าน

สิ่งที่พลาดง่าย: ราคาเท่ากันคืน 0; ศูนย์ห้ามเป็นตัวหาร ตรวจชนิดและลำดับของผลลัพธ์ก่อนคืนค่า. ตรวจค่าที่คืนและชนิดของมันก่อนตรวจการแสดงผล
