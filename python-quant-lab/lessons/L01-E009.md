# L01-E009 — แก้บั๊กชนิดข้อมูลจาก input()

## เป้าหมาย

ระบุและแก้ปัญหาการบวก string กับ integer

## แนวคิด

ค่าที่อ่านด้วย `input()` เป็นข้อความเสมอ การคำนวณจำนวนเต็มต้องแปลงด้วย `int()` ก่อน

## ตัวอย่าง

```python
age = int(input())
print(age + 1)
```

## โจทย์

แก้โปรแกรมที่เกิด TypeError ให้เมื่อป้อนจำนวนเต็มแล้วแสดงค่านั้นบวกหนึ่ง ห้ามแปลงผลลัพธ์เป็นข้อความเพื่อหลบข้อผิดพลาด

## รูปแบบ input/output

ป้อน 9 แล้วแสดง 10

ผลที่ต้องการ: จำนวนที่ป้อนบวกหนึ่ง

ข้อควรระวัง: ใช้การต่อข้อความหรือแก้เฉพาะค่าตัวอย่าง
