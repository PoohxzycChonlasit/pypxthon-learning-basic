# L02-E010 — เพิ่มเฉพาะค่าบวกเป็นสองเท่า

**ระดับ:** Level 2 — เงื่อนไขและลูป<br>
**ความยาก:** Tier 4 — ท้าทาย — เงื่อนไขและกรณีขอบ<br>
**ชนิดคำตอบ:** เขียนฟังก์ชันและคืนค่าด้วย return

## 1. เรียนรู้อะไร

คืน list ความยาวเดิม; ค่ามากกว่า 0 คูณ 2; ค่า 0 หรือติดลบคงเดิม

## 2. ก่อนเริ่ม

ทบทวน: [L02-E009](L02-E009.md). หากคำศัพท์ในโจทย์ยังไม่คุ้น ให้เริ่มจากคำอธิบายแนวคิดในหน้านี้ก่อน

**แนวคิดสำคัญ:** แนวคิด: คืน list ความยาวเดิม; ค่ามากกว่า 0 คูณ 2; ค่า 0 หรือติดลบคงเดิม

คิดทีละขั้น: เลือกผลลัพธ์ด้วย if/else สำหรับแต่ละค่า; ไม่กรองสมาชิกออก

## 3. ตัวอย่างสั้น

ตัวอย่างนี้ฝึกแนวคิดที่เกี่ยวข้อง แต่ใช้ค่าและสถานการณ์แยกจากโจทย์ที่ต้องส่ง

~~~python
numbers = [7, 2, 7, 4]
unique = list(dict.fromkeys(numbers))
print(unique)
~~~

อ่าน arguments ที่ส่งให้ฟังก์ชันแล้วตามค่าที่ return; ถ้าไม่มี print การคืนค่าไม่ได้แสดงใน Terminal

## 4. งานของคุณ

สถานการณ์: ร้านค้าเพิ่มแต้มสะสมสองเท่าเฉพาะค่าบวก และเก็บรายการอื่นไว้

เขียน double_only_winners(values) ให้ทำตามสัญญา: คืน list ความยาวเดิม; ค่ามากกว่า 0 คูณ 2; ค่า 0 หรือติดลบคงเดิม.

กรณีขอบ: รักษาลำดับและสมาชิกทุกตำแหน่ง.
ส่งค่ากลับด้วย return และรักษาชนิดผลลัพธ์ตามตัวอย่าง

## 5. เขียนคำตอบที่ไหน

ไฟล์ส่งคำตอบ: [exercises/level_02/L02-E010.py](../exercises/level_02/L02-E010.py)

แก้ฟังก์ชัน double_only_winners(values) ในไฟล์นี้. คงชื่อและ signature ไว้ และคืนผลด้วย return

## 6. ลำดับทำงาน

1. อ่าน signature double_only_winners(values) และดูว่า parameter แต่ละตัวรับข้อมูลอะไร
2. แก้เฉพาะ body ที่โจทย์กำหนด และส่งผลด้วย return
3. ตรวจกรณีขอบที่ระบุ โดยคงชื่อฟังก์ชันและ signature
4. ใช้ run ดูค่าคืนจากกรณีแรก แล้วใช้ check ตรวจ test ทั้งหมด

## 7. ข้อมูลเข้าและผลลัพธ์

- **ข้อมูลเข้า:** grader เรียก double_only_winners ด้วย parameters ตาม signature ที่ให้.
- **ผลลัพธ์:** ฟังก์ชันต้องคืนค่า (list); return ส่งค่ากลับ ส่วน print แสดงข้อความ.
- **ชุดตรวจ:** มี 2 กรณี รวมขอบเขตตามโจทย์

ข้อจำกัดที่ต้องรักษา: Python 3.12; รักษาลำดับและสมาชิกทุกตำแหน่ง; ใช้เฉพาะข้อมูลตามสัญญาโจทย์; ห้ามแก้ grader หรือเฉลย

## 8. Run และ Check

รันจากโฟลเดอร์โครงการที่มี practice.py:

~~~powershell
py -3.12 -B practice.py run L02-E010
py -3.12 -B practice.py check L02-E010
~~~

บน macOS Terminal ใช้ python3.12 แทน py -3.12:

~~~sh
python3.12 -B practice.py run L02-E010
~~~

Run ทดลองกรณีตัวอย่างแรก; Check เปรียบเทียบกับทุกกรณีและบันทึกสถานะการเรียน
