# L10-E014 — บันทึกเหตุการณ์แบบมีโครงสร้าง

**ระดับ:** Level 10 — วิศวกรรม paper bot ออฟไลน์<br>
**ความยาก:** Tier 2 — ง่าย — รวมแนวคิดคุ้นเคย<br>
**ชนิดคำตอบ:** เขียนฟังก์ชันและคืนค่าด้วย return

## 1. เรียนรู้อะไร

คืน dict event=id, side=side, paper_only=True

## 2. ก่อนเริ่ม

ทบทวน: [L10-E013](L10-E013.md). หากคำศัพท์ในโจทย์ยังไม่คุ้น ให้เริ่มจากคำอธิบายแนวคิดในหน้านี้ก่อน

**แนวคิดสำคัญ:** แนวคิด: คืน dict event=id, side=side, paper_only=True

ขั้นตอน: คัด id และ side; เพิ่ม paper_only=True เสมอ

## 3. ตัวอย่างสั้น

ตัวอย่างนี้ฝึกแนวคิดที่เกี่ยวข้อง แต่ใช้ค่าและสถานการณ์แยกจากโจทย์ที่ต้องส่ง

~~~python
numbers = [7, 2, 7, 4]
unique = list(dict.fromkeys(numbers))
print(unique)
~~~

อ่าน arguments ที่ส่งให้ฟังก์ชันแล้วตามค่าที่ return; ถ้าไม่มี print การคืนค่าไม่ได้แสดงใน Terminal

## 4. งานของคุณ

สถานการณ์: ระบบ log เก็บข้อมูลสำคัญของ event พร้อมป้าย paper_only

เขียน structured_event_log(event) ตามสัญญา: คืน dict event=id, side=side, paper_only=True.

กรณีขอบ: field ที่หายคืน None; paper_only ต้อง boolean True.
ใช้ข้อมูลจำลองออฟไลน์เท่านั้นและคืนค่าตามโจทย์

## 5. เขียนคำตอบที่ไหน

ไฟล์ส่งคำตอบ: [exercises/level_10/L10-E014.py](../exercises/level_10/L10-E014.py)

แก้ฟังก์ชัน structured_event_log(event) ในไฟล์นี้. คงชื่อและ signature ไว้ และคืนผลด้วย return

## 6. ลำดับทำงาน

1. อ่าน signature structured_event_log(event) และดูว่า parameter แต่ละตัวรับข้อมูลอะไร
2. แก้เฉพาะ body ที่โจทย์กำหนด และส่งผลด้วย return
3. ตรวจกรณีขอบที่ระบุ โดยคงชื่อฟังก์ชันและ signature
4. ใช้ run ดูค่าคืนจากกรณีแรก แล้วใช้ check ตรวจ test ทั้งหมด

## 7. ข้อมูลเข้าและผลลัพธ์

- **ข้อมูลเข้า:** grader เรียก structured_event_log ด้วย parameters ตาม signature ที่ให้.
- **ผลลัพธ์:** ฟังก์ชันต้องคืนค่า (dict มี key: event, side, paper_only); return ส่งค่ากลับ ส่วน print แสดงข้อความ.
- **ชุดตรวจ:** มี 2 กรณี รวมขอบเขตตามโจทย์

ข้อจำกัดที่ต้องรักษา: Python 3.12; field ที่หายคืน None; paper_only ต้อง boolean True; ไม่มีการเชื่อมต่อ exchange หรือ wallet

## 8. Run และ Check

รันจากโฟลเดอร์โครงการที่มี practice.py:

~~~powershell
py -3.12 -B practice.py run L10-E014
py -3.12 -B practice.py check L10-E014
~~~

บน macOS Terminal ใช้ python3.12 แทน py -3.12:

~~~sh
python3.12 -B practice.py run L10-E014
python3.12 -B practice.py check L10-E014
~~~

การกด Run บนฟังก์ชันที่มีแต่ def อาจไม่แสดงอะไร เพราะยังไม่มีใครเรียกฟังก์ชัน; practice.py run เรียก test แรกให้ ส่วน check เรียกทุกกรณี

Run ทดลองกรณีตัวอย่างแรก; Check เปรียบเทียบกับทุกกรณีและบันทึกสถานะการเรียน

## 9. ถ้าไม่ผ่าน

สิ่งที่พลาดง่าย: field ที่หายคืน None; paper_only ต้อง boolean True ห้ามแปลงงานจำลองเป็นคำสั่งเงินจริง. ตรวจค่าที่คืนและชนิดของมันก่อนตรวจการแสดงผล

หากต้องการความช่วยเหลือหลังลองเอง ให้ใช้ py -3.12 -B practice.py hint L10-E014 1. คำใบ้และการเปิดเฉลยจะถูกบันทึกใน progress
