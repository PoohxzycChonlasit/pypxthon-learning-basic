# L04-E014 — เลือกค่าระมัดระวัง

**ระดับ:** Level 4 — ฟังก์ชันและโมดูล<br>
**ความยาก:** Tier 1 — ง่ายมาก — แนวคิดเดียว<br>
**ชนิดคำตอบ:** เขียนฟังก์ชันและคืนค่าด้วย return

## 1. เรียนรู้อะไร

คืนค่าต่ำสุดระหว่าง estimate_a และ estimate_b

## 2. ก่อนเริ่ม

ทบทวน: [L04-E013](L04-E013.md). หากคำศัพท์ในโจทย์ยังไม่คุ้น ให้เริ่มจากคำอธิบายแนวคิดในหน้านี้ก่อน

**แนวคิดสำคัญ:** แนวคิด: คืนค่าต่ำสุดระหว่าง estimate_a และ estimate_b

คิดทีละขั้น: เปรียบเทียบสองประมาณการแล้วคืนตัวที่น้อยกว่า

## 3. ตัวอย่างสั้น

ตัวอย่างนี้ฝึกแนวคิดที่เกี่ยวข้อง แต่ใช้ค่าและสถานการณ์แยกจากโจทย์ที่ต้องส่ง

~~~python
text = "  offline paper  "
print(text.strip().upper())
~~~

อ่าน arguments ที่ส่งให้ฟังก์ชันแล้วตามค่าที่ return; ถ้าไม่มี print การคืนค่าไม่ได้แสดงใน Terminal

## 4. งานของคุณ

สถานการณ์: ผู้วางแผนใช้งบเลือกค่าประมาณที่ต่ำกว่าเพื่อกันความเสี่ยงจากการประเมินสูงเกินจริง

เขียน choose_conservative_estimate(x, y) ให้ทำตามสัญญา: คืนค่าต่ำสุดระหว่าง estimate_a และ estimate_b.

กรณีขอบ: ค่าที่เท่ากันคืนค่านั้น; รองรับจำนวนลบ.
ส่งค่ากลับด้วย return และรักษาชนิดผลลัพธ์ตามตัวอย่าง

## 5. เขียนคำตอบที่ไหน

ไฟล์ส่งคำตอบ: [exercises/level_04/L04-E014.py](../exercises/level_04/L04-E014.py)

แก้ฟังก์ชัน choose_conservative_estimate(x, y) ในไฟล์นี้. คงชื่อและ signature ไว้ และคืนผลด้วย return

## 6. ลำดับทำงาน

1. อ่าน signature choose_conservative_estimate(x, y) และดูว่า parameter แต่ละตัวรับข้อมูลอะไร
2. แก้เฉพาะ body ที่โจทย์กำหนด และส่งผลด้วย return
3. ตรวจกรณีขอบที่ระบุ โดยคงชื่อฟังก์ชันและ signature
4. ใช้ run ดูค่าคืนจากกรณีแรก แล้วใช้ check ตรวจ test ทั้งหมด

## 7. ข้อมูลเข้าและผลลัพธ์

- **ข้อมูลเข้า:** grader เรียก choose_conservative_estimate ด้วย parameters ตาม signature ที่ให้.
- **ผลลัพธ์:** ฟังก์ชันต้องคืนค่า (int); return ส่งค่ากลับ ส่วน print แสดงข้อความ.
- **ชุดตรวจ:** มี 2 กรณี รวมขอบเขตตามโจทย์

ข้อจำกัดที่ต้องรักษา: Python 3.12; ค่าที่เท่ากันคืนค่านั้น; รองรับจำนวนลบ; ใช้เฉพาะข้อมูลตามสัญญาโจทย์; ห้ามแก้ grader หรือเฉลย

## 8. Run และ Check

รันจากโฟลเดอร์โครงการที่มี practice.py:

~~~powershell
py -3.12 -B practice.py run L04-E014
py -3.12 -B practice.py check L04-E014
~~~

บน macOS Terminal ใช้ python3.12 แทน py -3.12:

~~~sh
python3.12 -B practice.py run L04-E014
python3.12 -B practice.py check L04-E014
~~~

การกด Run บนฟังก์ชันที่มีแต่ def อาจไม่แสดงอะไร เพราะยังไม่มีใครเรียกฟังก์ชัน; practice.py run เรียก test แรกให้ ส่วน check เรียกทุกกรณี

Run ทดลองกรณีตัวอย่างแรก; Check เปรียบเทียบกับทุกกรณีและบันทึกสถานะการเรียน
