# L03-E013 — เพิ่มผลรวมท้ายรายการ

**ระดับ:** Level 3 — โครงสร้างข้อมูล<br>
**ความยาก:** Tier 2 — ง่าย — รวมแนวคิดคุ้นเคย<br>
**ชนิดคำตอบ:** เขียนฟังก์ชันและคืนค่าด้วย return

## 1. เรียนรู้อะไร

คืน list ใหม่ที่คงสมาชิกเดิมและเพิ่ม sum(items) เป็นสมาชิกสุดท้าย

## 2. ก่อนเริ่ม

ทบทวน: [L03-E012](L03-E012.md). หากคำศัพท์ในโจทย์ยังไม่คุ้น ให้เริ่มจากคำอธิบายแนวคิดในหน้านี้ก่อน

**แนวคิดสำคัญ:** แนวคิด: คืน list ใหม่ที่คงสมาชิกเดิมและเพิ่ม sum(items) เป็นสมาชิกสุดท้าย

คิดทีละขั้น: คำนวณ sum แล้วต่อเป็น list หนึ่งสมาชิก

## 3. ตัวอย่างสั้น

ตัวอย่างนี้ฝึกแนวคิดที่เกี่ยวข้อง แต่ใช้ค่าและสถานการณ์แยกจากโจทย์ที่ต้องส่ง

~~~python
items = ["tea", "rice"]
items.append("coffee")
print(items)
~~~

อ่าน arguments ที่ส่งให้ฟังก์ชันแล้วตามค่าที่ return; ถ้าไม่มี print การคืนค่าไม่ได้แสดงใน Terminal

## 4. งานของคุณ

สถานการณ์: ร้านค้าต่อผลรวมท้ายรายการราคาเพื่อสร้างสรุปใบเสร็จ

เขียน append_collection_total(items) ให้ทำตามสัญญา: คืน list ใหม่ที่คงสมาชิกเดิมและเพิ่ม sum(items) เป็นสมาชิกสุดท้าย.

กรณีขอบ: list ว่างคืน [0]; ต้องไม่แก้ list ต้นฉบับ.
ส่งค่ากลับด้วย return และรักษาชนิดผลลัพธ์ตามตัวอย่าง

## 6. ลำดับทำงาน

1. อ่าน signature append_collection_total(items) และดูว่า parameter แต่ละตัวรับข้อมูลอะไร
2. แก้เฉพาะ body ที่โจทย์กำหนด และส่งผลด้วย return
3. ตรวจกรณีขอบที่ระบุ โดยคงชื่อฟังก์ชันและ signature
4. ใช้ run ดูค่าคืนจากกรณีแรก แล้วใช้ check ตรวจ test ทั้งหมด

## 7. ข้อมูลเข้าและผลลัพธ์

- **ข้อมูลเข้า:** grader เรียก append_collection_total ด้วย parameters ตาม signature ที่ให้.
- **ผลลัพธ์:** ฟังก์ชันต้องคืนค่า (list); return ส่งค่ากลับ ส่วน print แสดงข้อความ.
- **ชุดตรวจ:** มี 2 กรณี รวมขอบเขตตามโจทย์

ข้อจำกัดที่ต้องรักษา: Python 3.12; list ว่างคืน [0]; ต้องไม่แก้ list ต้นฉบับ; ใช้เฉพาะข้อมูลตามสัญญาโจทย์; ห้ามแก้ grader หรือเฉลย
