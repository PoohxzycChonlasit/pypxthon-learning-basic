# L09-E002 — ทำนายค่าอ้างอิงที่ใช้ข้อมูลก่อนหน้า

**ระดับ:** Level 9 — วิจัย Quant และ backtest<br>
**ความยาก:** Tier 1 — ง่ายมาก — แนวคิดเดียว<br>
**ชนิดคำตอบ:** ทำนายผลแล้วเขียนคำตอบในไฟล์ข้อความ

## 1. เรียนรู้อะไร

ติดตาม slice ของอดีตโดยไม่รวมราคาปัจจุบัน

## 2. ก่อนเริ่ม

ทบทวน: [L09-E001](L09-E001.md). หากคำศัพท์ในโจทย์ยังไม่คุ้น ให้เริ่มจากคำอธิบายแนวคิดในหน้านี้ก่อน

**แนวคิดสำคัญ:** slice prices[index-2:index] ใช้ข้อมูลก่อน index และไม่รวมสมาชิกตำแหน่ง index

## 3. ตัวอย่างสั้น

ตัวอย่างนี้ฝึกแนวคิดที่เกี่ยวข้อง แต่ใช้ค่าและสถานการณ์แยกจากโจทย์ที่ต้องส่ง

~~~python
point = (3, 4)
x, y = point
print(x + y)
~~~

แยกการคำนวณในตัวอย่างตามลำดับเครื่องหมาย แล้วเทียบกับ comment; ค่าตัวอย่างนี้ไม่ใช่คำตอบของโจทย์

## 4. งานของคุณ

เขียนผลที่จะแสดงสองบรรทัดลงไฟล์คำตอบ:

~~~python
prices = [100, 104, 102, 110]
for index in range(2, len(prices)):
    previous = prices[index - 2:index]
    print(index, round(sum(previous) / len(previous), 1))
~~~

- **รูปแบบ:** ใส่เฉพาะค่าที่แสดง ไม่ใส่โค้ด, ANSWER, comment, code fence หรือคำอธิบายเพิ่ม

