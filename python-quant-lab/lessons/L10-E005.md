# L10-E005 — จำลอง paper buy/sell พร้อม accounting invariant

**ระดับ:** Level 10 — วิศวกรรม paper bot ออฟไลน์<br>
**ความยาก:** Tier 2 — ง่าย — รวมแนวคิดคุ้นเคย<br>
**ชนิดคำตอบ:** โปรแกรม Python แสดงผล (stdout)

## 1. เรียนรู้อะไร

ปรับ state จำลองโดยบังคับเงินสด จำนวนหน่วย fee และ notional cap

## 2. ก่อนเริ่ม

ทบทวน: [L10-E004](L10-E004.md). หากคำศัพท์ในโจทย์ยังไม่คุ้น ให้เริ่มจากคำอธิบายแนวคิดในหน้านี้ก่อน

**แนวคิดสำคัญ:** การจำลองหนึ่ง event ต้องตรวจทั้งหมดก่อนปรับ state; buy หัก notional+fee ส่วน sell เพิ่ม notional-fee

## 3. ตัวอย่างสั้น

ตัวอย่างนี้ฝึกแนวคิดที่เกี่ยวข้อง แต่ใช้ค่าและสถานการณ์แยกจากโจทย์ที่ต้องส่ง

~~~python
message = "python"
print(message.title())  # Python
~~~

ในตัวอย่างนี้ ให้ดูว่าคำสั่ง print ส่งค่าใดไปยังหน้าจอ; ข้อความหลังเครื่องหมาย # เป็นคำอธิบาย output ของตัวอย่าง

## 4. งานของคุณ

รับ JSON หนึ่งบรรทัดที่มี state {cash, units}, event {side, quantity, price}, max_order_value และ fee_rate จำลอง buy หรือ sell ในหน่วยความจำเท่านั้น ปฏิเสธข้อมูลผิด, buy ที่ใช้เงินเกิน, notional เกิน cap และ sell ที่ขายเกินจำนวนที่ถือ แสดง accepted, cash, units และ live_trading=False
