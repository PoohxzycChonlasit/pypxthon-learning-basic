# L09-E001 — ค่าเฉลี่ยเคลื่อนที่สองช่วง

**ระดับ:** Level 9 — วิจัย Quant และ backtest<br>
**ความยาก:** Tier 1 — ง่ายมาก — แนวคิดเดียว<br>
**ชนิดคำตอบ:** เขียนฟังก์ชันและคืนค่าด้วย return

## 1. เรียนรู้อะไร

คืนค่าเฉลี่ยของทุกคู่ค่าติดกัน; หน้าต่างเลื่อนไปหนึ่ง

## 2. ก่อนเริ่ม

ทบทวน: [L08-E015](L08-E015.md). หากคำศัพท์ในโจทย์ยังไม่คุ้น ให้เริ่มจากคำอธิบายแนวคิดในหน้านี้ก่อน

**แนวคิดสำคัญ:** แนวคิด: คืนค่าเฉลี่ยของทุกคู่ค่าติดกัน; หน้าต่างเลื่อนไปหนึ่ง

ขั้นตอน: จับคู่ราคาก่อนหน้ากับราคาปัจจุบัน; บวกแล้วหาร 2

## 3. ตัวอย่างสั้น

ตัวอย่างนี้ฝึกแนวคิดที่เกี่ยวข้อง แต่ใช้ค่าและสถานการณ์แยกจากโจทย์ที่ต้องส่ง

~~~python
items = ["tea", "rice"]
items.append("coffee")
print(items)
~~~

อ่าน arguments ที่ส่งให้ฟังก์ชันแล้วตามค่าที่ return; ถ้าไม่มี print การคืนค่าไม่ได้แสดงใน Terminal

## 4. งานของคุณ

สถานการณ์: นักวิเคราะห์ smoothing ราคาปิดด้วยค่าเฉลี่ยสองช่วงติดกัน

เขียน two_period_sma(values) ตามสัญญา: คืนค่าเฉลี่ยของทุกคู่ค่าติดกัน; หน้าต่างเลื่อนไปหนึ่ง.

กรณีขอบ: น้อยกว่าสองค่าคืน []; ผลลัพธ์ยาว n-1.
คืนค่าตามลำดับเวลาและอย่า shuffle time series

## 6. ลำดับทำงาน

1. อ่าน signature two_period_sma(values) และดูว่า parameter แต่ละตัวรับข้อมูลอะไร
2. แก้เฉพาะ body ที่โจทย์กำหนด และส่งผลด้วย return
3. ตรวจกรณีขอบที่ระบุ โดยคงชื่อฟังก์ชันและ signature
4. ใช้ run ดูค่าคืนจากกรณีแรก แล้วใช้ check ตรวจ test ทั้งหมด

## 7. ข้อมูลเข้าและผลลัพธ์

- **ข้อมูลเข้า:** grader เรียก two_period_sma ด้วย parameters ตาม signature ที่ให้.
- **ผลลัพธ์:** ฟังก์ชันต้องคืนค่า (list); return ส่งค่ากลับ ส่วน print แสดงข้อความ.
- **ชุดตรวจ:** มี 2 กรณี รวมขอบเขตตามโจทย์

ข้อจำกัดที่ต้องรักษา: Python 3.12; น้อยกว่าสองค่าคืน []; ผลลัพธ์ยาว n-1; time series เรียงตามเวลา; ห้ามใช้ข้อมูลอนาคตสร้างผลในอดีต
