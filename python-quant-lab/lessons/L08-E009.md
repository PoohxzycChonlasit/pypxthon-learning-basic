# L08-E009 — ระยะความเสี่ยง

**ระดับ:** Level 8 — การเงินและความเสี่ยง<br>
**ความยาก:** Tier 2 — ง่าย — รวมแนวคิดคุ้นเคย<br>
**ชนิดคำตอบ:** เขียนฟังก์ชันและคืนค่าด้วย return

## 1. เรียนรู้อะไร

total risk = abs(entry-stop)*quantity

## 2. ก่อนเริ่ม

ทบทวน: [L08-E008](L08-E008.md). หากคำศัพท์ในโจทย์ยังไม่คุ้น ให้เริ่มจากคำอธิบายแนวคิดในหน้านี้ก่อน

**แนวคิดสำคัญ:** แนวคิด: total risk = abs(entry-stop)*quantity

คิดทีละขั้น: หาความเสี่ยงต่อหน่วยก่อน; คูณจำนวนหน่วย

## 3. ตัวอย่างสั้น

ตัวอย่างนี้ฝึกแนวคิดที่เกี่ยวข้อง แต่ใช้ค่าและสถานการณ์แยกจากโจทย์ที่ต้องส่ง

~~~python
point = (3, 4)
x, y = point
print(x + y)
~~~

อ่าน arguments ที่ส่งให้ฟังก์ชันแล้วตามค่าที่ return; ถ้าไม่มี print การคืนค่าไม่ได้แสดงใน Terminal

## 4. งานของคุณ

สถานการณ์: ผู้จัดการความเสี่ยงคำนวณความเสี่ยงรวมจาก entry, stop และจำนวนหน่วย

เขียน risk_distance(entry, stop, quantity) ให้ทำตามสัญญา: total risk = abs(entry-stop)*quantity.

กรณีขอบ: quantity ไม่ติดลบ; ราคาเท่ากันเสี่ยง 0.
คืนค่าเท่านั้น; งานทั้งหมดเป็นการจำลอง paper

## 6. ลำดับทำงาน

1. อ่าน signature risk_distance(entry, stop, quantity) และดูว่า parameter แต่ละตัวรับข้อมูลอะไร
2. แก้เฉพาะ body ที่โจทย์กำหนด และส่งผลด้วย return
3. ตรวจกรณีขอบที่ระบุ โดยคงชื่อฟังก์ชันและ signature
4. ใช้ run ดูค่าคืนจากกรณีแรก แล้วใช้ check ตรวจ test ทั้งหมด

## 7. ข้อมูลเข้าและผลลัพธ์

- **ข้อมูลเข้า:** grader เรียก risk_distance ด้วย parameters ตาม signature ที่ให้.
- **ผลลัพธ์:** ฟังก์ชันต้องคืนค่า (int); return ส่งค่ากลับ ส่วน print แสดงข้อความ.
- **ชุดตรวจ:** มี 2 กรณี รวมขอบเขตตามโจทย์
