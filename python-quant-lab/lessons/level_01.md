# Level 1 — Python พื้นฐาน

**เป้าหมาย:** อ่านและเขียนคำสั่ง Python พื้นฐาน ตั้งแต่แสดงข้อความจนถึงรับและคำนวณค่า

**ทำไมสำคัญ:** คำสั่งและชนิดข้อมูลพื้นฐานเป็นหน่วยที่ใช้สร้างโปรแกรมทุกแบบ

**ก่อนเริ่ม:** ไม่ต้องรู้ Python มาก่อน

**แนวคิดหลัก:** print() และข้อความ · ตัวแปรและตัวเลข · input() และการแปลงชนิด · สูตรคำนวณและ f-string

## ตัวอย่างสั้นที่ทำตามได้

ตัวอย่างนี้ใช้ข้อมูลคนละชุดกับแบบฝึกหัด ให้ทำนายผลก่อนอ่านบรรทัดผลลัพธ์

~~~python
message = "สวัสดี"
print(message)
~~~

**อ่านทีละขั้น:**
1. message เก็บข้อความไว้ในตัวแปร
2. print(message) แสดงค่าที่เก็บไว้

ผลของตัวอย่าง:

~~~text
สวัสดี
~~~
