# L02-E006 — กรองค่าศูนย์

**ระดับ:** Level 2 — เงื่อนไขและลูป<br>
**ความยาก:** Tier 2 — ง่าย — รวมแนวคิดคุ้นเคย<br>
**ชนิดคำตอบ:** เขียนฟังก์ชันและคืนค่าด้วย return

## 1. เรียนรู้อะไร

คืน list ใหม่ที่ตัดเฉพาะสมาชิกเท่ากับ 0; รักษาลำดับและค่าที่เหลือ

## 2. ก่อนเริ่ม

ทบทวน: [L02-E005](L02-E005.md). หากคำศัพท์ในโจทย์ยังไม่คุ้น ให้เริ่มจากคำอธิบายแนวคิดในหน้านี้ก่อน

**แนวคิดสำคัญ:** แนวคิด: คืน list ใหม่ที่ตัดเฉพาะสมาชิกเท่ากับ 0; รักษาลำดับและค่าที่เหลือ

คิดทีละขั้น: เริ่ม list ผลลัพธ์; อ่านค่าทีละตัว; เพิ่มเมื่อค่าไม่เท่ากับศูนย์

## 3. ตัวอย่างสั้น

ตัวอย่างนี้ฝึกแนวคิดที่เกี่ยวข้อง แต่ใช้ค่าและสถานการณ์แยกจากโจทย์ที่ต้องส่ง

~~~python
point = (3, 4)
x, y = point
print(x + y)
~~~

อ่าน arguments ที่ส่งให้ฟังก์ชันแล้วตามค่าที่ return; ถ้าไม่มี print การคืนค่าไม่ได้แสดงใน Terminal

## 4. งานของคุณ

สถานการณ์: เจ้าหน้าที่เซนเซอร์ลบค่า 0 ที่หมายถึงไม่มีการอ่าน แต่เก็บค่าติดลบไว้

เขียน keep_nonzero_readings(values) ให้ทำตามสัญญา: คืน list ใหม่ที่ตัดเฉพาะสมาชิกเท่ากับ 0; รักษาลำดับและค่าที่เหลือ.

กรณีขอบ: list ว่างคืน [].
ส่งค่ากลับด้วย return และรักษาชนิดผลลัพธ์ตามตัวอย่าง

## 5. เขียนคำตอบที่ไหน

ไฟล์ส่งคำตอบ: [exercises/level_02/L02-E006.py](../exercises/level_02/L02-E006.py)

แก้ฟังก์ชัน keep_nonzero_readings(values) ในไฟล์นี้. คงชื่อและ signature ไว้ และคืนผลด้วย return

## 6. ลำดับทำงาน

1. อ่าน signature keep_nonzero_readings(values) และดูว่า parameter แต่ละตัวรับข้อมูลอะไร
2. แก้เฉพาะ body ที่โจทย์กำหนด และส่งผลด้วย return
3. ตรวจกรณีขอบที่ระบุ โดยคงชื่อฟังก์ชันและ signature
4. ใช้ run ดูค่าคืนจากกรณีแรก แล้วใช้ check ตรวจ test ทั้งหมด

## 7. ข้อมูลเข้าและผลลัพธ์

- **ข้อมูลเข้า:** grader เรียก keep_nonzero_readings ด้วย parameters ตาม signature ที่ให้.
- **ผลลัพธ์:** ฟังก์ชันต้องคืนค่า (list); return ส่งค่ากลับ ส่วน print แสดงข้อความ.
- **ชุดตรวจ:** มี 2 กรณี รวมขอบเขตตามโจทย์

ข้อจำกัดที่ต้องรักษา: Python 3.12; list ว่างคืน []; ใช้เฉพาะข้อมูลตามสัญญาโจทย์; ห้ามแก้ grader หรือเฉลย
