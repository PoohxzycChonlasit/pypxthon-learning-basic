# L08-E001 — กำไรขั้นต้นสถานะซื้อ

**ระดับ:** Level 8 — การเงินและความเสี่ยง<br>
**ความยาก:** Tier 1 — ง่ายมาก — แนวคิดเดียว<br>
**ชนิดคำตอบ:** เขียนฟังก์ชันและคืนค่าด้วย return

## 1. เรียนรู้อะไร

gross profit = (exit-entry)*quantity; quantity ไม่ติดลบ

## 2. ก่อนเริ่ม

ทบทวน: [L07-E015](L07-E015.md). หากคำศัพท์ในโจทย์ยังไม่คุ้น ให้เริ่มจากคำอธิบายแนวคิดในหน้านี้ก่อน

**แนวคิดสำคัญ:** แนวคิด: gross profit = (exit-entry)*quantity; quantity ไม่ติดลบ

คิดทีละขั้น: คำนวณการเปลี่ยนแปลงต่อหน่วยแล้วคูณจำนวนหน่วย

## 3. ตัวอย่างสั้น

ตัวอย่างนี้ฝึกแนวคิดที่เกี่ยวข้อง แต่ใช้ค่าและสถานการณ์แยกจากโจทย์ที่ต้องส่ง

~~~python
text = "  offline paper  "
print(text.strip().upper())
~~~

อ่าน arguments ที่ส่งให้ฟังก์ชันแล้วตามค่าที่ return; ถ้าไม่มี print การคืนค่าไม่ได้แสดงใน Terminal

## 4. งานของคุณ

สถานการณ์: ผู้ดูแล paper portfolio สรุปกำไรขั้นต้นของสถานะซื้อก่อนหักค่าธรรมเนียม

เขียน long_gross_profit(entry, exit, quantity) ให้ทำตามสัญญา: gross profit = (exit-entry)*quantity; quantity ไม่ติดลบ.

กรณีขอบ: ราคาออกเท่าราคาเข้าให้กำไร 0.
คืนค่าเท่านั้น; งานทั้งหมดเป็นการจำลอง paper

## 5. เขียนคำตอบที่ไหน

ไฟล์ส่งคำตอบ: [exercises/level_08/L08-E001.py](../exercises/level_08/L08-E001.py)

แก้ฟังก์ชัน long_gross_profit(entry, exit, quantity) ในไฟล์นี้. คงชื่อและ signature ไว้ และคืนผลด้วย return

## 6. ลำดับทำงาน

1. อ่าน signature long_gross_profit(entry, exit, quantity) และดูว่า parameter แต่ละตัวรับข้อมูลอะไร
2. แก้เฉพาะ body ที่โจทย์กำหนด และส่งผลด้วย return
3. ตรวจกรณีขอบที่ระบุ โดยคงชื่อฟังก์ชันและ signature
4. ใช้ run ดูค่าคืนจากกรณีแรก แล้วใช้ check ตรวจ test ทั้งหมด

## 7. ข้อมูลเข้าและผลลัพธ์

- **ข้อมูลเข้า:** grader เรียก long_gross_profit ด้วย parameters ตาม signature ที่ให้.
- **ผลลัพธ์:** ฟังก์ชันต้องคืนค่า (int); return ส่งค่ากลับ ส่วน print แสดงข้อความ.
- **ชุดตรวจ:** มี 2 กรณี รวมขอบเขตตามโจทย์

ข้อจำกัดที่ต้องรักษา: Python 3.12; ราคาออกเท่าราคาเข้าให้กำไร 0; ไม่มีการเชื่อมต่อ exchange หรือคำสั่งเงินจริง

## 8. Run และ Check

รันจากโฟลเดอร์โครงการที่มี practice.py:

~~~powershell

py -3.12 -B practice.py check L08-E001
~~~

บน macOS Terminal ใช้ python3.12 แทน py -3.12:

~~~sh
python3.12 -B practice.py run L08-E001
~~~

Run ทดลองกรณีตัวอย่างแรก; Check เปรียบเทียบกับทุกกรณีและบันทึกสถานะการเรียน

## 9. ถ้าไม่ผ่าน
