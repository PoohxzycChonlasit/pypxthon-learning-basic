# L03-E011 — ค่าเฉลี่ยเคลื่อนที่สองจุด

**ระดับ:** Level 3 — โครงสร้างข้อมูล<br>
**ความยาก:** Tier 4 — ท้าทาย — เงื่อนไขและกรณีขอบ<br>
**ชนิดคำตอบ:** เขียนฟังก์ชันและคืนค่าด้วย return

## 1. เรียนรู้อะไร

คืนค่า (a+b)/2 ของทุกคู่ติดกัน; หน้าต่างเลื่อนทีละหนึ่ง

## 2. ก่อนเริ่ม

ทบทวน: [L03-E010](L03-E010.md). หากคำศัพท์ในโจทย์ยังไม่คุ้น ให้เริ่มจากคำอธิบายแนวคิดในหน้านี้ก่อน

**แนวคิดสำคัญ:** แนวคิด: คืนค่า (a+b)/2 ของทุกคู่ติดกัน; หน้าต่างเลื่อนทีละหนึ่ง

คิดทีละขั้น: จับคู่ list กับ list ที่เริ่ม index 1; บวกแล้วหารสอง

## 3. ตัวอย่างสั้น

ตัวอย่างนี้ฝึกแนวคิดที่เกี่ยวข้อง แต่ใช้ค่าและสถานการณ์แยกจากโจทย์ที่ต้องส่ง

~~~python
person = {"name": "Mali", "active": True}
print(person.get("active", False))
~~~

อ่าน arguments ที่ส่งให้ฟังก์ชันแล้วตามค่าที่ return; ถ้าไม่มี print การคืนค่าไม่ได้แสดงใน Terminal

## 4. งานของคุณ

สถานการณ์: นักวิเคราะห์ทำค่าเฉลี่ยของแต่ละคู่วันติดกันเพื่อ smoothing

เขียน two_item_moving_averages(items) ให้ทำตามสัญญา: คืนค่า (a+b)/2 ของทุกคู่ติดกัน; หน้าต่างเลื่อนทีละหนึ่ง.

กรณีขอบ: น้อยกว่าสองค่าให้คืน []; ผลลัพธ์ยอมเป็น float.
ส่งค่ากลับด้วย return และรักษาชนิดผลลัพธ์ตามตัวอย่าง

## 5. เขียนคำตอบที่ไหน

ไฟล์ส่งคำตอบ: [exercises/level_03/L03-E011.py](../exercises/level_03/L03-E011.py)

แก้ฟังก์ชัน two_item_moving_averages(items) ในไฟล์นี้. คงชื่อและ signature ไว้ และคืนผลด้วย return

## 6. ลำดับทำงาน

1. อ่าน signature two_item_moving_averages(items) และดูว่า parameter แต่ละตัวรับข้อมูลอะไร
2. แก้เฉพาะ body ที่โจทย์กำหนด และส่งผลด้วย return
3. ตรวจกรณีขอบที่ระบุ โดยคงชื่อฟังก์ชันและ signature
4. ใช้ run ดูค่าคืนจากกรณีแรก แล้วใช้ check ตรวจ test ทั้งหมด

## 7. ข้อมูลเข้าและผลลัพธ์

- **ข้อมูลเข้า:** grader เรียก two_item_moving_averages ด้วย parameters ตาม signature ที่ให้.
- **ผลลัพธ์:** ฟังก์ชันต้องคืนค่า (list); return ส่งค่ากลับ ส่วน print แสดงข้อความ.
- **ชุดตรวจ:** มี 2 กรณี รวมขอบเขตตามโจทย์

ข้อจำกัดที่ต้องรักษา: Python 3.12; น้อยกว่าสองค่าให้คืน []; ผลลัพธ์ยอมเป็น float; ใช้เฉพาะข้อมูลตามสัญญาโจทย์; ห้ามแก้ grader หรือเฉลย

## 8. Run และ Check

รันจากโฟลเดอร์โครงการที่มี practice.py:

~~~powershell
py -3.12 -B practice.py run L03-E011
py -3.12 -B practice.py check L03-E011
~~~

บน macOS Terminal ใช้ python3.12 แทน py -3.12:

~~~sh
python3.12 -B practice.py run L03-E011
~~~

Run ทดลองกรณีตัวอย่างแรก; Check เปรียบเทียบกับทุกกรณีและบันทึกสถานะการเรียน

## 9. ถ้าไม่ผ่าน

สิ่งที่พลาดง่าย: น้อยกว่าสองค่าให้คืน []; ผลลัพธ์ยอมเป็น float ตรวจชนิดและลำดับของผลลัพธ์ก่อนคืนค่า. ตรวจค่าที่คืนและชนิดของมันก่อนตรวจการแสดงผล
