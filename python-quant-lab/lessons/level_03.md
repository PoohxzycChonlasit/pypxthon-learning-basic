# Level 3 — โครงสร้างข้อมูล

**เป้าหมาย:** เลือกโครงสร้างข้อมูลให้เหมาะกับรายการ ค่าคู่ และระเบียนที่มีชื่อกำกับ

**ทำไมสำคัญ:** การจัดข้อมูลให้เป็นรูปแบบช่วยให้ค้นหา ตรวจ และคำนวณได้ตรงกับความหมาย

**ก่อนเริ่ม:** ทบทวนเงื่อนไขและลูปจาก Level 2

**แนวคิดหลัก:** list และ tuple · set · dict · การวนและค้นข้อมูล · การจัดเรียง

## ตัวอย่างสั้นที่ทำตามได้

ตัวอย่างนี้ใช้ข้อมูลคนละชุดกับแบบฝึกหัด ให้ทำนายผลก่อนอ่านบรรทัดผลลัพธ์

~~~python
cart = {"tea": 2, "coffee": 1}
print(cart["tea"])
~~~

**อ่านทีละขั้น:**
1. dict ผูกชื่อสินค้าแต่ละตัวกับจำนวน
2. cart["tea"] เลือกจำนวนของ tea
3. print() แสดงค่านั้น

ผลของตัวอย่าง:

~~~text
2
~~~

## ตัวอย่างฝึกระดับเพิ่มเติม

เนื้อหาฝึกเดิมของระดับนี้ยังคงไว้เพื่อใช้ทบทวน

**เป้าหมาย:** เลือกวิธีเก็บข้อมูลให้ตรงกับงาน แล้วค้นหาและสรุปข้อมูลได้

## พิมพ์ตาม: สรุปตะกร้าสินค้า

### ขั้นที่ 1 — แนวคิด

list เหมาะกับรายการที่เรียงลำดับ; dict เก็บข้อมูลที่มีชื่อกำกับ เช่น ราคาหรือจำนวน; tuple ใช้เก็บกลุ่มค่าที่มักใช้ด้วยกัน

### ขั้นที่ 2–3 — พิมพ์ตัวอย่างนี้

~~~python
cart = [
    {"name": "ชา", "price": 30, "quantity": 2},
    {"name": "ข้าว", "price": 25, "quantity": 1},
]

total = 0
for product in cart:
    line_total = product["price"] * product["quantity"]
    total = total + line_total

print(total)
print(cart[0]["name"])
~~~

### ขั้นที่ 4 — อ่านทีละส่วน

- cart เป็น list ของระเบียนสินค้า
- แต่ละระเบียนเป็น dict จึงใช้ key เช่น price เพื่ออ่านค่า
- ลูปคำนวณราคารวมของแต่ละแถวแล้วสะสม
- index 0 หมายถึงรายการแรก

### ขั้นที่ 5 — ผลลัพธ์ที่คาด

~~~text
85
ชา
~~~

### ขั้นที่ 6–7 — ทดลองเปลี่ยน

เปลี่ยน quantity ของข้าวจาก 1 เป็น 3 ยอดรวมจะเพิ่ม 50 เป็น 135

### ขั้นที่ 8 — ลองเอง

เพิ่มสินค้ารายการที่สาม และเขียนลูปหาชื่อสินค้าที่มีจำนวนเป็นศูนย์ อย่าพึ่งลำดับของ set เมื่อต้องการแสดงผลแบบเรียง

**แนวคิดของระดับนี้:** slicing เลือกช่วงโดยไม่รวมปลายทาง, set ช่วยเอาค่าซ้ำออก และ dict.get(key, default) ช่วยจัดการ key ที่อาจหายไป
