# L02-E015 — ประเมินเงื่อนไขและลูป

**ระดับ:** Level 2 — เงื่อนไขและลูป<br>
**ความยาก:** Tier 5 — ประยุกต์ขั้นสูง — ใช้ความรู้เดิมกับโจทย์ใหม่<br>
**ชนิดคำตอบ:** เขียนฟังก์ชันและคืนค่าด้วย return

## 1. เรียนรู้อะไร

ใช้เงื่อนไขและลูปแปลง input เป็น output ตาม prompt ของ variant ที่เลือก

## 2. ก่อนเริ่ม

ทบทวน: [L02-E014](L02-E014.md). หากคำศัพท์ในโจทย์ยังไม่คุ้น ให้เริ่มจากคำอธิบายแนวคิดในหน้านี้ก่อน

**แนวคิดสำคัญ:** ใช้ prompt ของ variant ปัจจุบันเป็น contract; A/B อาจขอผลลัพธ์ต่างกัน ระบุ output ทุกช่อง แล้ววนข้อมูลเพื่อคำนวณแต่ละช่องตามเงื่อนไขของมัน ตรวจค่าขอบก่อนคืนผล.

## 3. ตัวอย่างสั้น

ตัวอย่างนี้ฝึกแนวคิดที่เกี่ยวข้อง แต่ใช้ค่าและสถานการณ์แยกจากโจทย์ที่ต้องส่ง

~~~python
for value in [2, 5, 3]:
    print(value)
~~~

อ่าน arguments ที่ส่งให้ฟังก์ชันแล้วตามค่าที่ return; ถ้าไม่มี print การคืนค่าไม่ได้แสดงใน Terminal

## 4. งานของคุณ

แบบประเมิน A/B: เขียนฟังก์ชัน final_loop_assessment(values) ตามโจทย์ของ variant ที่ระบบแสดงอยู่ ใช้ input ที่รับเข้ามาคำนวณและคืนผลตาม รูปแบบข้อมูล ที่กำหนด ห้าม hardcode คำตอบของตัวอย่าง

## 5. เขียนคำตอบที่ไหน

ไฟล์ส่งคำตอบ: [exercises/level_02/L02-E015.py](../exercises/level_02/L02-E015.py)

แก้ฟังก์ชัน final_loop_assessment(values) ในไฟล์นี้. คงชื่อและ signature ไว้ และคืนผลด้วย return

## 6. ลำดับทำงาน

1. อ่าน signature final_loop_assessment(values) และดูว่า parameter แต่ละตัวรับข้อมูลอะไร
2. แก้เฉพาะ body ที่โจทย์กำหนด และส่งผลด้วย return
3. ตรวจกรณีขอบที่ระบุ โดยคงชื่อฟังก์ชันและ signature
4. ใช้ run ดูค่าคืนจากกรณีแรก แล้วใช้ check ตรวจ test ทั้งหมด

## 7. ข้อมูลเข้าและผลลัพธ์

- **ข้อมูลเข้า:** grader เรียก final_loop_assessment ด้วย parameters ตาม signature ที่ให้.
- **ผลลัพธ์:** ฟังก์ชันต้องคืนค่า (dict มี key: count, positive, net); return ส่งค่ากลับ ส่วน print แสดงข้อความ.
- **ชุดตรวจ:** มี 3 กรณี รวมขอบเขตตามโจทย์

ข้อจำกัดที่ต้องรักษา: ใช้ Python 3.12 และ standard library; ห้ามแก้ tests, curriculum หรือไฟล์เฉลย; ตัวอย่างการเทรดเป็น paper-only

## 8. Run และ Check

รันจากโฟลเดอร์โครงการที่มี practice.py:

~~~powershell
py -3.12 -B practice.py run L02-E015
py -3.12 -B practice.py check L02-E015
~~~

บน macOS Terminal ใช้ python3.12 แทน py -3.12:

~~~sh
python3.12 -B practice.py run L02-E015
python3.12 -B practice.py check L02-E015
~~~

การกด Run บนฟังก์ชันที่มีแต่ def อาจไม่แสดงอะไร เพราะยังไม่มีใครเรียกฟังก์ชัน; practice.py run เรียก test แรกให้ ส่วน check เรียกทุกกรณี

Run ทดลองกรณีตัวอย่างแรก; Check เปรียบเทียบกับทุกกรณีและบันทึกสถานะการเรียน

## 9. ถ้าไม่ผ่าน

สิ่งที่พลาดง่าย: ทดสอบ list ว่าง ค่าลบ ศูนย์ และค่าบวก แล้วตรวจแต่ละช่องตาม prompt ของ variant ปัจจุบัน. ตรวจค่าที่คืนและชนิดของมันก่อนตรวจการแสดงผล
