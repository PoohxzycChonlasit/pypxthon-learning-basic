# L08-E008 — ปรับราคาขายด้วย slippage

**ระดับ:** Level 8 — การเงินและความเสี่ยง<br>
**ความยาก:** Tier 2 — ง่าย — รวมแนวคิดคุ้นเคย<br>
**ชนิดคำตอบ:** เขียนฟังก์ชันและคืนค่าด้วย return

## 1. เรียนรู้อะไร

รับ exit_price และ slippage_rate; คืน exit_price*(1-slippage_rate)

## 2. ก่อนเริ่ม

ทบทวน: [L08-E007](L08-E007.md). หากคำศัพท์ในโจทย์ยังไม่คุ้น ให้เริ่มจากคำอธิบายแนวคิดในหน้านี้ก่อน

**แนวคิดสำคัญ:** แนวคิด: รับ exit_price และ slippage_rate; คืน exit_price*(1-slippage_rate)

คิดทีละขั้น: หาส่วนราคาที่เสียไปแล้วหักออกจากราคาขาย

## 3. ตัวอย่างสั้น

ตัวอย่างนี้ฝึกแนวคิดที่เกี่ยวข้อง แต่ใช้ค่าและสถานการณ์แยกจากโจทย์ที่ต้องส่ง

~~~python
items = ["tea", "rice"]
items.append("coffee")
print(items)
~~~

อ่าน arguments ที่ส่งให้ฟังก์ชันแล้วตามค่าที่ return; ถ้าไม่มี print การคืนค่าไม่ได้แสดงใน Terminal

## 4. งานของคุณ

สถานการณ์: ผู้ดูแลการจำลองลดราคาขายเพื่อสะท้อน slippage ของคำสั่งขาย

เขียน slippage_adjusted_exit(exit_price, slippage_rate) ให้ทำตามสัญญา: รับ exit_price และ slippage_rate; คืน exit_price*(1-slippage_rate).

กรณีขอบ: slippage เป็นสัดส่วน เช่น 0.01 คือ 1%.
คืนค่าเท่านั้น; งานทั้งหมดเป็นการจำลอง paper

## 5. เขียนคำตอบที่ไหน

ไฟล์ส่งคำตอบ: [exercises/level_08/L08-E008.py](../exercises/level_08/L08-E008.py)

แก้ฟังก์ชัน slippage_adjusted_exit(exit_price, slippage_rate) ในไฟล์นี้. คงชื่อและ signature ไว้ และคืนผลด้วย return

## 6. ลำดับทำงาน

1. อ่าน signature slippage_adjusted_exit(exit_price, slippage_rate) และดูว่า parameter แต่ละตัวรับข้อมูลอะไร
2. แก้เฉพาะ body ที่โจทย์กำหนด และส่งผลด้วย return
3. ตรวจกรณีขอบที่ระบุ โดยคงชื่อฟังก์ชันและ signature
4. ใช้ run ดูค่าคืนจากกรณีแรก แล้วใช้ check ตรวจ test ทั้งหมด

## 7. ข้อมูลเข้าและผลลัพธ์

- **ข้อมูลเข้า:** grader เรียก slippage_adjusted_exit ด้วย parameters ตาม signature ที่ให้.
- **ผลลัพธ์:** ฟังก์ชันต้องคืนค่า (float); return ส่งค่ากลับ ส่วน print แสดงข้อความ.
- **ชุดตรวจ:** มี 2 กรณี รวมขอบเขตตามโจทย์

ข้อจำกัดที่ต้องรักษา: Python 3.12; slippage เป็นสัดส่วน เช่น 0.01 คือ 1%; ไม่มีการเชื่อมต่อ exchange หรือคำสั่งเงินจริง
