# L07-E013 — ค่าเบี่ยงเบนสัมบูรณ์เฉลี่ย

**ระดับ:** Level 7 — คณิตศาสตร์และสถิติ<br>
**ความยาก:** Tier 4 — ท้าทาย — เงื่อนไขและกรณีขอบ<br>
**ชนิดคำตอบ:** เขียนฟังก์ชันและคืนค่าด้วย return

## 1. เรียนรู้อะไร

คืน mean(abs(value-mean(values)))

## 2. ก่อนเริ่ม

ทบทวน: [L07-E012](L07-E012.md). หากคำศัพท์ในโจทย์ยังไม่คุ้น ให้เริ่มจากคำอธิบายแนวคิดในหน้านี้ก่อน

**แนวคิดสำคัญ:** แนวคิด: คืน mean(abs(value-mean(values)))

ลำดับคิด: หาค่าเฉลี่ย; หาค่าเบี่ยงเบนสัมบูรณ์แต่ละตัว; เฉลี่ยค่าคลาดเคลื่อน

## 3. ตัวอย่างสั้น

ตัวอย่างนี้ฝึกแนวคิดที่เกี่ยวข้อง แต่ใช้ค่าและสถานการณ์แยกจากโจทย์ที่ต้องส่ง

~~~python
person = {"name": "Mali", "active": True}
print(person.get("active", False))
~~~

อ่าน arguments ที่ส่งให้ฟังก์ชันแล้วตามค่าที่ return; ถ้าไม่มี print การคืนค่าไม่ได้แสดงใน Terminal

## 4. งานของคุณ

สถานการณ์: ทีมวิเคราะห์วัดความคลาดเฉลี่ยจากค่าเฉลี่ยเพื่อสรุปการกระจาย

เขียน mean_absolute_deviation(values) ตามกติกา: คืน mean(abs(value-mean(values))).

กรณีขอบ: ข้อมูลว่างคืน 0; นี่คือ mean absolute deviation ไม่ใช่ standard deviation.
ส่งค่ากลับด้วย return และอย่าแก้ input ต้นฉบับ
