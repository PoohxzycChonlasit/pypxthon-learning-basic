# L02-E007 — รวมสลับตำแหน่ง

**ระดับ:** Level 2 — เงื่อนไขและลูป<br>
**ความยาก:** Tier 3 — ปานกลาง — หลายขั้นตอน<br>
**ชนิดคำตอบ:** เขียนฟังก์ชันและคืนค่าด้วย return

## 1. เรียนรู้อะไร

index คู่บวกเข้า total และ index คี่ลบออก; index เริ่มจาก 0

## 2. ก่อนเริ่ม

ทบทวน: [L02-E006](L02-E006.md). หากคำศัพท์ในโจทย์ยังไม่คุ้น ให้เริ่มจากคำอธิบายแนวคิดในหน้านี้ก่อน

**แนวคิดสำคัญ:** แนวคิด: index คู่บวกเข้า total และ index คี่ลบออก; index เริ่มจาก 0

คิดทีละขั้น: วนพร้อม index; ใช้เศษจากการหาร index ด้วย 2 เพื่อเลือกเครื่องหมาย

## 3. ตัวอย่างสั้น

ตัวอย่างนี้ฝึกแนวคิดที่เกี่ยวข้อง แต่ใช้ค่าและสถานการณ์แยกจากโจทย์ที่ต้องส่ง

~~~python
import json
settings = json.loads('{"mode": "offline", "retry": 2}')
print(settings["mode"], settings["retry"])
~~~

อ่าน arguments ที่ส่งให้ฟังก์ชันแล้วตามค่าที่ return; ถ้าไม่มี print การคืนค่าไม่ได้แสดงใน Terminal

## 4. งานของคุณ

สถานการณ์: นักวิเคราะห์ปรับยอดที่มีเครื่องหมายบวกและลบสลับตำแหน่ง

เขียน sum_alternating_values(values) ให้ทำตามสัญญา: index คู่บวกเข้า total และ index คี่ลบออก; index เริ่มจาก 0.

กรณีขอบ: list ว่างคืน 0; สมาชิกแรกใช้เครื่องหมายบวก.
ส่งค่ากลับด้วย return และรักษาชนิดผลลัพธ์ตามตัวอย่าง

## 5. เขียนคำตอบที่ไหน

ไฟล์ส่งคำตอบ: [exercises/level_02/L02-E007.py](../exercises/level_02/L02-E007.py)

แก้ฟังก์ชัน sum_alternating_values(values) ในไฟล์นี้. คงชื่อและ signature ไว้ และคืนผลด้วย return

## 6. ลำดับทำงาน

1. อ่าน signature sum_alternating_values(values) และดูว่า parameter แต่ละตัวรับข้อมูลอะไร
2. แก้เฉพาะ body ที่โจทย์กำหนด และส่งผลด้วย return
3. ตรวจกรณีขอบที่ระบุ โดยคงชื่อฟังก์ชันและ signature
4. ใช้ run ดูค่าคืนจากกรณีแรก แล้วใช้ check ตรวจ test ทั้งหมด

## 7. ข้อมูลเข้าและผลลัพธ์

- **ข้อมูลเข้า:** grader เรียก sum_alternating_values ด้วย parameters ตาม signature ที่ให้.
- **ผลลัพธ์:** ฟังก์ชันต้องคืนค่า (int); return ส่งค่ากลับ ส่วน print แสดงข้อความ.
- **ชุดตรวจ:** มี 2 กรณี รวมขอบเขตตามโจทย์

ข้อจำกัดที่ต้องรักษา: Python 3.12; list ว่างคืน 0; สมาชิกแรกใช้เครื่องหมายบวก; ใช้เฉพาะข้อมูลตามสัญญาโจทย์; ห้ามแก้ grader หรือเฉลย
