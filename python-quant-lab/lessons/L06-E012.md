# L06-E012 — นับค่าบวก

**ระดับ:** Level 6 — วิเคราะห์ข้อมูล<br>
**ความยาก:** Tier 2 — ง่าย — รวมแนวคิดคุ้นเคย<br>
**ชนิดคำตอบ:** เขียนฟังก์ชันและคืนค่าด้วย return

## 1. เรียนรู้อะไร

นับค่าที่มากกว่า 0 และไม่ใช่ None

## 2. ก่อนเริ่ม

ทบทวน: [L06-E011](L06-E011.md). หากคำศัพท์ในโจทย์ยังไม่คุ้น ให้เริ่มจากคำอธิบายแนวคิดในหน้านี้ก่อน

**แนวคิดสำคัญ:** แนวคิด: นับค่าที่มากกว่า 0 และไม่ใช่ None

ลำดับคิด: ตรวจแต่ละค่าด้วยเงื่อนไข not None และ > 0

## 3. ตัวอย่างสั้น

ตัวอย่างนี้ฝึกแนวคิดที่เกี่ยวข้อง แต่ใช้ค่าและสถานการณ์แยกจากโจทย์ที่ต้องส่ง

~~~python
numbers = [7, 2, 7, 4]
unique = list(dict.fromkeys(numbers))
print(unique)
~~~

อ่าน arguments ที่ส่งให้ฟังก์ชันแล้วตามค่าที่ return; ถ้าไม่มี print การคืนค่าไม่ได้แสดงใน Terminal

## 4. งานของคุณ

สถานการณ์: นักวิเคราะห์นับผลตอบแทนบวก โดยเว้นช่อง None และไม่นับศูนย์

เขียน positive_observation_count(values) ตามกติกา: นับค่าที่มากกว่า 0 และไม่ใช่ None.

กรณีขอบ: None และ 0 ไม่นับ; list ว่างคืน 0.
ส่งค่ากลับด้วย return และอย่าแก้ input ต้นฉบับ

## 5. เขียนคำตอบที่ไหน

ไฟล์ส่งคำตอบ: [exercises/level_06/L06-E012.py](../exercises/level_06/L06-E012.py)

แก้ฟังก์ชัน positive_observation_count(values) ในไฟล์นี้. คงชื่อและ signature ไว้ และคืนผลด้วย return

## 6. ลำดับทำงาน

1. อ่าน signature positive_observation_count(values) และดูว่า parameter แต่ละตัวรับข้อมูลอะไร
2. แก้เฉพาะ body ที่โจทย์กำหนด และส่งผลด้วย return
3. ตรวจกรณีขอบที่ระบุ โดยคงชื่อฟังก์ชันและ signature
4. ใช้ run ดูค่าคืนจากกรณีแรก แล้วใช้ check ตรวจ test ทั้งหมด

## 7. ข้อมูลเข้าและผลลัพธ์

- **ข้อมูลเข้า:** grader เรียก positive_observation_count ด้วย parameters ตาม signature ที่ให้.
- **ผลลัพธ์:** ฟังก์ชันต้องคืนค่า (int); return ส่งค่ากลับ ส่วน print แสดงข้อความ.
- **ชุดตรวจ:** มี 2 กรณี รวมขอบเขตตามโจทย์

ข้อจำกัดที่ต้องรักษา: Python 3.12; None และ 0 ไม่นับ; list ว่างคืน 0; ใช้ข้อมูลตามรูปแบบที่ระบุในโจทย์; output ต้องตรงทั้งชนิดและลำดับ
