# L03-E002 — ทำนายผลจาก list และ set

**ระดับ:** Level 3 — โครงสร้างข้อมูล<br>
**ความยาก:** Tier 1 — ง่ายมาก — แนวคิดเดียว<br>
**ชนิดคำตอบ:** ทำนายผลแล้วเขียนคำตอบในไฟล์ข้อความ

## 1. เรียนรู้อะไร

อ่านความยาว list การเอาค่าซ้ำออก และการอ่าน index

## 2. ก่อนเริ่ม

ทบทวน: [L03-E001](L03-E001.md). หากคำศัพท์ในโจทย์ยังไม่คุ้น ให้เริ่มจากคำอธิบายแนวคิดในหน้านี้ก่อน

**แนวคิดสำคัญ:** list รักษาสมาชิกและลำดับเดิม ส่วน set เก็บเฉพาะค่าที่ไม่ซ้ำ

## 3. ตัวอย่างสั้น

ตัวอย่างนี้ฝึกแนวคิดที่เกี่ยวข้อง แต่ใช้ค่าและสถานการณ์แยกจากโจทย์ที่ต้องส่ง

~~~python
raw = "  25 "
amount = int(raw.strip())
print(amount + 5)
~~~

แยกการคำนวณในตัวอย่างตามลำดับเครื่องหมาย แล้วเทียบกับ comment; ค่าตัวอย่างนี้ไม่ใช่คำตอบของโจทย์

## 4. งานของคุณ

อ่านโค้ดแล้วเขียน output ทุกบรรทัดลงไฟล์คำตอบ:

~~~python
items = ["tea", "rice", "tea"]
unique_items = set(items)
print(len(items))
print(len(unique_items))
print(items[0])
~~~
