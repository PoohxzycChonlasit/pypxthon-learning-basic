# L08-E013 — สัดส่วนการลดลง

**ระดับ:** Level 8 — การเงินและความเสี่ยง<br>
**ความยาก:** Tier 3 — ปานกลาง — หลายขั้นตอน<br>
**ชนิดคำตอบ:** เขียนฟังก์ชันและคืนค่าด้วย return

## 1. เรียนรู้อะไร

คืน max(0,(peak-current)/peak); หาก peak ไม่บวกคืน 0

## 2. ก่อนเริ่ม

ทบทวน: [L08-E012](L08-E012.md). หากคำศัพท์ในโจทย์ยังไม่คุ้น ให้เริ่มจากคำอธิบายแนวคิดในหน้านี้ก่อน

**แนวคิดสำคัญ:** แนวคิด: คืน max(0,(peak-current)/peak); หาก peak ไม่บวกคืน 0

คิดทีละขั้น: คำนวณสัดส่วนที่ลดจาก peak; clamp ค่าลบเป็น 0

## 3. ตัวอย่างสั้น

ตัวอย่างนี้ฝึกแนวคิดที่เกี่ยวข้อง แต่ใช้ค่าและสถานการณ์แยกจากโจทย์ที่ต้องส่ง

~~~python
numbers = [7, 2, 7, 4]
unique = list(dict.fromkeys(numbers))
print(unique)
~~~

อ่าน arguments ที่ส่งให้ฟังก์ชันแล้วตามค่าที่ return; ถ้าไม่มี print การคืนค่าไม่ได้แสดงใน Terminal

## 4. งานของคุณ

สถานการณ์: ทีมความเสี่ยงคำนวณ drawdown จาก peak equity ถึง current equity

เขียน drawdown_fraction(peak_equity, current_equity) ให้ทำตามสัญญา: คืน max(0,(peak-current)/peak); หาก peak ไม่บวกคืน 0.

กรณีขอบ: equity เหนือ peak ไม่ใช่ drawdown; คืน 0.
คืนค่าเท่านั้น; งานทั้งหมดเป็นการจำลอง paper
