# L02-E014 — แยกกำไรกับขาดทุน

**ระดับ:** Level 2 — เงื่อนไขและลูป<br>
**ความยาก:** Tier 5 — ประยุกต์ขั้นสูง — ใช้ความรู้เดิมกับโจทย์ใหม่<br>
**ชนิดคำตอบ:** เขียนฟังก์ชันและคืนค่าด้วย return

## 1. เรียนรู้อะไร

คืน tuple (gains, losses); กำไร > 0; ขาดทุน < 0; คงลำดับและค่าซ้ำ

## 2. ก่อนเริ่ม

ทบทวน: [L02-E013](L02-E013.md). หากคำศัพท์ในโจทย์ยังไม่คุ้น ให้เริ่มจากคำอธิบายแนวคิดในหน้านี้ก่อน

**แนวคิดสำคัญ:** แนวคิด: คืน tuple (gains, losses); กำไร > 0; ขาดทุน < 0; คงลำดับและค่าซ้ำ

คิดทีละขั้น: กรองรายการเดียวกันด้วยสองเงื่อนไข strict เพื่อสร้างสองกลุ่ม

## 3. ตัวอย่างสั้น

ตัวอย่างนี้ฝึกแนวคิดที่เกี่ยวข้อง แต่ใช้ค่าและสถานการณ์แยกจากโจทย์ที่ต้องส่ง

~~~python
class Product:
    def __init__(self, name, price):
        self.name = name
        self.price = price
tea = Product("tea", 20)
print(tea.name, tea.price)
~~~

อ่าน arguments ที่ส่งให้ฟังก์ชันแล้วตามค่าที่ return; ถ้าไม่มี print การคืนค่าไม่ได้แสดงใน Terminal

## 4. งานของคุณ

สถานการณ์: นักวิเคราะห์แยกวันที่กำไรกับวันที่ขาดทุนเป็นสองคอลัมน์

เขียน separate_gains_and_losses(values) ให้ทำตามสัญญา: คืน tuple (gains, losses); กำไร > 0; ขาดทุน < 0; คงลำดับและค่าซ้ำ.

กรณีขอบ: ศูนย์ถูกละเว้น; กลุ่มที่ไม่พบเป็น [].
ส่งค่ากลับด้วย return และรักษาชนิดผลลัพธ์ตามตัวอย่าง

4. ใช้ run ดูค่าคืนจากกรณีแรก แล้วใช้ check ตรวจ test ทั้งหมด

## 7. ข้อมูลเข้าและผลลัพธ์

- **ข้อมูลเข้า:** grader เรียก separate_gains_and_losses ด้วย parameters ตาม signature ที่ให้.
- **ผลลัพธ์:** ฟังก์ชันต้องคืนค่า (list); return ส่งค่ากลับ ส่วน print แสดงข้อความ.
