# L04-E009 — จำนวนหน่วยตามความเสี่ยง

**ระดับ:** Level 4 — ฟังก์ชันและโมดูล<br>
**ความยาก:** Tier 3 — ปานกลาง — หลายขั้นตอน<br>
**ชนิดคำตอบ:** เขียนฟังก์ชันและคืนค่าด้วย return

## 1. เรียนรู้อะไร

คืน risk_budget / abs(risk_per_unit); ถ้าระยะเป็นศูนย์คืน 0

## 2. ก่อนเริ่ม

ทบทวน: [L04-E008](L04-E008.md). หากคำศัพท์ในโจทย์ยังไม่คุ้น ให้เริ่มจากคำอธิบายแนวคิดในหน้านี้ก่อน

**แนวคิดสำคัญ:** แนวคิด: คืน risk_budget / abs(risk_per_unit); ถ้าระยะเป็นศูนย์คืน 0

คิดทีละขั้น: หาความเสี่ยงต่อหน่วย; ตรวจศูนย์; หารงบด้วยระยะ

## 3. ตัวอย่างสั้น

ตัวอย่างนี้ฝึกแนวคิดที่เกี่ยวข้อง แต่ใช้ค่าและสถานการณ์แยกจากโจทย์ที่ต้องส่ง

~~~python
import csv
import io
rows = list(csv.DictReader(io.StringIO("sku,qty\nA1,2\n")))
print(rows[0]["sku"], int(rows[0]["qty"]))
~~~

อ่าน arguments ที่ส่งให้ฟังก์ชันแล้วตามค่าที่ return; ถ้าไม่มี print การคืนค่าไม่ได้แสดงใน Terminal

## 7. ข้อมูลเข้าและผลลัพธ์
