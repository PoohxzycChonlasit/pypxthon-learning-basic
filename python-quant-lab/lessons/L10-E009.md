# L10-E009 — ใช้ค่าธรรมเนียมเริ่มต้น

**ระดับ:** Level 10 — วิศวกรรม paper bot ออฟไลน์<br>
**ความยาก:** Tier 3 — ปานกลาง — หลายขั้นตอน<br>
**ชนิดคำตอบ:** เขียนฟังก์ชันและคืนค่าด้วย return

## 1. เรียนรู้อะไร

คืน fee หากเป็น finite number >=0 และไม่ใช่ bool; มิฉะนั้น 0.0

## 2. ก่อนเริ่ม

ทบทวน: [L10-E008](L10-E008.md). หากคำศัพท์ในโจทย์ยังไม่คุ้น ให้เริ่มจากคำอธิบายแนวคิดในหน้านี้ก่อน

**แนวคิดสำคัญ:** แนวคิด: คืน fee หากเป็น finite number >=0 และไม่ใช่ bool; มิฉะนั้น 0.0

ขั้นตอน: ตรวจชนิด; ตรวจ finite; ยอมรับเฉพาะค่าที่ไม่ติดลบ

## 3. ตัวอย่างสั้น

ตัวอย่างนี้ฝึกแนวคิดที่เกี่ยวข้อง แต่ใช้ค่าและสถานการณ์แยกจากโจทย์ที่ต้องส่ง

~~~python
items = ["tea", "rice"]
items.append("coffee")
print(items)
~~~

อ่าน arguments ที่ส่งให้ฟังก์ชันแล้วตามค่าที่ return; ถ้าไม่มี print การคืนค่าไม่ได้แสดงใน Terminal

## 4. งานของคุณ

สถานการณ์: paper bot ใช้ fee 0 เมื่อ event ไม่มี fee หรือระบุค่าไม่สมเหตุผล

เขียน safe_default_fee(event) ตามสัญญา: คืน fee หากเป็น finite number >=0 และไม่ใช่ bool; มิฉะนั้น 0.0.

กรณีขอบ: ปฏิเสธ string, bool, NaN, infinity และค่าติดลบ.
ใช้ข้อมูลจำลองออฟไลน์เท่านั้นและคืนค่าตามโจทย์

## 5. เขียนคำตอบที่ไหน

ไฟล์ส่งคำตอบ: [exercises/level_10/L10-E009.py](../exercises/level_10/L10-E009.py)

แก้ฟังก์ชัน safe_default_fee(event) ในไฟล์นี้. คงชื่อและ signature ไว้ และคืนผลด้วย return

## 6. ลำดับทำงาน

1. อ่าน signature safe_default_fee(event) และดูว่า parameter แต่ละตัวรับข้อมูลอะไร
2. แก้เฉพาะ body ที่โจทย์กำหนด และส่งผลด้วย return
3. ตรวจกรณีขอบที่ระบุ โดยคงชื่อฟังก์ชันและ signature
4. ใช้ run ดูค่าคืนจากกรณีแรก แล้วใช้ check ตรวจ test ทั้งหมด

## 7. ข้อมูลเข้าและผลลัพธ์

- **ข้อมูลเข้า:** grader เรียก safe_default_fee ด้วย parameters ตาม signature ที่ให้.
- **ผลลัพธ์:** ฟังก์ชันต้องคืนค่า (float); return ส่งค่ากลับ ส่วน print แสดงข้อความ.
- **ชุดตรวจ:** มี 2 กรณี รวมขอบเขตตามโจทย์

ข้อจำกัดที่ต้องรักษา: Python 3.12; ปฏิเสธ string, bool, NaN, infinity และค่าติดลบ; ไม่มีการเชื่อมต่อ exchange หรือ wallet

## 9. ถ้าไม่ผ่าน

สิ่งที่พลาดง่าย: ปฏิเสธ string, bool, NaN, infinity และค่าติดลบ ห้ามแปลงงานจำลองเป็นคำสั่งเงินจริง. ตรวจค่าที่คืนและชนิดของมันก่อนตรวจการแสดงผล
