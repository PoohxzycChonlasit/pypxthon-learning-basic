# L03-E012 — เลือกทุกค่าลำดับที่สอง

**ระดับ:** Level 3 — โครงสร้างข้อมูล<br>
**ความยาก:** Tier 4 — ท้าทาย — เงื่อนไขและกรณีขอบ<br>
**ชนิดคำตอบ:** เขียนฟังก์ชันและคืนค่าด้วย return

## 1. เรียนรู้อะไร

คืน index 0,2,4,... ตามลำดับ; เป็นการเลือกตำแหน่งคงที่ไม่ใช่สุ่ม

## 2. ก่อนเริ่ม

ทบทวน: [L03-E011](L03-E011.md). หากคำศัพท์ในโจทย์ยังไม่คุ้น ให้เริ่มจากคำอธิบายแนวคิดในหน้านี้ก่อน

**แนวคิดสำคัญ:** แนวคิด: คืน index 0,2,4,... ตามลำดับ; เป็นการเลือกตำแหน่งคงที่ไม่ใช่สุ่ม

คิดทีละขั้น: ใช้ slice เริ่ม index 0 พร้อม step 2

## 3. ตัวอย่างสั้น

ตัวอย่างนี้ฝึกแนวคิดที่เกี่ยวข้อง แต่ใช้ค่าและสถานการณ์แยกจากโจทย์ที่ต้องส่ง

~~~python
def add_tip(total, rate=0.05):
    return total + total * rate
print(add_tip(80))
~~~

อ่าน arguments ที่ส่งให้ฟังก์ชันแล้วตามค่าที่ return; ถ้าไม่มี print การคืนค่าไม่ได้แสดงใน Terminal

## 4. งานของคุณ

สถานการณ์: นักวิจัยเลือกทุกแถวเว้นหนึ่งแถวเพื่อย่อข้อมูลสำหรับภาพรวม

เขียน every_second_observation(items) ให้ทำตามสัญญา: คืน index 0,2,4,... ตามลำดับ; เป็นการเลือกตำแหน่งคงที่ไม่ใช่สุ่ม.

กรณีขอบ: รวมสมาชิกแรก; list ว่างคืน [].
ส่งค่ากลับด้วย return และรักษาชนิดผลลัพธ์ตามตัวอย่าง

## 5. เขียนคำตอบที่ไหน

ไฟล์ส่งคำตอบ: [exercises/level_03/L03-E012.py](../exercises/level_03/L03-E012.py)

แก้ฟังก์ชัน every_second_observation(items) ในไฟล์นี้. คงชื่อและ signature ไว้ และคืนผลด้วย return

## 6. ลำดับทำงาน

1. อ่าน signature every_second_observation(items) และดูว่า parameter แต่ละตัวรับข้อมูลอะไร
2. แก้เฉพาะ body ที่โจทย์กำหนด และส่งผลด้วย return
3. ตรวจกรณีขอบที่ระบุ โดยคงชื่อฟังก์ชันและ signature
4. ใช้ run ดูค่าคืนจากกรณีแรก แล้วใช้ check ตรวจ test ทั้งหมด

## 7. ข้อมูลเข้าและผลลัพธ์

- **ข้อมูลเข้า:** grader เรียก every_second_observation ด้วย parameters ตาม signature ที่ให้.
- **ผลลัพธ์:** ฟังก์ชันต้องคืนค่า (list); return ส่งค่ากลับ ส่วน print แสดงข้อความ.
- **ชุดตรวจ:** มี 2 กรณี รวมขอบเขตตามโจทย์

ข้อจำกัดที่ต้องรักษา: Python 3.12; รวมสมาชิกแรก; list ว่างคืน []; ใช้เฉพาะข้อมูลตามสัญญาโจทย์; ห้ามแก้ grader หรือเฉลย
