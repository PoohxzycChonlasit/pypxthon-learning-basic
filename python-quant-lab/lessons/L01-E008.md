# L01-E008 — เติมการแปลง input เป็นจำนวนเต็ม

**ระดับ:** Level 1 — Python พื้นฐาน<br>
**ความยาก:** Tier 3 — ปานกลาง — หลายขั้นตอน<br>
**ชนิดคำตอบ:** โปรแกรม Python แสดงผล (stdout)

## 1. เรียนรู้อะไร

รับข้อความจาก input() และแปลงเป็น int

## 2. ก่อนเริ่ม

ทบทวน: [L01-E007](L01-E007.md). หากคำศัพท์ในโจทย์ยังไม่คุ้น ให้เริ่มจากคำอธิบายแนวคิดในหน้านี้ก่อน

**แนวคิดสำคัญ:** `input()` คืนค่าเป็น string แม้ผู้ใช้พิมพ์ตัวเลข ต้องใช้ `int()` ก่อนนำไปบวกเลขจำนวนเต็ม

## 3. ตัวอย่างสั้น

ตัวอย่างนี้ฝึกแนวคิดที่เกี่ยวข้อง แต่ใช้ค่าและสถานการณ์แยกจากโจทย์ที่ต้องส่ง

~~~python
box_count = int("4")
print(box_count * 6)  # 24
~~~

ในตัวอย่างนี้ ให้ดูว่าคำสั่ง print ส่งค่าใดไปยังหน้าจอ; ข้อความหลังเครื่องหมาย # เป็นคำอธิบาย output ของตัวอย่าง

## 4. งานของคุณ

เติมบรรทัด TODO ให้โปรแกรมอ่านจำนวนเต็ม แล้วแสดงจำนวนที่มากขึ้นหนึ่ง

## 5. เขียนคำตอบที่ไหน

ไฟล์ส่งคำตอบ: [exercises/level_01/L01-E008.py](../exercises/level_01/L01-E008.py)

แก้ไฟล์ Python นี้ตรงตำแหน่งงานที่โจทย์ระบุ; อย่าแก้ไฟล์ tests หรือ solutions

## 6. ลำดับทำงาน

1. อ่านโจทย์และตัวอย่างแยก แล้วหา TODO หรือบรรทัดที่ต้องแก้ในไฟล์ Python
2. เขียนคำสั่งให้แสดงผลตรงตามรูปแบบที่โจทย์ขอ
3. บันทึกไฟล์ แล้วใช้ run ดูกรณีตัวอย่างแรก
4. ใช้ check ตรวจทุกกรณี; อ่านชื่อ test แรกที่ไม่ผ่านก่อนแก้

## 7. ข้อมูลเข้าและผลลัพธ์

- **ข้อมูลเข้า:** ใช้ input ที่โจทย์หรือ test ส่งให้; ถ้าไม่มี stdin ก็ไม่ต้องพิมพ์ค่าเพิ่ม.
- **ผลลัพธ์:** ข้อความที่โปรแกรมส่งไป stdout ต้องมีลำดับ บรรทัด และรูปแบบตรงตามโจทย์.
- **การแสดงผล:** print() แสดงค่าที่ Terminal; การกำหนดตัวแปรอย่างเดียวไม่ทำให้เกิด output

ข้อจำกัดที่ต้องรักษา: Python 3.12; ใช้เฉพาะแนวคิดที่สอนถึงข้อนี้; การเทรดเป็นการจำลอง paper-only

## 9. ถ้าไม่ผ่าน

สิ่งที่พลาดง่าย: นำ string จาก input() ไปบวกกับ integer โดยตรง. ตรวจเครื่องหมายคำพูด การขึ้นบรรทัดใหม่ และค่าที่ print ทีละบรรทัด
