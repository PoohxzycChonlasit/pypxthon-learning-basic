# L01-E008 — เติมการแปลง input เป็นจำนวนเต็ม

## เป้าหมาย

รับข้อความจาก input() และแปลงเป็น int

## แนวคิด

`input()` คืนค่าเป็น string แม้ผู้ใช้พิมพ์ตัวเลข ต้องใช้ `int()` ก่อนนำไปบวกเลขจำนวนเต็ม

## ตัวอย่าง

```python
count = int(input())
print(count + 1)
```
