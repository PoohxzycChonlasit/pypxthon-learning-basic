# Level 2 — เงื่อนไขและลูป

**เป้าหมาย:** เขียนเงื่อนไขและลูปเพื่อใช้กฎกับข้อมูลหลายค่า

**ทำไมสำคัญ:** เงื่อนไขทำให้โปรแกรมเลือกผลตามกติกา ส่วนลูปช่วยประมวลผลรายการโดยไม่เขียนคำสั่งซ้ำ

**ก่อนเริ่ม:** ทบทวน Level 1 โดยเฉพาะตัวแปร ค่าจริง/เท็จ และการคำนวณ

**แนวคิดหลัก:** การเปรียบเทียบ · if/elif/else · for และ while · break และ continue

## ตัวอย่างสั้นที่ทำตามได้

ตัวอย่างนี้ใช้ข้อมูลคนละชุดกับแบบฝึกหัด ให้ทำนายผลก่อนอ่านบรรทัดผลลัพธ์

~~~python
score = 72
if score >= 60:
    print("ผ่าน")
else:
    print("ลองอีกครั้ง")
~~~

**อ่านทีละขั้น:**
1. score มีค่า 72
2. 72 >= 60 เป็นจริง จึงเลือกกิ่งแรก
3. print() แสดงคำว่า ผ่าน

ผลของตัวอย่าง:

~~~text
ผ่าน
~~~

## ตัวอย่างฝึกระดับเพิ่มเติม

เนื้อหาฝึกเดิมของระดับนี้ยังคงไว้เพื่อใช้ทบทวน

**เป้าหมาย:** เขียนกฎตัดสินใจและประมวลผลรายการหลายค่า ใช้ได้กับการคิดค่าส่ง การเตือนงบ และการตรวจข้อมูล

## พิมพ์ตาม: เตือนเมื่อค่าใช้จ่ายเกินงบ

### ขั้นที่ 1 — แนวคิด

เงื่อนไขเป็นคำถามที่ตอบ True หรือ False ส่วนลูปทำคำสั่งซ้ำ ใช้ if กับกฎหนึ่งครั้ง และใช้ for เมื่อมีข้อมูลหลายรายการ

### ขั้นที่ 2–3 — พิมพ์ตัวอย่างนี้

~~~python
expenses = [120, 80, 150]
budget = 400
spent = 0

for amount in expenses:
    spent = spent + amount

remaining = budget - spent
if remaining < 0:
    message = "เกินงบ"
elif remaining == 0:
    message = "ใช้งบครบ"
else:
    message = "ยังอยู่ในงบ"

print(spent)
print(message)
~~~

### ขั้นที่ 4 — อ่านทีละส่วน

- list เก็บค่าใช้จ่ายหลายรายการ
- for นำค่าแต่ละตัวไปบวกใน spent
- remaining คือเงินที่เหลือหลังรวมรายการ
- if/elif/else เลือกข้อความตามสถานะงบ

### ขั้นที่ 5 — ผลลัพธ์ที่คาด

~~~text
350
ยังอยู่ในงบ
~~~

### ขั้นที่ 6–7 — ทดลองเปลี่ยน

เปลี่ยน amount ตัวแรกเป็น 220 แล้วรันใหม่ ยอดใช้จ่ายจะเพิ่ม 100 และข้อความต้องเปลี่ยนเป็นเกินงบ

### ขั้นที่ 8 — ลองเอง

เพิ่มรายการใหม่ที่ทำให้ใช้เงินพอดีกับ budget แล้วตรวจว่ากิ่ง elif ทำงานหรือไม่ จากนั้นทำโจทย์ใน Level 2 ต่อ โดยทดสอบค่าตรงขอบเงื่อนไขด้วย

**แนวคิดของระดับนี้:** == ใช้ตรวจค่าเท่ากัน, >= ใช้ตรวจ threshold, break หยุดลูป และ continue ข้ามสมาชิกหนึ่งตัว อย่าเขียน while ที่ไม่มีทางหยุด
