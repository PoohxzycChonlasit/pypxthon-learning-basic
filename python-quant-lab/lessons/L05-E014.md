# L05-E014 — นับสัญลักษณ์ซ้ำ

**ระดับ:** Level 5 — Python สำหรับงานจริง<br>
**ความยาก:** Tier 3 — ปานกลาง — หลายขั้นตอน<br>
**ชนิดคำตอบ:** เขียนฟังก์ชันและคืนค่าด้วย return

## 1. เรียนรู้อะไร

ตัดช่องว่างและแปลงแต่ละ token เป็นตัวพิมพ์ใหญ่; คืน dict นับจำนวน; ข้าม token ว่าง

## 2. ก่อนเริ่ม

ทบทวน: [L05-E013](L05-E013.md). หากคำศัพท์ในโจทย์ยังไม่คุ้น ให้เริ่มจากคำอธิบายแนวคิดในหน้านี้ก่อน

**แนวคิดสำคัญ:** แนวคิด: ตัดช่องว่างและแปลงแต่ละ token เป็นตัวพิมพ์ใหญ่; คืน dict นับจำนวน; ข้าม token ว่าง

ลำดับคิด: normalize แต่ละ token ก่อนนับและเพิ่มค่าความถี่ใน dict

## 3. ตัวอย่างสั้น

ตัวอย่างนี้ฝึกแนวคิดที่เกี่ยวข้อง แต่ใช้ค่าและสถานการณ์แยกจากโจทย์ที่ต้องส่ง

~~~python
items = ["tea", "rice"]
items.append("coffee")
print(items)
~~~

อ่าน arguments ที่ส่งให้ฟังก์ชันแล้วตามค่าที่ return; ถ้าไม่มี print การคืนค่าไม่ได้แสดงใน Terminal

## 4. งานของคุณ

สถานการณ์: ทีมสนับสนุนสรุปจำนวน ticker ในข้อความ comma-separated โดยไม่สนตัวพิมพ์และช่องว่าง

เขียน count_repeated_symbols(text) ตามกติกา: ตัดช่องว่างและแปลงแต่ละ token เป็นตัวพิมพ์ใหญ่; คืน dict นับจำนวน; ข้าม token ว่าง.

กรณีขอบ: ticker ที่ต่างกันแค่ตัวพิมพ์นับรวม; ไม่แสดง key ว่าง.
ส่งค่ากลับด้วย return และอย่าแก้ input ต้นฉบับ

## 5. เขียนคำตอบที่ไหน

## 6. ลำดับทำงาน

1. อ่าน signature count_repeated_symbols(text) และดูว่า parameter แต่ละตัวรับข้อมูลอะไร
2. แก้เฉพาะ body ที่โจทย์กำหนด และส่งผลด้วย return
3. ตรวจกรณีขอบที่ระบุ โดยคงชื่อฟังก์ชันและ signature
4. ใช้ run ดูค่าคืนจากกรณีแรก แล้วใช้ check ตรวจ test ทั้งหมด

## 7. ข้อมูลเข้าและผลลัพธ์

- **ข้อมูลเข้า:** grader เรียก count_repeated_symbols ด้วย parameters ตาม signature ที่ให้.
- **ผลลัพธ์:** ฟังก์ชันต้องคืนค่า (dict มี key: BTC, ETH); return ส่งค่ากลับ ส่วน print แสดงข้อความ.
- **ชุดตรวจ:** มี 2 กรณี รวมขอบเขตตามโจทย์

ข้อจำกัดที่ต้องรักษา: Python 3.12; ticker ที่ต่างกันแค่ตัวพิมพ์นับรวม; ไม่แสดง key ว่าง; ใช้ข้อมูลตามรูปแบบที่ระบุในโจทย์; output ต้องตรงทั้งชนิดและลำดับ
