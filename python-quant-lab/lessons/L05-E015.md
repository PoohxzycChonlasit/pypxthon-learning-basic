# L05-E015 — ประเมินการแยกข้อมูล

**ระดับ:** Level 5 — Python สำหรับงานจริง<br>
**ความยาก:** Tier 3 — ปานกลาง — หลายขั้นตอน<br>
**ชนิดคำตอบ:** เขียนฟังก์ชันและคืนค่าด้วย return

## 1. เรียนรู้อะไร

แยกและแปลงข้อความตามรูปแบบที่ prompt ของ variant ที่เลือกกำหนด

## 2. ก่อนเริ่ม

ทบทวน: [L05-E014](L05-E014.md). หากคำศัพท์ในโจทย์ยังไม่คุ้น ให้เริ่มจากคำอธิบายแนวคิดในหน้านี้ก่อน

**แนวคิดสำคัญ:** ใช้ prompt ของ variant ปัจจุบันเป็น contract; ระบุตัวคั่น จำนวน field การปรับข้อความ และชนิดข้อมูลที่ต้องการ จากนั้นแยกข้อความ ตัดช่องว่าง และแปลงเฉพาะ field ที่ระบุ.

## 3. ตัวอย่างสั้น

ตัวอย่างนี้ฝึกแนวคิดที่เกี่ยวข้อง แต่ใช้ค่าและสถานการณ์แยกจากโจทย์ที่ต้องส่ง

~~~python
left, right = ("offline", "paper")
print(left, right)
~~~

อ่าน arguments ที่ส่งให้ฟังก์ชันแล้วตามค่าที่ return; ถ้าไม่มี print การคืนค่าไม่ได้แสดงใน Terminal

## 4. งานของคุณ

แบบประเมิน A/B: เขียนฟังก์ชัน final_parsing_assessment(text) ตามโจทย์ของ variant ที่ระบบแสดงอยู่ ใช้ input ที่รับเข้ามาคำนวณและคืนผลตาม รูปแบบข้อมูล ที่กำหนด ห้าม hardcode คำตอบของตัวอย่าง

## 5. เขียนคำตอบที่ไหน

ไฟล์ส่งคำตอบ: [exercises/level_05/L05-E015.py](../exercises/level_05/L05-E015.py)

แก้ฟังก์ชัน final_parsing_assessment(text) ในไฟล์นี้. คงชื่อและ signature ไว้ และคืนผลด้วย return

## 6. ลำดับทำงาน

1. อ่าน signature final_parsing_assessment(text) และดูว่า parameter แต่ละตัวรับข้อมูลอะไร
2. แก้เฉพาะ body ที่โจทย์กำหนด และส่งผลด้วย return
3. ตรวจกรณีขอบที่ระบุ โดยคงชื่อฟังก์ชันและ signature
4. ใช้ run ดูค่าคืนจากกรณีแรก แล้วใช้ check ตรวจ test ทั้งหมด

## 7. ข้อมูลเข้าและผลลัพธ์

- **ข้อมูลเข้า:** grader เรียก final_parsing_assessment ด้วย parameters ตาม signature ที่ให้.
- **ผลลัพธ์:** ฟังก์ชันต้องคืนค่า (dict มี key: fields, normalized); return ส่งค่ากลับ ส่วน print แสดงข้อความ.
- **ชุดตรวจ:** มี 3 กรณี รวมขอบเขตตามโจทย์

ข้อจำกัดที่ต้องรักษา: ใช้ Python 3.12 และ standard library; ห้ามแก้ tests, curriculum หรือไฟล์เฉลย; ตัวอย่างการเทรดเป็น paper-only

## 8. Run และ Check

รันจากโฟลเดอร์โครงการที่มี practice.py:

~~~powershell
py -3.12 -B practice.py run L05-E015
py -3.12 -B practice.py check L05-E015
~~~

บน macOS Terminal ใช้ python3.12 แทน py -3.12:

~~~sh
python3.12 -B practice.py run L05-E015
python3.12 -B practice.py check L05-E015
~~~

การกด Run บนฟังก์ชันที่มีแต่ def อาจไม่แสดงอะไร เพราะยังไม่มีใครเรียกฟังก์ชัน; practice.py run เรียก test แรกให้ ส่วน check เรียกทุกกรณี

Run ทดลองกรณีตัวอย่างแรก; Check เปรียบเทียบกับทุกกรณีและบันทึกสถานะการเรียน

## 9. ถ้าไม่ผ่าน

สิ่งที่พลาดง่าย: ตรวจตัวคั่น ช่องว่าง ลำดับ field และชนิดข้อมูลตาม prompt ของ variant ปัจจุบัน. ตรวจค่าที่คืนและชนิดของมันก่อนตรวจการแสดงผล

หากต้องการความช่วยเหลือหลังลองเอง ให้ใช้ py -3.12 -B practice.py hint L05-E015 1. คำใบ้และการเปิดเฉลยจะถูกบันทึกใน progress
