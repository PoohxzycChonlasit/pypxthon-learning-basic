# L08-E014 — จำนวนหน่วยตามระยะขาดทุน

**ระดับ:** Level 8 — การเงินและความเสี่ยง<br>
**ความยาก:** Tier 3 — ปานกลาง — หลายขั้นตอน<br>
**ชนิดคำตอบ:** เขียนฟังก์ชันและคืนค่าด้วย return

## 1. เรียนรู้อะไร

quantity = risk_budget/abs(entry-stop); ถ้าระยะเป็น 0 คืน 0

## 2. ก่อนเริ่ม

ทบทวน: [L08-E013](L08-E013.md). หากคำศัพท์ในโจทย์ยังไม่คุ้น ให้เริ่มจากคำอธิบายแนวคิดในหน้านี้ก่อน

**แนวคิดสำคัญ:** แนวคิด: quantity = risk_budget/abs(entry-stop); ถ้าระยะเป็น 0 คืน 0

คิดทีละขั้น: ใช้ระยะสัมบูรณ์; ตรวจศูนย์; หาร budget ด้วยระยะ

## 3. ตัวอย่างสั้น

ตัวอย่างนี้ฝึกแนวคิดที่เกี่ยวข้อง แต่ใช้ค่าและสถานการณ์แยกจากโจทย์ที่ต้องส่ง

~~~python
grades = [72, 88, 91]
print(sorted(grades))
~~~

อ่าน arguments ที่ส่งให้ฟังก์ชันแล้วตามค่าที่ return; ถ้าไม่มี print การคืนค่าไม่ได้แสดงใน Terminal

## 4. งานของคุณ

สถานการณ์: นักวิจัยกำหนดจำนวนหน่วยจาก risk budget และระยะขาดทุนต่อหน่วย

เขียน risk_sized_quantity(risk_budget, entry, stop) ให้ทำตามสัญญา: quantity = risk_budget/abs(entry-stop); ถ้าระยะเป็น 0 คืน 0.

กรณีขอบ: risk budget ไม่ติดลบ; quantity ที่คืนไม่ติดลบ.
คืนค่าเท่านั้น; งานทั้งหมดเป็นการจำลอง paper

1. อ่าน signature risk_sized_quantity(risk_budget, entry, stop) และดูว่า parameter แต่ละตัวรับข้อมูลอะไร

3. ตรวจกรณีขอบที่ระบุ โดยคงชื่อฟังก์ชันและ signature
4. ใช้ run ดูค่าคืนจากกรณีแรก แล้วใช้ check ตรวจ test ทั้งหมด

## 7. ข้อมูลเข้าและผลลัพธ์

- **ข้อมูลเข้า:** grader เรียก risk_sized_quantity ด้วย parameters ตาม signature ที่ให้.
- **ผลลัพธ์:** ฟังก์ชันต้องคืนค่า (int); return ส่งค่ากลับ ส่วน print แสดงข้อความ.
- **ชุดตรวจ:** มี 2 กรณี รวมขอบเขตตามโจทย์
