# L08-E003 — เติมการคำนวณขนาดสถานะจากวงเงินเสี่ยง

**ระดับ:** Level 8 — การเงินและความเสี่ยง<br>
**ความยาก:** Tier 3 — ปานกลาง — หลายขั้นตอน<br>
**ชนิดคำตอบ:** โปรแกรม Python แสดงผล (stdout)

## 1. เรียนรู้อะไร

แปลง risk budget เป็นจำนวนหน่วยโดยหารระยะ stop

## 2. ก่อนเริ่ม

ทบทวน: [L08-E002](L08-E002.md). หากคำศัพท์ในโจทย์ยังไม่คุ้น ให้เริ่มจากคำอธิบายแนวคิดในหน้านี้ก่อน

**แนวคิดสำคัญ:** เริ่มจากวงเงินที่ยอมขาดทุน แล้วหารความเสี่ยงต่อหน่วย ไม่ใช่เลือกขนาดจากกำไรที่อยากได้

## 3. ตัวอย่างสั้น

ตัวอย่างนี้ฝึกแนวคิดที่เกี่ยวข้อง แต่ใช้ค่าและสถานการณ์แยกจากโจทย์ที่ต้องส่ง

~~~python
values = [2, 5, 3]
total = 0
for value in values:
    total += value
print(total)
~~~

ในตัวอย่างนี้ ให้ดูว่าคำสั่ง print ส่งค่าใดไปยังหน้าจอ; ข้อความหลังเครื่องหมาย # เป็นคำอธิบาย output ของตัวอย่าง

## 4. งานของคุณ

เติม risk_based_quantity(equity, risk_percent, stop_distance) ให้คืน (equity * risk_percent / 100) / stop_distance; ถ้า equity ไม่บวก, risk_percent ติดลบ หรือ stop_distance ไม่บวก ให้คืน 0 รับค่าทีละบรรทัดและแสดงสองตำแหน่ง

1. อ่านโจทย์และตัวอย่างแยก แล้วหา TODO หรือบรรทัดที่ต้องแก้ในไฟล์ Python

## 7. ข้อมูลเข้าและผลลัพธ์

- **ข้อมูลเข้า:** ใช้ input ที่โจทย์หรือ test ส่งให้; ถ้าไม่มี stdin ก็ไม่ต้องพิมพ์ค่าเพิ่ม.
- **ผลลัพธ์:** ข้อความที่โปรแกรมส่งไป stdout ต้องมีลำดับ บรรทัด และรูปแบบตรงตามโจทย์.
- **การแสดงผล:** print() แสดงค่าที่ Terminal; การกำหนดตัวแปรอย่างเดียวไม่ทำให้เกิด output
