# Level 4 — ฟังก์ชันและโมดูล

**เป้าหมาย:** แยกการคำนวณออกเป็นฟังก์ชันที่อ่านง่าย ทดสอบซ้ำได้ และนำไปใช้หลายจุด

## พิมพ์ตาม: คำนวณยอดสุทธิหลังส่วนลด

### ขั้นที่ 1 — แนวคิด

ฟังก์ชันรับข้อมูลผ่าน parameters ทำงานหนึ่งหน้าที่ แล้วคืนผลด้วย return การคืนค่าทำให้ส่วนอื่นเรียกใช้หรือทดสอบได้โดยไม่ต้องอ่านหน้าจอ

### ขั้นที่ 2–3 — พิมพ์ตัวอย่างนี้

~~~python
def discounted_total(price, quantity, discount_rate=0.10):
    subtotal = price * quantity
    discount = subtotal * discount_rate
    return subtotal - discount

tea_total = discounted_total(30, 2)
rice_total = discounted_total(25, 3, 0)
print(tea_total)
print(rice_total)
~~~

### ขั้นที่ 4 — อ่านทีละส่วน

- price, quantity และ discount_rate เป็น parameters
- ค่าที่ส่งในวงเล็บตอนเรียกเป็น arguments
- rate มีค่าเริ่มต้น 0.10 ถ้าไม่ส่ง argument ตัวที่สาม
- return ส่งยอดสุทธิกลับไปเก็บในตัวแปร

### ขั้นที่ 5 — ผลลัพธ์ที่คาด

~~~text
54.0
75
~~~

### ขั้นที่ 6–7 — ทดลองเปลี่ยน

เปลี่ยน default discount_rate เป็น 0.20 ยอดชาเปลี่ยนเป็น 48.0 ส่วนยอดข้าวยังเป็น 75 เพราะเรียกโดยระบุส่วนลดเป็นศูนย์

### ขั้นที่ 8 — ลองเอง

สร้างฟังก์ชันย่อยสำหรับคิดภาษี แล้วเรียกจากฟังก์ชันสรุปยอด อย่าใช้ตัวแปร global เพื่อส่งข้อมูลระหว่างฟังก์ชัน

**แนวคิดของระดับนี้:** แยกสูตรเป็นส่วนเล็ก ตั้งชื่อให้บอกหน้าที่ และเพิ่ม type hints เมื่อต้องการอธิบายชนิดค่าที่รับและคืน
