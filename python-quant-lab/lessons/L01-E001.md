# L01-E001 — แสดงข้อความด้วย print()

## เป้าหมาย

ใช้ print() แสดงข้อความตามที่โจทย์กำหนด

## แนวคิด

`print()` แสดงข้อความบนหน้าจอ แล้วขึ้นบรรทัดใหม่ให้โดยอัตโนมัติ ข้อความต้องครอบด้วยเครื่องหมายคำพูด

## ตัวอย่าง

```python
print("Hello")  # แสดง Hello
```

## โจทย์

เขียนโปรแกรมให้แสดงข้อความ `สวัสดี Python` เพียงหนึ่งบรรทัด

## รูปแบบ input/output

ไม่ต้องป้อนข้อมูล

ผลที่ต้องการ: สวัสดี Python

ข้อควรระวัง: ลืมเครื่องหมายคำพูด หรือพิมพ์ข้อความเกินจากที่กำหนด
