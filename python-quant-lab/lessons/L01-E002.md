# L01-E002 — ทายผลลัพธ์ลำดับการคำนวณ

## เป้าหมาย

อธิบายลำดับการคำนวณและตอบผลลัพธ์โดยไม่รันโค้ด

## แนวคิด

วงเล็บจะถูกคำนวณก่อน และการคูณทำก่อนการบวก เครื่องหมายคำพูดทำให้ค่ากลายเป็นข้อความ

## ตัวอย่าง

```python
print(2 + 3 * 4)  # แสดง 14
```

## โจทย์

ยังไม่ต้องรันโค้ด ให้เขียนผลลัพธ์สองบรรทัดลงไฟล์คำตอบ .txt โดยหนึ่งผลลัพธ์ต่อบรรทัด สำหรับ print(8 + 2 * 3) และ print((8 + 2) * 3)

## รูปแบบ input/output

เขียนผลลัพธ์ที่คาดลงไฟล์ข้อความคำตอบตามจำนวนบรรทัดของ stdout

ผลที่ต้องการ: 14
30

ข้อควรระวัง: คำนวณซ้ายไปขวาโดยไม่สนลำดับเครื่องหมาย หรือคิดว่าวงเล็บไม่มีผล
