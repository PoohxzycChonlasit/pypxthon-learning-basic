# L04-E006 — ระยะความเสี่ยงสัมบูรณ์

**ระดับ:** Level 4 — ฟังก์ชันและโมดูล<br>
**ความยาก:** Tier 2 — ง่าย — รวมแนวคิดคุ้นเคย<br>
**ชนิดคำตอบ:** เขียนฟังก์ชันและคืนค่าด้วย return

## 1. เรียนรู้อะไร

คืน abs(entry-stop) ในหน่วยราคา

## 2. ก่อนเริ่ม

ทบทวน: [L04-E005](L04-E005.md). หากคำศัพท์ในโจทย์ยังไม่คุ้น ให้เริ่มจากคำอธิบายแนวคิดในหน้านี้ก่อน

**แนวคิดสำคัญ:** แนวคิด: คืน abs(entry-stop) ในหน่วยราคา

คิดทีละขั้น: ลบราคาสองค่าและใช้ abs กับผลต่าง

## 3. ตัวอย่างสั้น

ตัวอย่างนี้ฝึกแนวคิดที่เกี่ยวข้อง แต่ใช้ค่าและสถานการณ์แยกจากโจทย์ที่ต้องส่ง

~~~python
items = ["tea", "rice"]
items.append("coffee")
print(items)
~~~

อ่าน arguments ที่ส่งให้ฟังก์ชันแล้วตามค่าที่ return; ถ้าไม่มี print การคืนค่าไม่ได้แสดงใน Terminal

## 4. งานของคุณ

สถานการณ์: ผู้จัดการความเสี่ยงวัดระยะระหว่างราคาเข้ากับ stop

เขียน absolute_risk_distance(x, y) ให้ทำตามสัญญา: คืน abs(entry-stop) ในหน่วยราคา.

กรณีขอบ: ระยะไม่ขึ้นกับทิศทาง; ราคาเท่ากันคืน 0.
ส่งค่ากลับด้วย return และรักษาชนิดผลลัพธ์ตามตัวอย่าง

## 5. เขียนคำตอบที่ไหน

ไฟล์ส่งคำตอบ: [exercises/level_04/L04-E006.py](../exercises/level_04/L04-E006.py)

แก้ฟังก์ชัน absolute_risk_distance(x, y) ในไฟล์นี้. คงชื่อและ signature ไว้ และคืนผลด้วย return

## 6. ลำดับทำงาน

1. อ่าน signature absolute_risk_distance(x, y) และดูว่า parameter แต่ละตัวรับข้อมูลอะไร
2. แก้เฉพาะ body ที่โจทย์กำหนด และส่งผลด้วย return
3. ตรวจกรณีขอบที่ระบุ โดยคงชื่อฟังก์ชันและ signature
4. ใช้ run ดูค่าคืนจากกรณีแรก แล้วใช้ check ตรวจ test ทั้งหมด

## 7. ข้อมูลเข้าและผลลัพธ์

- **ข้อมูลเข้า:** grader เรียก absolute_risk_distance ด้วย parameters ตาม signature ที่ให้.
- **ผลลัพธ์:** ฟังก์ชันต้องคืนค่า (int); return ส่งค่ากลับ ส่วน print แสดงข้อความ.
- **ชุดตรวจ:** มี 2 กรณี รวมขอบเขตตามโจทย์

ข้อจำกัดที่ต้องรักษา: Python 3.12; ระยะไม่ขึ้นกับทิศทาง; ราคาเท่ากันคืน 0; ใช้เฉพาะข้อมูลตามสัญญาโจทย์; ห้ามแก้ grader หรือเฉลย
