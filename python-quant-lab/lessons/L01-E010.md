# L01-E010 — คำนวณงบคงเหลือจาก input

## เป้าหมาย

อ่านจำนวนทศนิยมและคำนวณเงินคงเหลือ

## แนวคิด

ใช้ `float()` แปลงข้อความเป็นจำนวนทศนิยม อ่านข้อมูลทีละบรรทัดตามลำดับที่โจทย์ระบุ

## ตัวอย่าง

```python
amount = float(input())
print(f"{amount:.2f}")
```

## โจทย์

อ่านรายรับ งบที่พัก และค่าอาหารอย่างละหนึ่งบรรทัด (ตัวเลขทศนิยม) แล้วแสดงเงินคงเหลือเป็นทศนิยมสองตำแหน่ง

## รูปแบบ input/output

อินพุต 1000, 400, 125.5 แสดง 474.50

ผลที่ต้องการ: รายรับ - ที่พัก - อาหาร โดยแสดงสองตำแหน่ง

ข้อควรระวัง: ใช้ int() จนทำให้เงินที่มีทศนิยมสูญหาย หรืออ่านบรรทัดสลับกัน
