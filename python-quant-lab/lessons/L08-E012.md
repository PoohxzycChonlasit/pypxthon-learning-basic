# L08-E012 — สัดส่วนเงินที่เปิดรับความเสี่ยง

**ระดับ:** Level 8 — การเงินและความเสี่ยง<br>
**ความยาก:** Tier 2 — ง่าย — รวมแนวคิดคุ้นเคย<br>
**ชนิดคำตอบ:** เขียนฟังก์ชันและคืนค่าด้วย return

## 1. เรียนรู้อะไร

fraction = price*quantity/equity; คืน None เมื่อ equity เป็น 0

## 2. ก่อนเริ่ม

ทบทวน: [L08-E011](L08-E011.md). หากคำศัพท์ในโจทย์ยังไม่คุ้น ให้เริ่มจากคำอธิบายแนวคิดในหน้านี้ก่อน

**แนวคิดสำคัญ:** แนวคิด: fraction = price*quantity/equity; คืน None เมื่อ equity เป็น 0

คิดทีละขั้น: คูณ price กับ quantity; ตรวจ equity; หารด้วย equity

## 3. ตัวอย่างสั้น

ตัวอย่างนี้ฝึกแนวคิดที่เกี่ยวข้อง แต่ใช้ค่าและสถานการณ์แยกจากโจทย์ที่ต้องส่ง

~~~python
raw = "  25 "
amount = int(raw.strip())
print(amount + 5)
~~~

อ่าน arguments ที่ส่งให้ฟังก์ชันแล้วตามค่าที่ return; ถ้าไม่มี print การคืนค่าไม่ได้แสดงใน Terminal

## 4. งานของคุณ

สถานการณ์: นักวิเคราะห์วัด notional exposure เทียบกับ equity ปัจจุบัน

เขียน exposure_fraction(price, quantity, equity) ให้ทำตามสัญญา: fraction = price*quantity/equity; คืน None เมื่อ equity เป็น 0.

กรณีขอบ: fraction เกิน 1 หมายถึง exposure มากกว่า equity; ไม่จำกัดอัตโนมัติ.
คืนค่าเท่านั้น; งานทั้งหมดเป็นการจำลอง paper
