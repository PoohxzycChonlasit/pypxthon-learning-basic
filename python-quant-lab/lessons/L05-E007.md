# L05-E007 — จัดรูปแบบบรรทัดบันทึก

**ระดับ:** Level 5 — Python สำหรับงานจริง<br>
**ความยาก:** Tier 3 — ปานกลาง — หลายขั้นตอน<br>
**ชนิดคำตอบ:** เขียนฟังก์ชันและคืนค่าด้วย return

## 1. เรียนรู้อะไร

แยกด้วย comma; strip แต่ละ field; ต่อกลับด้วย comma โดยคงคอลัมน์ว่าง

## 2. ก่อนเริ่ม

ทบทวน: [L05-E006](L05-E006.md). หากคำศัพท์ในโจทย์ยังไม่คุ้น ให้เริ่มจากคำอธิบายแนวคิดในหน้านี้ก่อน

**แนวคิดสำคัญ:** แนวคิด: แยกด้วย comma; strip แต่ละ field; ต่อกลับด้วย comma โดยคงคอลัมน์ว่าง

ลำดับคิด: วนทุก field ที่ split; strip; join ด้วย comma

## 3. ตัวอย่างสั้น

ตัวอย่างนี้ฝึกแนวคิดที่เกี่ยวข้อง แต่ใช้ค่าและสถานการณ์แยกจากโจทย์ที่ต้องส่ง

~~~python
text = "  offline paper  "
print(text.strip().upper())
~~~

อ่าน arguments ที่ส่งให้ฟังก์ชันแล้วตามค่าที่ return; ถ้าไม่มี print การคืนค่าไม่ได้แสดงใน Terminal

## 4. งานของคุณ

สถานการณ์: โปรแกรมนำเข้าบันทึกงานทำความสะอาดช่องว่างรอบแต่ละคอลัมน์ก่อนเขียนไฟล์รายงาน

เขียน format_log_row(text) ตามกติกา: แยกด้วย comma; strip แต่ละ field; ต่อกลับด้วย comma โดยคงคอลัมน์ว่าง.

กรณีขอบ: ไม่ลบ field ว่างและไม่แยก comma ที่อยู่ใน quoted field; รูปแบบนี้ไม่รองรับ quoted CSV.
ส่งค่ากลับด้วย return และอย่าแก้ input ต้นฉบับ

## 5. เขียนคำตอบที่ไหน

ไฟล์ส่งคำตอบ: [exercises/level_05/L05-E007.py](../exercises/level_05/L05-E007.py)

แก้ฟังก์ชัน format_log_row(text) ในไฟล์นี้. คงชื่อและ signature ไว้ และคืนผลด้วย return

## 6. ลำดับทำงาน

1. อ่าน signature format_log_row(text) และดูว่า parameter แต่ละตัวรับข้อมูลอะไร
2. แก้เฉพาะ body ที่โจทย์กำหนด และส่งผลด้วย return
3. ตรวจกรณีขอบที่ระบุ โดยคงชื่อฟังก์ชันและ signature
4. ใช้ run ดูค่าคืนจากกรณีแรก แล้วใช้ check ตรวจ test ทั้งหมด

## 7. ข้อมูลเข้าและผลลัพธ์

- **ข้อมูลเข้า:** grader เรียก format_log_row ด้วย parameters ตาม signature ที่ให้.
- **ผลลัพธ์:** ฟังก์ชันต้องคืนค่า (ข้อความ (str)); return ส่งค่ากลับ ส่วน print แสดงข้อความ.
- **ชุดตรวจ:** มี 2 กรณี รวมขอบเขตตามโจทย์

ข้อจำกัดที่ต้องรักษา: Python 3.12; ไม่ลบ field ว่างและไม่แยก comma ที่อยู่ใน quoted field; รูปแบบนี้ไม่รองรับ quoted CSV; ใช้ข้อมูลตามรูปแบบที่ระบุในโจทย์; output ต้องตรงทั้งชนิดและลำดับ
