# L04-E004 — แก้การตรวจหารด้วยศูนย์

**ระดับ:** Level 4 — ฟังก์ชันและโมดูล<br>
**ความยาก:** Tier 2 — ง่าย — รวมแนวคิดคุ้นเคย<br>
**ชนิดคำตอบ:** โปรแกรม Python แสดงผล (stdout)

## 1. เรียนรู้อะไร

ตรวจว่าเงื่อนไข safe division ตรวจตัวหาร ไม่ใช่ตัวตั้ง

## 2. ก่อนเริ่ม

ทบทวน: [L04-E003](L04-E003.md). หากคำศัพท์ในโจทย์ยังไม่คุ้น ให้เริ่มจากคำอธิบายแนวคิดในหน้านี้ก่อน

**แนวคิดสำคัญ:** กฎหารด้วยศูนย์ขึ้นกับตัวหาร ค่า numerator เป็นศูนย์ยังหารด้วยค่าที่ไม่เป็นศูนย์ได้

## 3. ตัวอย่างสั้น

ตัวอย่างนี้ฝึกแนวคิดที่เกี่ยวข้อง แต่ใช้ค่าและสถานการณ์แยกจากโจทย์ที่ต้องส่ง

~~~python
person = {"name": "Mali", "active": True}
print(person.get("active", False))
~~~

ในตัวอย่างนี้ ให้ดูว่าคำสั่ง print ส่งค่าใดไปยังหน้าจอ; ข้อความหลังเครื่องหมาย # เป็นคำอธิบาย output ของตัวอย่าง

## 4. งานของคุณ

ฟังก์ชัน safe_division(numerator, denominator) ควรคืน None เมื่อ denominator เป็นศูนย์ แต่โค้ดปัจจุบันตรวจตัวแปรผิดตัว แก้บั๊กและให้โปรแกรมแสดง NONE เมื่อไม่มีผลหาร

## 7. ข้อมูลเข้าและผลลัพธ์

- **ข้อมูลเข้า:** ใช้ input ที่โจทย์หรือ test ส่งให้; ถ้าไม่มี stdin ก็ไม่ต้องพิมพ์ค่าเพิ่ม.
- **ผลลัพธ์:** ข้อความที่โปรแกรมส่งไป stdout ต้องมีลำดับ บรรทัด และรูปแบบตรงตามโจทย์.
- **การแสดงผล:** print() แสดงค่าที่ Terminal; การกำหนดตัวแปรอย่างเดียวไม่ทำให้เกิด output
