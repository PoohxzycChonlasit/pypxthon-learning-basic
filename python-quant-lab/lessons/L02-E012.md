# L02-E012 — นับช่วงที่เพิ่มขึ้น

**ระดับ:** Level 2 — เงื่อนไขและลูป<br>
**ความยาก:** Tier 4 — ท้าทาย — เงื่อนไขและกรณีขอบ<br>
**ชนิดคำตอบ:** เขียนฟังก์ชันและคืนค่าด้วย return

## 1. เรียนรู้อะไร

นับคู่ติดกันที่ current > previous; นับจำนวนช่วงเพิ่ม ไม่ใช่ความยาวของช่วง

## 2. ก่อนเริ่ม

ทบทวน: [L02-E011](L02-E011.md). หากคำศัพท์ในโจทย์ยังไม่คุ้น ให้เริ่มจากคำอธิบายแนวคิดในหน้านี้ก่อน

**แนวคิดสำคัญ:** แนวคิด: นับคู่ติดกันที่ current > previous; นับจำนวนช่วงเพิ่ม ไม่ใช่ความยาวของช่วง

คิดทีละขั้น: สร้างคู่ติดกัน; เพิ่มตัวนับเฉพาะเมื่อค่าที่สองมากกว่าค่าแรก

## 3. ตัวอย่างสั้น

ตัวอย่างนี้ฝึกแนวคิดที่เกี่ยวข้อง แต่ใช้ค่าและสถานการณ์แยกจากโจทย์ที่ต้องส่ง

~~~python
from math import sqrt
print(sqrt(81))
~~~

อ่าน arguments ที่ส่งให้ฟังก์ชันแล้วตามค่าที่ return; ถ้าไม่มี print การคืนค่าไม่ได้แสดงใน Terminal

## 4. งานของคุณ

สถานการณ์: ทีมรายงานนับกี่ครั้งที่ยอดวันนี้สูงกว่ายอดวันก่อน

เขียน count_consecutive_rises(values) ให้ทำตามสัญญา: นับคู่ติดกันที่ current > previous; นับจำนวนช่วงเพิ่ม ไม่ใช่ความยาวของช่วง.

กรณีขอบ: ค่าซ้ำไม่นับ; มีน้อยกว่าสองค่าคืน 0.
ส่งค่ากลับด้วย return และรักษาชนิดผลลัพธ์ตามตัวอย่าง

## 5. เขียนคำตอบที่ไหน

ไฟล์ส่งคำตอบ: [exercises/level_02/L02-E012.py](../exercises/level_02/L02-E012.py)

แก้ฟังก์ชัน count_consecutive_rises(values) ในไฟล์นี้. คงชื่อและ signature ไว้ และคืนผลด้วย return

## 6. ลำดับทำงาน

1. อ่าน signature count_consecutive_rises(values) และดูว่า parameter แต่ละตัวรับข้อมูลอะไร
2. แก้เฉพาะ body ที่โจทย์กำหนด และส่งผลด้วย return
3. ตรวจกรณีขอบที่ระบุ โดยคงชื่อฟังก์ชันและ signature
4. ใช้ run ดูค่าคืนจากกรณีแรก แล้วใช้ check ตรวจ test ทั้งหมด

## 7. ข้อมูลเข้าและผลลัพธ์

- **ข้อมูลเข้า:** grader เรียก count_consecutive_rises ด้วย parameters ตาม signature ที่ให้.
- **ผลลัพธ์:** ฟังก์ชันต้องคืนค่า (int); return ส่งค่ากลับ ส่วน print แสดงข้อความ.
- **ชุดตรวจ:** มี 2 กรณี รวมขอบเขตตามโจทย์

ข้อจำกัดที่ต้องรักษา: Python 3.12; ค่าซ้ำไม่นับ; มีน้อยกว่าสองค่าคืน 0; ใช้เฉพาะข้อมูลตามสัญญาโจทย์; ห้ามแก้ grader หรือเฉลย

## 8. Run และ Check

รันจากโฟลเดอร์โครงการที่มี practice.py:

~~~powershell
py -3.12 -B practice.py run L02-E012
py -3.12 -B practice.py check L02-E012
~~~

บน macOS Terminal ใช้ python3.12 แทน py -3.12:

~~~sh
python3.12 -B practice.py run L02-E012
~~~

Run ทดลองกรณีตัวอย่างแรก; Check เปรียบเทียบกับทุกกรณีและบันทึกสถานะการเรียน

## 9. ถ้าไม่ผ่าน
