## Input และรูปแบบคำตอบ

อ่านโค้ดแล้วเขียนผลลัพธ์สองบรรทัดลงไฟล์คำตอบ:

~~~python
def after_fee(amount, fee=2):
    return amount - fee

print(after_fee(100))
print(after_fee(100, 5))
~~~

คำตอบเป็นข้อความธรรมดา ห้ามใส่ comment, code fence หรือคำอธิบายเพิ่ม เว้นแต่โจทย์ขอไว้

## Syntax ที่เกี่ยวข้อง

**ค่าเริ่มต้นของพารามิเตอร์** — กำหนดค่าที่ใช้เมื่อผู้เรียกไม่ส่ง argument นั้น

```python
def label(name, prefix="ID"):
    return f"{prefix}-{name}"
print(label("7"))
```

ผลที่คาดจากตัวอย่าง syntax: `ID-7` (ตัวอย่างนี้ไม่ใช่คำตอบของโจทย์)

อ่านเพิ่มใน [Python syntax handbook](../../docs/python-syntax-handbook.md) และ [บทเรียนรายข้อ](../../lessons/level_04.md).
