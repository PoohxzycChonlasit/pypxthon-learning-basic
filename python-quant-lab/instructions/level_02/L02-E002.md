# L02-E002 — ทำนายผลลูปข้ามศูนย์

> บทเรียน Level 2 · Tier 1: ง่ายมาก — แนวคิดเดียว · `ทำนายผล`

## เป้าหมายและเหตุผล

อ่าน for, continue และการสะสมยอด ทักษะนี้ช่วยให้ตรวจผลการทำงานของโปรแกรมก่อนเชื่อผลลัพธ์

## สถานการณ์

ผู้ใช้/บทบาท: ผู้พัฒนา Python ที่ทำนายผลลัพธ์ก่อนรันโปรแกรม. สถานการณ์: ยังไม่ต้องรัน ให้ทำนายข้อความที่จะแสดง แล้วเขียนทุกบรรทัดตามลำดับลงไฟล์คำตอบ. เหตุผล: ช่วยให้โปรแกรมให้ผลคงที่และตรงตามข้อกำหนด.

## Input และรูปแบบคำตอบ

ยังไม่ต้องรัน ให้ทำนายข้อความที่จะแสดง แล้วเขียนทุกบรรทัดตามลำดับลงไฟล์คำตอบ.

~~~python
values = [3, 0, 2]
total = 0
for value in values:
    if value == 0:
        continue
    total += value
print(total)
print(values[-1])
~~~

ผลลัพธ์มีสองบรรทัด

คำตอบเป็นข้อความธรรมดา ห้ามใส่ comment, code fence หรือคำอธิบายเพิ่ม เว้นแต่โจทย์ขอไว้

## Syntax ที่เกี่ยวข้อง

**for loop** — ทำคำสั่งซ้ำกับสมาชิกแต่ละตัวในข้อมูล

```python
for item in [2, 4]:
    print(item * 2)
```

ผลที่คาดจากตัวอย่าง syntax: `4
8` (ตัวอย่างนี้ไม่ใช่คำตอบของโจทย์)
