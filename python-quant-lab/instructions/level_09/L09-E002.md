# L09-E002 — ทำนายค่าอ้างอิงที่ใช้ข้อมูลก่อนหน้า

> บทเรียน Level 9 · Tier 1: ง่ายมาก — แนวคิดเดียว · `ทำนายผล`

## เป้าหมายและเหตุผล

ติดตาม slice ของอดีตโดยไม่รวมราคาปัจจุบัน ทักษะนี้ช่วยให้ตรวจผลการทำงานของโปรแกรมก่อนเชื่อผลลัพธ์

## สถานการณ์

ผู้ใช้/บทบาท: ผู้พัฒนา Python ที่ทำนายผลลัพธ์ก่อนรันโปรแกรม. สถานการณ์: เขียนผลที่จะแสดงสองบรรทัดลงไฟล์คำตอบ:. เหตุผล: ช่วยให้ผู้ใช้ตรวจผลและป้องกันการสรุปข้อมูลผิด.

## Input และรูปแบบคำตอบ

เขียนผลที่จะแสดงสองบรรทัดลงไฟล์คำตอบ:

~~~python
prices = [100, 104, 102, 110]
for index in range(2, len(prices)):
    previous = prices[index - 2:index]
    print(index, round(sum(previous) / len(previous), 1))
~~~

คำตอบเป็นข้อความธรรมดา ห้ามใส่ comment, code fence หรือคำอธิบายเพิ่ม เว้นแต่โจทย์ขอไว้

## Syntax ที่เกี่ยวข้อง

**look-ahead** — ค่า ณ เวลา t ต้องคำนวณจากข้อมูลที่มีถึง t เท่านั้น

```python
history = [2, 4, 8]
print(sum(history[:-1]) / 2)
```

ผลที่คาดจากตัวอย่าง syntax: `3.0` (ตัวอย่างนี้ไม่ใช่คำตอบของโจทย์)
