# L06-E002 — ทำนายผลการกรอง missing values

> บทเรียน Level 6 · Tier 1: ง่ายมาก — แนวคิดเดียว · `ทำนายผล`

## เป้าหมายและเหตุผล

แยกค่าที่หายจากศูนย์และอ่านค่าเฉลี่ยของข้อมูลที่เหลือ ทักษะนี้ช่วยให้ตรวจผลการทำงานของโปรแกรมก่อนเชื่อผลลัพธ์

## สถานการณ์

ผู้ใช้/บทบาท: ผู้พัฒนา Python ที่ทำนายผลลัพธ์ก่อนรันโปรแกรม. สถานการณ์: อ่านโค้ดแล้วเขียน output สองบรรทัดลงไฟล์คำตอบ:. เหตุผล: ช่วยให้ผู้ใช้ตรวจผลและป้องกันการสรุปข้อมูลผิด.

## Input และรูปแบบคำตอบ

อ่านโค้ดแล้วเขียน output สองบรรทัดลงไฟล์คำตอบ:

~~~python
values = [100, None, 110, None, 90]
clean = [value for value in values if value is not None]
print(len(values) - len(clean))
print(sum(clean) / len(clean))
~~~

คำตอบเป็นข้อความธรรมดา ห้ามใส่ comment, code fence หรือคำอธิบายเพิ่ม เว้นแต่โจทย์ขอไว้

## Syntax ที่เกี่ยวข้อง

**list comprehension** — สร้างผลลัพธ์ใหม่จากสมาชิกที่ผ่านเงื่อนไข

```python
values = [2, 5, 8]
above = [x for x in values if x > 4]
print(above)
```

ผลที่คาดจากตัวอย่าง syntax: `[5, 8]` (ตัวอย่างนี้ไม่ใช่คำตอบของโจทย์)
