# L03-E002 — ทำนายผลจาก list และ set

## เป้าหมายและเหตุผล

อ่านความยาว list การเอาค่าซ้ำออก และการอ่าน index ทักษะนี้ช่วยให้ตรวจผลการทำงานของโปรแกรมก่อนเชื่อผลลัพธ์

## สถานการณ์

ผู้ใช้/บทบาท: ผู้พัฒนา Python ที่ทำนายผลลัพธ์ก่อนรันโปรแกรม. สถานการณ์: อ่านโค้ดแล้วเขียน output ทุกบรรทัดลงไฟล์คำตอบ:. เหตุผล: ช่วยให้โปรแกรมให้ผลคงที่และตรงตามข้อกำหนด.

## Input และรูปแบบคำตอบ

อ่านโค้ดแล้วเขียน output ทุกบรรทัดลงไฟล์คำตอบ:

~~~python
items = ["tea", "rice", "tea"]
unique_items = set(items)
print(len(items))
print(len(unique_items))
print(items[0])
~~~

คำตอบเป็นข้อความธรรมดา ห้ามใส่ comment, code fence หรือคำอธิบายเพิ่ม เว้นแต่โจทย์ขอไว้

## Syntax ที่เกี่ยวข้อง

**dict และ get()** — dict จับคู่ key/value; get() อ่านค่าโดยมีค่าเริ่มต้น

```python
stock = {"tea": 4}
print(stock.get("rice", 0))
```

ผลที่คาดจากตัวอย่าง syntax: `0` (ตัวอย่างนี้ไม่ใช่คำตอบของโจทย์)
