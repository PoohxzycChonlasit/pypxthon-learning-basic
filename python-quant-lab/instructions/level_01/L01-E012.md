# L01-E012 — ทายผลคำนวณเปอร์เซ็นต์

> บทเรียน Level 1 · Tier 4: ท้าทาย — เงื่อนไขและกรณีขอบ · `ทำนายผล`

## เป้าหมายและเหตุผล

อ่านนิพจน์เปอร์เซ็นต์และทายผลชนิดตัวเลข ทักษะนี้ช่วยให้ตรวจผลการทำงานของโปรแกรมก่อนเชื่อผลลัพธ์

## สถานการณ์

ผู้ใช้/บทบาท: เจ้าหน้าที่สำนักงานหรือบัญชีที่ตรวจตัวเลขและรายงาน. สถานการณ์: ทายค่าที่ print แสดงจาก amount = 80, percent = 10, print(amount * percent / 100) แล้วเขียนค่าหนึ่งบรรทัดลงไฟล์คำตอบ .txt. เหตุผล: ช่วยให้โปรแกรมให้ผลคงที่และตรงตามข้อกำหนด.

## สิ่งที่ต้องทำ

- [ ] อ่านโจทย์และติดตามค่าทีละขั้น
- [ ] เขียนเฉพาะ output ที่โจทย์ขอ โดยรักษาลำดับและจำนวนบรรทัด
- [ ] บันทึกคำตอบลง `answers/level_01/L01-E012.txt`
- [ ] ตรวจกรณีขอบและรันคำสั่ง check

## Input และรูปแบบคำตอบ

ทายค่าที่ print แสดงจาก amount = 80, percent = 10, print(amount * percent / 100) แล้วเขียนค่าหนึ่งบรรทัดลงไฟล์คำตอบ .txt

คำตอบเป็นข้อความธรรมดา ห้ามใส่ comment, code fence หรือคำอธิบายเพิ่ม เว้นแต่โจทย์ขอไว้

## Syntax ที่เกี่ยวข้อง

**ลำดับเครื่องหมาย** — คูณและหารก่อนบวกและลบ; วงเล็บเปลี่ยนลำดับได้

```python
print(5 + 2 * 3)
```
