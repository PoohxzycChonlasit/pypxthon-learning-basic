# L01-E002 — ทายผลลัพธ์ลำดับการคำนวณ

> บทเรียน Level 1 · Tier 1: ง่ายมาก — แนวคิดเดียว · `ทำนายผล`

## เป้าหมายและเหตุผล

อธิบายลำดับการคำนวณและตอบผลลัพธ์โดยไม่รันโค้ด ทักษะนี้ช่วยให้ตรวจผลการทำงานของโปรแกรมก่อนเชื่อผลลัพธ์

## สถานการณ์

ผู้ใช้/บทบาท: ผู้พัฒนา Python ที่ทำนายผลลัพธ์ก่อนรันโปรแกรม. สถานการณ์: ยังไม่ต้องรันโค้ด ให้เขียนผลลัพธ์สองบรรทัดลงไฟล์คำตอบ .txt โดยหนึ่งผลลัพธ์ต่อบรรทัด สำหรับ print(8 + 2 * 3) และ print((8 + 2) * 3). เหตุผล: ช่วยให้โปรแกรมให้ผลคงที่และตรงตามข้อกำหนด.

## Input และรูปแบบคำตอบ

ยังไม่ต้องรันโค้ด ให้เขียนผลลัพธ์สองบรรทัดลงไฟล์คำตอบ .txt โดยหนึ่งผลลัพธ์ต่อบรรทัด สำหรับ print(8 + 2 * 3) และ print((8 + 2) * 3)

คำตอบเป็นข้อความธรรมดา ห้ามใส่ comment, code fence หรือคำอธิบายเพิ่ม เว้นแต่โจทย์ขอไว้

## Syntax ที่เกี่ยวข้อง

**ลำดับเครื่องหมาย** — คูณและหารก่อนบวกและลบ; วงเล็บเปลี่ยนลำดับได้

```python
print(5 + 2 * 3)
```

ผลที่คาดจากตัวอย่าง syntax: `11` (ตัวอย่างนี้ไม่ใช่คำตอบของโจทย์)
