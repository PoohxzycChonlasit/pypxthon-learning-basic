## เป้าหมายและเหตุผล

แยก gross profit, fee และ net profit ทักษะนี้ช่วยให้ตรวจผลการทำงานของโปรแกรมก่อนเชื่อผลลัพธ์

## Input และรูปแบบคำตอบ

อ่านโค้ดแล้วเขียน output สามบรรทัดลงไฟล์คำตอบ:

~~~python
entry = 100
exit_price = 110
quantity = 0.5
fee_rate = 0.001
gross = (exit_price - entry) * quantity
fee = (entry + exit_price) * quantity * fee_rate
net = gross - fee
print(round(gross, 3))
print(round(fee, 3))
print(round(net, 3))
~~~

คำตอบเป็นข้อความธรรมดา ห้ามใส่ comment, code fence หรือคำอธิบายเพิ่ม เว้นแต่โจทย์ขอไว้

## Syntax ที่เกี่ยวข้อง

**อัตราส่วน** — หารด้วยตัวหารที่ไม่เป็นศูนย์และระบุหน่วยให้ชัด

```python

reward = 10
print(reward / risk)
```
