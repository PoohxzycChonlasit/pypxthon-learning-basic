## เป้าหมายและเหตุผล

ติดตาม try/except และตัวนับเมื่อแปลงข้อมูลบางแถวไม่ได้ ทักษะนี้ช่วยให้ตรวจผลการทำงานของโปรแกรมก่อนเชื่อผลลัพธ์

## สถานการณ์

ผู้ใช้/บทบาท: เจ้าหน้าที่สำนักงานหรือบัญชีที่ตรวจตัวเลขและรายงาน. สถานการณ์: อ่านโค้ดแล้วเขียน output สองบรรทัดลงไฟล์คำตอบ:. เหตุผล: ช่วยให้ผู้ใช้ตรวจผลและป้องกันการสรุปข้อมูลผิด.

## Input และรูปแบบคำตอบ

อ่านโค้ดแล้วเขียน output สองบรรทัดลงไฟล์คำตอบ:

~~~python
amounts = ["2", "bad", "5"]
valid = []
rejected = 0
for text in amounts:
    try:
        valid.append(int(text))
    except ValueError:
        rejected += 1
print(sum(valid))
print(rejected)
~~~

คำตอบเป็นข้อความธรรมดา ห้ามใส่ comment, code fence หรือคำอธิบายเพิ่ม เว้นแต่โจทย์ขอไว้

## Syntax ที่เกี่ยวข้อง

**csv.reader** — อ่านช่อง CSV โดยเคารพ quote และ comma ภายในค่า

```python
import csv, io
rows = csv.reader(io.StringIO("sku,qty\nA1,2"))
print(next(rows))
```

ผลที่คาดจากตัวอย่าง syntax: `['sku', 'qty']` (ตัวอย่างนี้ไม่ใช่คำตอบของโจทย์)
