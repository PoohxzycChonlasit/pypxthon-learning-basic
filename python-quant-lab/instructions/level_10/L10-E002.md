## Input และรูปแบบคำตอบ

อ่านโค้ดแล้วเขียน output สองบรรทัด:

~~~python
cash = 100.0
quantity = 0.2
price = 50.0
fee_rate = 0.001
notional = quantity * price
fee = notional * fee_rate
cash_after = cash - notional - fee
print(round(cash_after, 2))
print(False)  # live_trading
~~~

คำตอบเป็นข้อความธรรมดา ห้ามใส่ comment, code fence หรือคำอธิบายเพิ่ม เว้นแต่โจทย์ขอไว้
