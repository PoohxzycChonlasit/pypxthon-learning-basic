## เป้าหมายและเหตุผล

แยกค่ากลางที่ไวต่อค่าผิดปกติกับค่าที่อยู่ตำแหน่งกลาง ทักษะนี้ช่วยให้ตรวจผลการทำงานของโปรแกรมก่อนเชื่อผลลัพธ์

## สถานการณ์

ผู้ใช้/บทบาท: ทีมปฏิบัติการร้านค้าออนไลน์ที่ตรวจรายการขายและสินค้า. สถานการณ์: อ่านโค้ดแล้วเขียน output สองบรรทัดลงไฟล์คำตอบ:. เหตุผล: ช่วยให้ผู้ใช้ตรวจผลและป้องกันการสรุปข้อมูลผิด.

## Input และรูปแบบคำตอบ

อ่านโค้ดแล้วเขียน output สองบรรทัดลงไฟล์คำตอบ:

~~~python
values = [2, 4, 10]
mean = sum(values) / len(values)
ordered = sorted(values)
median = ordered[len(ordered) // 2]
print(round(mean, 2))
print(median)
~~~

คำตอบเป็นข้อความธรรมดา ห้ามใส่ comment, code fence หรือคำอธิบายเพิ่ม เว้นแต่โจทย์ขอไว้

## Syntax ที่เกี่ยวข้อง

**variance ประชากร** — หารด้วยจำนวนข้อมูลเมื่อชุดนี้คือประชากรทั้งหมด

```python
values = [1, 3]
average = sum(values) / len(values)
print(sum((x-average)**2 for x in values)/len(values))
```

ผลที่คาดจากตัวอย่าง syntax: `1.0` (ตัวอย่างนี้ไม่ใช่คำตอบของโจทย์)
