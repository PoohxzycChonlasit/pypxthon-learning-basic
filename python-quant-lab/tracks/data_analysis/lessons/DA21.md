# DA21 — คำนวณ returns, fees และ drawdown แบบออฟไลน์

**Track:** Data Analysis · **ไฟล์โจทย์:** <code>tracks/data_analysis/exercises/capstone.py</code> · **ฟังก์ชัน:** <code>financial_metrics()</code><br>
**Package:** ต้องมี NumPy และ pandas ใน project environment อยู่แล้ว

## เรียนรู้อะไร

position ของช่วงหนึ่งใช้กับ return ถัดไป; หัก fee ตาม exposure; drawdown เทียบ peak และไม่เป็นบวก

## ก่อนเริ่ม

ทำ DA06–DA09; เข้าใจ simple/log return; ต้องมี NumPy. ต้องมี NumPy และ pandas ใน project environment อยู่แล้ว.

**ข้อมูลที่ใช้:** ลำดับ prices และ positions จาก grader; เป็นข้อมูลสังเคราะห์ ไม่มี broker/exchange.

หลายข้ออยู่ใน Python module เดียวกัน ให้แก้เฉพาะฟังก์ชัน <code>financial_metrics</code> ที่มีชื่อ DA21; อย่าเปลี่ยน function signature, ฟังก์ชันอื่น หรือ grader/solution
