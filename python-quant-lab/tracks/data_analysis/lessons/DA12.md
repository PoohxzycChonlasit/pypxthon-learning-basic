# DA12 — กรองและเรียงยอดขายด้วย loc และ iloc

**Track:** Data Analysis · **ไฟล์โจทย์:** <code>tracks/data_analysis/exercises/pandas_practice.py</code> · **ฟังก์ชัน:** <code>filter_sort_sales()</code><br>
**Package:** ต้องมี NumPy และ pandas ใน project environment อยู่แล้ว

## เรียนรู้อะไร

loc เลือกแถวด้วยเงื่อนไข; iloc เลือกตำแหน่ง; revenue = quantity × unit_price

## ก่อนเริ่ม

ทำ DA10–DA11; รู้จักเงื่อนไข boolean และการเรียง. ต้องมี NumPy และ pandas ใน project environment อยู่แล้ว.

**ข้อมูลที่ใช้:** CSV ชั่วคราวมี category, quantity, unit_price จาก grader.

หลายข้ออยู่ใน Python module เดียวกัน ให้แก้เฉพาะฟังก์ชัน <code>filter_sort_sales</code> ที่มีชื่อ DA12; อย่าเปลี่ยน function signature, ฟังก์ชันอื่น หรือ grader/solution

## ตัวอย่างเล็ก

ตัวอย่าง: หมวด X จำนวน 2 ราคา 6 มีรายได้ 12 จึงผ่าน threshold 10

ตัวอย่างใช้ค่าคนละชุดกับ grader เพื่อให้ลองแนวคิดก่อน
