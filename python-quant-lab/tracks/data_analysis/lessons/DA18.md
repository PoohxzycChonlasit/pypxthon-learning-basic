# DA18 — เลือกกราฟให้ตรงคำถามธุรกิจ

**Track:** Data Analysis · **ไฟล์โจทย์:** <code>tracks/data_analysis/exercises/visualization.py</code> · **ฟังก์ชัน:** <code>business_charts()</code><br>
**Package:** ต้องมี Matplotlib และ pandas ใน project environment อยู่แล้ว

## เรียนรู้อะไร

line ดูแนวโน้มเวลา; bar เปรียบเทียบหมวด; histogram ดู distribution; scatter ดูความสัมพันธ์ระหว่างตัวเลข

## ก่อนเริ่ม

ทำ DA10–DA17; ต้องมี Matplotlib/pandas; รู้จัก line, bar, histogram, scatter. ต้องมี Matplotlib และ pandas ใน project environment อยู่แล้ว.

**ข้อมูลที่ใช้:** data/website_sessions.csv เป็นข้อมูลสังเคราะห์; grader ใช้ CSV ตัวอย่าง.

หลายข้ออยู่ใน Python module เดียวกัน ให้แก้เฉพาะฟังก์ชัน <code>business_charts</code> ที่มีชื่อ DA18; อย่าเปลี่ยน function signature, ฟังก์ชันอื่น หรือ grader/solution

## ตัวอย่างเล็ก

ตัวอย่าง: ใช้ bar เปรียบเทียบ sessions ต่อ channel แทน line ที่ไม่มีลำดับเวลา

ตัวอย่างใช้ค่าคนละชุดกับ grader เพื่อให้ลองแนวคิดก่อน

## ตรวจงาน

รันจากโฟลเดอร์ <code>python-quant-lab</code> หลังบันทึกไฟล์

**Windows PowerShell**

~~~powershell
py -3.12 -B -m unittest discover -s tracks/data_analysis/tests -p grade_visualization.py -k DA18 -v
~~~

**macOS Terminal**

~~~sh
python3.12 -B -m unittest discover -s tracks/data_analysis/tests -p grade_visualization.py -k DA18 -v
~~~
