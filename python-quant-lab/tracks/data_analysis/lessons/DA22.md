**Track:** Data Analysis · **ไฟล์โจทย์:** <code>tracks/data_analysis/exercises/pandas_practice.py</code> · **ฟังก์ชัน:** <code>export_analysis()</code><br>
**Package:** ต้องมี NumPy และ pandas ใน project environment อยู่แล้ว

## เรียนรู้อะไร

index เป็นป้ายแถว ไม่ใช่คอลัมน์ธุรกิจ; round-trip คืออ่านไฟล์ที่บันทึกกลับมาเพื่อตรวจโครงสร้าง

## ก่อนเริ่ม

ทำ DA10–DA11; รู้จัก path และ encoding UTF-8. ต้องมี NumPy และ pandas ใน project environment อยู่แล้ว.

**ข้อมูลที่ใช้:** DataFrame และ output path จาก grader; เขียนใน temporary directory.

หลายข้ออยู่ใน Python module เดียวกัน ให้แก้เฉพาะฟังก์ชัน <code>export_analysis</code> ที่มีชื่อ DA22; อย่าเปลี่ยน function signature, ฟังก์ชันอื่น หรือ grader/solution

ตัวอย่างใช้ค่าคนละชุดกับ grader เพื่อให้ลองแนวคิดก่อน
