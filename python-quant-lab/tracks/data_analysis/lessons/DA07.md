# DA07 — เลือกคอลัมน์ close ด้วย index และ slice

**Track:** Data Analysis · **ไฟล์โจทย์:** <code>tracks/data_analysis/exercises/numpy_practice.py</code> · **ฟังก์ชัน:** <code>select_close_window()</code><br>
**Package:** ต้องมี NumPy ใน interpreter ที่เลือกอยู่แล้ว

## เรียนรู้อะไร

index เริ่มจากศูนย์; slice [start:stop] ไม่รวม stop; close คือคอลัมน์ index 3

## ก่อนเริ่ม

ทำ DA06; รู้จักแถว คอลัมน์ และช่วงที่ไม่รวม stop. ต้องมี NumPy ใน interpreter ที่เลือกอยู่แล้ว.

**ข้อมูลที่ใช้:** อาร์เรย์ OHLC 2 มิติจาก grader; คอลัมน์ open, high, low, close.

หลายข้ออยู่ใน Python module เดียวกัน ให้แก้เฉพาะฟังก์ชัน <code>select_close_window</code> ที่มีชื่อ DA07; อย่าเปลี่ยน function signature, ฟังก์ชันอื่น หรือ grader/solution

## ตัวอย่างเล็ก

ตัวอย่าง: ช่วง [1:2] จากสองแถวเลือกเฉพาะ close ของแถวที่สอง

ตัวอย่างใช้ค่าคนละชุดกับ grader เพื่อให้ลองแนวคิดก่อน

## งานของคุณ

เปิด <code>tracks/data_analysis/exercises/numpy_practice.py</code> แล้วค้นหา <code>def select_close_window(</code>. แทน <code>raise NotImplementedError</code> เฉพาะในฟังก์ชันนี้ โดยรักษาผลลัพธ์ตามสัญญา:

> array หนึ่งมิติของ close ตั้งแต่ start ถึงก่อน stop; เป็นสำเนาอิสระ
