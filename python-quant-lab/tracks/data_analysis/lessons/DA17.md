# DA17 — ทำ EDA และแยกข้อสังเกตจากข้อสรุป

**Track:** Data Analysis · **ไฟล์โจทย์:** <code>tracks/data_analysis/exercises/pandas_practice.py</code> · **ฟังก์ชัน:** <code>eda_summary()</code><br>
**Package:** ต้องมี NumPy และ pandas ใน project environment อยู่แล้ว

## เรียนรู้อะไร

EDA คือการสำรวจก่อนสรุป; IQR ใช้ช่วงควอไทล์; correlation บอกความสัมพันธ์ ไม่ได้พิสูจน์เหตุผล

## ก่อนเริ่ม

ทำ DA10–DA16; เข้าใจสถิติและการจัดกลุ่ม. ต้องมี NumPy และ pandas ใน project environment อยู่แล้ว.

**ข้อมูลที่ใช้:** CSV ชั่วคราวที่มี value, comparison, category และ date columns.

หลายข้ออยู่ใน Python module เดียวกัน ให้แก้เฉพาะฟังก์ชัน <code>eda_summary</code> ที่มีชื่อ DA17; อย่าเปลี่ยน function signature, ฟังก์ชันอื่น หรือ grader/solution

## ตัวอย่างเล็ก

ตัวอย่าง: ถ้า sessions กับ conversions เพิ่มพร้อมกัน ให้บอกว่ามีความสัมพันธ์ ไม่สรุปว่าอย่างหนึ่งทำให้อีกอย่างเพิ่ม

ตัวอย่างใช้ค่าคนละชุดกับ grader เพื่อให้ลองแนวคิดก่อน

## งานของคุณ

เปิด <code>tracks/data_analysis/exercises/pandas_practice.py</code> แล้วค้นหา <code>def eda_summary(</code>. แทน <code>raise NotImplementedError</code> เฉพาะในฟังก์ชันนี้ โดยรักษาผลลัพธ์ตามสัญญา:

3. เขียนฟังก์ชันตามลำดับ และไม่แก้ input ต้นฉบับถ้าสัญญาห้าม
4. บันทึกไฟล์ แล้วรัน grader ของ DA17

## ตรวจงาน

รันจากโฟลเดอร์ <code>python-quant-lab</code> หลังบันทึกไฟล์

**Windows PowerShell**

~~~powershell
py -3.12 -B -m unittest discover -s tracks/data_analysis/tests -p grade_numpy_pandas.py -k DA17 -v
~~~

**macOS Terminal**

~~~sh
python3.12 -B -m unittest discover -s tracks/data_analysis/tests -p grade_numpy_pandas.py -k DA17 -v
~~~

grader จะเรียกฟังก์ชันด้วย input ตัวอย่างและกรณีขอบ; ผ่านเมื่อ test ที่มีชื่อ DA17 แสดง <code>ok</code>. ถ้าพบ import error แปลว่า interpreter นี้ไม่มี package ที่ต้องใช้ ให้พักกลุ่มนี้และทำข้อ Standard library ก่อน ไม่ต้องติดตั้ง package จากบทเรียน
