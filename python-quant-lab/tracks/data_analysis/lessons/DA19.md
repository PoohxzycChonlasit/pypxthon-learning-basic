# DA19 — วาด OHLCV สังเคราะห์พร้อมตรวจข้อมูล

**Track:** Data Analysis · **ไฟล์โจทย์:** <code>tracks/data_analysis/exercises/visualization.py</code> · **ฟังก์ชัน:** <code>ohlcv_chart()</code><br>
**Package:** ต้องมี Matplotlib และ pandas ใน project environment อยู่แล้ว

## เรียนรู้อะไร

OHLC คือ open/high/low/close; volume คือปริมาณ; high ต้องครอบ open/close และ low ต้องต่ำกว่า open/close; timestamp เรียงและไม่ซ้ำ

## ก่อนเริ่ม

ทำ DA18; ต้องมี Matplotlib/pandas; รู้จัก OHLCV. ต้องมี Matplotlib และ pandas ใน project environment อยู่แล้ว.

**ข้อมูลที่ใช้:** data/synthetic_btc_ohlcv_daily.csv เป็นข้อมูลสังเคราะห์ offline; grader ยังสร้างแถวตัวอย่างและกรณีผิด.

หลายข้ออยู่ใน Python module เดียวกัน ให้แก้เฉพาะฟังก์ชัน <code>ohlcv_chart</code> ที่มีชื่อ DA19; อย่าเปลี่ยน function signature, ฟังก์ชันอื่น หรือ grader/solution

## ตัวอย่างเล็ก

ตัวอย่าง: open=10, high=12, low=9, close=11 ผ่านเงื่อนไข OHLC

ตัวอย่างใช้ค่าคนละชุดกับ grader เพื่อให้ลองแนวคิดก่อน
