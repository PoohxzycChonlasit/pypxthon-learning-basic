# DA02 — อ่าน CSV และตรวจชื่อหัวคอลัมน์

**Track:** Data Analysis · **ไฟล์โจทย์:** <code>tracks/data_analysis/exercises/foundations.py</code> · **ฟังก์ชัน:** <code>load_csv_records()</code><br>
**Package:** ใช้ Python 3.12 standard library ไม่ต้องติดตั้ง package

## เรียนรู้อะไร

CSV คือข้อมูลคั่นด้วย comma; header คือแถวชื่อคอลัมน์; header ต้องมีชื่อ ไม่ว่าง และไม่ซ้ำ

## ก่อนเริ่ม

รู้จัก string, list และ dictionary; แนะนำ DA01. ใช้ Python 3.12 standard library ไม่ต้องติดตั้ง package.

**ข้อมูลที่ใช้:** CSV UTF-8 ที่ grader สร้างในโฟลเดอร์ชั่วคราว.

หลายข้ออยู่ใน Python module เดียวกัน ให้แก้เฉพาะฟังก์ชัน <code>load_csv_records</code> ที่มีชื่อ DA02; อย่าเปลี่ยน function signature, ฟังก์ชันอื่น หรือ grader/solution

## ตัวอย่างเล็ก

ตัวอย่าง: code,qty แล้ว A1,3 จะได้ {"code":"A1","qty":"3"}

ตัวอย่างใช้ค่าคนละชุดกับ grader เพื่อให้ลองแนวคิดก่อน

## งานของคุณ

เปิด <code>tracks/data_analysis/exercises/foundations.py</code> แล้วค้นหา <code>def load_csv_records(</code>. แทน <code>raise NotImplementedError</code> เฉพาะในฟังก์ชันนี้ โดยรักษาผลลัพธ์ตามสัญญา:

> list ของ dict[str,str] โดยคงค่าแต่ละช่องเป็นข้อความ

### ขั้นตอน

1. อ่าน function docstring และข้อมูล input/output ข้างต้น
2. ตรวจชนิดข้อมูลและกรณีขอบก่อนคำนวณ
3. เขียนฟังก์ชันตามลำดับ และไม่แก้ input ต้นฉบับถ้าสัญญาห้าม
4. บันทึกไฟล์ แล้วรัน grader ของ DA02
