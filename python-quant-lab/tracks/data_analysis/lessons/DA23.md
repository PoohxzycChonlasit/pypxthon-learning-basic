# DA23 — สร้างกราฟ conversion แบบโต้ตอบ (ส่วนเสริม)

**Track:** Data Analysis · **ไฟล์โจทย์:** <code>tracks/data_analysis/exercises/plotly_extension.py</code> · **ฟังก์ชัน:** <code>interactive_conversion_chart()</code><br>
**Package:** เป็นส่วนเสริม ต้องมี Plotly และ pandas อยู่แล้ว; ข้ามได้

## เรียนรู้อะไร

conversion = conversions/sessions; sessions=0 ต้องเป็น missing; รวมตาม date/channel; ห้ามเปลี่ยน source CSV

## ก่อนเริ่ม

ทำ DA18 และรู้จัก groupby; Plotly/pandas ต้องมีอยู่แล้ว; ข้อนี้ข้ามได้. เป็นส่วนเสริม ต้องมี Plotly และ pandas อยู่แล้ว; ข้ามได้.

**ข้อมูลที่ใช้:** data/website_sessions.csv เป็นข้อมูลสังเคราะห์; grader ใช้ CSV สั้นและเขียน HTML ชั่วคราว.

หลายข้ออยู่ใน Python module เดียวกัน ให้แก้เฉพาะฟังก์ชัน <code>interactive_conversion_chart</code> ที่มีชื่อ DA23; อย่าเปลี่ยน function signature, ฟังก์ชันอื่น หรือ grader/solution

## ตัวอย่างเล็ก

ตัวอย่าง: email 100 sessions และ 10 conversions ในวันหนึ่งมี rate 0.10

ตัวอย่างใช้ค่าคนละชุดกับ grader เพื่อให้ลองแนวคิดก่อน
