# DA14 — รวมยอดตามหมวดด้วย groupby และ merge

**Track:** Data Analysis · **ไฟล์โจทย์:** <code>tracks/data_analysis/exercises/pandas_practice.py</code> · **ฟังก์ชัน:** <code>sales_by_category()</code><br>
**Package:** ต้องมี NumPy และ pandas ใน project environment อยู่แล้ว

## เรียนรู้อะไร

merge เชื่อมด้วย product_id; many-to-one หมายถึงหลายรายการขายอ้างสินค้าเดียว; product id ซ้ำหรือหาไม่พบต้องปฏิเสธ

## ก่อนเริ่ม

ทำ DA10–DA13; รู้จัก key, groupby และการ join ตาราง. ต้องมี NumPy และ pandas ใน project environment อยู่แล้ว.

**ข้อมูลที่ใช้:** transactions.csv และ products.csv ขนาดเล็กที่ grader สร้าง.

หลายข้ออยู่ใน Python module เดียวกัน ให้แก้เฉพาะฟังก์ชัน <code>sales_by_category</code> ที่มีชื่อ DA14; อย่าเปลี่ยน function signature, ฟังก์ชันอื่น หรือ grader/solution

## ตัวอย่างเล็ก

ตัวอย่าง: สองรายการราคา 5 ในหมวดเดียวกันรวม gross revenue 10

ตัวอย่างใช้ค่าคนละชุดกับ grader เพื่อให้ลองแนวคิดก่อน
