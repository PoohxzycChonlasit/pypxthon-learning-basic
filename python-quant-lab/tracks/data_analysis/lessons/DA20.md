# DA20 — สรุป KPI จากธุรกรรม ผู้เข้าชม และสต็อก

**Track:** Data Analysis · **ไฟล์โจทย์:** <code>tracks/data_analysis/exercises/capstone.py</code> · **ฟังก์ชัน:** <code>business_kpis()</code><br>
**Package:** ต้องมี NumPy และ pandas ใน project environment อยู่แล้ว; ถ้าไม่มีให้ข้าม

## เรียนรู้อะไร

รายได้หัก discount_rate แบบสัดส่วน; conversion = conversions / sessions; sessions รวมศูนย์ให้ None; movement ติดลบคือของออก

## ก่อนเริ่ม

ทำ DA10–DA17; เข้าใจ revenue, conversion และส่วนลด. ต้องมี NumPy และ pandas ใน project environment อยู่แล้ว; ถ้าไม่มีให้ข้าม. Plotly ใช้เฉพาะข้อเสริม DA23.

**ข้อมูลที่ใช้:** grader สร้าง transactions.csv, sessions.csv และ inventory.csv ขนาดเล็ก; inventory ใช้ quantity_delta.

หลายข้ออยู่ใน Python module เดียวกัน ให้แก้เฉพาะฟังก์ชัน <code>business_kpis</code> ที่มีชื่อ DA20; อย่าเปลี่ยน function signature, ฟังก์ชันอื่น หรือ grader/solution

## ตัวอย่างเล็ก

ตัวอย่าง: จำนวน 2 ราคา 10 ส่วนลด 10% ให้รายได้สุทธิ 18

ตัวอย่างใช้ค่าคนละชุดกับ grader เพื่อให้ลองแนวคิดก่อน
