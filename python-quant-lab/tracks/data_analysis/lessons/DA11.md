# DA11 — สำรวจ CSV ด้วย read_csv, head, info, describe

**Track:** Data Analysis · **ไฟล์โจทย์:** <code>tracks/data_analysis/exercises/pandas_practice.py</code> · **ฟังก์ชัน:** <code>csv_overview()</code><br>
**Package:** ต้องมี NumPy และ pandas ใน project environment อยู่แล้ว

## เรียนรู้อะไร

DataFrame คือข้อมูลสองมิติ; info แสดง dtype และ missing; describe สรุปคอลัมน์ตัวเลข

## ก่อนเริ่ม

ทำ DA10; รู้จักแถว คอลัมน์ และชนิดข้อมูล. ต้องมี NumPy และ pandas ใน project environment อยู่แล้ว.

**ข้อมูลที่ใช้:** CSV ชั่วคราวจาก grader; ตรวจชื่อคอลัมน์และ dtype ก่อนสรุป.

หลายข้ออยู่ใน Python module เดียวกัน ให้แก้เฉพาะฟังก์ชัน <code>csv_overview</code> ที่มีชื่อ DA11; อย่าเปลี่ยน function signature, ฟังก์ชันอื่น หรือ grader/solution

## ตัวอย่างเล็ก

ตัวอย่าง: CSV 3 แถว 2 คอลัมน์มี shape (3, 2)

ตัวอย่างใช้ค่าคนละชุดกับ grader เพื่อให้ลองแนวคิดก่อน
