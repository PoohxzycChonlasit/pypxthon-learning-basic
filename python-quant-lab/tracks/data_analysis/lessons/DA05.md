# DA05 — ตรวจธุรกรรมและเก็บเหตุผลรายการที่ปฏิเสธ

**Track:** Data Analysis · **ไฟล์โจทย์:** <code>tracks/data_analysis/exercises/foundations.py</code> · **ฟังก์ชัน:** <code>clean_transaction_rows()</code><br>
**Package:** ใช้ Python 3.12 standard library ไม่ต้องติดตั้ง package

## เรียนรู้อะไร

ตรวจ id ซ้ำ, วันที่, quantity มากกว่า 0, ราคา finite และไม่ติดลบ และ discount ระหว่าง 0–1; ห้ามแก้ input

## ก่อนเริ่ม

ทำ DA01–DA04; รู้จัก date, set และ try/except. ใช้ Python 3.12 standard library ไม่ต้องติดตั้ง package.

**ข้อมูลที่ใช้:** data/ecommerce_transactions_dirty.csv เป็นข้อมูลสังเคราะห์ที่มีแถวผิดรูปแบบ.

หลายข้ออยู่ใน Python module เดียวกัน ให้แก้เฉพาะฟังก์ชัน <code>clean_transaction_rows</code> ที่มีชื่อ DA05; อย่าเปลี่ยน function signature, ฟังก์ชันอื่น หรือ grader/solution

## ตัวอย่างเล็ก

ตัวอย่าง: discount_rate 0.2 หมายถึง 20%; ค่า 1.2 อยู่นอกช่วง

ตัวอย่างใช้ค่าคนละชุดกับ grader เพื่อให้ลองแนวคิดก่อน

## งานของคุณ

เปิด <code>tracks/data_analysis/exercises/foundations.py</code> แล้วค้นหา <code>def clean_transaction_rows(</code>. แทน <code>raise NotImplementedError</code> เฉพาะในฟังก์ชันนี้ โดยรักษาผลลัพธ์ตามสัญญา:

> dict แยก accepted rows และ rejected records ที่บอก id กับเหตุผลหนึ่งข้อ

### ขั้นตอน

1. อ่าน function docstring และข้อมูล input/output ข้างต้น
2. ตรวจชนิดข้อมูลและกรณีขอบก่อนคำนวณ
3. เขียนฟังก์ชันตามลำดับ และไม่แก้ input ต้นฉบับถ้าสัญญาห้าม
4. บันทึกไฟล์ แล้วรัน grader ของ DA05
