# DA06 — สร้าง NumPy array ชนิด float

**Track:** Data Analysis · **ไฟล์โจทย์:** <code>tracks/data_analysis/exercises/numpy_practice.py</code> · **ฟังก์ชัน:** <code>make_price_array()</code><br>
**Package:** ต้องมี NumPy ใน interpreter ที่เลือกอยู่แล้ว

## เรียนรู้อะไร

NumPy array เก็บตัวเลขเพื่อคำนวณทั้งชุด; shape บอกจำนวนมิติและขนาดแต่ละแกน

## ก่อนเริ่ม

ทำ DA01–DA05; NumPy ต้องมีอยู่แล้วใน interpreter ที่เลือก. ต้องมี NumPy ใน interpreter ที่เลือกอยู่แล้ว.

**ข้อมูลที่ใช้:** list ตัวเลขจาก grader; ไม่ต้องใช้ CSV.

หลายข้ออยู่ใน Python module เดียวกัน ให้แก้เฉพาะฟังก์ชัน <code>make_price_array</code> ที่มีชื่อ DA06; อย่าเปลี่ยน function signature, ฟังก์ชันอื่น หรือ grader/solution

## ตัวอย่างเล็ก

ตัวอย่าง: [3, 7] กลายเป็นค่าทศนิยม 3.0 และ 7.0

ตัวอย่างใช้ค่าคนละชุดกับ grader เพื่อให้ลองแนวคิดก่อน
