# DA13 — ทำความสะอาดเหตุการณ์และแยกแถวผิด

**Track:** Data Analysis · **ไฟล์โจทย์:** <code>tracks/data_analysis/exercises/pandas_practice.py</code> · **ฟังก์ชัน:** <code>clean_event_csv()</code><br>
**Package:** ต้องมี NumPy และ pandas ใน project environment อยู่แล้ว

## เรียนรู้อะไร

ปฏิเสธวันที่หายหรือผิดรูปแบบ, ค่า non-finite/ติดลบ และ id ซ้ำ; rejected ledger บันทึกแถวที่ไม่รับ

## ก่อนเริ่ม

ทำ DA10–DA12; รู้จักวันเวลาและ missing values. ต้องมี NumPy และ pandas ใน project environment อยู่แล้ว.

**ข้อมูลที่ใช้:** CSV ชั่วคราว event_id, timestamp, value จาก grader.

หลายข้ออยู่ใน Python module เดียวกัน ให้แก้เฉพาะฟังก์ชัน <code>clean_event_csv</code> ที่มีชื่อ DA13; อย่าเปลี่ยน function signature, ฟังก์ชันอื่น หรือ grader/solution

## ตัวอย่างเล็ก

ตัวอย่าง: timestamp ที่ parse ไม่ได้กลายเป็น NaT และต้องบันทึกเป็น rejected

ตัวอย่างใช้ค่าคนละชุดกับ grader เพื่อให้ลองแนวคิดก่อน

## งานของคุณ

เปิด <code>tracks/data_analysis/exercises/pandas_practice.py</code> แล้วค้นหา <code>def clean_event_csv(</code>. แทน <code>raise NotImplementedError</code> เฉพาะในฟังก์ชันนี้ โดยรักษาผลลัพธ์ตามสัญญา:

> ผลแยก accepted/rejected พร้อมเหตุผล; รักษาลำดับแถวต้นฉบับ

### ขั้นตอน

1. อ่าน function docstring และข้อมูล input/output ข้างต้น
2. ตรวจชนิดข้อมูลและกรณีขอบก่อนคำนวณ
3. เขียนฟังก์ชันตามลำดับ และไม่แก้ input ต้นฉบับถ้าสัญญาห้าม
4. บันทึกไฟล์ แล้วรัน grader ของ DA13
