# DA03 — อ่าน JSON และตรวจรูปแบบข้อมูล

**Track:** Data Analysis · **ไฟล์โจทย์:** <code>tracks/data_analysis/exercises/foundations.py</code> · **ฟังก์ชัน:** <code>load_json_records()</code><br>
**Package:** ใช้ Python 3.12 standard library ไม่ต้องติดตั้ง package

## เรียนรู้อะไร

JSON ใช้ list และ object แทนข้อมูล; รูปแบบอื่นหรือสมาชิกที่ไม่ใช่ dictionary ต้องถูกปฏิเสธด้วย ValueError

## ก่อนเริ่ม

รู้จัก list, dict และไฟล์ UTF-8; แนะนำ DA01. ใช้ Python 3.12 standard library ไม่ต้องติดตั้ง package.

**ข้อมูลที่ใช้:** ไฟล์ JSON ชั่วคราวที่ grader สร้าง.

หลายข้ออยู่ใน Python module เดียวกัน ให้แก้เฉพาะฟังก์ชัน <code>load_json_records</code> ที่มีชื่อ DA03; อย่าเปลี่ยน function signature, ฟังก์ชันอื่น หรือ grader/solution

## ตัวอย่างเล็ก

ตัวอย่าง: {"records":[{"code":"A1"}]} มี record หนึ่งรายการ

ตัวอย่างใช้ค่าคนละชุดกับ grader เพื่อให้ลองแนวคิดก่อน

## งานของคุณ

เปิด <code>tracks/data_analysis/exercises/foundations.py</code> แล้วค้นหา <code>def load_json_records(</code>. แทน <code>raise NotImplementedError</code> เฉพาะในฟังก์ชันนี้ โดยรักษาผลลัพธ์ตามสัญญา:

> list ของ dictionary; รองรับ JSON list หรือ object ที่มี key records

### ขั้นตอน

1. อ่าน function docstring และข้อมูล input/output ข้างต้น
2. ตรวจชนิดข้อมูลและกรณีขอบก่อนคำนวณ
3. เขียนฟังก์ชันตามลำดับ และไม่แก้ input ต้นฉบับถ้าสัญญาห้าม
4. บันทึกไฟล์ แล้วรัน grader ของ DA03
