# DA09 — สรุปสถิติตัวเลขด้วย NumPy

**Track:** Data Analysis · **ไฟล์โจทย์:** <code>tracks/data_analysis/exercises/numpy_practice.py</code> · **ฟังก์ชัน:** <code>numeric_summary()</code><br>
**Package:** ต้องมี NumPy ใน interpreter ที่เลือกอยู่แล้ว

## เรียนรู้อะไร

population standard deviation ใช้ข้อมูลทั้งชุดและ ddof=0; ข้อมูลว่าง, non-finite หรือหลายมิติใช้ไม่ได้

## ก่อนเริ่ม

ทำ DA06–DA08; รู้จัก sum, mean, min และ max. ต้องมี NumPy ใน interpreter ที่เลือกอยู่แล้ว.

**ข้อมูลที่ใช้:** ลำดับตัวเลขหนึ่งมิติที่ grader ส่งให้.

หลายข้ออยู่ใน Python module เดียวกัน ให้แก้เฉพาะฟังก์ชัน <code>numeric_summary</code> ที่มีชื่อ DA09; อย่าเปลี่ยน function signature, ฟังก์ชันอื่น หรือ grader/solution

## ตัวอย่างเล็ก

ตัวอย่าง: [2,4,6] มี mean 4 และ population standard deviation ประมาณ 1.633

ตัวอย่างใช้ค่าคนละชุดกับ grader เพื่อให้ลองแนวคิดก่อน

## งานของคุณ

เปิด <code>tracks/data_analysis/exercises/numpy_practice.py</code> แล้วค้นหา <code>def numeric_summary(</code>. แทน <code>raise NotImplementedError</code> เฉพาะในฟังก์ชันนี้ โดยรักษาผลลัพธ์ตามสัญญา:

> dict มี sum, mean, population standard deviation, min และ max

### ขั้นตอน

1. อ่าน function docstring และข้อมูล input/output ข้างต้น
2. ตรวจชนิดข้อมูลและกรณีขอบก่อนคำนวณ
3. เขียนฟังก์ชันตามลำดับ และไม่แก้ input ต้นฉบับถ้าสัญญาห้าม
4. บันทึกไฟล์ แล้วรัน grader ของ DA09


**macOS Terminal**

~~~sh
python3.12 -B -m unittest discover -s tracks/data_analysis/tests -p grade_numpy_pandas.py -k DA09 -v
~~~
