สัญญา input/output ทำให้ผู้เขียนและผู้ตรวจเข้าใจพฤติกรรมเดียวกัน ระบุชนิด
ข้อมูล ผลลัพธ์ และสิ่งที่เกิดเมื่อ input ไม่ผ่าน ก่อนลงมือเขียนฟังก์ชัน

## Type along: order line

```python
item = {"sku": "A1", "quantity": 2, "unit_price": 30.0}
line_total = item["quantity"] * item["unit_price"]
print(line_total)
```

สัญญาของตัวอย่างนี้คือรับ `quantity` และ `unit_price` ที่เป็นตัวเลข แล้วได้
ยอดบรรทัดก่อนส่วนลด หากระบบจริงต้องรองรับ input ที่ผิดชนิด ให้เพิ่มกติกานั้น
ในข้อกำหนดและทดสอบโดยตรง

## Pseudocode ก่อน Python

สำหรับ e-commerce order processor ให้เขียนลำดับก่อน:

```text
รับรายการสินค้าและกติกาสต็อก
ตรวจว่าแต่ละรายการมี SKU, จำนวนบวก และราคาไม่ติดลบ
ตรวจว่าสต็อกพอสำหรับทุกรายการ
ถ้ารายการใดไม่ผ่าน ให้ปฏิเสธทั้งคำสั่งซื้อโดยไม่เปลี่ยนสต็อก
มิฉะนั้นคำนวณยอดและหักสต็อก แล้วคืนใบสรุป
```

โมเดลข้อมูลเริ่มต้นอาจเป็น list ของ dict โดยแต่ละ dict มี `sku`, `quantity`
และ `unit_price` อย่าเพิ่มฟิลด์หรือสถานะที่โจทย์ยังไม่ต้องใช้
