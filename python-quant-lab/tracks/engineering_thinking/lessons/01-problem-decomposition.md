# 01 — Problem Decomposition and Requirements

เริ่มจากอธิบายปัญหาให้ชัดก่อนเลือกภาษา ไลบรารี หรือให้ AI เขียนโค้ด ถ้า
ข้อกำหนดยังคลุมเครือ โค้ดที่รันได้ก็อาจแก้ปัญหาผิดเรื่อง

## Type along: expense tracker

สมมติผู้ใช้ต้องการบันทึกรายจ่ายและดูยอดรวมรายเดือน ลองเขียนตัวอย่างข้อมูล
หนึ่งรายการ แล้วพิมพ์ค่าออกมาดู:

```python
expense = {"date": "2026-10-01", "category": "food", "amount": 120.0}
required_fields = ("date", "category", "amount")
print(all(field in expense for field in required_fields), expense["amount"])
```

ก่อนสร้างระบบ ให้แยกคำขอออกเป็นข้อกำหนดที่ตรวจได้:

- เพิ่มรายการเมื่อมีวันที่ หมวดหมู่ และจำนวนเงินที่ถูกต้อง
- ปฏิเสธจำนวนเงินที่ไม่ใช่ตัวเลขหรือไม่มากกว่าศูนย์
- รวมยอดเฉพาะเดือนที่ผู้ใช้เลือก
- แสดงเหตุผลเมื่อข้อมูลไม่ผ่าน แทนการทิ้งแถวเงียบ ๆ

บันทึกสิ่งที่ยังไม่รู้ เช่น สกุลเงินหรือเขตเวลา เป็นคำถาม ไม่ใช่ข้อเท็จจริง
อย่าให้ agent ตัดสินใจแทนเจ้าของผลิตภัณฑ์
