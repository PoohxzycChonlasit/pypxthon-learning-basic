# Exercise — Expense Tracker

## Do this before asking AI

เขียนด้วยคำของตนเองก่อน:

1. ผู้ใช้คือใคร และต้องการตัดสินใจอะไรจากยอดรายจ่าย?
2. เขียน functional requirements 4 ข้อ และสิ่งที่อยู่นอกขอบเขต 2 ข้อ
3. ระบุ fields ของ expense record พร้อมชนิดข้อมูล
4. กำหนด input/output contract ของ `add_expense` และ `monthly_total`
5. เขียน pseudocode สำหรับเพิ่มรายการและรวมยอดเดือนหนึ่ง
6. ระบุ test ปกติ รายการว่าง จำนวนเงินผิดชนิด และวันที่ผิดรูปแบบ

## Scenario

ออกแบบรุ่นแรกแบบ local/offline สำหรับเพิ่มรายการและดูยอดตามเดือน ไม่ต้องมี
บัญชีผู้ใช้ cloud, การจ่ายเงินจริง หรือการเชื่อมบัญชีธนาคาร

## Bounded AI task

หลังทำรายการด้านบน ให้ agent ช่วยตรวจความครบถ้วนของ test cases อย่างเดียว
อย่าให้ agent เปลี่ยนกติกาสกุลเงินหรือรูปแบบวันที่โดยไม่มีการตัดสินใจจากคุณ

## Review

บันทึกข้อสมมติที่ agent เพิ่ม ตรวจว่า rejected input ไม่ถูกนับเป็นรายจ่าย และ
อธิบายได้ว่าทำไมแต่ละ test จึงจำเป็น
