# Learning Tracks

Python Quant Lab has a standard-library core and optional companion tracks.
The companion tracks add deeper practice without changing the 150 core
exercise IDs.

| Track | Use it for | Prerequisites |
|---|---|---|
| [Engineering Thinking and AI-Assisted Development](engineering_thinking/README.md) | Turn a problem into requirements, contracts, a data model, an algorithm, a plan, tests and a reviewable AI task. | No package installation; basic Python helps but is not required for the first lessons. |
| [Data Analysis Practice Track](data_analysis/README.md) | Practice CSV, JSON, SQLite, NumPy, pandas, charts and offline analytics. | Start with DA01–DA05; later exercises use the listed optional packages. |

The engineering track is useful before delegating implementation. The Data
Analysis track is an optional technical extension after the core foundations.
